# dev space

`dev-space` holds internal explorations, generated showcases, and dated records of major technical or product changes. Nothing here is a public website route.

For a major brand, infrastructure, data, deployment, or product migration, add a Markdown record named:

```text
YYYY-MM-DD-descriptive-change-name.md
```

Include the date inside the document, along with the decision, scope, systems changed, verification performed, release and synchronization state, and deliberately deferred follow-up. Never store secrets, API tokens, recovery codes, private keys, or database credentials in these records.
