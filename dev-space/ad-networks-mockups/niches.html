How do we sort sites into niches?

We give each site one niche, based on what its pages are about. A site that covers several topics goes into its main one. Sites we can't place yet stay unsorted and don't count toward any niche here.

Why can a niche's shares add up to more than 100%?

Many sites run more than one ad network at the same time. Each share counts the sites that use that network, so one site can count toward several networks in the same niche.
