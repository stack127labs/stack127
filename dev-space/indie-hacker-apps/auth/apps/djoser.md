**Material security/dependency notice:** The [2.3.5 release](https://api.github.com/repos/sunscrapers/djoser/releases/latest) relaxes the social-auth dependency pin so patched social-auth majors can be installed for **CVE-2026-57175 through CVE-2026-57179**. The release says those patched packages require **Python 3.10+ and Django 5.2+**. Older environments can still resolve older social packages; upgrading Djoser alone is not proof of a patched installed dependency graph. The [publisher metadata](https://pypi.org/pypi/djoser/json) also marks **2.3.2 yanked** for a broken Django dependency pin. Checked date: **2026-11-05**.

**Feature-scope notice:** The [social API](https://djoser.readthedocs.io/en/latest/social_endpoints.html) is explicitly **beta**, with no backwards-compatibility guarantee. The [released WebAuthn extra](https://raw.githubusercontent.com/sunscrapers/djoser/2.3.5/pyproject.toml) requires **webauthn<1.0**, not the current library major. Its [latest eligible version is 0.4.7, uploaded March 13, 2020](https://pypi.org/pypi/webauthn/json); this is a legacy browser-key flow, not evidence of a modern cross-platform passkey matrix.
