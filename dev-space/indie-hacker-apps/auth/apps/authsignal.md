**Scope for the directory:** Authsignal is an authentication and orchestration service that works with an existing app or identity stack. It supports primary passwordless login as well as MFA/step-up. It also stores user/authenticator records and can issue, refresh and revoke session tokens. Those features matter, but do not establish a complete native password/social account system or customer-organization product. Keep it out of a standalone whole-account cost ranking unless the external primary system and missing baseline features are included.
