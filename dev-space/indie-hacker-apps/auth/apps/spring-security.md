## Field problems

- **F07–F11, F16, F18–F19 and F47:** Hosted account/billing/uptime questions do not describe this embedded library. Core licence permissions and optional enterprise support must stay separate.
- **F13–F15, F27–F28 and F38:** Groups, authorities, federation and extension interfaces are useful building blocks, but do not establish full customer tenancy, provisioning, invitations or safe identity linking. A binary feature count would overstate the finished product.
- **F22–F25 and F32–F33:** Keep Servlet, reactive and native-client scope separate. OTT expiry, OAuth token expiry, browser-session lifetime and remember-me cookies are different mechanisms.
- **F35, F39–F43, F45–F46:** Storage, exports, deletion, retention, capacity and data residency depend on the application/operator. There is no honest universal operating bill or hosted assurance inherited from the library.
- **F50:** Current documentation URLs can redirect to an unversioned reference. Versioned source was used for code defaults. Legal pages with only an indexed body are explicitly distinguished from successfully read source files.
