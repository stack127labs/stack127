Consumer examples select social login, with no compulsory Auth email sends during the chosen month. They add a weekly-activity assumption on Free and assume other resource usage remains within quota. Those assumptions do not establish sufficient peak capacity.

Values retain the published dollar amounts, treated as USD list-price subscenarios consistently with the billing and SMS documentation. Regional checkout currency, applicable tax, external app hosting/provider costs, actual message sends and development/operations work are not calculated. The public MAU counting rule is incomplete, so the examples explicitly assume each distinct returning sign-in user counts once per cycle. ## Field problems

- **F08/F12:** Monthly active users need a precise qualifying-event definition. Published headline allowances are usable for conditional subtotals, not complete workload bills. Keep resource/delivery assumptions beside each cost.
- **F13/F15/F26/F28:** Native Teams, upstream OIDC, downstream OAuth2 server, app-user SAML, builder SSO and SCIM are separate features. A future SAML offer cannot be priced as an existing free connection.
- **F14/F16/F27:** Builder billing organizations and customer teams have different caps. A role-array limit is not a member limit. Do not charge every app member as a Console seat.
- **F22/F23/F48:** Current Cloud guides, pinned self-host release and older comparison/release-policy prose need separate dates/version scopes. Their conflicting statements cannot be flattened into a yes/no feature list.
- **F31:** App-owned login/account screens have no single vendor language or accessibility score. Template locale support is a narrower confirmed fact.
- **F35/F39/F41/F42:** Database backup, user export, portable credentials, account closure, retained records and all-data residency require different evidence. One migration button is insufficient proof for all of them.
- **F50:** Used only the six requested states. “Our calculation” labels provenance, not a seventh state. No apps.md row error was found; its existing offer column says Not checked and lifecycle says active. The row was not edited.
