## Field problems

- **Embedded software is not Entra:** F01/F02/F05 and hosted fields distinguish local Identity from Microsoft identity platform, Entra, Azure hosting and external identity servers. Core software permission is not a free hosted plan.
- **A single “default” hides different implementations:** Razor UI, Blazor template, MapIdentityApi and bare option classes have different flow/configuration choices. F22/F24/F25/F44/F45 name the layer that supplies each value.
