# Laravel authentication (Fortify, Sanctum, Passport)

**Lifecycle checked first:** No official notice retiring or replacing these three whole packages, or announcing their acquisition, was found in the bounded check of their official overviews, repositories, release records, security policies and official-site searches. [Fortify](https://api.github.com/repos/laravel/fortify), [Sanctum](https://api.github.com/repos/laravel/sanctum) and [Passport](https://api.github.com/repos/laravel/passport) are not archived or disabled. Latest checked stable versions are **Fortify 1.41.0**, **Sanctum 4.3.3** and **Passport 13.10.0**, confirmed against their publisher metadata. Checked date: **2026-11-05**.

**Deprecation notice:** [Passport 13's upgrade guide](https://raw.githubusercontent.com/laravel/passport/v13.10.0/UPGRADE.md) deprecates the old JSON management API, which is **disabled by default**. The [current OAuth guide](https://raw.githubusercontent.com/laravel/docs/13.x/passport.md) also discourages password and implicit grants; [release source](https://raw.githubusercontent.com/laravel/passport/v13.10.0/src/Passport.php) keeps those grants off until enabled. These are feature/version boundaries, not a Passport shutdown. Checked date: **2026-11-05**.

**Keep the packages separate:**

- **[Fortify](https://raw.githubusercontent.com/laravel/docs/13.x/fortify.md)** supplies headless account routes and logic: login, registration, reset, verification and configurable factor/passkey integration. App or starter-kit code supplies screens.
- **[Sanctum](https://raw.githubusercontent.com/laravel/docs/13.x/sanctum.md)** authenticates existing users through framework browser sessions or simple bearer API tokens. It does not supply registration/reset routes or an OAuth authorization server.
- **[Passport](https://raw.githubusercontent.com/laravel/docs/13.x/passport.md)** supplies an OAuth 2 server, client/grant/token management and scopes. It does not turn the app into a SAML/OIDC enterprise broker or implement Fortify's account flows.
- **[Framework core](https://raw.githubusercontent.com/laravel/docs/13.x/authentication.md)** supplies guards, user providers and browser session services. **[Starter kits](https://raw.githubusercontent.com/laravel/docs/13.x/starter-kits.md)**, **[Socialite](https://raw.githubusercontent.com/laravel/docs/13.x/socialite.md)**, the passkey dependencies and external WorkOS variants are separately identified wherever their features apply.

## Field problems

- **One family contains different products.** F02/F20/F23/F25/F26/F29/F37 are split by package, framework, starter or optional integration where behavior really changes. Fortify account routes, Sanctum opaque tokens and Passport OAuth grants cannot be treated as one interchangeable feature set.
- **Hosted fields are not library facts.** F06 to F08, F10 to F11, F14 to F16, F18 to F19, hosted F43 and F47 have no SaaS plan value here. They are not_applicable with licence/scope evidence, rather than unclear after searching for irrelevant Cloud pricing.
- **A local OAuth client is not a SAML connection.** F13 remains unsupported by the three packages alone even though optional starters add teams and Passport adds OAuth clients. Missing SAML cannot be priced at $0.
- **MFA does not automatically cover every credential exchange.** Fortify's session-login pipeline, Sanctum's app-written mobile endpoint and Passport grants are separate code paths. Enrollment support does not prove universal enrollment enforcement or token-route protection.
- **Scopes are not tenant roles.** Framework gates/policies and app data enforce permissions and ownership. [Sanctum's documented tokenCan behavior](https://raw.githubusercontent.com/laravel/docs/13.x/sanctum.md) returns true for first-party SPA requests; app policy checks remain necessary.
- **Operation cost and data exit need separate answers.** Zero software charges do not price servers, databases, messages or work. JSON visibility, hashed bearer/client secrets, encryption material and passkey RP/domain settings limit what an ordinary profile export proves.
- **Retention has more than one unit.** Session idle minutes, reset-token minutes, broker-throttle seconds, OAuth token years and log-file rotation counts are kept distinct. No daily log setting is presented as a universal audit-retention contract.
- **Dates and runtime ranges differ in scope.** PHP ^8.2 in package manifests does not lower Laravel 13's PHP >=8.3 requirement. Package latest-major policy is separate from dated framework support.
- **No apps.md correction identified.** The active local-library family description and Passport.js distinction are accurate.
