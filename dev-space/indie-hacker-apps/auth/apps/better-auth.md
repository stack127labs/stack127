## Field problems

- F07–F19 and F42/F47 need separate records for embedded code and the optional managed add-on. A single app-level yes/no or monthly cost would mix different products.
- F12/F13 cannot become whole-account hosted cost curves for a library. Software licensing is calculable; operations and delivery are not. Core permission to deploy does not prove capacity at 100,000 monthly users.

- F22/F23/F28 need enforcement and lifecycle notes. A passkey, an MFA enrollment switch or a SCIM deletion does not alone establish complete account recovery or offboarding.
- F29/F31 concern app-owned screens here. Error-message translations do not establish translated UI or accessibility conformance.
- F39 needs credential-by-credential portability. Database access does not prove cross-provider password/passkey compatibility.
- F48 needs component versions and checked dates. Current docs, package manifests and releases can differ without proving a conflict.
