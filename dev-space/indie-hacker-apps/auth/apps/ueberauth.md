## Field problems

- Hosted trial, dashboard-seat, MAU billing, region and SLA fields do not fit an embedded library. They are marked not applicable, with deployment and external-provider boundaries recorded.
- A strategy is an adapter. Calling Identity a full password system, a returned refresh token an automatic session service, or a provider tenant an app organization would overstate the product.
- Version scope matters: published package dependency ranges can differ from current monorepository source even when the version string looks unchanged. Runtime requirements are per component; an older plugin's low Elixir floor does not lower core's floor.
- The cost baselines do not settle app infrastructure or provider conditions. Zero licence cost is useful, but it cannot be presented as zero running cost or a price for unavailable packaged business features.
- The allowed state list replaces the older state words in fields.md. Derived software subtotals use confirmed only for that narrow calculation; unsupported complete business scenarios use not_applicable.
