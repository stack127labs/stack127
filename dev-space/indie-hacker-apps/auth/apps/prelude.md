## Cost examples — our calculation

All scenarios below are our calculations. An existing user returning on two days does not necessarily cause two phone checks. Separate phone examples deliberately assume two new verification windows per user per month, one SMS per window, successful first attempt and no fallback. Each request is far enough apart to open a new window. General formula:

- Verify PAYG reference = billed verification windows × EUR 0.032 + US SMS messages × EUR 0.0039.
- Same-window resends do not automatically create a second verification, but each delivery attempt may change message cost.
- At a published Startup volume point, compare its displayed monthly package reference + message charges. Do not extrapolate the 100,000+ display into unlimited usage.
- Auth's EUR 100/month / 50k-MAU bundle is a separate product reference. Actual feature entitlement, counted-user definition and compulsory delivery treatment must be established before ranking it as a fully comparable account plan.

## Conflicts and unknowns

- **Rebrand and product scope:** Ding→Prelude is a documented rebrand, not a shutdown. Verify remains an add-on; Auth now owns accounts/sessions. The inventory row should either name “Prelude Verify” or qualify its account/session note to distinguish Auth. Sources: https://prelude.so/blog/ding-s-becoming-prelude, https://docs.prelude.so/auth/documentation/introduction.
- **Country/channel rate mismatch:** The current main pricing page's default US panel shows RCS EUR 0.00 (https://prelude.so/pricing), while the dedicated US page says EUR 0.0008 (https://prelude.so/countries/us). No documented rounding rule resolves this; one conflicting row records it. Older indexed SMS content showed EUR 0.0043, but live direct/web reads of the US page and pricing page showed EUR 0.0039.
