No signup, login, payment, quote request or production provisioning was attempted. Only public documentation, source files, package metadata and the public OpenAPI schema were read.

Authress supplies real hosted authentication plus a separate authorization engine. It bills requests rather than monthly active users. The public homepage's USD rate differs from the terms' euro fallback, and the terms add an access-record billing floor. Business accounts can use native login tenants, permissions and invites, but the builder still creates its application accounts, forms and delivery logic. No separate current Free/Pro/Enterprise tariff table was found; the advertised offer includes features with usage billing. The table splits components and flow types where their actual behavior differs instead of inventing plan tiers.

## Cost examples — our calculation

These are six comparisons under the approved user/organization inputs, with explicit extra request assumptions. The exact baseline totals remain **unclear**. - R is total stored access records. Assume one record per user and no additional records, so R = N. This is an explicit hypothetical configuration, not a claim that every production account automatically has exactly N records.
- G is remaining initial free billable calls. Assume G = 0: the account has already used its one-time 1,000-call allowance. Registration before the month alone does not establish this, so it is stated separately.
