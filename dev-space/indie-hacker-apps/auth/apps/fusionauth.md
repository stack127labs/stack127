## Cost examples — our calculation

One production application, one developer portal seat; distinct existing users returning on at least two days in the calendar month; monthly figures in original USD, excluding tax. Consumer: email/password or core social login, no organizations/SSO/SMS/paid extra security. Business: 100 members per organization, membership/invitations/roles, SP-initiated SAML, no SCIM/SMS. No grants, discounts or annual discounts assumed.

Software and managed hosting are shown in separate rows for each of the six required scenarios. **A US$0 software license is not a US$0 operating bill.** No server, database, search-service or developer-hour estimate was added.

Community is the cheapest published software feature set for the consumer baseline. For business A/B, the cheapest software sub-scenario uses Community's core groups, application registrations/roles, SAML SP identity providers and customer-built invitation/member administration. This is usable only if the builder implements and enforces that workflow. It does not claim a native full organization invitation product or independent per-organization role system comes with a group.

For the fixed business inputs, each user belongs to one of the disjoint organization groups. The application checks both the user's organization membership and registered role for every organization-scoped operation. Backend code sends setup-password invitations, assigns/retains the correct membership/role, and enforces invitation acceptance and access. A ready-made customer admin interface, entity-specific grants, SCIM, application MFA policies or advanced form validation is outside that cheapest sub-scenario and may require a higher plan.
