# Neon Auth (Managed Better Auth)

**Acquisition and lifecycle notices:** Databricks announced its Neon acquisition on 2025-05-14; current company information says Neon is part of Databricks. Managed Better Auth is generally available. The legacy Stack-based offer is closed to new Neon adopters but remains supported for existing integrations; no mandatory migration deadline was found. The old `@neondatabase/auth-ui` package is deprecated in favor of Better Auth UI. Neon Azure regions were deprecated on 2026-04-07 and stopped receiving platform updates on 2026-10-05; managed Auth is available on AWS, not Azure. No whole-product shutdown or sunset notice found in the current sources reviewed. Sources: [acquisition announcement](https://neon.com/blog/neon-and-databricks), [current company page](https://neon.com/about-us), [managed Auth availability](https://neon.com/docs/auth/roadmap), [legacy migration notice](https://neon.com/docs/auth/migrate/from-legacy-auth), [UI deprecation](https://neon.com/docs/auth/reference/ui-components), [Azure notice](https://neon.com/docs/import/azure-regions-deprecation); checked 2026-11-05.
