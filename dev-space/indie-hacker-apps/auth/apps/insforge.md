## Cost examples — our calculation

All inputs below were checked on 2026-11-05. These use one production app and one builder, with existing users who log in during the month and return on at least two days. Use social login for the no-email-send sub-scenario. Email/password remains a supported method, but verification/recovery traffic is unspecified. No SMS, customer organizations, business SSO or paid security add-on is included in consumer examples.

Prices retain the published **$** notation. No currency conversion, tax, startup grant or annual discount is applied. Monthly plan/user inputs: https://github.com/InsForge/InsForge/blob/main/docs/pricing.mdx. Backend compute inputs: https://insforge.dev/pricing. Mail dependency: https://github.com/InsForge/InsForge/blob/main/docs/core-concepts/messaging/custom-smtp.mdx and https://github.com/InsForge/InsForge/blob/main/docs/core-concepts/messaging/overview.mdx.

**Comparability limit:** the provider names MAU but does not publish enough detail to prove how its cloud bill maps to the baseline. The table therefore explicitly assumes each distinct signed-in person counts once. Public source usage statistics count stored users; that code is not sufficient to replace the advertised MAU definition. See https://github.com/InsForge/InsForge/blob/main/backend/src/services/usage/usage.service.ts and https://github.com/InsForge/InsForge/blob/main/openapi/usage.yaml.

Let M be billable MAU under that assumption. For Pro:

`monthly subscription + user excess + backend compute excess + resource excess + mail + applicable tax`

`= $25 + max(M − 100,000, 0) × $0.00325 + max(C − $10, 0) + R + E + tax`

C is actual hourly backend compute spend across the developer organization. For the narrow one-Micro monthly-estimate sub-scenario, C = $10 and no other project spends the credit. R means database, bandwidth, file storage and function excess at the published rates. E is any mail/provider charge. Do not substitute the separate Custom Compute container allowance for backend compute.
