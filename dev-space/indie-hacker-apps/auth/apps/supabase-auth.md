# Supabase Auth

Lifecycle check: **Active hosted service and maintained self-hosted Auth server.** No whole-product shutdown, sunset, acquisition or rebrand notice was found in the official-source review on 2026-11-05. Latest public Auth release: **v2.197.0**, published **2026-09-09T15:27:11Z**; the repository was active on November 4. A hosted project's exact deployed version was not checked. Sources: [product](https://supabase.com/auth), [repo](https://github.com/supabase/auth), [release](https://github.com/supabase/auth/releases/tag/v2.197.0), [changelog](https://supabase.com/changelog.md).

Component notices found first, checked 2026-11-05:

- The old Auth UI repository is archived; its README says Supabase maintenance ended **2024-02-07**. Auth Helpers are deprecated; the successor is **@supabase/ssr**. Sources: [oldUI](https://github.com/supabase-community/auth-ui), [oldUIreadme](https://github.com/supabase-community/auth-ui/blob/main/README.md), [helpers](https://supabase.com/docs/guides/auth/server-side/migrating-to-ssr-from-auth-helpers.md).
- Four **@supabase/server** framework adapters for Hono, H3, Elysia and NestJS are deprecated and scheduled for removal **2026-12-01**; use the documented framework bridges. **@supabase/ssr** and **withSupabase** are not deprecated. Source: [adapters](https://supabase.com/changelog/supabase-server-adapters-deprecated).
- Four legacy CBC TLS 1.2 ciphers for hosted Auth HTTP endpoints may stop working **2026-11-10 at the earliest**. The notice includes custom domains and says self-hosted deployments are unaffected. Source: [tls](https://supabase.com/changelog/cbc-tls-ciphers-deprecated).
- Legacy Slack v1 is deprecated in favor of **Slack (OIDC)**. The dated notice set **2025-01-15** for dashboard configuration removal. The present guide's “10th October” wording is stale/ambiguous and is not used as an assurance of continued support. Sources: [slacknotice](https://supabase.com/changelog/30772-slack-v1-oauth-provider-deprecated-in-favour-of-slack-oidc), [slack](https://supabase.com/docs/guides/auth/social-sign-in/auth-slack.md).
- Primary passkeys and the newer recovery/WebAuthn MFA APIs remain experimental where documented. Sources: [passkeys](https://supabase.com/docs/guides/auth/passkeys.md), [recoveryGenerate](https://supabase.com/docs/reference/javascript/auth-mfa-recovery-codes-generate), [swiftmfa](https://supabase.com/docs/reference/swift/auth-mfa-api).

## Field problems

- **F08/F12/F13:** MAU alone does not set compute, DB, egress, log or delivery cost. An exact hosted platform subtotal can be shown only with explicit usage/capacity assumptions. The six cost rows use unclear for the full total while keeping each known subtotal/formula.

- **F39/F41/F42:** Profile JSON, native DB backups, credential portability, vendor-account closure and regional storage are separate questions. An all-data export, immediate erasure or region guarantee cannot be inferred from one of them.
