Checked date throughout: 2026-11-04 UTC. Covered MonoCloud's hosted Free and Pro plans, ScaleX, Secure+, mTLSConnect and Workload Identity add-ons, and separately licensed SDKs. No signup, login, form submission, payment, quote request or production deployment was attempted. Public API schemas/examples were read as documentation; no live user or tenant data was requested.

MonoCloud has a production Free plan with 50,000 monthly active users. Its public paid rate makes the consumer baseline calculable without inventing request volume. Several security controls and larger resource limits have explicit Pro/add-on gates. Current business marketing advertises SAML, SCIM, organizations and customer self-service, but the public pricing and technical references do not establish the complete business-baseline entitlement/fees. Those gaps remain visible rather than treating generic groups as a complete organization product. The unrelated monocloud.me service and MontyCloud are not evidence for this app.

## Cost examples — our calculation

All sources in this section were checked 2026-11-04. Values retain the tariff's dollar symbol; an explicit ISO currency code was not located on the checked pricing page. No currency conversion or silent rounding is used.

Consumer inputs follow fields.md: one production application, one developer dashboard operator, and N = 1,000 / 10,000 / 50,000 / 100,000 distinct users. Every user registered before the month and returns on at least two days. No customer organizations, business SSO, SMS, M2M tokens or paid extra security. Use ordinary password or social login, both included in Free/Pro. Existing users can sign in without choosing email OTP/magic-link delivery or a new password reset. No compulsory email send is identified for this selected baseline. Sources: https://www.monocloud.com/pricing ; https://www.monocloud.com/platform/password ; https://www.monocloud.com/docs/apis/management/openapi.json.

The published MAU definition is a unique user authenticating at least once in a billing cycle. Repeat visits do not multiply one user's MAU count. It does not require a request-volume assumption as a request-priced product would. Source: https://www.monocloud.com/pricing.

Public comparison formula:

- Free, while N ≤ 50,000 and its resource/feature limits fit: **$0/month**.
- Pro: **$24.99 + $0.015 × max(N − 50,000, 0) + $0.0008 × max(T − 5,000, 0)** per month, where T is M2M token issuance. Here T = 0.
- Add the named optional subscriptions, trust stores, message usage and their external providers only when required. None is compulsory for the selected consumer baseline. A 50,000-user Pro subscription would cost $24.99, but the cheaper Free plan already fits this baseline.
- Plan resources allow one application on both tiers. Public dashboard collaborator-seat pricing is not established; the single operator assumed here is the account operator in documented self-service setup, not an added paid teammate.

Formula and setup sources: https://www.monocloud.com/pricing ; https://www.monocloud.com/docs/sdks/nextjs/installation ; https://www.monocloud.com/docs/quickstarts/nextjs-app-router.
