Its phase descriptions differ: the main path gives three months of archive access and a fallback paragraph gives two. The [community page](https://www.keycloak.org/community) still advertises the forum for new questions. We use the newer notice’s named timeline, without claiming its implementation was tested. Current [release metadata](https://api.github.com/repos/keycloak/keycloak/releases/latest), [downloads](https://www.keycloak.org/downloads.html) and [repository metadata](https://api.github.com/repos/keycloak/keycloak) show maintained server releases; no product shutdown, sunset or acquisition notice was found in that bounded search.
- **Current versus historical feature descriptions.** The [feature maturity table](https://www.keycloak.org/server/features), [organization guide](https://www.keycloak.org/docs/latest/server_admin/index.html#_managing_organizations) and [SCIM guide](https://www.keycloak.org/docs/latest/server_admin/index.html#_managing_scim) establish supported 26.8 organizations, organization groups, workflows, passkeys, recovery codes and native SCIM. Older preview/extension-only SCIM descriptions are not used. A supported default server feature still needs relevant realm/client setup. [downloads](https://www.keycloak.org/downloads.html) marks the Node adapter deprecated even though the [Node adapter guide](https://www.keycloak.org/securing-apps/nodejs-adapter) remains accessible. [JavaScript adapter guide](https://www.keycloak.org/securing-apps/javascript-adapter) separately deprecates its built-in Cordova modes; generic OIDC clients/custom adapters are another route. No planned removal date is invented.
- **No upstream hosted price was found because this scope is self-operated software.** Read the [official site](https://www.keycloak.org/), [downloads](https://www.keycloak.org/downloads.html), [Apache license](https://raw.githubusercontent.com/keycloak/keycloak/main/LICENSE.txt), [production guide](https://www.keycloak.org/server/configuration-production), [database guide](https://www.keycloak.org/server/db) and commercial [Red Hat entitlement article](https://access.redhat.com/articles/7044244).
