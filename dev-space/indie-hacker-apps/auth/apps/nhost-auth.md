## Conflicts and unknowns

All pages named below were checked on 2026-11-05. Findings of “not published” apply to this public-source review, not to every possible contract or private support answer.

- **Repository deprecation, not product shutdown.** [The old Hasura Auth README](https://raw.githubusercontent.com/nhost/hasura-auth/main/README.md) explicitly moves development to [Nhost's monorepo](https://github.com/nhost/nhost). Current [Cloud pricing](https://nhost.io/pricing) and [Auth 0.52.0 release](https://github.com/nhost/nhost/releases/tag/auth%400.52.0) remain public. No shutdown, sunset or acquisition notice found on the official product, pricing, repository notice or current release pages reviewed. No signup was tested.
- **Stable versus rolling API.** [The auth@0.52.0 API definition](https://raw.githubusercontent.com/nhost/nhost/auth%400.52.0/services/auth/docs/openapi.yaml) has WebAuthn elevation routes. [The live API definition](https://docs.nhost.io/openapi/auth.json) additionally lists TOTP, email OTP and SMS OTP elevation. The [0.53.0-beta1 tag](https://api.github.com/repos/nhost/nhost/releases/tags/auth%400.53.0-beta1) is treated as preview even though GitHub's prerelease flag is false. Its empty release description does not prove exact feature inclusion. Check the deployed Auth version before relying on rolling examples. The live JSON API was readable by direct public fetch even though the web reader could not open it.
- **Billing arithmetic.** [Billing example 4](https://docs.nhost.io/platform/cloud/billing) says $66 while its line items produce $60. Our calculation is $25 + ($50 − $15) = $60. Do not use the printed $66 to derive a tariff.
