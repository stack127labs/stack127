## Field problems

- F08/F12: MAU scenarios are an incomplete capacity specification for fixed backend plans. A known base charge is useful, but an exact total or “users included” figure would create false precision.
- F13–F16/F26–F28: Builder SSO/team management, application organizations, infrastructure tenants and MCP identity are separate products or workflows. Reusing one as evidence for another would overstate customer auth.
- F20–F25/F36–F38: Xano provides editable primitives and templates. Classify the implementation and outside sender explicitly; do not turn a possible custom flow into a maintained built-in auth feature.
- F35/F39/F48: Local Engine, commercial Custom deployment and open-source SDK rights differ. The local Engine currently resets application data on restart/update; free binary price is not a durable production-service total.
- F41/F42/F43/F47/F49: Legacy plan names and conflicting pricing/docs prevent a single clean retention, SLA or refund answer. Keep unresolved contract scope visible instead of choosing the more favorable claim.
