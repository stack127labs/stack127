- **Self-hosted, including Enterprise.** [pricing](https://goauthentik.io/pricing/) explicitly says there is no current hosted version, and [Enterprise start guide](https://docs.goauthentik.io/enterprise/get-started/) uses the same images/install procedure with local key validation. Subscription/support is not managed hosting. [architecture guide](https://docs.goauthentik.io/core/architecture/), [backup guide](https://docs.goauthentik.io/sys-mgmt/ops/backup-restore/) and [HA guide](https://docs.goauthentik.io/install-config/high-availability/) leave database, files, backups, operating work and chosen infrastructure services to the operator. No vendor-region promise or all-in MAU hosting bill is inferred.
- **Public commercial terms disagree with the current sales model.** [pricing](https://goauthentik.io/pricing/) quotes workforce/customer per-user rates, [license-management guide](https://docs.goauthentik.io/enterprise/manage-enterprise/) counts active internal/external users, and [Enterprise license](https://raw.githubusercontent.com/goauthentik/authentik/main/authentik/enterprise/LICENSE) requires user seats.
