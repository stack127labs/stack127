## Cost examples — our calculation

These six examples use the fields.md inputs. They are our calculations from the public rate card and calculator, not vendor quotes. Use monthly billing with no startup grants, volume discounts or annual substitutions. Every returning person is one distinct account in one app. The main-calculator base is `N < 5,000 ? 0 : ceil(0.02 × N)`; its conflicting 5,000-user-deduction article is disclosed above.

The consumer baseline uses existing email/password accounts, so a successful ordinary return login does not itself need a message. Password resets, email verification and any separately configured mail provider remain unpriced extras if used. All scenarios exclude SMS, SCIM, optional paid security, extra apps/environments and extra dashboard credentials. Cloud still requires your own application/backend hosting. Self-host totals must add Core/PostgreSQL hosting, backups, delivery, monitoring and operations.
