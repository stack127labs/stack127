Wristband's Standard plan includes SSO, MFA, roles and invitations and can continue with paid usage above its free allowance. It is the cheapest public plan that fits all six specified scenarios; Pro buys branding/domains/webhooks and a larger tenant allowance rather than being necessary for basic business auth. Identity records belong to one tenant and IdP, so this is different from one shared user record joining several organizations. The stock export script writes only five profile columns, and the official FAQ explicitly rules out importing existing password hashes.
