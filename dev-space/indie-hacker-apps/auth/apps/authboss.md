These are **our calculations**, using the fixed `fields.md` inputs. There is no currency-denominated Authboss hosted rate card. The consumer examples select **password login**, with app-provided storage, state and rendering. Every user is already registered before the month and returns on at least two days.

**Software licence subtotal = Authboss core and bundled modules 0.** No user-count licence meter, monthly hosted minimum, annual discount or tax assumption is added. **Running total = software subtotal + hosting + account/session storage + optional lifecycle-message delivery + app integration/operation; unknown.** No hosting/database price or developer-hours estimate is invented.

The password-login use-case table says Mailer is not required for login itself. Optional confirmation, password recovery and factor-setup email need a real sender. `defaults.SetCore` installs a log mailer, which is not delivered email. Those external delivery costs are not silently counted as free.
