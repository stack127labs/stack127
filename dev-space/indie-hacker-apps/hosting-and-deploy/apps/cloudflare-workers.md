## Cost examples: our calculation

Calculated **2026-11-05** for one builder, a public commercial product, one existing private source repository, one custom domain, normal monthly billing and no startup credits, annual discount or optional support. Native currency **USD**, before applicable tax. Domain registration is outside hosting. No other workloads are consuming account allowances. Sources: [Source](https://developers.cloudflare.com/workers/platform/pricing/); [Source](https://www.cloudflare.com/terms/); [Source](https://developers.cloudflare.com/workers/ci-cd/builds/limits-and-pricing/); [Source](https://developers.cloudflare.com/workers/configuration/routing/custom-domains/).

Scope: **ordinary Workers plus native Workers Static Assets/Workers Builds and basic Workers Logs**. No R2, D1, KV, Durable Objects, Containers, Workflows, Queues, AI or image-service usage is silently included. Those products can have separate charges. An active Cloudflare zone can be on its Free tier; Workers Paid is a separate account subscription. Sources: [Source](https://developers.cloudflare.com/workers/platform/pricing/); [Source](https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/); [Source](https://developers.cloudflare.com/billing/understand/faq/).

### A. Small commercial static site

Inputs: **100 MB deployed files; 1,000,000 HTTP requests/month; 100 GB outbound; 20 builds × 5 minutes = 100 build minutes; one private source repository; one custom domain**.

Select **Workers Free with native Static Assets and Workers Builds**. Assume at most **20,000 files**, each at most **25 MiB**; total 100 MB alone does not settle those constraints. All requests go directly to static assets, with no SSR/authentication Worker script, no `run_worker_first` on those paths and no optional **Workers Caching**. Ordinary native static caching is used. Sources: [Source](https://developers.cloudflare.com/workers/static-assets/); [Source](https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/); [Source](https://developers.cloudflare.com/workers/platform/limits/); [Source](https://developers.cloudflare.com/workers/platform/pricing/).

Our formula:

- Plan: **USD 0**.
- Static delivery/requests: **1,000,000 × USD 0 = USD 0**.
- Native asset storage: **100 MB × no additional asset-storage charge = USD 0**.
- Worker egress: **100 GB × no Worker egress charge = USD 0**.
- Builds: **20 × 5 = 100 minutes**, below the **3,000 included/month**, and each below the **20-minute timeout**: **USD 0 extra**.
- Custom-domain hosting/certificate: **USD 0 additional**; domain registration excluded.
- No separate required origin server, gateway/IP rental, R2 bucket or Workers Paid subscription.

**Total: USD 0/month hosting**, subject to the file-layout, routing and account-allowance assumptions. Sources for the formula: [Source](https://developers.cloudflare.com/workers/platform/pricing/); [Source](https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/); [Source](https://developers.cloudflare.com/workers/ci-cd/builds/limits-and-pricing/); [Source](https://developers.cloudflare.com/workers/configuration/routing/custom-domains/); [Source](https://developers.cloudflare.com/workers/platform/limits/); checked 2026-11-05. If this account is already on Workers Paid, its **USD 5/month account base** remains payable; the incremental static delivery/storage for this site is still free under these assumptions.

Private source is not required to be published. Workers Builds uses the repositories authorized to the GitHub/GitLab integration; Wrangler also deploys local source/assets without publishing a Git repository. No additional Cloudflare private-repository tier is listed. The **100 hosted build minutes** are counted above, rather than quietly substituting an unpriced external build. Git provider access was not connected/tested. Sources: [Source](https://developers.cloudflare.com/workers/ci-cd/builds/git-integration/); [Source](https://developers.cloudflare.com/workers/ci-cd/builds/git-integration/github-integration/); [Source](https://developers.cloudflare.com/workers/ci-cd/builds/configuration/); [Source](https://developers.cloudflare.com/workers/wrangler/commands/workers/).

Commercial hosting is contemplated, but the self-serve agreement forbids processing/collecting credit-card information on web properties receiving Free Services. This static example assumes it does not collect such information. The estimate does not certify commerce/compliance for an unspecified checkout flow. Sources: [Source](https://www.cloudflare.com/products/workers/); [Source](https://www.cloudflare.com/terms/); [Source](https://www.cloudflare.com/service-specific-terms-developer-platform/).

### B. Small commercial app API

Inputs: **1,000,000 HTTP requests/month; 100 ms active processor work and 250 ms elapsed time/request; 256 MiB working memory; 100 GB outbound; the same 100 build minutes/private source/domain**.

**The defined workload does not fit ordinary Workers.** Both Free and Paid have **128 MB per isolate**, including JavaScript/WebAssembly and concurrent request memory. The requested **256 MiB** is higher. Paying for more requests/CPU does not increase that ceiling. This is a function/isolate runtime, so the server example's 1 vCPU/1 GiB/730-hour minimum cannot be substituted into a Workers price. Sources: [Source](https://developers.cloudflare.com/workers/platform/limits/); [Source](https://developers.cloudflare.com/workers/reference/how-workers-works/); [Source](https://developers.cloudflare.com/workers/platform/pricing/).

For transparency, here is **our conditional compute/request subtotal if the app is redesigned to fit the memory limit**. It is **not** a total for the original B workload:

1. Active CPU: **1,000,000 × 100 ms = 100,000,000 CPU-ms**.
2. Included Paid CPU: **30,000,000 CPU-ms**.
3. Excess: **100,000,000 − 30,000,000 = 70,000,000 CPU-ms**.
4. CPU overage: **70,000,000 ÷ 1,000,000 × USD 0.02 = USD 1.40**.
5. Requests: **max(1,000,000 − 10,000,000, 0) ÷ 1,000,000 × USD 0.30 = USD 0**.
6. Subscription: **USD 5**.
7. **Conditional Workers subtotal: USD 5 + USD 1.40 = USD 6.40/month before tax**.

Sources: [Source](https://developers.cloudflare.com/workers/platform/pricing/); [Source](https://developers.cloudflare.com/workers/platform/limits/); checked 2026-11-05. Free is also unsuitable for the assumed **100 ms CPU/request**, above its 10 ms limit. Paid's ordinary HTTP default CPU cap is 30 seconds, so 100 ms fits that limit in the redesigned variant.

Elapsed duration arithmetic: **1,000,000 × 250 ms = 250,000 seconds**. Ordinary Workers does not bill this as provisioned-memory GB-seconds or HTTP wall duration. It still requires the client to stay connected for ongoing work and is subject to runtime/resource interruption. No physical-core speed or measured throughput equivalence is claimed. Sources: [Source](https://developers.cloudflare.com/workers/platform/pricing/); [Source](https://developers.cloudflare.com/workers/platform/limits/); [Source](https://developers.cloudflare.com/workers/reference/how-workers-works/).

Other stated inputs in that conditional variant: **100 GB egress USD 0**, **100 build minutes within 6,000 Paid included USD 0 extra**, native domain/certificate **USD 0 extra**. Assume one invocation event plus one application log per request: **2 × 1,000,000 = 2,000,000 log events**, below the **20 million Paid logs/month**, so **USD 0 log overage**. Logpush is optional and omitted. No separate mandatory gateway/IP/always-on server bill is documented for this native Worker path. Sources: [Source](https://developers.cloudflare.com/workers/platform/pricing/); [Source](https://developers.cloudflare.com/workers/ci-cd/builds/limits-and-pricing/); [Source](https://developers.cloudflare.com/workers/observability/logs/workers-logs/); [Source](https://developers.cloudflare.com/workers/configuration/routing/custom-domains/).

### C. App plus persistent data

Inputs: B plus **PostgreSQL with at least 1 GiB RAM and 10 GB storage, daily backup retained 7 days, and 10 GB/month app-to-database traffic**.

**No compatible complete C total.** The API still fails the **256 MiB** Worker-memory condition. Additionally, **D1 has SQLite semantics, not PostgreSQL**, and KV/R2/DO storage does not satisfy the requested database type/RAM. No included Worker feature supplies a PostgreSQL server of that configuration. Sources: [Source](https://developers.cloudflare.com/workers/platform/limits/); [Source](https://developers.cloudflare.com/d1/); [Source](https://developers.cloudflare.com/hyperdrive/); [Source](https://developers.cloudflare.com/workers/platform/pricing/).

A possible named dependency is **external PlanetScale PostgreSQL connected through Hyperdrive**. Cloudflare documents separate PlanetScale database billing, including optional pass-through billing on the Cloudflare invoice. A qualifying PlanetScale plan with the stated RAM/storage/backup requirements has **not been selected or priced here**; those requirements stay unresolved rather than being replaced by D1. Sources: [Source](https://developers.cloudflare.com/hyperdrive/); [Source](https://developers.cloudflare.com/hyperdrive/platform/pricing/).

Our conditional formula, **only after redesigning B to fit Worker memory**, is:

**USD 6.40 Workers subtotal + external PlanetScale PostgreSQL plan + required backup/storage/operations + any database-provider charge for 10 GB traffic + applicable tax.**

Hyperdrive Paid pooling/query caching has no additional charge and no Hyperdrive egress fee, but this does not pay for the upstream database. Its connection/query allowance is separate from the database's RAM, disk, backup retention and transfer terms. **No exact total or lower-bound ranking is published for C.** Sources: [Source](https://developers.cloudflare.com/workers/platform/pricing/); [Source](https://developers.cloudflare.com/hyperdrive/platform/pricing/).

D1's own Time Travel windows are useful only for D1: **7 days Free, 30 days Paid**, with no extra history/restore charge. They are **not** a daily backup for a PostgreSQL server and are not included in C. Worker code rollback does not restore bound data or an external database. Sources: [Source](https://developers.cloudflare.com/d1/platform/limits/); [Source](https://developers.cloudflare.com/d1/reference/time-travel/); [Source](https://developers.cloudflare.com/workers/versions-and-deployments/rollbacks/).

## Field problems

- **03/06/15:** a Workers isolate is not a 1-vCPU server or an independently reserved memory allocation per request. B/C's **256 MiB** assumption fails the documented **128 MB** ceiling. A cheap CPU subtotal must not be shown as a compatible full-workload quote.
- **07/11/13/26:** the platform price page includes several product tables. Keep native Worker request/CPU billing, Static Assets, Workers Builds and logs distinct from R2/D1/KV/DO/Containers. A free binding allowance is not an unlimited free attached disk/database.
- **08/10:** Free is not labelled personal-only, but the actual agreement restricts credit-card data collection on properties receiving Free Services. A general “commercial use: yes” needs that qualification.
- **14:** alerts, per-invocation CPU limits and asynchronous product usage blocks solve different problems. Preserve opt-in state, scope and unknown enforcement delay; do not reduce them to a single hard-cap checkbox.
- **16/17:** placement hints named after an AWS/GCP/Azure region do not mean the code runs in that provider's server. Regional execution also does not keep code/secrets/all logs/backups there.
- **19:** current recommended Next.js path is a beta API reimplementation with a feature matrix, not universal unmodified Node compatibility. Retain partial support and compatibility-check requirements.
- **28/31:** Preview/code version isolation is separate from durable data isolation and recovery. A service binding can still call production; reusing a D1/KV/R2 identifier shares its data.
- **32/33:** the public Workers SLA and generic support table use contract/plan scopes that do not map cleanly to the USD 5 subscription. Keep those two uncertainties visible.
- **35/36:** no self-hosted Workers-platform installation is evaluated. workerd/SDK source availability does not price or recreate the hosted global network and data services.
- No identity/status row error found in apps.md. Its **Global network advertised** status is a broad existing note; this file supplies execution/placement/residency qualifications without editing the shared list.
