**Status and migration notices:** Active public service; no whole-product shutdown, sunset or acquisition notice found in the checked [product](https://www.oracle.com/cloud/cloud-native/functions/), [release notes](https://docs.oracle.com/en-us/iaas/releasenotes/services/functions/) and [service-change announcements](https://docs.oracle.com/en-us/iaas/Content/servicechanges.htm) on 2026-11-05. ## Cost examples: our calculations

Calculated and checked on **2026-11-05**. Region: **US East, Ashburn (`us-ashburn-1`), commercial OC1**. Currency: **USD**. Functions publishes consistent regional pricing; the [current catalog](https://apexapps.oracle.com/pls/apex/cetools/api/v1/products/?partNumber=B90617,B90618) gives the USD PAYG tiers and was last updated 2026-11-02. This is not a quote for a different account currency or an OCI sovereign/government contract. Buyer-specific taxes are excluded.

Each scenario is independent and assumes the account's monthly **2 million invocation and 400,000 GB-second** allowances are unused elsewhere. Do not apply the same allowance independently to multiple production functions. No introductory credits, annual discount, paid support upgrade or provisioned concurrency are selected.

Common inputs: one builder, one private Git source repository, an existing custom domain, and **20 local builds of 5 minutes = 100 minutes**. Local compilation/packaging is self-managed work, not 100 free Oracle build minutes. Existing local hardware/electricity is outside this cloud invoice model. The [code-only deployment guide](https://docs.oracle.com/en-us/iaas/Content/Functions/Tasks/functions-codeonly-about.htm) permits direct archive upload, so B assumes its complete archive fits the conservative **25 MB** direct limit. It does not need an externally hosted private Git build pipeline, customer registry or archive-source bucket. A larger archive, paid CI system or image workflow changes the bill.

For a public custom-domain endpoint, select **OCI API Gateway**, separately billed from Functions. Its [USD PAYG catalog](https://apexapps.oracle.com/pls/apex/cetools/api/v1/products/?partNumber=B92072) lists **USD 3 per million incoming API calls**. Thus `1,000,000 / 1,000,000 × USD 3 = USD 3`. The [gateway domain guide](https://docs.oracle.com/en-us/iaas/Content/APIGateway/Tasks/apigatewaysettingupcustomdomainscerts.htm) requires a customer-obtained custom-domain certificate and describes customer renewal responsibility. Certificate purchase/renewal cost is not established here; call it `T` rather than pretending default-hostname certificate automation covers the custom domain. Domain registration is outside the hosting estimate. All sources in this paragraph checked 2026-11-05.

The [network price table](https://www.oracle.com/cloud/networking/pricing/) includes the first **10 TB/month outbound originating in North America** and free inbound transfer. Under the explicit assumption that this allowance is unused by other workloads, the specified **100 GB outbound = USD 0** for that transfer component. This is not a Functions-specific 10 TB allocation. Other configured network resources/routes are denoted `N`.

### A. Small commercial static site

Inputs: **100 MB assets; 1,000,000 HTTP requests; 100 GB outbound; the common builds, private source and custom domain**.

**Compatibility is conditional.** Functions is not a native directory of uploaded website files. A custom handler could serve assets through API Gateway, but each function response must fit **6 MB** ([Functions overview](https://docs.oracle.com/en-us/iaas/Content/Functions/Concepts/functionsoverview.htm), checked 2026-11-05). The workload specifies total asset size, not maximum individual response size. A separate static hosting product is outside this Functions estimate.

For an illustrative function-backed implementation, select **512 MB memory**, package assets in a container image, and use the documented registry workflow. The full image size, retained image versions and registry storage cost are not specified; denote that cost `R`. Code-only archives have different size limits and should not be treated as unlimited uploaded-site storage.

Let `D` be mean billed execution seconds per request, including whatever time the billing meter counts. **Our modeling assumption** converts the 512 MB setting to **0.5 billing GB**; Oracle's pages retain MB/GB labels without an explicit byte-level conversion in the sources read.

`Invocation cost = max(1,000,000 − 2,000,000, 0) × USD 0.0000002 = USD 0`

`Execution cost = max(1,000,000 × 0.5 × D − 400,000, 0) × USD 0.00001417`

`A = execution cost + USD 3 gateway + USD 0 stated outbound + R + L + N + T`

Here `L` means selected logging/tracing costs. Neither (D), registry size nor required operational-service quantities are supplied, so **no complete A total** is published. The source inputs are the [Functions tariff](https://apexapps.oracle.com/pls/apex/cetools/api/v1/products/?partNumber=B90617,B90618), [memory settings](https://docs.oracle.com/en-us/iaas/Content/Functions/Tasks/functionscustomizing.htm), [image deployment guide](https://docs.oracle.com/en-us/iaas/Content/Functions/Tasks/functionsusingcustomdockerfiles.htm) and gateway/network sources above, checked 2026-11-05.

### B. Small commercial app API

Inputs: **1,000,000 requests/month; assumed 100 ms useful processor work and 250 ms total elapsed per request; 256 MiB app working memory; 100 GB outbound; the common builds/domain**.

Use an on-demand **512 MB** function, leaving room above the 256 MiB application working set for runtime overhead. Actual memory/throughput fit is untested. This is a function model, so the server-only 1 vCPU/730-hour requirement does not apply.

Use **250 ms = 0.250 seconds** as the modeled billed duration, not 100 ms of useful CPU. The [service description](https://www.oracle.com/a/ocom/docs/paas-iaas-universal-credits-3940775.pdf) meters allocated RAM times execution duration and describes millisecond measurement; actual startup, handler and overhead behavior must be measured before publishing a production budget. No foreign provider's rounding increment is inserted.

Under the explicit **512 MB to 0.5 billing GB modeling assumption**:

`Usage = 1,000,000 × 0.250 × 0.5 = 125,000 GB-seconds`

`Execution = max(125,000 − 400,000, 0) × USD 0.00001417 = USD 0`

`Invocations = max(1,000,000 − 2,000,000, 0) × USD 0.0000002 = USD 0`

`Gateway = 1 × USD 3 = USD 3`

`Stated outbound = USD 0 within unused North American 10 TB allowance`

**Known Functions plus API Gateway subtotal: USD 3/month**, consisting of **USD 0 Functions** and **USD 3 gateway**. This does not mean the whole public app is free or costs exactly USD 3. The full bill is `USD 3 + L + N + T`, with any extra artifact/CI dependencies added if the chosen direct-upload/local-build assumptions do not hold.

The memory-unit convention is explicit rather than a hidden conversion. A decimal interpretation also leaves this modeled execution quantity well below 400,000 GB-seconds, but actual execution overhead, other account usage and production log volume can change eligibility for zero Functions charges. Logs can be configured through [OCI Logging or syslog](https://docs.oracle.com/en-us/iaas/Content/Functions/Tasks/functionsexportingfunctionlogfiles.htm); no unlimited free log retention is assumed. All linked inputs checked 2026-11-05.

### C. App plus persistent data

Add to B **one separately billed OCI Database with PostgreSQL system**, with one primary node and **PostgreSQL.VM.Standard.E5.Flex, 1 OCPU/16 GB RAM**. This exceeds the required 1 GiB memory. The [shapes guide](https://docs.oracle.com/en-us/iaas/Content/postgresql/supported-shapes.htm) and [creation guide](https://docs.oracle.com/en-us/iaas/Content/postgresql/create-db.htm), checked 2026-11-05, establish that shape and one required primary node. Availability/capacity in a specific tenancy was not tested.

Choose at least **10 GB of application data**, plus PostgreSQL's actual index/WAL/other storage overhead. Storage grows dynamically and is billed on used capacity per the [database billing guide](https://docs.oracle.com/en-us/iaas/Content/postgresql/billing.htm); do not call 10 GB of user data exactly 10 GB of billable database storage.

Enable **daily backups with seven-day retention** using the [backup management policy](https://docs.oracle.com/en-us/iaas/Content/postgresql/schedule-backup.htm). [Backups](https://docs.oracle.com/en-us/iaas/Content/postgresql/backups.htm) support up to 35 days for automatic retention and incur charges once created. Backup size is not specified. Choose a private endpoint/network path for the specified **10 GB/month app-to-database traffic**, which requires matching VCN/subnet and access policy; creation docs describe a private database endpoint. These sources were checked 2026-11-05.

Known **external database surcharges** from the [USD PAYG catalog](https://apexapps.oracle.com/pls/apex/cetools/api/v1/products/?partNumber=B99060,B99062), used for Ashburn/us-ashburn-1:

- PostgreSQL service SKU B99060: **USD 0.098/OCPU-hour**. Our calculation: `1 × 730 × 0.098 = USD 71.54/month`.
- Database Optimized Storage SKU B99062: **USD 0.072/GB-month**. If `S` is average billable GB, our calculation is `USD 0.072 × S`.

The [PostgreSQL pricing page](https://www.oracle.com/cloud/postgresql/pricing/) explicitly adds these to standard compute/block-storage costs and charges Object Storage for backups. They are **not the complete database price**. Let `Cbase` be base compute, `Sbase` base storage/performance, `Bkup` backup storage/operations, and `Ndb` database-route transfer.

`C = USD 3 + USD 71.54 + USD 0.072S + Cbase + Sbase + Bkup + Ndb + L + N + T`.

At an illustrative **S = 10 GB**, the known gateway plus database-surcharge components equal **USD 75.26**. That is not a total, a guaranteed minimum bill, or proof 10 GB of application data occupies only 10 GB. A complete regional base-resource quote, backup quantity, log quantity and route costs remain unresolved after checking the database pricing/catalog/billing pages. A Functions code rollback does not restore PostgreSQL data.
