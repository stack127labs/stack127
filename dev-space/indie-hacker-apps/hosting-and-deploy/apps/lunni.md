## Current status and notices

The official site, pricing page, documentation, and installation guide loaded on 2026-11-07. The install guide labels Lunni “Public beta.” The homepage, pricing page, and install guide show no last-updated date. The public GitLab project listing for Lunni's Frontend repository shows its latest listed update as 2026-02-15, about nine months before this check. The legal and privacy pages say they were last updated 2024-05-27; the security policy says 2024-06-04. I could not verify a current release or the most recent commit because GitLab's release and commit pages returned a cache-miss error. **Lunni looks inactive or very slow-moving**, although its site and install docs still load. Treat ongoing maintenance as unconfirmed; no shutdown notice was found in the checked official pages.

The official site links its source code to GitLab. The exact-name GitHub account at `https://github.com/lunni` has no public repositories, so it did not provide a release or maintenance record. The homepage has no blog or changelog link. The official `/blog/` and `/changelog/` URLs could not be fetched; their failure is not proof that no notice exists. The installer page is live, but both direct installer-script URLs failed to load in the research browser, so I could not inspect or verify the scripts themselves.

The old documentation says a one-node Swarm can be extended, but the newer install guide says multi-node is not currently supported with Lunni. The newer guide is used for current guidance; the difference is recorded below as a conflict.
