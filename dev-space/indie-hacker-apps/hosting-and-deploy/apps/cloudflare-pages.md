## Cost examples: our calculations

Calculation date: 2026-11-04. One builder, public commercial product, private source repository, one existing custom domain, monthly billing, no annual discount, startup credits, trial or optional support. Domain registration and applicable taxes are outside hosting totals. Do not equate 100 MB with a 25 MiB individual-file allowance, or a function memory ceiling with a VM's installed RAM. Input facts and their checked dates are in the table; exact URLs are repeated at each calculation's input boundary.

### A. Small commercial static site

Inputs: 100 MB total deployed files; 1,000,000 HTTP requests and 100 GB outgoing/month; 20 builds of 5 minutes; one private repository; one custom domain. Choose Pages Free with native Git builds, no Functions or middleware. Static delivery has no Functions request meter; the native deployment flow supplies file hosting. Sources: https://developers.cloudflare.com/pages/functions/pricing/ and https://developers.cloudflare.com/pages/configuration/git-integration/ (checked 2026-11-04).

Feasibility conditions: no more than 20,000 files; each file at most 25 MiB; 20 builds is below 500/month and each assumed five-minute build below the 20-minute timeout; one custom domain fits the allowance. Total asset bytes alone do not establish these conditions. Sources: https://developers.cloudflare.com/pages/platform/limits/ and https://developers.cloudflare.com/pages/configuration/custom-domains/ (checked 2026-11-04).

Our calculation, conditional hosting subtotal:

`$0 base + $0 static request/delivery usage + $0 builds within Free allowance + $0 ordinary deployed-file hosting within limits + $0 included SSL/custom-domain attachment = $0/month`

This is a technical hosting subtotal, not unconditional approval for an unspecified commercial activity. Free Services have the documented credit-card-data restriction. No explicit per-activity Free permission for ads, affiliates and selling goods was located; do not rank this as a fully verified commercial-free result. A marketing site that sends a buyer elsewhere for payment is a different configuration from collecting card details on this property. Sources: https://www.cloudflare.com/products/pages/ and https://www.cloudflare.com/terms/ (checked 2026-11-04). If the commercial activity or file conditions fail, the estimate needs revision. An unknown asset distribution must not silently become a successful deployment.

### B. Small commercial app API

Inputs: 1,000,000 requests/month; 100 ms active CPU and 250 ms elapsed/request; 256 MiB working memory; 100 GB outbound; the same builds/domain as A.

Compatibility: no, as written. Both Free and Paid have a 128 MB isolate ceiling. The required 256 MiB is larger under either conventional reading of MB; this conclusion does not silently convert a published allocation. Free additionally allows only 10 ms CPU/invocation, below the assumed 100 ms. Sources: https://developers.cloudflare.com/workers/platform/limits/ and https://developers.cloudflare.com/pages/functions/ (checked 2026-11-04).

Our calculation of the paid usage meters only, for a hypothetical memory-compatible rewrite:

- CPU work: `1,000,000 × 100 ms = 100,000,000 CPU ms`.
- CPU excess: `max(0, 100,000,000 - 30,000,000) / 1,000,000 × $0.02 = $1.40`.
- Requests: `max(0, 1,000,000 - 10,000,000) / 1,000,000 × $0.30 = $0`.
- Monthly minimum plus usage: `$5 + $1.40 + $0 = $6.40 USD` before tax.

The 250 ms elapsed input does not create a separate duration/memory-time charge. Pages Functions inherit the cited Workers rates; ordinary function transfer has no egress fee. Source: https://developers.cloudflare.com/workers/platform/pricing/ (checked 2026-11-04). This illustration assumes the account's included allowances are otherwise unused, no extra bindings/cached-Workers product, and builds/assets within A's limits. It is **not the cost of scenario B**, which fails the memory test. No alternative container product is substituted into the Pages record. Persistent external log collection, if required by an actual application, needs its own selection and price; Pages' live logs are not saved history. Source: https://developers.cloudflare.com/pages/functions/debugging-and-logging/ (checked 2026-11-04).

### C. App plus persistent data

Inputs: all of B, plus Postgres with at least 1 GiB memory and 10 GB storage, daily backups kept seven days, and 10 GB/month app-to-database traffic.

Compatibility: no, because the inherited 256 MiB application requirement already fails. D1's SQLite model does not satisfy Postgres, and its published storage/PITR allowances do not document a Postgres RAM allocation. Sources: https://developers.cloudflare.com/workers/platform/limits/ and https://developers.cloudflare.com/d1/best-practices/import-export-data/ (checked 2026-11-04).

An adapted lower-memory app could connect to an **external Postgres provider** using Hyperdrive. That connector is not the database. Even a database purchased through the Cloudflare/PlanetScale integration is separately billed. No provider/configuration is selected here for a workload that the app runtime cannot support; its RAM, 10 GB storage, seven-day backup cost and outgoing traffic remain unpriced. Source: https://developers.cloudflare.com/hyperdrive/platform/pricing/ (checked 2026-11-04).

Our calculation structure, not a total:

`adapted Pages app hosting subtotal + actual external Postgres plan + daily-backup retention charge + external database transfer/operations + any compulsory extras`

The hypothetical hosting meter illustration is $6.40 USD above. C's actual hosting subtotal and total are not applicable as written. Do not label $6.40 plus an unspecified database as a comparable C price, or call a code rollback a database restore.
