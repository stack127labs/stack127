- Kamatera's official blog says it finalized the acquisition of VPSserver in late 2023. It described the combined provider as operating as Kamatera. ## Cost examples

All totals below are our calculations from the public configuration and allowance. The site shows amounts with `$` but does not print a currency code. The public price cards do not identify a data-center zone, so the location for each price is **not specified by Kamatera's displayed price**. No currency conversion is made.

### A. Small commercial static site

- Fit: possible with a customer-managed static web server; build speed and the private repository workflow are not provider-managed or verified.
- Inputs: 100 MB of site files, 1,000,000 requests/month, 100 GB outbound, 20 builds × 5 minutes, one private repository and one custom domain.
- Server: Basic Type A, 1 vCPU, 1 GB RAM, 20 GB NVMe, 5 TB monthly traffic; public price $4/month.
- Formula: 1 VM × $4/month = **$4/month server subtotal**.
- 100 GB outbound is below the 5 TB included allowance for most locations. Hong Kong, Sydney, Tokyo and Singapore have 1 TB allowances, still above 100 GB.
- Build and repository access must be set up by the customer on the VM or with a separate CI provider. The exact build performance and external CI cost are not included. Domain registration and tax are not included.

### B. Small commercial app API

- Fit: compatible with a self-managed VM, but the stated request rate and 100 ms active CPU time have not been load-tested. Type A uses a non-dedicated CPU thread.
- Inputs: 1,000,000 requests/month; assumed 100 ms active CPU and 250 ms total elapsed time per request; 256 MiB working memory; 100 GB outbound; same build/domain inputs as A.
- Server: Standard Type B, 2 vCPU, 2 GB RAM, 20 GB NVMe and 5 TB monthly traffic; public price $25/month. The 2 GB label exceeds the requested 1 GiB minimum without silently treating GB as GiB.
- Formula: 1 VM × $25/month = **$25/month server subtotal** for the assumed 730-hour month. The 100 GB transfer is within the included allowance in all named exception zones too.
- Type B threads have dedicated reserved resources, but this does not prove the assumed CPU time or throughput. Build tools, app logs, domain and TLS are configured by the customer. Domain registration and tax are not included.

### C. API plus persistent Postgres data

- Fit: possible as a two-VM customer-managed setup, but not as a managed Kamatera Postgres feature in the Cloud Servers entry price.
