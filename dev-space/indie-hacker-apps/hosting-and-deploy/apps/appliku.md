## Conflicts and unknowns

- The official runtime page lists Python 3.14 but still calls 3.13 the latest stable release. The same page marks Node 10, 12 and 14 as legacy/end-of-life while listing them as available images.
- The Free plan is described for weekend projects, but the Terms do not clearly say whether commercial apps are allowed on that plan. I left that as unclear.
- I checked the pricing page, billing docs, Terms, Privacy Policy, GDPR DPA, Contact page, official blog, docs home, status page and the guessed /changelog path. The marketing site has a current blog and docs but no separate product newsroom or accessible product changelog in the pages found.
- The signup link routes to app.appliku.com/auth/sign-up, but the page returned no extractable content in the research browser. I did not submit the form.
- The Privacy Policy names Hetzner as the website host, not as a guaranteed location for dashboard, build or log data. The 2020 DPA allows processing inside and outside the EU and worldwide.
- Cost examples show the Appliku subscription portion only. No cloud provider, server size beyond the comparable minimum, or region was selected, so the full totals remain unknown.
- No acquisition, sunset or shutdown notice was found in the official pages checked. The status page showed monitors, but no reporting window or general contractual uptime percentage was visible.

## Field problems

- **05 and 15:** The subscription fee is exact, but a complete workload bill requires choosing a separate server provider, region, domain registrar and possibly an object-storage provider.
- **10:** The pages do not settle commercial use on the Free plan.
- **17:** The Privacy Policy and old DPA do not give current per-data-type residency for build logs, app configuration and all dashboard records.
- **18:** The supported-stack page contains the Python latest-version mismatch described above.
- **22:** Non-HTTP TCP and UDP ports are possible, but direct ports bypass Nginx TLS and rate limiting; encrypted app protocols need their own TLS configuration.
- **28:** A zero-downtime deployment guide is linked, but the fetched guide content did not allow confirming the exact conditions. The general deploy flow replaces containers, so zero interruption should not be assumed.
- **35–36:** Appliku is a hosted panel, not a software package to install on your own server. Server requirements describe the customer's app server, not the hosted control plane.
