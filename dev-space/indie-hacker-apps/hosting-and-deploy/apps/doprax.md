## Field problems

- Doprax's name covers **managed containers, customer-managed VMs and one-time app installation**. A single “managed hosting” value hides most ongoing work; the row's maintenance caution is warranted.
- A/B/C insist on a private repository and custom domain. Current native App Space lacks the relevant connection/domain flow, so its low starting price must not become an estimate for those exact workloads. The VM alternatives have different responsibilities.
- Headline monthly prices are **720-hour equivalents**, not monthly caps or fixed subscriptions. For the required 730 hours, divide by 720 before multiplying. Rounded four-decimal hourly display values cannot safely replace the explicit formula.
- RAM is published in GB, while B/C require GiB. We conservatively choose larger documented plans rather than silently treating 1 GB as exactly 1 GiB.
- Prepaid deposit, processing fee, available credit, accrued charges and consumed resource cost are different amounts. The sub-$50 card cash examples and fee waiver affect cash needed; unused deposit is not consumed monthly hosting.
- Snapshot price depends on actual image size, with disk-size fallback. Database size alone does not determine backup bytes, and a disk snapshot does not prove an application-consistent Postgres backup.
- Native snapshot scheduling/retention is not included. C's daily schedule/seven-day policy and consistency procedure are customer implementation choices; no complete verified backup total is claimed.
- Current and legacy tooling overlap in documentation. Code-workspace snapshots, VM disk snapshots, legacy rollback, current source redeploy and durable logs should not be grouped as one recovery feature.
- Provider port restrictions, rescue/resize/snapshot support and egress pricing are Doprax-specific. Direct retail facts from Hetzner, OVH or another cloud were not substituted for this reseller/platform path.
- API examples show a minimum balance that can vary by environment; current VM-cost prose says $1 while an API test example shows $3. Treat the dashboard/API-required amount as authoritative for a real order, not a universal fixed minimum inferred from one example.
- No field was skipped; advanced unknowns and authenticated specification gaps remain explicit.
