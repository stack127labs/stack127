### A. Small commercial static site

Inputs: **100 MB deployed files, 1,000,000 HTTP requests/month, 100 GB outbound/month, 20 builds × 5 minutes = 100 build minutes, one private source repository and one custom domain**.

**Basic USD 0/month is the known hosting subtotal for prebuilt static files.** It includes 3 channels, a 0.1-core CPU share, 128 MiB per-container memory ceiling, domains/HTTPS and no per-request/egress charge. The authenticated app git repository can store the source/output; an external paid private-repository account is not a required xhostd dependency. Our hosting formula: **USD 0 plan + USD 0 request charge + USD 0 traffic charge + USD 0 domain/certificate fee = USD 0/month hosting subtotal**, subject to fair use and actual resource fit. There is no byte-metered static delivery fee in the published offer. A million requests and 100 GB do not by themselves guarantee that 0.1 CPU/128 MiB meets the arrival pattern. Sources: [Source](https://xhostd.com/pricing); [Source](https://xhostd.com/faq); [Source](https://xhostd.com/pricing.md); [Source](https://docs.xhostd.com/domains).

**The complete original workload is not exactly priced.** The native static template serves committed files as-is and performs no build. Docker builds have a separate 4 GB memory budget, but the actual image must fit the **512 MiB charged-image cap** and the public docs do not state a build-minute allowance/time limit.
