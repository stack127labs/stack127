## Lifecycle and current status

Amazon EC2 is active and offered to new AWS accounts. I found no EC2 service shutdown, acquisition, or overall sunset notice. I checked the AWS What's New feed, EC2 News Blog category, AWS News Blog deprecation category, EC2 instance-type guide and its document history, and AWS service sunset/full-shutdown lists. The What's New feed and instance guide show current releases, including T8i instances announced September 17, 2026.

The relevant retirement and end-of-sale notices I found are narrower:

- AWS's instance guide says U-9tb1, U-12tb1, U-18tb1, and U-24tb1 cannot be launched as new instances; the end-of-sale notice is dated June 20, 2025. The current guide recommends U7i for new high-memory needs.
- The EC2 instance-types guide's document history says the P3 family was removed from the guide January 1, 2026. It does not state that existing P3 instances were deleted or provide a retirement date in that history entry.
- AWS's EC2-Classic networking retirement is complete. AWS's News Blog update says no EC2-Classic instances remained after August 23, 2023. This is a retired network mode, not an EC2 service shutdown.
- The EC2 documentation also describes instance-specific hardware retirement notices. AWS notifies account contacts; an EBS-root instance is stopped and may be restarted on new hardware, while an instance-store-root instance is terminated. That process is not a scheduled end-of-life for the EC2 product or every instance family.

## Cost examples

All examples are **our calculations**, not AWS quotes. They use Linux/Unix On-Demand rates for US East (N. Virginia), `us-east-1`, 730 running hours/month, one public IPv4, and assume the AWS-wide 100 GB monthly transfer allowance is unused by other AWS services. Data prices are USD before tax. Domain registration, Marketplace software, and separately purchased services are excluded. EBS rates and egress tiers below come from the coordinator-saved AWS price feeds fetched 2026-11-09.

- t3.micro + one public IPv4 + 20 GB gp3: `(730 × $0.0104) + (730 × $0.005) + (20 × $0.08) + $0 eligible egress = $12.842/month`.
- t3.small + one public IPv4 + 20 GB gp3: `(730 × $0.0209) + (730 × $0.005) + (20 × $0.08) + $0 eligible egress = $20.507/month`.
- t3.medium + one public IPv4 + 30 GB gp3: `(730 × $0.0418) + (730 × $0.005) + (30 × $0.08) + $0 eligible egress = $36.564/month`, before snapshots.

For each example, the 100 GB egress is USD $0 only if no other AWS service has used the account-wide monthly allowance. The next us-east-1 egress tier is $0.090/GB. gp3 includes 3,000 IOPS and 125 MiB/s; any extra provisioned performance is not included above. T3 Unlimited surplus CPU credits, if accrued, are extra.

- **Scenario A — commercial static site:** compatible as a self-managed VM. Assume t3.micro and 20 GB gp3. Our calculation is **USD $12.842/month** under the stated free-egress assumption. Builds run outside EC2; domain, tax, and any external build service are excluded.
- **Scenario B — small stateless API:** compatible as a self-managed VM, but capacity is untested. Assume t3.micro and 20 GB gp3. Our calculation is **USD $12.842/month** under the same egress assumption; any T3 surplus-credit charge is additional.
- **Scenario C — API plus Postgres:** possible by self-hosting both on a t3.medium with 30 GB gp3 total; no managed database is included. The known base is **USD $36.564/month**. Add standard snapshot storage at `USD $0.05 × actual stored snapshot GB-month`; the exact snapshot amount depends on changed data and retention, so the complete total is not fixed.

## Conflicts and unknowns

- **T3 small/medium rates:** the AWS T3 product page and AWS Prescriptive Guidance show slightly different rates for t3.small and t3.medium. The product page's rates are used for the examples; no attempt was made to determine whether the guidance page is stale or the difference reflects an update.
- **Price-feed update (2026-11-09):** coordinator-saved AWS Price List API data resolves the us-east-1 internet-egress tiers and EBS gp3, gp2, snapshot, extra-IOPS, and extra-throughput rates. These are on-demand USD list prices before tax; source publication dates and exact URLs are in the facts table.
- **New-account free offer:** current free account credits and six-month access rules differ from the legacy 12-month Free Tier, and T4g's separate trial ends on December 31, 2026. Do not combine them into one perpetual free allowance.
- No EC2 overall shutdown/acquisition notice was found. AWS docs list end-of-sale for four U-1 instance sizes and a completed EC2-Classic network retirement, but those do not indicate that ordinary EC2 instances are closed.
