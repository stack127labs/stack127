## Cost examples: our calculations

Our calculations, checked 2026-11-07. These are Coolify-platform subtotals, not complete server-hosting quotes. Assumptions: one solo builder, a commercial site/app, monthly Cloud billing, no annual discount, no taxes, and at most two connected workload servers. The price page uses `$` without an ISO currency code; calculations keep the published `$` symbol. The customer’s domain registration is excluded.

Inputs and sources:

- Self-hosted software fee: `$0` recurring platform charge: https://coolify.io/pricing . Recommended control-plane machine: 2 CPU cores, 2 GB RAM, 10 GB free disk: https://coolify.io/docs/start-with-self-hosted . The machine is still paid to the chosen provider.
- Coolify Cloud: `$5/month` including up to two connected servers; each further server adds `$3/month`: https://coolify.io/pricing . Apps and databases run on customer servers: https://coolify.io/docs/choose-your-path .
- Supported DB backup schedule and S3 destination: https://coolify.io/docs/databases/backups . Coolify does not publish the connected server or S3 storage bill.

### A. Small commercial static site

Inputs: 100 MB published files, 1,000,000 requests, 100 GB outbound/month, 20 builds of 5 minutes, one private Git repository, one custom domain. Coolify can build/serve static site files, but the server and transfer are external.

- Self-hosted platform subtotal: `$0/month` license + provider server/transfer charges (unknown).
- Cloud platform subtotal, one connected server: `$5/month` + provider server/transfer charges (unknown).
- Formula: `platform subtotal = $0 (self-hosted) OR $5 (Cloud with 1–2 slots); full total = platform subtotal + workload server + outbound traffic + domain (if purchased)`. No request or build-minute meter is listed by Coolify.
- Result: exact monthly total unknown because Coolify does not price the server or workload traffic.

### B. Small commercial app API

Inputs: stateless HTTP app, 1,000,000 requests/month, 100 ms assumed active CPU and 250 ms assumed elapsed time per request, 256 MiB assumed working memory, 100 GB outbound/month, 20 five-minute builds, private repository, custom domain. The comparison workload requires a server with at least 1 vCPU and 1 GiB RAM for 730 hours; Coolify does not sell that server.

- Self-hosted platform subtotal: `$0/month` license + provider server/transfer charges (unknown).
- Cloud platform subtotal, one connected server: `$5/month` + provider server/transfer charges (unknown).
- Formula: `platform subtotal + 730-hour server price + 100 GB provider egress + any domain/provider fees`. The 730-hour server price and egress meter are external and were not estimated.
- Result: exact monthly total unknown; Coolify is the deployment manager, not the capacity provider.

### C. App plus persistent data

Inputs: workload B plus one Postgres database with at least 1 GiB memory and 10 GB storage; daily backup retained for 7 days; 10 GB/month app-to-database traffic. Coolify supports scheduled Postgres backups, but a single one-click database is not a managed HA cluster.

- Self-hosted platform subtotal: `$0/month` license + provider server, storage, and backup destination charges (unknown).
- Cloud platform subtotal, one connected server: `$5/month` + provider server, storage, and backup destination charges (unknown).
- Formula: `platform subtotal + app/database server + 10 GB persistent storage + backup storage/transfer + provider network costs`. If database and app share one server, their capacity is shared; if separate, they use two Cloud slots, still within the base subscription.
- Result: exact monthly total unknown because customer-server and object-storage prices depend on the selected providers. A successful scheduled backup is not a restore test.
