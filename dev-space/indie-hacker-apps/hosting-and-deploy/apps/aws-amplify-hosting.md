## Cost examples — our calculations

Calculated **2026-11-04**. One paying commercial builder, normal on-demand billing, no startup/trial credits, no annual discount, no optional paid support/WAF, existing private repository and custom domain. Choose US East (N. Virginia), subject to final resource availability. Domain registration and applicable taxes are outside hosting subtotals. Published USD is retained; AWS India's invoice conversion is not performed here.

Price inputs checked 2026-11-04: [Amplify pricing](https://aws.amazon.com/amplify/pricing/) gives Standard builds $0.01/minute, storage $0.023/GB-month, delivery $0.15/GB, SSR $0.30/million requests and $0.20/GB-hour. Team access and public certificates carry no additional listed charge. [Private-repository previews](https://docs.aws.amazon.com/amplify/latest/userguide/pr-previews.html) establish private-source support. No purchase of a source-provider subscription is assumed for an existing repository.

No Hosting Free Tier allocation is subtracted. This avoids presenting cohort-dependent, time-limited allowances as steady-state free usage. Counts of requests below are Hosting requests; no additional Lambda/API Gateway cost is added for the current managed compute HTTP route alone.

**A. Small commercial static site**

Inputs: 100 MB built output, 1,000,000 HTTP requests, 100 GB delivery, 20 builds × five minutes, private source, one custom domain. Compatible through Git or static upload; use Git builds for this comparison.

| Our calculation | Formula | Result |
| --- | --- | --- |
| Standard builds | 20 × 5 min × $0.01/min | $1/month |
| Delivery | 100 vendor-labelled GB × $0.15/GB | $15/month |
| Stored deployments | S actual billed GB-month × $0.023 | $0.023 × S |
| Static-request line | No separate static request meter listed; SSR request rate not applied | No separately identified charge |
| Known build/delivery subtotal | $1 + $15 | **$16/month** |
| Illustrative storage assumption | 20 separately retained 100 MB outputs, each present for the full month; assume decimal 100 MB = 0.1 GB: S = 2 | $0.046/month |
| Conditional illustration including that storage | $16 + $0.046 | **$16.046/month** |

**Exact total unknown.** The 2 GB-month assumption is illustrative, not a claim about how long each deployment exists or which artifacts are billed. Pricing's own examples multiply app size by number of builds but divide MB by 1024 despite labelling rates GB. Applying that example convention instead gives S = 20 × 100/1024 = 1.953125 and $0.044921875 storage, or $16.044921875 subtotal. Neither unit convention is silently selected as authoritative. Actual billed bytes/time, older versions and cleanup need verification. Optional DNS/support/firewall costs are excluded explicitly.
