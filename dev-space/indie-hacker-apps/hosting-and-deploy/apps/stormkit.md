### A. Small commercial static site

Inputs: 100 MB deployed files; 1,000,000 HTTP requests and 100 GB outbound/month; 20 builds of 5 minutes; one private source repository; one custom domain.

- Plan-price calculation: 1 seat × $0/month Cloud Free = $0/month subscription subtotal.
- The site says “Unlimited usage,” but it does not publish numeric build or bandwidth allowances, domain entitlements by plan, or a complete overage rule. Total fit and total hosting cost remain unverified.

### B. Small commercial app API

Inputs: 1,000,000 requests/month; assumed 100 ms active processor work and 250 ms total elapsed time per request; assumed 256 MiB working memory; 100 GB outbound/month; 20 five-minute builds; private repository; custom domain.

- Plan-price calculation: 1 seat × $20/month Cloud Premium = $20/month subscription subtotal.
- The documented Cloud function timeout is 15 seconds per call, but memory, aggregate requests, build caps, bandwidth, and full workload compatibility are not published. This is not an all-in estimate.

### C. App plus persistent data

Inputs: workload B plus PostgreSQL with at least 1 GiB memory and 10 GB storage; daily backup retained seven days; 10 GB/month app-to-database traffic.

- Cloud cost: no exact total. The homepage FAQ describes managed Postgres, while current database docs and the README say the database feature is self-hosted-only; no Cloud database price is published.
- Self-hosted formula: $0 Community Edition software fee + server + PostgreSQL + Redis + storage + transfer + backups. The infrastructure components depend on the operator's provider, so a monthly total cannot be calculated from Stormkit prices.
