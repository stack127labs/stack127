- **Shutdown, sunset, acquisition, and maintenance check:** The official product page and forum announce aaPanel 8.0.7 on October 13, 2026. The GitHub repo remains active, although its latest tagged release shown is 7.65.0 and its tag sequence does not match the panel's 8.0.7 release. The aaPanel blog, News & Updates archive, forum, and GitHub release/security pages checked showed no acquisition, shutdown, sunset, or rename announcement. The GitHub security page says there are no published repo advisories; aaPanel's own advisory page loads its list with JavaScript and showed no entries to this reader. See the security notes below for reported vulnerabilities and privacy/security concerns.
- **Product scope:** This record covers the international aaPanel at aapanel.com: free and paid server-control software installed on a Linux server supplied by the user. The Chinese BT Panel/宝塔 product is not treated as a separate listing here. aaPanel's repo retains `BTPanel` and `BT-Panel` names and its installer says `BT-SOFT`; the official pages checked do not explain the relationship between the international product and the Chinese product.
- **Security notes:** An external CVE/GitHub advisory published March 18, 2026 describes critical arbitrary file upload leading to code execution in aaPanel v7.57.0; its affected and patched version fields remain unknown, and no aaPanel vendor advisory or current remediation was found. In aaPanel's forum, users reported in 2025 and 2026 that (a) the Pro tampercore module may have been involved in a compromised server, (b) malware scanning uploaded file contents to a cloud endpoint, and (c) the built-in terminal displayed saved SSH credentials in plain text. These are community reports, not confirmed security advisories. The scan thread later reports an aaPanel repair removed automatic cloud scanning, but says a manually triggered file check still sent file contents as of September 2026. aaPanel's October 2026 PHP security update concerns upstream PHP CVEs, not an aaPanel panel vulnerability; aaPanel posted patched builds and update steps.

## Conflicts and unknowns

- The official About and Privacy pages identify AAPANEL LIMITED, while the repository's custom license names Dongguan Baita Network Technology Co., Ltd. The pages do not explain the relationship.
- The international product site calls the panel aaPanel. Its repo and installer retain BTPanel/BT-Panel/BT-SOFT labels, but no official page checked clearly explains how the international aaPanel relates to Chinese BT Panel/宝塔.
- The product site and forum show aaPanel 8.0.7, while GitHub's latest visible tag is 7.65.0 and its release page omits the year from “Jan 22.” The public version tracks are inconsistent.
- The quick-start guide and download page give different minimum OS ranges. The quick-start page is narrower and explicitly describes current development on Ubuntu 22.04; the download page lists older distributions too.
- The pricing page displays separate monthly, annual, and lifetime Pro cards, not a period switch. A Black Friday banner advertises discounted rates but does not expose an expiry date. The standard USD rates are retained as the plan prices; eligibility and promo dates remain unclear.
- The official repo Security page says no published GitHub advisories, but aaPanel's Security Advisories page requires JavaScript and did not expose any entries to this reader. The external CVE/GHSA entry for v7.57.0 has unknown affected and patched versions, so whether it applies to 8.0.7 is unresolved.
- The malware-scan thread documents a claim that scanned file contents were sent to a cloud endpoint. aaPanel staff initially said they would ask the developer; a later reply said the panel was optimized. The forum user's follow-up says automatic scanning no longer used that upload after repair, but manual file testing still did. This is an unverified forum report, not a vendor security bulletin.
- A separate December 5, 2025 forum report attributes a server compromise to a buffer overflow in the Pro tampercore kernel module after an alleged WordPress-plugin breach. aaPanel staff replied privately by email; the public thread does not confirm root cause or publish a patch/remediation.
- An October 21, 2026 aaPanel notice describes critical upstream PHP CVEs and provides patched builds/update instructions. These concern PHP runtime versions, not aaPanel's panel code.
- The public privacy policy covers the website and account usage but does not specify self-hosted panel telemetry, a product DPA, or complete data-flow inventory.
- A legal terms page was not linked from the pricing footer; two candidate Terms of Service paths failed. The repository license and pricing FAQ were readable and supply the terms recorded above.
- The optional SSL certificate shop is dynamic. The page showed price placeholders rather than amounts, so a certificate product total could not be recorded.
- No linked status page or hosted service SLA was found. `status.aapanel.com` did not open in the web reader; a server SLA must come from the chosen infrastructure provider.
