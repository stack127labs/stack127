## Lifecycle and current status

Azure Virtual Machines is an active, general-purpose infrastructure-as-a-service product from Microsoft. This record covers Linux virtual machines (VMs) in East US, with the guest operating system and application managed by the customer.

**B-series V1 is being retired on November 15, 2028.** That includes B1s, B1ms, and B2s. From July 2026, new subscriptions cannot deploy affected B-series V1 sizes; existing subscriptions are limited to already approved quota and available regional capacity. The free-account page still lists B1s, so the offer and current deployment restriction do not line up cleanly. The API price rows below include both B-series V1 and current B2ats_v2 rates; the B-series V1 prices do not imply eligibility for new subscriptions.

Microsoft's current free-account page advertises 750 hours each per month for B1s, B2pts v2, and B2ats v2 for 12 months. The VM pricing page instead lists B2ts v2, B2pts v2, and B2ats v2. The differing Intel SKU and B1s lifecycle restriction mean the free Intel VM should be checked in the portal before relying on it.
