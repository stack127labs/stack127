## Cost examples

These are **our calculations**, not vendor quotes. Amounts are in IDR. The current standard monthly prices do not state tax treatment. The 11% PPN exclusion appeared only in expired 2026 promotions, so it is not applied to these totals.

### A. Small commercial static site

- **Fit:** A static site can be served from a customer-managed VPS. CloudKilat does not provide managed Git builds; builds must run on the VM or elsewhere. One public IP is included. Transfer is unmetered under fair use. A domain is not included, but a domain is not an unavoidable hosting purchase if you already own one.
- **Inputs and formula:** XXS (1 vCPU, 1 GB RAM, 20 GB SSD) × 1 monthly plan = IDR 90,000/month.
- **Result:** **IDR 90,000/month known VPS subtotal.** The workload's 100 MB of files fits the published disk size, but the 1,000,000 requests, 100 GB outbound, and 20 builds are not performance-tested. Any domain bought separately and applicable tax are not included in this subtotal.

### B. Small commercial app API

- **Fit:** XXS meets the defined server floor of 1 vCPU and 1 GB RAM, and includes one public IP. The API runs as a customer-managed guest application. CloudKilat publishes no request-meter charge or per-GB transfer charge, but the shared fair-use policy applies.
- **Inputs and formula:** 1 × XXS monthly plan = IDR 90,000/month for the assumed 730-hour month. No separate request rate is published.
- **Result:** **IDR 90,000/month known VPS subtotal.** This is not a performance guarantee for one million requests. Tax inclusion, throughput, response times, and costs for any separately purchased domain remain unsettled.
