## Current status and lifecycle notices

**Active offering; no whole-service shutdown, sunset or acquisition notice found in the checked official product, pricing, support-policy and retirement pages.** [home](https://azure.microsoft.com/en-us/products/app-service/), [linuxprice](https://azure.microsoft.com/en-us/pricing/details/app-service/linux/), [winprice](https://azure.microsoft.com/en-us/pricing/details/app-service/windows/), [policy](https://learn.microsoft.com/en-us/azure/app-service/language-support-policy), [retire](https://learn.microsoft.com/en-us/azure/advisor/advisor-how-to-use-service-upgrade-retirement-recommendations). Checked 2026-11-05.

- **Docker Compose deployment retires March 31, 2027.** Sidecars are the current migration direction. This is a feature retirement, not closure of App Service. [container](https://learn.microsoft.com/en-us/azure/app-service/configure-custom-container), [sidecar](https://learn.microsoft.com/en-us/azure/app-service/configure-sidecar). Checked 2026-11-05.
- **Linked-database custom-backup support retires March 31, 2028.** App Service app backups are not described as retiring. Flexible Server PostgreSQL/MySQL are already excluded from linked-database backup. [backup](https://learn.microsoft.com/en-us/azure/app-service/manage-backup). Checked 2026-11-05.
- **Runtime support matters now:** Node.js 20 and .NET 9 STS already reached the listed 2026 retirement dates; .NET 8 LTS reaches November 10, 2026, and PHP 8.2 December 31, 2026. These are runtime security/support deadlines, not a statement that the hosting service closes. [retire](https://learn.microsoft.com/en-us/azure/advisor/advisor-how-to-use-service-upgrade-retirement-recommendations), [policy](https://learn.microsoft.com/en-us/azure/app-service/language-support-policy). Checked 2026-11-05.
- **ASE v1/v2 are retired**, with SLA coverage removed as of September 1, 2024. Current Isolated v2/ASE v3 names refer to different generations. [slaDoc](https://www.microsoft.com/licensing/docs/documents/download/OnlineSvcsConsolidatedSLA%28WW%29%28English%29%28November_2026%29%28CR%29.docx). Checked 2026-11-05.

Scope: ordinary multi-tenant App Service Windows/Linux code and custom-container plans, with separate notes for Managed Instance and Isolated editions. App Service's own rates and limits are kept separate from PostgreSQL, Azure Functions, Container Apps, monitoring, networking and other Azure products. No account was created or deployment tested.
