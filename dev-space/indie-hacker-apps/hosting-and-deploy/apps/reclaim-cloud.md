### Transfer and builds shared by A, B and C

Each scenario includes 100 GB outbound and 20 builds × 5 minutes = **100 build minutes**. The stated request timing is not a billed function duration.

Traffic is accounted hourly. If the 100 GB is spread evenly over 730 hours, it is 100/730 = approximately **0.13698630137 GB/hour**, explicitly rounded here. Under the published 2 GB/hour allowance, that specified traffic would incur no excess **only if the applicable allowance is available to this workload each hour**. The same 100 GB concentrated in one hour exceeds that hour's allowance by 98 GB. The workloads do not specify timing, inbound byte counting or other shared traffic, so a zero monthly traffic bill is not unconditional. The displayed excess rate's GB/hour dimension cannot be safely converted into a normal per-GB transfer charge.

No build hardware size, minimum duration/rounding, included build budget or guaranteed build fee was found. Builds may use application or separate customer-controlled resources. Therefore E cannot be set to zero from a count of build minutes alone.
