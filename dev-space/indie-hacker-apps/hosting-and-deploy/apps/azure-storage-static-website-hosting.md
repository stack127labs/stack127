## Cost examples: our calculation

Calculated 2026-11-04. One paying builder, an ongoing month after setup, no startup/trial credits or annual reservation, and no optional paid support. Native currency USD, before taxes and invoice rounding. Domain registration is excluded. Existing DNS and a private local source repository are supplied by the builder. The 20 five-minute builds run locally on existing hardware; storage does not supply a hosted build service. A selected paid Git/CI service would need its actual cost added.

### A. Small commercial static site

Fixed workload: 100 MB deployed files, 1,000,000 HTTP requests/month, 100 GB outbound, 20 builds, one private source repository, one custom domain. Select Standard GPv2, Hot LRS, East US, flat namespace. Assume 100 MB means 100,000,000 bytes, held for a full month. Transfer inputs below mean the published service's billed GB; no decimal/binary substitution is silently made. No version history, soft-deleted retained output, backups, paid logs, advanced metrics, SFTP, or customer-managed encryption keys are enabled.

Price inputs, checked 2026-11-04:

- Storage and operations: the exact [Microsoft retail-price query](https://prices.azure.com/api/retail/prices?%24filter=serviceName+eq+%27Storage%27+and+armRegionName+eq+%27eastus%27+and+productName+eq+%27General+Block+Blob+v2%27+and+skuName+eq+%27Hot+LRS%27+and+priceType+eq+%27Consumption%27&currencyCode=USD). The [Blob price page](https://azure.microsoft.com/en-us/pricing/details/storage/blobs/) supplies binary storage units and Hot retrieval treatment. We did not treat its dynamically displayed `$-` cells as zero.
- Network: [direct Azure bandwidth](https://azure.microsoft.com/en-us/pricing/details/bandwidth/), [Front Door rates](https://azure.microsoft.com/en-us/pricing/details/frontdoor/), and [Front Door meter definitions](https://learn.microsoft.com/en-us/azure/frontdoor/billing).
- TLS: free managed certificates in the [Front Door overview](https://learn.microsoft.com/en-us/azure/frontdoor/front-door-overview). Existing external DNS is allowed by the [custom-domain guide](https://learn.microsoft.com/en-us/azure/frontdoor/standard-premium/how-to-add-custom-domain).

Let `R` be billable Blob read/other operations, including origin fetches/probes/metadata calls; `W` write operations; `L` list/create-container operations; `Q` billed GB sent from Front Door edges to the origin; and `X` other configured/in-scope charges. `R` is not assumed equal to viewer visits when caching is used.

**Custom-domain HTTPS variant:** Azure Front Door Standard for a full billing month, all delivery/requests in North America Zone 1, existing custom subdomain mapped directly to Front Door, Microsoft-managed TLS, and HTTPS to the storage website origin. Select no optional edge actions or other billable add-ons. Both the viewer connection and origin connection can be encrypted; the storage account's direct custom-domain HTTP mapping is not used.

Known delivery components: base USD 35; viewer egress `100 × 0.083 = USD 8.30`; requests `1,000,000 / 10,000 × 0.009 = USD 0.90`; upstream bytes `Q × USD 0.02`. Azure-origin-to-Front-Door egress is included at USD 0. Ordinary Blob request charges remain. Free managed TLS adds USD 0; using existing DNS adds no newly purchased Azure DNS service.

`HTTPS hosting estimate = USD 44.2019371509552001953125 + R × 0.0000004 + (W + L) × 0.000005 + Q × 0.02 + X`.

**Fully specified illustration:** 100 objects of 1,000,000 bytes; 20 complete overwrites during the month, using one PutBlob per object and one ListBlobs per deployment. Therefore `W = 2,000` and `L = 20`. Assume `R = 1,000,000`, inclusive of any billable probes/metadata requests, and `Q = 1` billed GB, with `X = 0`. These are calculation assumptions, not observed traffic or a promise about AzCopy's default call count. Health checks, retries, cache revalidation, missing-file handling, and upload tools can increase operations. No particular cache-hit percentage is implied.

`35 + 8.30 + 0.90 + 0.0019371509552001953125 + 0.40 + 0.01 + 0.0001 + 0.02 = USD 44.6320371509552001953125/month`.

Displayed to eight decimal places: **about USD 44.63203715/month**, before taxes and invoice rounding. The monthly base is the published USD 35 equivalent; partial-month profile usage is billed hourly. An exact total for the original workload is not determined without geography, `R`, `W`, `L`, `Q`, and any additional services. The illustration is not a claim that Front Door is the cheapest possible external delivery provider.

**Native-address HTTPS or custom-domain HTTP subtotal:** no Front Door, same storage/uploads/lists, one million reads/other operations, and the recurring 100 GB direct-egress allowance wholly available:

`0.0019371509552001953125 + (1,000,000 / 10,000 × 0.004) + (2,000 / 10,000 × 0.05) + (20 / 10,000 × 0.05) = USD 0.4120371509552001953125/month`.

That is **about USD 0.41203715/month**, rounded to eight decimal places. ## Field problems

- **03–04 and 26:** this mode is a feature of object storage. Azure Functions, App Service, Static Web Apps, Front Door, and database services must not be counted as included capabilities or independent names for the same product.
- **06, 18, 21, 23–25, 36:** server hardware, runtimes, processes, and idle instances do not map to static-file delivery. Relevant object/account targets and persistence are recorded instead.
- **08–09 and 14:** a zero feature-enablement fee, free direct-bandwidth allowance, temporary credit, introductory service allowance, and paid-plan budget alert mean different things. Pay-as-you-go lacks the trial spending limit.
- **15:** comparable bytes/requests/builds omit file counts, deployment calls, caching/probes, upstream request bytes, and edge geography. A formula plus a declared example is more useful than a false exact total.
- **19:** current REST documentation includes DefaultIndexDocumentPath with HTTP 200 fallback. A generic statement that all browser-app deep links must return 404 would miss this setting; it does not prove support for server framework features.
- **27:** native hostname HTTPS and custom-domain HTTPS have different architectures/costs. Certificate renewal conditions also differ between direct-CNAME subdomains, apex names, and wildcards.
- **28–31:** redundancy, per-blob versions, soft delete, and atomic point-in-time data restore have different scope and compatibility. None alone means a complete, automatic deployment/configuration/database backup.
