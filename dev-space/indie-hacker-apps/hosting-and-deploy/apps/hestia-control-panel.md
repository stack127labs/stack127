## Cost examples

These are **our calculations**. Hestia software cost is $0. The examples do not add an external server provider's unresearched rate, taxes, domain registration, network charge, or remote-backup fee.

- **Scenario A, static site:** Hestia can serve the 100 MB site. **Our calculation:** $0 software + server-month price + 100 GB egress price + domain/DNS price. **Result:** Hestia component = $0/month; total monthly cost is unknown until a provider, region, and domain are selected. The 20 five-minute builds run on your server or a separate CI service; Hestia has no build-minute meter.
- **Scenario B, API:** A custom app can be put behind Nginx, but Hestia does not run a managed API service. **Our calculation:** $0 software + 730 × provider hourly server rate + provider charge for 100 GB outbound data. **Result:** Hestia component = $0/month; full total is unknown because no infrastructure provider or region was specified. The workload's capacity is not guaranteed by the 1-core/1-GB install minimum.
- **Scenario C, API and PostgreSQL:** PostgreSQL is an optional server component; daily backups can be configured, with a package limit of at least seven retained backups for seven daily copies. **Our calculation:** $0 software + 730 × provider hourly server rate + provider network charges + remote backup storage for seven copies. **Result:** Hestia component = $0/month; full total is unknown without provider rates and storage size. The 10 GB install disk minimum is not a capacity claim for a 10 GB database plus operating system and app files.
