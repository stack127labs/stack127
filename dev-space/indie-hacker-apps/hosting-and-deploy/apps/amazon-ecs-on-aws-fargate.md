AWS also routinely retires platform revisions for maintenance: service tasks are replaced, while standalone tasks require their own restart handling. This is not a service shutdown. [platform retirement table](https://docs.aws.amazon.com/AmazonECS/latest/developerguide/platform-versions-retired.html), [current versions](https://docs.aws.amazon.com/AmazonECS/latest/developerguide/platform-fargate.html), [task maintenance and replacement](https://docs.aws.amazon.com/AmazonECS/latest/developerguide/task-maintenance.html); checked **2026-11-05**.

The current migration notice points to ECS Express Mode, CDK or continued management of generated infrastructure. [current ECS notice](https://docs.aws.amazon.com/AmazonECS/latest/developerguide/AWS_Copilot.html), [dedicated announcement](https://aws.amazon.com/blogs/containers/announcing-the-end-of-support-for-the-aws-copilot-cli/), [older conflicting banner](https://aws.amazon.com/blogs/containers/introducing-aws-copilot/); checked **2026-11-05**.

## Field problems

- **Hosted containers require an architecture choice.** There is no single mandatory ALB/NAT/DNS/database bundle. The cost section selects one documented public-subnet/ALB path and names its assumptions; optional alternative architectures are not silently added to it.
- **Smallest plan versus comparable capacity:** the 0.25-vCPU/512-MiB entry task fits a different comparison than the schema's at-least-1-vCPU server rule. The smallest qualifying B/C task is 1 vCPU/2 GiB, not an invented 1-GiB shape.
- **Serverless does not imply request-only billing or automatic idle sleep.** Allocated capacity, image download, replacements and persistent dependencies create separate billable time.
- **Persistent disk needs lifecycle notes.** Included task disk is temporary, EFS is another service, and service-task EBS deletion prevents treating it as a normal reusable volume.
- **Monthly request/traffic inputs cannot fix ALB hourly capacity billing.** The task totals above are conditional base subtotals, with actual capacity and replacement variables retained.
- **Daily backup retention does not define retained bytes.** RDS incrementality/churn and possible skipped busy-window snapshots matter; no promise of seven independently complete daily copies is added.
- **Account experience changes controls.** Region choice, granular IAM/networking and enforced project spend limits differ between new and advanced signup. A generic AWS-wide cap/card statement would hide those conditions.
- No `apps.md` row error found. Its **Active** status and container-without-host-management description remain appropriate. Express Mode is already identified as a related mode, not another vendor.
