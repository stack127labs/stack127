## Cost examples: our calculations

Calculated on 2026-11-06 for one builder, a public commercial product, custom domain already owned, normal monthly usage, no credits, no annual discount, no optional support package. Domain registration is excluded. **Currency: USD.** Each example uses New Jersey (`ewr`) as the intended compute location so the location is explicit; however, the accessible official public starting price does not state its region, and Vultr says location prices can vary. Therefore the figures below are conditional reference calculations, not verified EWR quotes. Tax is extra and depends on the billing address/service location.

Inputs checked 2026-11-06:

- Entry reference rate `r0 = USD $0.005/hour`, for a 1-vCPU, 0.5-GB, 10-GB entry server; the product docs do not name its price location: https://docs.vultr.com/product-overviews/cloud-compute
- Cloud Compute billing minimum is one hour and the monthly cap is 672 billable hours; a stopped instance still bills until destroyed: https://docs.vultr.com/support/platform/billing/how-am-i-billed-for-my-servers and https://docs.vultr.com/support/platform/billing/are-stopped-instances-still-billed-on-vultr
- Automatic backups add 20% to the base hourly/monthly instance fee and are on by default in the documented provisioning flow: https://docs.vultr.com/support/platform/billing/how-much-does-it-cost-to-enable-automatic-backups and https://docs.vultr.com/products/compute/instances/cloud-compute/provisioning
- The account bandwidth allocation includes 2 TB/month plus a running-hour share for each instance. Only outbound counts; overage is USD $0.01/GB: https://docs.vultr.com/support/platform/billing/how-are-bandwidth-caps-calculated, https://docs.vultr.com/support/platform/billing/how-is-bandwidth-usage-calculated, and https://docs.vultr.com/support/platform/billing/what-is-the-bandwidth-overage-rate
- Exact current EWR rate for `vc2-1c-1gb` and larger plans could not be retrieved from the public pricing page; no account/Console login was used: https://www.vultr.com/pricing/
- Snapshot storage reference rate is USD $0.05/GB/month: https://docs.vultr.com/support/platform/billing/does-vultr-charge-for-stored-snapshots

### A. Small commercial static site

Inputs: 100 MB deployed files; 1,000,000 HTTP requests; 100 GB outbound/month; 20 builds of 5 minutes; one private repository; one custom domain. The 0.5-GB entry VM has 1 vCPU and 10 GB storage. Vultr does not build from Git as a managed feature, so source checkout and builds are customer-managed. The 100 GB transfer fits within the published 2 TB/month account allocation. Actual capacity for this site is untested.

- Conditional compute: `min(730 hours, 672 billable hours) × USD $0.005/hour = USD $3.36`.
- Conditional default-backup fee: `USD $3.36 × 20% = USD $0.672`.
- Conditional reference subtotal: `USD $3.36 + USD $0.672 = USD $4.032 before tax`, if the public entry rate applies to the chosen EWR instance.
- Result: exact EWR total is **unknown** because the public docs do not map `USD $0.005/hour` to EWR and the selected regional price table was blocked. No egress overage is expected under the stated 100-GB workload and published 2-TB account allocation. Tax is additional. A custom TLS certificate/DNS setup is customer-managed; any third-party cost is excluded.

### B. Small commercial app API

Inputs: 1,000,000 stateless HTTP requests/month; assumed 100 ms active processor work and 250 ms elapsed time per request; assumed 256 MiB working memory; 100 GB outbound; same 20 builds/domain/private repository as A. The scenario requires at least 1 vCPU and 1 GiB RAM for 730 hours. An official example `vc2-1c-1gb` plan has 1 vCPU, 1 GB RAM, and 25 GB storage, but its regional hourly rate was not accessible.

- Let `p1` be the selected EWR `vc2-1c-1gb` hourly rate in USD. It is not published in the accessible docs.
- Conditional compute and default backups: `min(730,672) hours × p1 × 1.20 = 806.4 × p1`.
- 100 GB outbound is below the published 2-TB account bandwidth allocation. The VM billing model is hourly; the 1,000,000 requests do not add a documented request-meter fee.
- Result: monthly total is **unknown** until Vultr's selected EWR rate is available. The formula excludes tax and assumes no additional separately purchased services. Actual throughput and memory fit are untested.

### C. App plus persistent data

Inputs: B plus self-managed Postgres with at least 1 GiB RAM and 10 GB storage; seven daily backup points retained; 10 GB/month app-to-database traffic. A single server running both app and database needs at least the sum of those process allocations plus OS overhead; no exact plan is selected because its EWR price could not be checked. The database is not Vultr Managed Database in this example.

- Let `pC` be the selected EWR Cloud Compute hourly rate for a plan with enough memory/CPU/storage. Conditional VM plus default backups: `672 × pC × 1.20 = 806.4 × pC`.
- Automatic Backups on their own keep the two most recent points, not seven daily points. A customer-managed daily database dump plus seven retained snapshots is a possible recovery design, but requires operational work. Snapshot charge formula: `total stored snapshot GB × USD $0.05/GB/month`; stored GB is unknown until the actual snapshots exist.
- Result: exact monthly total is **unknown** because `pC`, snapshot storage size, and tax are unknown. If the daily backup process uses another provider, that provider and its storage price must be added. Restoring an app VM image does not establish a database rollback guarantee.
