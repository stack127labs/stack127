## Cost examples: our calculations

Calculated from the coordinator-saved public plans/regions API text fetched 2026-11-09. Prices are USD before tax. Cloud Compute bills hourly with a one-hour minimum and a 672-hour monthly cap; these examples use the API’s listed monthly plan prices and the separate 20% Automatic Backup charge. The API gives location counts per plan, not the named locations, so the monthly figures below are **conditional plan subtotals, not verified New Jersey (`ewr`) quotes**. New Jersey appears in the 33-location list, but the saved API text does not establish that each selected plan is offered there.

Common inputs: one public commercial app, no signup credit, no annual discount or optional services, and no domain purchase. Vultr Automatic Backups are enabled by default and add 20%. The API lists monthly bandwidth by plan; the 100 GB site/API workload below fits within each selected plan’s published allowance, without relying on an unknown regional quote.

### A. Small commercial static site

Use the standard dual-stack `vc2-1c-0.5gb` plan: 1 vCPU, 512 MB RAM, 10 GB disk; USD $3.50/month; 512 GB/month plan bandwidth; offered in one unnamed location.

- Plan: $3.50/month.
- Default backups: `$3.50 × 20% = $0.70/month`.
- Our conditional subtotal: `$3.50 + $0.70 = USD $4.20/month`, before tax.
- 100 GB outbound is below the 512 GB plan allowance. The exact EWR total is unresolved because the API does not name the plan’s single available location.

### B. Small commercial app API

Use `vc2-1c-1gb`: 1 vCPU, 1 GB RAM, 25 GB disk; USD $5/month; 1 TB/month plan bandwidth; offered in 31 locations. The API lists USD $0.007/hour separately.

- Plan: $5/month.
- Default backups: `$5 × 20% = $1/month`.
- Our conditional subtotal: `$5 + $1 = USD $6/month`, before tax.
- 100 GB outbound is below the 1 TB plan allowance. Exact EWR pricing is not verified because the API gives a location count, not the list of 31 locations; request count adds no separate VM request fee.

### C. App plus persistent data

Use `vc2-2c-4gb`: 2 vCPU, 4 GB RAM, 80 GB disk; USD $20/month; 3 TB/month plan bandwidth; offered in 31 locations. This is a planning assumption for the app plus self-managed Postgres; actual capacity is not tested.

- Plan: $20/month.
- Default backups: `$20 × 20% = $4/month`.
- Our conditional server subtotal: `$20 + $4 = USD $24/month`, before tax and snapshots.
- The 100 GB outbound assumption is below the 3 TB plan allowance. A separate daily database backup plus seven retained snapshots requires customer setup. Snapshot storage is `$0.05 × actual stored GB-month`; actual stored size is not known, so the full total is not exact. Exact EWR availability is also not mapped by the API.
