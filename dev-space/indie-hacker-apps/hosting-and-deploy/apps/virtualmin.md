Virtualmin is active self-hosted server software. Its latest GPL virtual-server release found is 8.3.0, dated September 29, 2026. Virtualmin GPL is free and has no domain cap. Virtualmin Pro is a separate paid license for one server, with 10, 50, 100, 250, and unlimited-domain tiers. The current shop exposes the 10-domain prices; its other tier amounts are controlled by a selector that did not expose values in the pages checked.

The official community forum did carry an October 2026 notice about two upstream PHP RCE vulnerabilities. The forum directs operators to fixed PHP releases or patched operating-system packages; this is not evidence of a Virtualmin code vulnerability.
- **Release date:** The official changelog identifies Virtualmin 8.3.0 as released on September 29, 2026. The forum's announcement appeared the following day; treated as posting-time difference, not a substantive version conflict.
- **Tax and trial:** The current shop text does not say whether tax is included. A Pro “Try” link is present, but the checked product/FAQ pages do not give a trial duration or conditions. Terms publish a 30-day refund request period.
- **Infrastructure:** Virtualmin does not provide servers, traffic, regions, app build service, managed database, or backup storage. Full workload costs require a named server and service provider.
