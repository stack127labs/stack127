## Cost examples — our calculation

Calculated on 2026-11-05. These are partial estimates, not vendor-quoted workload totals. Use one paying builder, a public commercial product, one custom domain, private source, monthly billing, no trial/legacy credit, no annual discount, no optional support and no selected paid AI generation. Domain registration is outside the hosting total.

Currency: retain the vendors' published `$` notation. Combining Val Town and Neon below assumes the quoted dollars refer to the same currency, USD; Val Town's public pages did not explicitly settle the checkout currency code. No exchange rate or tax conversion is applied. Tax inclusion and buyer-specific tax remain unknown. Val Town does not publish a region-specific price table in the checked sources; no selectable compute region is assumed.

### A. Small commercial static site

Inputs: 100 MB deployed files, 1,000,000 HTTP requests/month, 100 GB outbound/month, 20 builds of five minutes, one private source repository and one custom domain.

- Choose Pro at **$25/month**. Pro has ten custom domains, private vals and a daily quota of one million runs. Monthly price: https://docs.val.town/faq; quota/domain/private-plan details: https://www.val.town/pricing and https://www.val.town/limits, checked 2026-11-05.
- Serve HTML through an HTTP handler and place larger/binary assets in scoped Blob storage. This is an app serving files, rather than a separately priced static CDN product. Blob documentation's Pro `1gb` allowance accommodates 100 MB under ordinary unit readings; the documentation does not define the byte basis or establish a separately additive SQLite allowance. Source-file limit is 80,000 **characters**, not a 100 MB per-file upload allowance. Sources: https://docs.val.town/vals/http, https://docs.val.town/reference/std/blob, https://docs.val.town/reference/file-io, https://www.val.town/limits, checked 2026-11-05.
- Retain the private GitHub source through the documented sync workflow; GitHub Actions or local bundling is separate from Val Town's save-and-deploy model. The 20 × 5 = **100 build minutes** are workload inputs, not a published Val Town build charge. No exact external Actions cost can be inferred without workflow runner/plan details. Sources: https://docs.val.town/guides/github-sync/github-actions, https://docs.val.town/guides/github-sync, https://docs.val.town/reference/version-control, checked 2026-11-05.
- A normal val.run endpoint has managed HTTPS. Custom-domain routing is documented, but its exact certificate commercial/renewal terms were not fully established in the provider's own guide. Sources: https://docs.val.town/guides/deploy-an-api-endpoint, https://docs.val.town/vals/http/custom-domains, checked 2026-11-05.

**Formula:** `$25 Pro base + unknown price for 100 GB transfer + any external build cost + any mandatory certificate/other charge not settled by public terms + applicable tax`.

**Result:** known Val Town subscription subtotal **$25/month**; complete total **unknown**. Custom domain and private code make Free unsuitable for the stated new-account workload. This is an editorial compatibility assessment, not a benchmark or a promise that quota counts every asset request in a particular way. Assume the million requests are distributed so the daily run allowance is not exceeded. The bandwidth gap remains after checking https://www.val.town/pricing, https://www.val.town/limits, https://docs.val.town/reference/runtime, https://docs.val.town/vals/http/cdns and https://www.val.town/termsofuse on 2026-11-05.
