## Cost examples

All figures below are **our calculations**, not vendor quotes. Prices are in Indonesian rupiah (IDR), for a legacy NVC rate, and exclude applicable taxes. The public plan table does not map prices to compute regions. Jakarta 2 is used as the scenario assumption because it appears in the NVC order guide. NVC is scheduled to retire on 2027-01-31, and the pages do not settle whether a new customer can still buy it.

### A. Small commercial static site

- **Fit:** A customer-managed VM can host a static site. The site, 1,000,000 monthly requests, and 100 GB outbound are not performance-tested; bandwidth is listed as free/unmetered within reasonable use. NVC does not build from a private repository, so the customer must run builds in the VM or use external CI.
- **Inputs and formula:** SS2.1, 1 core / 2 GB RAM / 60 GB: 1 × Rp179,000/month = **Rp179,000/month**. The requested 20 × 5-minute builds equal 100 minutes of customer-managed build work.
- **Result:** Our known VM subtotal is **Rp179,000/month before tax**. This is not an exact purchasable new-customer total: current sale access is unclear; domain registration is separate; and no per-region price or measured capacity is published. Guest HTTPS can be configured by the customer.
- **Sources:** https://www.biznetgio.com/en/pricelist ; https://www.biznetgio.com/blog/migrasi-nvc/ ; https://www.biznetgio.com/legal ; https://www.biznetgio.com/product/neo-virtual-compute/ ; https://kb.biznetgio.com/id_ID/neo-virtual-compute/order-layanan-neo-virtual-compute-nvc-di-portal-biznet-gio (checked 2026-11-06).

### B. Small commercial app API

- **Fit:** SS2.1 meets the scenario’s server floor of at least 1 vCPU and 1 GiB RAM. A VM does not guarantee 1,000,000 requests/month or the assumed response performance.
- **Inputs and formula:** One SS2.1 for a 730-hour month: monthly = **Rp179,000**; hourly alternative = 730 × Rp360/hour = **Rp262,800**. The listed monthly rate is the lower known legacy compute amount. App work assumption: 1,000,000 × 100 ms = 100,000 seconds of active processor work; this is not converted into billable VM hours or a throughput guarantee.
- **Result:** Our known VM subtotal is **Rp179,000/month before tax**. Listed NVC transfer has no separate charge, but there is no published performance test, region-specific price, current new-customer access, or exact tax percentage. One public IP and one router are free per account according to the order guide; if already used, later resources may cost extra.
- **Sources:** https://www.biznetgio.com/en/pricelist ; https://www.biznetgio.com/product/neo-virtual-compute/ ; https://www.biznetgio.com/legal ; https://kb.biznetgio.com/id_ID/neo-virtual-compute/order-layanan-neo-virtual-compute-nvc-di-portal-biznet-gio (checked 2026-11-06).

### C. App plus persistent data
