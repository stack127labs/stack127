## Lifecycle and access notices

**Active public AWS service; no whole-product shutdown, sunset or acquisition notice found in the official product, documentation, pricing and current launch notices.** Current docs call the original handler-based mode **Event Functions** and add **Web Functions** and **MicroVMs**; this is not a migration or replacement of existing function ARNs/APIs. These are runtime/support notices, not a Lambda closure. [runtime lifecycle](https://docs.aws.amazon.com/lambda/latest/dg/lambda-runtimes.html), [support plans and transitions](https://docs.aws.amazon.com/awssupport/latest/user/getting-started.html); checked **2026-11-05**.
