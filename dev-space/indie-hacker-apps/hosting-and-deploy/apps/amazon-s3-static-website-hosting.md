- Scope: Amazon S3 general purpose buckets with S3 Standard storage and the website endpoint. CloudFront is a separately configured delivery option. Private S3 REST origins are distinguished from website endpoints. Directory buckets, S3 Files, Tables, Vectors, Amplify Hosting, and application servers are outside this product's core scope.
- Method: official public pricing, documentation, terms, and policies. No account creation, login, deployment, form submission, or customer-data access. Prices below use US East (N. Virginia), `us-east-1`, unless stated otherwise.

## Cost examples — our calculation

Calculated 2026-11-04. These are pre-tax USD usage estimates, not AWS quotes or guaranteed final invoices. One builder, monthly pay-as-you-go billing, one existing custom subdomain and existing DNS, no startup credits, annual commitment, or optional paid support. Domain registration is excluded as requested. Local build hardware and the existing private local source repository are customer-supplied; this is not a claim of included hosted CI. An external private Git/CI subscription would need its actual price added.

### A. Small commercial static site

Inputs from `fields.md`: 100 MB deployed output, 1,000,000 HTTP requests/month, 100 GB outbound, 20 five-minute builds, private source, one custom domain. Assume 100 MB means **100,000,000 bytes**, held for the full month in S3 Standard us-east-1. The transfer input is within the published delivery allowance whether interpreted as decimal GB or binary GB. Versioning, logs, backups, KMS, acceleration, edge functions, and paid protection features are not enabled. They are not compulsory for this defined task.

The workload omits file count and cache behavior. Define:

- `M`: billable S3 GET/HEAD origin requests during the month, including any cache revalidation.
- `P`: billable Tier 1 upload/copy/list requests.
- `X`: other billable usage, if configured or incurred outside these assumptions.

S3 rates come from the [official us-east-1 price file](https://pricing.us-east-1.amazonaws.com/offers/v1.0/aws/AmazonS3/current/us-east-1/index.json), checked 2026-11-04. The binary storage unit is documented on [S3 pricing](https://aws.amazon.com/s3/pricing/), checked 2026-11-04.

| Line item | Formula | Result |
| --- | --- | --- |
| Stored output | `100,000,000 / 1,073,741,824` | `0.09313225746154785` billing GB |
| Full-month storage | `0.09313225746154785 × USD 0.023` | USD `0.0021420419216156006` |
| Origin reads | `M × USD 0.0000004` | Depends on origin fetches, not just viewer visits |
| Upload/list/copy operations | `P × USD 0.000005` | Depends on file count and deployment method |
| Twenty local builds | `20 × 5 = 100` local minutes | No S3 build-compute charge; local costs outside hosting subtotal |

**HTTPS delivery variant:** CloudFront pay-as-you-go in front of the S3 website endpoint, an ordinary ACM integrated certificate, [SNI delivery](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/cnames-https-dedicated-ip-or-sni.html), existing DNS CNAME to CloudFront, and no other account usage consuming the recurring allowance. The [CloudFront pricing table](https://aws.amazon.com/cloudfront/pricing/pay-as-you-go/), checked 2026-11-04, makes the stated viewer requests/transfer and AWS-origin transfer USD 0 under that allowance. [ACM pricing](https://aws.amazon.com/certificate-manager/pricing/), checked 2026-11-04, supplies the certificate input. [CloudFront origin docs](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/DownloadDistS3AndCustomOrigins.html), checked 2026-11-04, establish that regular S3 fees still apply.

`Monthly HTTPS hosting subtotal = USD 0.0021420419216156006 + M × 0.0000004 + P × 0.000005 + X`.

This variant encrypts browser-to-CloudFront traffic. Its public S3 website origin remains HTTP. For a private origin with encryption on both connections, use a regular S3 REST origin and OAC as documented in [origin access control](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/private-content-restricting-access-to-s3.html), checked 2026-11-04; website redirect/index behavior then needs separate configuration.

**Fully specified illustrative case:** 100 objects of 1,000,000 bytes each; 20 complete uploads during the month, including the first upload; one LIST per upload; no version history; no extra console/API operations. Therefore `P = 20 × 100 + 20 = 2,020`. Assume every viewer request makes exactly one billable S3 read, `M = 1,000,000`, with no retries, extra origin probes, error-document fetches, or revalidations. Use at most 20 wildcard cache-invalidation paths, within the recurring invalidation allowance.

`USD 0.0021420419216156006 + (1,000,000 × 0.0000004) + (2,020 × 0.000005) = USD 0.4122420419216156/month`.

That is **about USD 0.41224204/month**, rounded to eight decimal places for display, before tax and AWS invoice rounding. With the same operation assumptions and `0 ≤ M ≤ 1,000,000`, the subtotal ranges from approximately **USD 0.01224204 to USD 0.41224204/month**. This is a conditional cache illustration, not a universal upper bound: extra requests, direct-origin access, consumed pooled allowances, or enabled services change the bill. An exact total for the workload as originally specified is not determined without `M`, `P`, and any additional charges.

**HTTP-only comparison:** direct S3 website delivery, same storage and `P`, one million direct reads. If the shared recurring [100 GB AWS regional internet allowance](https://aws.amazon.com/about-aws/whats-new/2021/11/aws-price-reduction-data-transfers-internet/) is unused, the illustrative subtotal is the same USD `0.4122420419216156`. This does not satisfy encrypted delivery. If the allowance is already exhausted and all 100 billed GB fall in the first paid tier, the [AWS Data Transfer rate file](https://pricing.us-east-1.amazonaws.com/offers/v1.0/aws/AWSDataTransfer/current/us-east-1/index.json), checked 2026-11-04, adds `100 × USD 0.09 = USD 9`, for USD `9.412242041921616` before tax and rounding. Other tiers or partial allowance use change that amount.

The alternative CloudFront flat-rate Free bundle can offset storage too, subject to eligibility and its included services. It is not combined with the pay-as-you-go allowances or startup credits in this example. No assertion is made that the selected configuration is the cheapest for every account or application.
