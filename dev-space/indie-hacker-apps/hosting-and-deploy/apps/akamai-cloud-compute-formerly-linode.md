# Akamai Cloud Compute, formerly Linode

- **Official URL:** https://www.akamai.com/products/cpu
- **apps.md status:** Active (row last checked 2026-11-04). The linked CPU product page and the current compute docs describe the same offer.
- **Name and new-customer note:** Akamai completed its Linode acquisition on 2022-03-21. It announced Akamai Connected Cloud in 2023 and later renamed that platform Akamai Cloud. Linode VMs, Cloud Manager, CLI, and API continue under the Akamai Cloud name. New buyers create an Akamai Cloud account through the existing `login.linode.com` signup flow; the account guide offers Personal and Business account choices. The public US$100/60-day credit offer is for new customers only and is not a recurring free tier. Sources: https://www.akamai.com/newsroom/press-release/akamai-completes-acquisition-of-linode, https://www.ir.akamai.com/news-releases/news-release-details/akamai-unveils-akamai-connected-cloud-and-new-cloud-computing, https://www.akamai.com/faqs, https://techdocs.akamai.com/cloud-computing/docs/getting-started, https://www.akamai.com/lp/linodetube; checked 2026-11-06.
- **Shutdown, sunset, acquisition check:** Active product and documentation; no shutdown or sunset notice found. The acquisition is confirmed above. Akamai’s current Newsroom and recent Blog pages were checked, including its 2026-10-27 Akamai Cloud launch announcement; those pages show ongoing cloud investment and no Cloud Compute closure notice. This is a bounded check, not a promise about future availability.

- **Scope:** Shared CPU and Dedicated CPU Cloud Compute virtual machines, plus charges and controls attached directly to those VMs. GPU, High Memory, Accelerated/VPU, Kubernetes, managed databases, Object Storage, CDN, and Managed Services remain separate products. The products page also calls the VM families “CPU” plans; the docs and console retain the Linode name.

## Cost examples: our calculations

Calculated 2026-11-06 for one builder, a public commercial product, one custom domain already owned, normal monthly billing, no credits, no annual discount, and no optional Managed Services. **Currency: USD. Region for all VM examples: Newark, New Jersey, USA (North America price table).** Tax is extra. No invoice, login, deployment, or benchmark was performed.

- Shared CPU rates and capacity: Nanode 1 GB is US$5/month or US$0.0075/hour; Linode 2 GB is US$12/month or US$0.018/hour; Linode 4 GB is US$24/month or US$0.036/hour. Sources: https://www.akamai.com/cloud/pricing/cpu ; https://techdocs.akamai.com/cloud-computing/docs/compute-instance-plan-types
- Most services bill by rounded-up instance hours to a monthly cap. Source: https://techdocs.akamai.com/cloud-computing/docs/understanding-how-billing-works
- Core Shared CPU transfer allowances are pooled; inbound traffic is unmetered. North America egress overage is US$0.005/GB. Sources: https://techdocs.akamai.com/cloud-computing/docs/network-transfer-usage-and-costs ; https://www.akamai.com/cloud/pricing/cpu
- Backups for the 4 GB Shared CPU plan are a separate US$5/month line in the North America table and cover four restore points, not seven daily points. Sources: https://www.akamai.com/cloud/pricing/backups ; https://techdocs.akamai.com/cloud-computing/docs/backup-service
- Current public prices exclude taxes. Source: https://techdocs.akamai.com/cloud-computing/docs/tax-information

### A. Small commercial static site

Inputs: 100 MB deployed files; 1,000,000 HTTP requests; 100 GB outbound/month; 20 builds of 5 minutes; one private repository; one custom domain.

- VM: `min(730 hours × US$0.0075/hour, US$5 monthly cap) = US$5/month` for the Nanode 1 GB.
- Transfer: 100 GB is within the plan’s 1 TB pooled allowance; expected egress overage is US$0.
- Result: **US$5 before tax for the VM**. The plan’s 1 vCPU/1 GB RAM/25 GB SSD capacity is the smallest published option; actual site and build capacity is untested. Source checkout/builds, DNS/domain registration, and TLS configuration are customer-managed; domain cost is excluded.

### B. Small commercial app API

Inputs: 1,000,000 stateless HTTP requests/month; assumed 100 ms active processor work and 250 ms elapsed time per request; assumed 256 MiB working memory; 100 GB outbound; same builds/domain/private repository as A. The server planning floor is at least 1 vCPU and 1 GiB RAM for 730 hours.

- VM: choose Shared CPU Linode 2 GB (1 vCPU, 2 GB RAM, 50 GB SSD): `min(730 × US$0.018/hour, US$12 monthly cap) = US$12/month`.
- Transfer: 100 GB is within the 2 TB pooled allowance; no request-based fee is documented for this VM product.
- Result: **US$12 before tax for the VM**. Actual throughput and memory fit are untested; customer-managed deployment and TLS work are excluded as labor, not a separate Akamai fee.

### C. App plus persistent data

Inputs: B plus self-managed Postgres with at least 1 GiB RAM and 10 GB disk; one daily backup retained for seven days; 10 GB/month app-to-database traffic. Choose one larger VM so app and database share resources.

- VM: Shared CPU Linode 4 GB (2 vCPU, 4 GB RAM, 80 GB SSD): `min(730 × US$0.036/hour, US$24 monthly cap) = US$24/month`.
- Backup add-on: US$5/month in the North America table, so the **sourced subtotal is US$29 before tax**.
- Limitation: Akamai’s VM Backup service keeps daily, weekly, biweekly, and one manual point, not seven daily database dumps. Seven-day database retention needs a customer-managed dump/export destination or another backup service; its cost is unknown and is not included. The US$29 subtotal is not the full C workload total. VM backup snapshots may be inconsistent for a running database.
