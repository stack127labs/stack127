## Cost examples: our calculation

Calculated **2026-11-05** for one paying commercial builder, one private source repository and one custom domain. Use normal monthly billing, no startup credits, annual discount, Black Friday discount or optional support package. Domain registration is outside the hosting total. Global prices are USD and exclude applicable taxes. [Payment methods and currencies](https://www.hostinger.com/support/1583236-what-payment-methods-are-available-at-hostinger/); [Universal terms of service](https://www.hostinger.com/legal/universal-terms-of-service-agreement).

Define M_U as the actual normal one-month Unlimited hosting charge. That one-month quote was not established from public product/pricing pages or billing terms. It is **not** replaced by the $2.79 promotional equivalent, the $18.99 crossed-out reference, or the $16.99 renewal equivalent for a 48-month subscription. No exact normal-month total follows from those numbers.

Published inputs:
- Unlimited has 2 CPU cores, 3 GB RAM and 50 GB disk; five Node.js websites. This is shared plan capacity, not a dedicated VM. [Plan CPU, RAM, disk and database limits](https://www.hostinger.com/support/6976044-parameters-and-limits-of-hosting-plans-in-hostinger/); [Node.js runtime and process limits](https://www.hostinger.com/support/hostinger-node-js-limits-for-web-and-cloud-plans/).
- Private GitHub, ZIP and local CLI inputs are supported. Managed SSL/CDN and daily backups are included; the public offer advertises unlimited requests/bandwidth subject to operating limits and fair use. [Web Apps Hosting features](https://www.hostinger.com/web-apps-hosting); [Local project/CLI deployment](https://www.hostinger.com/support/how-to-deploy-a-website-with-the-hostinger-cli/).
- Dependency installation and build each have a 15-minute time limit. No separate per-build usage price is published. [Deployment tutorial with build limits](https://www.hostinger.com/ng/tutorials/how-to-deploy-a-website-from-claude-code/).
- No tested throughput, peak concurrency, CPU performance or guaranteed per-app RAM allocation is assumed.

### A. Small commercial static site

Inputs: 100 MB deployed files; 1,000,000 requests/month; 100 GB outbound; 20 builds × 5 minutes = **100 build minutes**; one private repository and one custom domain.

Compatibility: supported in principle as a static frontend built through the Node.js workflow. Static output does not need a persistent web process. 100 MB is below the 50 GB plan disk cap, but dependencies, build folders, other websites and inode use also count. The private repository can remain local if the CLI/ZIP route is used. [Node.js setup and release layout](https://www.hostinger.com/support/how-to-deploy-a-nodejs-website-in-hostinger/); [Plan CPU, RAM, disk and database limits](https://www.hostinger.com/support/6976044-parameters-and-limits-of-hosting-plans-in-hostinger/); [Local project/CLI deployment](https://www.hostinger.com/support/how-to-deploy-a-website-with-the-hostinger-cli/).

Known included-component calculation: additional request/CDN charge for the stated normal traffic = **$0** under the flat-price/unlimited-request offer; additional managed certificate charge = **$0**; daily backup feature = **$0 additional** on the eligible plan. These are included features, not an unlimited-compute allowance. [Web Apps Hosting features](https://www.hostinger.com/web-apps-hosting); [Daily backup retention](https://www.hostinger.com/support/1665153-how-to-activate-daily-backups-in-hostinger/); [Free certificate issue and renewal](https://www.hostinger.com/support/1583258-how-to-install-lifetime-ssl-at-hostinger/).

Formula: **A = M_U + $0 included requests/delivery + $0 SSL + $0 included backup feature**, plus applicable tax and any compulsory charge not established in the public fee disclosures. Build time is within the published stage ceiling, but build resource fit is untested. **Full normal-month total unknown because M_U is unknown.** No promo is used as the answer.

### B. Small commercial app API

Inputs: 1,000,000 requests/month; assumed 100 ms active CPU and 250 ms elapsed/request; 256 MiB working memory; 100 GB outbound; A's builds, private repository and domain; running for **730 hours**.

Selection: Unlimited is the smallest documented managed Node.js tier, with 2 CPU cores and 3 GB plan RAM. It exceeds the minimum nominal capacity in the workload in principle, but there is no verified reservation of a dedicated vCPU or per-app memory. 250 ms is below the 120-second HTTP cap; actual performance at peaks is untested. [Plan CPU, RAM, disk and database limits](https://www.hostinger.com/support/6976044-parameters-and-limits-of-hosting-plans-in-hostinger/); [Node.js runtime and process limits](https://www.hostinger.com/support/hostinger-node-js-limits-for-web-and-cloud-plans/).

Our arithmetic: 1,000,000 × 0.100 seconds = **100,000 active CPU-seconds** of assumed app work. This does not become a function-time bill: the service is charged by subscription, not that workload counter. Staying online for 730 hours does not create a published per-hour tariff. [Express.js hosting and fee behavior](https://www.hostinger.com/web-apps-hosting/expressjs-hosting); [Managed Node.js offer](https://www.hostinger.com/nodejs-hosting).

Formula: **B = M_U + the same included-component additions as A**. No hourly normalization or CPU-second performance conversion is used. **Normal-month total unknown.** A calendar subscription and a 730-hour observation are not used to invent a billing divisor.

### C. App plus persistent data

Inputs: B plus PostgreSQL with at least 1 GiB memory and 10 GB storage, daily backup retained seven days, and 10 GB/month app-to-database traffic.

Compatibility: **external dependency required.** Hostinger web/cloud does not host a native PostgreSQL server; its included database is MySQL. Supabase is an officially documented external PostgreSQL route. Hostinger's connector does not establish a qualifying Supabase paid allocation or include that provider's database/backup/transfer bill. [Supported native databases and services](https://www.hostinger.com/support/which-databases-and-data-tools-are-supported-at-hostinger/); [External database connector](https://www.hostinger.com/support/connecting-a-supabase-database-to-a-hostinger-node-js-application/).

Formula: **C = B + P_external_Postgres(≥1 GiB RAM,10 GB storage) + B_external(daily,7 days) + N_external(10 GB app–DB traffic)**. Those external rates and allocation guarantees are not quoted by the Hostinger sources. No free Supabase plan is silently assumed to satisfy them.

Result: **Hostinger subtotal is B, whose one-month base remains unknown; combined C total unknown.** Hostinger's seven-day native-hosting backups do not automatically back up external PostgreSQL. Provisioning a Hostinger VPS to run PostgreSQL would add another self-managed product, not make it part of this managed plan. Returning to earlier app code does not restore external database records.
