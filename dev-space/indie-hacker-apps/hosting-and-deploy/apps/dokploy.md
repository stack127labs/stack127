## Cost examples: our calculations

Calculated 2026-11-04. Selected mode: free self-hosted core on one **DigitalOcean Basic Regular bundled CPU Droplet in NYC1**, 2 shared vCPU, 4 GiB RAM, 80 GiB local SSD, 4,000 GiB/month outbound, $0.03571/hour capped at $24/month. Existence 730 hours. One commercial builder, existing custom domain, private repository, no startup credit, annual discount or paid support. USD; tax extra by buyer location. Labor is not priced.

### A. Small commercial static site

Inputs: 100 MB deployed files; 1,000,000 requests, 100 GB outbound/month; 20 five-minute builds, one private repository and custom domain. Dokploy static build uses NGINX: https://docs.dokploy.com/docs/core/applications/build-type (checked 2026-11-04).

`software $0 + min(730 × $0.03571, $24 monthly cap) + max(0, 93.1322574615 - 4,000) × $0.01 = $24/month before tax`.

Builds, file/image storage, request handling, local logs, included IPv4 and local proxy use the purchased VM. Existing domain/DNS and free certificate add $0 hosting fee under chosen setup. No compulsory external CDN, builder, registry or load balancer selected. Compatible by documented deployment method; actual build memory and request capacity untested. This is a selected overhead-inclusive setup, not the cheapest possible static server.

### B. Small commercial app API

Inputs: stateless app, 1,000,000 requests, 100 ms assumed active CPU and 250 ms total elapsed/request, 256 MiB working RAM; 100 GB outbound and same builds/repo/domain as A. The app plus controller share the selected 2-vCPU/4-GiB VM, with at least 1 GiB planning capacity beyond controller allowance, for 730 hours.

`software $0 + capped VM $24 + transfer overage $0 + other selected hosting meters $0 = $24/month before tax`.

CPU/memory/request/build use is inside VM allocation. Request timing assumptions do not turn shared vCPU into function-time performance or reduce idle server billing. Capacity, traffic peaks and build contention untested. No extra app framework/registry/support fee selected.

### C. App plus persistent data

Inputs: B plus one self-managed Postgres with at least 1 GiB planning memory and 10 decimal GB persistent data, daily backup retained seven days, 10 GB app/DB traffic. Select the same VM, explicitly sharing its resources as above. Persist Postgres in a named Docker volume on the VM's **local boot disk**, with at least 10 GB assigned data capacity; 80 GiB accommodates the controller/disk recommendation and extra data under this assumption. No separate block volume.

For this priced example choose **DigitalOcean's daily whole-Droplet disk backup**, not Dokploy's S3 database backup. Daily provider backup costs 30% of VM price: https://docs.digitalocean.com/products/backups/details/pricing/ (verified March 9, 2026); retained seven days: https://docs.digitalocean.com/products/backups/getting-started/quickstart/ (verified September 3, 2026). Checked 2026-11-04.

`software $0 + VM $24 + DB software/inside-VM storage $0 incremental + daily backup (0.30 × $24 = $7.20) + same-host DB traffic $0 + public transfer overage $0 = $31.20/month before tax`.

This backs up boot-disk files, including local volume data and controller state, as a crash-consistent system image. It is not transaction-aware Postgres logical backup or offsite geographic protection. Provider excludes attached volumes and unflushed RAM/cache: https://docs.digitalocean.com/products/backups/details/limits/ (verified June 17, 2025; checked 2026-11-04). Recovery untested. If the intended scenario requires database-consistent dumps, this disk-backup estimate does not satisfy that stronger condition.

Dokploy's database-backup alternative is more specific: pg_dump plus gzip to S3, with cron schedule. It needs separate object-storage pricing and a verified seven-day retention setup. Those inputs are not established here, so no exact native-backup total is claimed. Source https://docs.dokploy.com/docs/core/databases/restore and https://docs.dokploy.com/docs/core/databases/backups , checked 2026-11-04. Code rollback does not restore database data.

Cloud is an alternative controller service. Keeping this same one-server infrastructure would add the advertised Hobby $4.50/month/server, but its checkout currency/tax and backup/job limit interpretation remain unresolved. No final mixed-currency Cloud total is published. It may need less server overhead because Dokploy hosts the controller; no new minimum application-server quote is inferred without sizing evidence.
