### A. Small commercial static site

Inputs preserved: 100 MB deployed files; 1,000,000 HTTP requests; 100 GB outbound/month; 20 × 5-minute builds = **100 build minutes**; one private source repository; one custom domain. Scalingo's static guide runs a Node/Express or Nginx server in an application container. Use one S container, 256 MB RAM/low CPU priority, as the smallest listed ongoing runtime. The 100-MB files alone fit the 2-GiB image limit; application/server dependencies must also fit. No throughput benchmark was performed.

Known 730-hour runtime subtotal: **€7.20 × 730 ÷ 720 = €7.30**. For exactly thirty days instead, the runtime estimate is €7.20. Incoming/outgoing traffic have explicit zero fees, so 100 GB has **€0 transfer charge**. Custom domain attachment, automatic TLS, basic metrics/log archives/collaborators are included. The normal app is served through regional routers; no compulsory CDN is documented. A private repository can deploy through ordinary Git without requiring a paid Git-provider integration.

**Complete hosting total: unknown.** Formula: **€7.30 + U_build(100 minutes)**, plus any separately contracted charge not established by this public tariff. An explicit builder minute price or statement that builds are included/free was not found after checking the public pricing page, billing process, deployment limits/process and GTC, plus targeted official-site searches. The public table does not list a request fee, but silence is not turned into a new invented request rate. No optional image export, VPN, worker or database is included.

Fit: static serving is documented, but the 1M-request/100-GB workload's actual performance on S is untested. This is a runtime-hosted static site, with no managed worldwide edge-cache claim.
