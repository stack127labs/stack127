## Cost examples: our calculations

Calculated on 2026-11-05. Use **Singapore (`ap-southeast-1`), USD before tax**, one builder, normal usage, no trial credit, annual discount or optional paid support. Exclude domain registration. [Tax/currency terms](https://www.alibabacloud.com/help/en/legal/latest/legal-payment-and-tax-terms) govern the actual account; no currency conversion is performed.

These examples use **CPU elastic functions**, minimum instances 0, default 512 MB temporary disk, concurrency 1, no session affinity, deep sleep or stored instance snapshot. Code is uploaded directly as a ZIP/folder after building locally; no optional ACR image, OSS deployment bucket, API Gateway, CDN or NAT Gateway is selected. [Web creation](https://www.alibabacloud.com/help/en/functioncompute/creating-a-web-function) documents direct code upload and a native HTTP endpoint. [CPU specifications](https://www.alibabacloud.com/help/en/functioncompute/instance-types-and-specifications) restrict valid CPU/RAM combinations. The default function URL forces attachment downloads, so all examples bind the specified custom domain.

[CU billing](https://www.alibabacloud.com/help/en/functioncompute/billing-overview-of-fc) uses **configured resources × elapsed execution duration**, rather than measured CPU work. [Pay-as-you-go rules](https://www.alibabacloud.com/help/en/functioncompute/pay-as-you-go-billing-methods) supply the standard Singapore rate of USD 0.000020/CU in the first regional monthly tier, per-function hourly CU ceiling-rounding and the USD 0.01 minimum for each function-hour with activity or continuous resources. No old monthly 400000-GB-s/one-million-request allowance is deducted. The special discounted CU tariff ended August 27, 2026.

Common non-compute items:

- **Builds/private source:** `20 × 5 = 100 build minutes` on an existing local machine, using [Serverless Devs' local build workflow](https://www.alibabacloud.com/help/en/functioncompute/what-is-serverless-devs). No FC hosted builder is purchased. Local hardware/electricity or a separately chosen CI provider's fees are outside the metered FC subtotal; FC does not thereby include a private Git hosting subscription.
- **100 GB outbound:** [current CDT tariff](https://www.alibabacloud.com/help/en/cdt/internet-data-transfers/) provides an account-shared 200 GB monthly pool outside mainland China. If the pool is otherwise unused and this BGP traffic qualifies, `max(100 − 200, 0) = 0 billed GB`, so USD 0 CDT transfer. If no free quota is available, first-tier Singapore transfer is `100 × USD 0.100 = USD 10`. This is a transfer sensitivity, not an extra fee added while the free quota is available. The old FC transition notice's 10 GB quota is not used.
- **Logs:** keep [default SLS logging](https://www.alibabacloud.com/help/en/functioncompute/configure-the-logging-feature-1) enabled for operation. Let `L` be the monthly SLS bill for actual ingestion, indexes, storage, metrics and retention after applicable SLS allowances. [SLS billing](https://www.alibabacloud.com/help/en/sls/billable-items) is separate. For a pay-by-feature LogStore, the [Singapore-applicable standard table](https://www.alibabacloud.com/en/product/log-service/pricing) lists USD 0.045/GB read/write, USD 0.0875/GB indexing and USD 0.002875/GB-day log storage, each with its listed allowance; operations/shards have additional meters. Let billed quantities after applicable allowances be R GB read/write, I GB indexed and D GB-days storage: those three components are our calculation `USD 0.045R + USD 0.0875I + USD 0.002875D`, before other applicable SLS meters. The workload supplies no log bytes, index policy or telemetry volume, so `L` is unknown; it is not made zero by the FC trial.
- **HTTPS:** [custom-domain settings](https://www.alibabacloud.com/help/en/functioncompute/configure-custom-domain-names) accept a purchased/selected Alibaba certificate or manual PEM upload. Let `C_TLS` be the monthly certificate cost under the builder's chosen arrangement. Existing externally obtained certificates can be uploaded, but automatic free issuance/renewal by FC was not established. This research does not assume a paid certificate is compulsory or that its issue/renewal has no cost.
- **Code artifacts:** no ACR/NAS/OSS artifact service is selected for the direct-upload model. This is a deployment choice, not a promise those separate products are free.

### A. Small commercial static site

Inputs: 100 MB deployed files, 1000000 HTTP requests, 100 GB outbound, 100 local build minutes, one private source repository and one custom domain.

A web function can serve packaged static files through an HTTP server. In Singapore, the 500 MB console ZIP quota allows room for this workload if the final package, including its server/dependencies, stays within that quota; the raw files alone do not determine final package size. The [web guide](https://www.alibabacloud.com/help/en/functioncompute/web-functions) explains server/response handling. This is a function serving files, not a storage-only/CDN static plan.

Choose a valid **0.10 vCPU + 128 MB** allocation; using the [billing example's 512 MB = 0.5 GB convention](https://www.alibabacloud.com/help/en/functioncompute/billing-overview-of-fc), 128 displayed MB represents 0.125 billing GB. The [CPU ratio rule](https://www.alibabacloud.com/help/en/functioncompute/instance-types-and-specifications) permits this pair. No capacity benchmark was performed.

Let `T_h` be total billed active instance-seconds in hour `h`, and `N_h` be requests in that hour. At concurrency 1:

```text
CPU CU_h    = 0.10 × T_h
Memory CU_h = 0.125 × T_h × 0.15
Request CU_h = N_h / 10000 × 75
Total CU_h = 0.11875 × T_h + 0.0075 × N_h
FC_h = max(USD 0.01, ceil(Total CU_h) × USD 0.000020)
```

Apply the minimum only to hours with activity/continuous usage. At zero instances and no requests, that hour has no runtime charge. Monthly FC compute is the sum of applicable hourly charges, subject to the regional tier. The million requests contribute **7500 CU**, or **USD 0.15 before hourly rounding/minima**. Active file-serving time is not given, so a numeric compute total cannot be inferred from request count and 100 GB alone.

If there is activity in every one of 730 hours, the hourly minimum alone creates **at least `730 × USD 0.01 = USD 7.30`** of FC compute charges. More compute can raise it. Full A cost remains `FC_A + CDT + L + C_TLS`, with `FC_A`, `L` and certificate arrangement unresolved. A very small allocation is not proven to satisfy the requested traffic pattern.

### B. Small commercial app API

Inputs: 1000000 requests; assumed 100 ms processor work and 250 ms elapsed time each; 256 MiB working memory; 100 GB outbound; same builds/domain/private source.

Choose **1 vCPU + 1024 MB (1 billing GB)** to provide CPU headroom and satisfy the documented CPU:RAM constraint. The working-memory assumption is not itself a valid 1-vCPU/256-MiB FC allocation. Use concurrency 1 and minimum instances 0. We assume the specified 250 ms elapsed duration actually holds for this chosen allocation; no equal-performance or load-test claim is made.

Our calculation before per-hour rounding/minima and additional lifecycle time:

- Elapsed instance time: `1000000 × 0.250 s = 250000 s`.
- CPU: `1 vCPU × 250000 s × 1 CU/vCPU-s = 250000 CU`.
- Memory: `1 GB × 250000 s × 0.15 CU/GB-s = 37500 CU`.
- Requests: `1000000 / 10000 × 75 = 7500 CU`.
- Default temporary disk: no paid disk quantity in this model.
- Raw usage: `250000 + 37500 + 7500 = 295000 CU`.
- Raw first-tier value: `295000 × USD 0.000020 = USD 5.90`.

**USD 5.90 is not a final monthly invoice.** If requests are approximately evenly distributed across all 730 hours (1369 or 1370 per hour), each hour's raw CPU/memory/request value is below USD 0.01, so our model gives **USD 7.30 FC compute**. Billable initialization/extra execution that pushes an hour above the minimum adds cost. Concentrating requests into fewer hours produces a different result. Retries, failed invocations that reach executing code and simultaneous release environments can also add usage.

The 100 ms processor-work assumption is `1000000 × 0.1 = 100000 processor-work seconds`; it does not replace billed `1 vCPU × 250000 elapsed seconds`. Working-memory consumption does not replace configured memory either.

Known model: **USD 7.30 compute + USD 0 qualifying CDT transfer** under the stated even-hour pattern, plus `L + C_TLS` and any extra lifecycle usage. No complete total is published because those quantities/arrangements are unspecified. A/B are alternative examples, not two apps each receiving a fresh CDT allowance.

### C. App plus persistent data

Keep B and add a **separate ApsaraDB RDS PostgreSQL Serverless Basic Edition** instance in Singapore. [Creation documentation](https://www.alibabacloud.com/help/en/rds/apsaradb-rds-for-postgresql/create-a-serverless-apsaradb-rds-for-postgresql-instance) defines 1 RCU as 1 vCPU plus 2 GB memory and a **20 GB minimum provisioned volume**, so a 10 GB purchase is not offered for this configuration. Select 1 RCU minimum/maximum, disable auto-pause, and assume 1 RCU for all 730 hours. Basic Edition is a single-node option for workloads that tolerate downtime; a production HA choice would add a second billed instance.

Using [Singapore RDS rates](https://www.alibabacloud.com/help/en/rds/apsaradb-rds-for-postgresql/pricing-of-serverless-apsaradb-rds-for-sql-server-instances):

- Compute: `1 RCU × 730 h × USD 0.0796/RCU-h = USD 58.108`.
- Storage: `20 GB × 730 h × USD 0.0004/GB-h = USD 5.84`.
- Database compute/storage subtotal: **USD 63.948**.
- B's modeled FC compute plus that database subtotal: `USD 7.30 + USD 63.948 = USD 71.248`, before logs, TLS, extra lifecycle usage and any billable backup excess.

[Backup policy](https://www.alibabacloud.com/help/en/rds/apsaradb-rds-for-postgresql/back-up-an-apsaradb-rds-for-postgresql-instance): select every day and retain seven days. Cloud-disk instances use snapshots; Basic Edition lacks log-backup point-in-time recovery. [Backup storage terms](https://www.alibabacloud.com/help/en/rds/apsaradb-rds-for-postgresql/billable-items-and-pricing-for-the-backup-storage-of-an-apsaradb-rds-for-postgresql-instance) give a `20 GB × 200% = 40 GB` free quota and a generic international excess-snapshot rate of USD 0.00004/GB-hour. That table is not split by region; it is applied here to the Singapore model, with its hourly context preserved.

Let `S_h` be retained backup GB at each billed hour. Our backup formula is:

```text
Backup excess = USD 0.00004 × Σ_h max(S_h − 40 GB, 0)
```

Do not infer `S_h` from “seven days” or assume snapshots always occupy seven complete volume copies. As an illustrative sensitivity only, constant 70 GB retained all month would cost `(70 − 40) × 730 × USD 0.00004 = USD 0.876`. This is our storage assumption, not a vendor backup-size promise.

Use [same-region VPC connectivity from FC](https://www.alibabacloud.com/help/en/functioncompute/access-the-rds-postgresql-database) and the [RDS internal endpoint](https://www.alibabacloud.com/help/en/rds/apsaradb-rds-for-postgresql/how-do-i-connect-to-an-apsaradb-rds-instance) for the 10 GB/month app/database traffic. The RDS connection guide describes same-VPC traffic as free; applying that stated network rule to this same-VPC architecture is our interpretation. No cross-region network, public gateway or paid database proxy is selected. Confirm the actual linked services' meters before publishing a complete quote.

C remains **USD 71.248 + backup excess + L + C_TLS + additional FC lifecycle usage**, under the stated capacity/traffic assumptions. RDS storage can expand automatically and is not automatically reduced afterwards. A function rollback does not restore database data; restoring a snapshot may require another billed database instance.

Old rates/free quotas are not combined with CU rates. The published CU promotion expired before this research date.

- **HTTP limits:** [Web Functions](https://www.alibabacloud.com/help/en/functioncompute/web-functions) gives 8 KB headers and 32 MB synchronous body; [shared responsibility](https://www.alibabacloud.com/help/en/functioncompute/shared-responsibilities-1) says 4 KB and 16 MB. No exhaustive current accepted-country or named-country ban list was established in those pages, Membership Agreement, payment docs or targeted official searches. Singapore hosting does not make all other legal/account restrictions disappear.
