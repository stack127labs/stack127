## Current status and retirement notices

**Azure Functions is active. No whole-product shutdown, sunset or acquisition notice was found in the checked official product, pricing and hosting/runtime sources.** [home](https://azure.microsoft.com/en-us/products/functions/), [price](https://azure.microsoft.com/en-us/pricing/details/functions/), [scale](https://learn.microsoft.com/en-us/azure/azure-functions/functions-scale), [versions](https://learn.microsoft.com/en-us/azure/azure-functions/functions-versions). Checked 2026-11-05.

- **Linux Consumption retires September 30, 2028.** It is a legacy plan with no new features/language versions; Windows Consumption is not covered by this Linux retirement. Current guidance recommends Flex Consumption for new serverless apps. [consumption](https://learn.microsoft.com/en-us/azure/azure-functions/consumption-plan), [scale](https://learn.microsoft.com/en-us/azure/azure-functions/functions-scale), [migrate](https://learn.microsoft.com/en-us/azure/azure-functions/migration/migrate-plan-consumption-to-flex). Checked 2026-11-05.
- **Runtime v1 support ended September 14, 2026; v2/v3 are unsupported. Linux Consumption v3 apps stop running after September 30, 2026.** Move to runtime v4 and an appropriate supported plan. [versions](https://learn.microsoft.com/en-us/azure/azure-functions/functions-versions), [consumption](https://learn.microsoft.com/en-us/azure/azure-functions/consumption-plan). Checked 2026-11-05.
- **November 10, 2026 deadlines:** .NET in-process model, .NET 8, .NET 9 and PowerShell 7.4 reach the current listed support end date, five days after this check. The current .NET 9 table explains the extension from its earlier expected date. [versions](https://learn.microsoft.com/en-us/azure/azure-functions/functions-versions), [inprocess](https://learn.microsoft.com/en-us/azure/azure-functions/dotnet-isolated-in-process-differences), [dotnet](https://learn.microsoft.com/en-us/azure/azure-functions/dotnet-isolated-process-guide). Checked 2026-11-05.
- **Functions on Container Apps V1 retires September 30, 2027 and then stops processing.** Migrate from the legacy Microsoft.Web integration to native V2 Microsoft.App/kind=functionapp. This is not retirement of all Container Apps-hosted Functions. [functionretire](https://github.com/microsoft/azure-container-apps/issues/1843), [aca](https://learn.microsoft.com/en-us/azure/azure-functions/functions-container-apps-hosting), [acaV2](https://learn.microsoft.com/en-us/azure/container-apps/functions-overview). Checked 2026-11-05.
- **Python 3.10 support presentation conflicts:** the Flex supported-stack table includes it, while the runtime schedule omits it and Advisor lists retirement October 1, 2026. Do not choose that stale table entry as a supported new runtime. [flex](https://learn.microsoft.com/en-us/azure/azure-functions/flex-consumption-plan), [versions](https://learn.microsoft.com/en-us/azure/azure-functions/functions-versions), [advisor](https://learn.microsoft.com/en-us/azure/advisor/advisor-how-to-use-service-upgrade-retirement-recommendations). Checked 2026-11-05.

Scope: managed Azure hosting with **Flex Consumption**, **legacy Consumption**, **Elastic Premium**, **Dedicated/App Service** and **Container Apps V1/V2** kept separate. Conditional self-host/Arc notes do not imply those modes inherit the managed-host SLA. Azure storage, databases, telemetry, gateways and registries retain separate costs/limits.
