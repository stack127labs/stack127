## Cost examples: our calculations

Calculated on 2026-11-06. The server location is **FI-HEL1, Helsinki, Finland**. UpCloud lists the selected Starter prices as **Global EUR monthly prices**, before local taxes. Each plan is hourly billed and capped at 672 hours per month. We assume a current custom domain is already registered, no startup credit, no annual discount, no paid support upgrade, and no external CI bill. The source price page gives the current price scope; the compute location is HEL1.

### A. Small commercial static site

Inputs: 100 MB deployed files, 1,000,000 HTTP requests, 100 GB outbound transfer, 20 builds of 5 minutes, one private source repository, one custom domain. Use one Starter 1 CPU/1 GB/10 GB VM and run the build on the same server.

- Server: `1 × €3/month = €3/month` (Starter; Global EUR; FI-HEL1 compute; before tax).
- Transfer: `100 GB < 0.5 TB fair-transfer allowance = €0 additional egress fee` under the standard policy.
- Storage and IPv4: included in this Starter plan.
- Builds: no separate UpCloud build meter; they use the already-priced VM. External CI, if chosen, is outside this total.
- **Known UpCloud hosting subtotal: €3/month before tax.** DNS/domain and TLS configuration are customer-managed; outside fees, if any, are excluded. The workload’s fit and peak throughput are not benchmarked.

### B. Small commercial app API

Inputs: 1,000,000 requests/month; 100 ms active CPU work and 250 ms total elapsed time per request; 256 MiB working memory; 100 GB outbound; same build schedule and custom domain; 1 CPU/1 GiB minimum server for 730 hours.

- Server: `1 × €3/month = €3/month` (Starter; Global EUR; FI-HEL1; before tax). The 672-hour monthly cap means a 730-hour calendar-month run does not exceed the published monthly plan cap.
- Modeled active CPU time: `1,000,000 × 0.100 s = 100,000 CPU-seconds`. There is no per-request or CPU-second charge on the always-on VM plan.
- Transfer: `100 GB < 0.5 TB allowance = €0 additional egress fee` under standard Fair Transfer.
- **Known UpCloud hosting subtotal: €3/month before tax.** TLS/domain costs outside UpCloud are excluded; request throughput is unknown until the app is deployed and measured.

### C. App plus persistent data

Inputs: Scenario B plus PostgreSQL with at least 1 GiB memory and 10 GB database storage; daily backup retained seven days; 10 GB/month app-to-database traffic. Use one Starter 1 CPU/4 GB/30 GB VM in FI-HEL1. This is a single-server, self-managed database arrangement with no high availability.

- Server: `1 × €10/month = €10/month` (Starter 1 CPU/4 GB/30 GB; Global EUR; FI-HEL1; before tax).
- Week Simple Backup: `€10 × 20% = €2/month` for seven daily backups.
- App-to-database traffic on the same VM: no separate network traffic meter.
- Outbound traffic: 100 GB is below the plan’s 1 TB Fair Transfer limit.
- **Known UpCloud total: €10 + €2 = €12/month before tax.** The 30 GB disk is total included system storage, with 10 GB reserved by assumption for database data. Any extra volume, managed database, domain, or support package is outside the estimate.
