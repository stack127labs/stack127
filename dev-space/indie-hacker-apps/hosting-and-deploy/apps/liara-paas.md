### A. Small commercial static site

Inputs: 100MB deployed files; 1,000,000 HTTP requests/month; 100GB outbound; 20 builds × 5 minutes; one private repository; one custom domain.

Select Earth/Base: 0.512GB RAM, 0.5 vCPU and 5GB SSD. The [Static deployment guide](https://docs.liara.ir/paas/static/how-tos/deploy-app/), checked 2026-11-05, supports console, CLI and GitHub deployment. A local checkout of the existing private repository can be uploaded by CLI, so the estimate does not assume a paid private-repository integration tier.

**Our calculation, displayed monthly price:** 475,000 hardware + 275,000 Base feature package = **750,000 toman/month hosting-capacity subtotal**.
