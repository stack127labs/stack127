# Upsun Cloud, formerly Platform.sh

Lifecycle check: **Active Cloud hosting; renamed, not a verified shutdown.** The company announced the Platform.sh → Upsun rebrand on 23 September 2025. Current pricing and September 2026 terms call the service **Upsun Cloud**. The older rebrand landing page calls Platform.sh **Upsun Fixed** and the flexible product **Upsun Flex**; current terms restrict Fixed Organizations to legacy customers. Research and prices below cover the flexible Cloud offer for new customers. No acquisition or Cloud-wide sunset notice was found in the official product, pricing, rebrand, legal, runtime and status sources checked. [Company announcement](https://upsun.com/blog/platformsh-evolves-into-upsun/), [older naming page](https://upsun.com/platform-sh-is-now-upsun/), [current edition terms](https://upsun.com/trust-center/legal/service-specific-terms/), checked 2026-11-05.

Component sunset: the current composable-image guide lists Nix 25.11, 25.05, 24.11 and 24.05 as retired; 26.05 is supported. Node.js 20 and older are in Sunset for existing projects and unavailable for new projects. These are runtime/image lifecycle rules, not a product closure. [Composable images](https://developer.upsun.com/docs/configure-apps/app-reference/composable-image), [Node.js lifecycle](https://developer.upsun.com/docs/languages/nodejs), checked 2026-11-05.

Status at research: public feed has no unresolved incident entry, but shows emergency maintenance in progress in eu/Ireland, eu-5/Sweden and fr-3/France. ## Cost examples — our calculation

Calculation date: 2026-11-05. All arithmetic below is ours, not an Upsun quotation. Use current flexible Cloud billing in **EUR**, one licensed builder, one project, eu/Ireland, one custom domain, normal monthly billing, no annual commitment, no startup credit and no optional support upgrade. Domain registration is outside the hosting subtotal. Taxes are additional under [TOS 13](https://upsun.com/trust-center/legal/tos/), checked 2026-11-05. The regional 3% credit is not applied because eu is not an eligible region in the [region guide](https://developer.upsun.com/docs/development/regions), checked 2026-11-05.

The current [pricing page](https://upsun.com/pricing/), checked 2026-11-05, calls hourly resource prices estimates based on a 732-hour average month and bills allocations per second. The examples use the required **730 hours**, so resource arithmetic is an estimate using those displayed hourly figures, not a claim about exact invoice rounding. The page does not define how the profiles’ MB become billable GB. Both conversion models are shown explicitly as sensitivity calculations; neither is claimed as verified metering.

The recurring First Project Incentive is separate from a startup credit: it covers the fee components every month while eligible. Let:

- `F = €9 project + €10 user = €19/month`.
- `K = €19/month` for an eligible full-month first-project setup; `K = €0` if the incentive does not apply. See the [offer conditions](https://upsun.com/faq/), checked 2026-11-05.
- `S = 0.10 × the provider’s “global spend” support basis`. Standard support is mandatory. Pricing, FAQ, billing docs and TOS do not define exactly which fees/credits enter that basis or the order of the incentive versus support calculation. Therefore `S` is not silently removed or assigned a guessed amount.
- `m_A`, `m_B`, `m_DB` are the billable GB quantities for the published 64 MB, 1920 MB and 1408 MB allocations. No verified MB/GB mapping was found.

Use one active production environment, default stop/start deployment and no previews/workers/CDN. This avoids optional rolling-deployment overlap. It also means short deployment interruptions are possible; the calculation does not purchase a zero-downtime promise. [Deployment lifecycle](https://developer.upsun.com/docs/core-concepts/build-deploy), checked 2026-11-05.

### Shared traffic, build and domain inputs

For each scenario, 1,000,000 incoming requests and 100 GB outgoing data are delivered by the origin:

`Request excess = (1,000,000 − 500,000) / 100,000 × €1 = €5/month`.

`Egress excess = (100 − 10) GB × €0.03 = €2.70/month`.

Thus `origin traffic = €7.70/month`. This assumes the published additional-request unit is charged proportionally or in the five complete units present here; no fractional-unit rounding assumption is needed. [Origin rates](https://upsun.com/pricing/), checked 2026-11-05.

Twenty five-minute builds equal `100/60 = 5/3 hours`. For an explicitly selected 1-vCPU/2-GB builder:

`CPU = 1 × 5/3 = 1⅔ CPU-hours < 2.5 included`;

`RAM = 2 × 5/3 = 3⅓ GB-hours < 5 included`.

Build excess is therefore **€0 under this allocation assumption**, provided each stated build really completes in five minutes. The source does not benchmark that duration or publish builder selection bounds. The exact unassumed build formula is:

`€0.033 × max(0, build_CPU_hours − 2.5) + €0.013 × max(0, build_GB_hours − 5)`.

[Build allowances and allocation controls](https://developer.upsun.com/docs/manage-resources/build-resources), [build prices](https://upsun.com/pricing/), checked 2026-11-05. Source-code build support is used; Docker images would require an external image build, outside these inputs.

## Field problems

- **05/08/09:** a recurring first-project fee credit is neither an ongoing free compute plan nor a startup grant. The current offer must retain its changing conditions beside the base fees.
- **06/07/15:** Upsun couples shared CPU and memory through profiles and uses MB in the tables versus GB in billing. Keep original units and explicitly qualify any conversion. A 1-vCPU HIGH_CPU app does not meet the comparison memory floor.
- **12/15:** 100 build minutes do not give CPU/RAM-hours without builder sizing. The chosen 1-vCPU/2-GB build assumption fits included units arithmetically; its five-minute completion time is untested.
- **13/15/33:** “no optional support package” cannot remove the public default +10% support charge. The exact spending basis is not defined in the pages read, so the estimate remains a formula.
- **15/25/31:** provisioned database disk, usable database payload and billable backup bytes are different quantities. Seven-day retention is configurable but not the default; no snapshot size is supplied by fields.md.
- **17:** project-data residency does not cover every account, support, telemetry and optional CDN data flow. The DPA and subprocessor list limit a blanket “EU-only” label.
- **18/20/36:** public Docker image support is documented separately from native source builds. It does not turn the managed platform into an installable control panel or make all Docker registries/images verified.
- **22/24:** runtime-specific PHP settings, route ports, cron/task timeouts and HTTP-proxy limits need separate scopes. A generic “unlimited request duration” claim was not defensible from the current technical docs.
- **28/31/34:** a Git rollback, a full environment restore, a raw database export and access to a deleted project are different recovery paths.
- **37:** freshness is research metadata rather than a hosting capability, but is counted as one attempted field because the approved schema includes it.
