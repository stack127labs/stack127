## Lifecycle and access notices

**Active public Standard and Flexible offer. No whole-App-Engine shutdown, sunset or acquisition notice found in the current offer, release notes, runtime schedules and feature-deprecation pages.** Migration options to Cloud Run do not establish that App Engine itself is closing. [offer](https://cloud.google.com/appengine), [Standard releases](https://docs.cloud.google.com/appengine/docs/standard/python3/release-notes), [Flexible releases](https://docs.cloud.google.com/appengine/docs/flexible/python/release-notes), [deprecation policy](https://docs.cloud.google.com/appengine/docs/deprecations), [past shutdowns](https://docs.cloud.google.com/appengine/docs/standard/deprecations/shut-down); checked **2026-11-05**.

**Important Standard legacy deadline:** first-generation **Go 1.11, Java 8, PHP 5.5 and Python 2.7** were deprecated **January 31, 2026** and list **January 31, 2027** decommission. Deprecated deployments cannot be re-enabled through the former policy exception; decommissioned workloads may be disabled. [Standard schedule](https://docs.cloud.google.com/appengine/docs/standard/lifecycle/support-schedule), [lifecycle effects](https://docs.cloud.google.com/appengine/docs/standard/lifecycle/runtime-lifecycle); checked **2026-11-05**.

**Current-runtime support dates:** Node.js 20 support ended **April 30, 2026**, with deprecation **April 30, 2027** in both environments. Python 3.10 support ended **October 4, 2026**; its next dates differ by environment. **Flexible .NET 8 support ends November 10, 2026**, five days after this check. Use supported replacements rather than taking an older tutorial runtime as current. Node.js 26/Python 3.15 remain Preview in the checked schedules. [Standard dates](https://docs.cloud.google.com/appengine/docs/standard/lifecycle/support-schedule), [Flexible dates](https://docs.cloud.google.com/appengine/docs/flexible/lifecycle/support-schedule), [stdpolicy](https://docs.cloud.google.com/appengine/docs/standard/lifecycle/runtime-lifecycle), [flexpolicy](https://docs.cloud.google.com/appengine/docs/flexible/lifecycle/runtime-lifecycle); checked **2026-11-05**.

**Related feature/dependency notices:** App Engine spending limits shut down **July 1, 2023**. New deployment guidance moved from retired Container Registry to Artifact Registry. These notices must not be confused with a whole-product closure or a current hard spending cap. [spending-limit shutdown](https://docs.cloud.google.com/appengine/docs/standard/deprecations/shut-down), [registry migration notice](https://docs.cloud.google.com/appengine/docs/standard/python3/release-notes); checked **2026-11-05**.
