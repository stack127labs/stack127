## Cost examples

Each estimate is **our calculation**, not a vendor quote. Prices are BRL with taxes included. Calculations use the SE1 region and the published 730-hour reference month. Current zero-rate egress/IP figures may change; the Help Center conflicts on public IPv4 charges.

### A. Small commercial static site

- Inputs: 100 MB of site files, 1,000,000 HTTP requests, 100 GB outbound/month, 20 builds of 5 minutes, one private source repository, one custom domain.
- Fit: The VM can serve static files through customer-installed software. Magalu Cloud does not publish a managed static host or build service. Build minutes total 20 × 5 = 100 minutes; if builds run on this same VM, no separate build meter is listed, but the VM size needed for the build is not established. Domain registration is excluded by the workload definition.
- VM input: smallest SE1 Linux configuration, 1 vCPU / 1 GB RAM / 10 GB local disk, R$0.047932 per hour.
- Formula: 730 hours × R$0.047932/hour = R$34.99036; the published 730-hour reference is R$34.99. Current public egress is R$0/GiB.
- Result: **Known Magalu VM subtotal: R$34.99/month. Full workflow total unknown** because the source repository and build/deployment workflow are external or customer-managed and not priced by Magalu Cloud.

### B. Small commercial app API

- Inputs: 1,000,000 requests/month, 100 ms active processor work and 250 ms elapsed time per request, 256 MiB working memory, 100 GB outbound, same 20 builds and custom domain.
- Fit: Use one 1 vCPU / 2 GB RAM / 10 GB BV VM in SE1. The listed 2 GB RAM is above the workload's 1 GiB minimum. Workload capacity and throughput are not benchmarked.
- Formula: 730 hours × R$0.061630/hour = R$44.9899; the published 730-hour reference is R$44.99. Request count is not a separate VM meter; current 100 GB egress and public IP are listed at no charge.

### C. App plus persistent data

- Inputs: Scenario B plus PostgreSQL with at least 1 GiB RAM and 10 GB storage, daily backup retained 7 days, and 10 GB/month app-to-database traffic.
- Fit and choices: Keep the 1 vCPU / 2 GB / 10 GB VM at R$44.99/month; add the smallest listed SE1 PostgreSQL DBaaS configuration, 1 vCPU / 4 GB / 10 GB, R$94.22 per 730 hours. The DBaaS API documents 7-day backup retention by default. This is a separate managed product.

## Conflicts and unknowns

- **Public IPv4 price:** The current VM/network pricing pages list public IPs at no charge now and say charging may begin at any time. A Help Center answer says a public IPv4 is billed separately. I recorded the difference rather than picking one as certain.
- **Local disk on stop:** The Help Center's local-disk comparison says local-disk data is lost when a VM stops; its shutdown FAQ says data remains and only cache is cleared. The glossary calls local disks ephemeral. Use separate Block Storage for persistent app data.
- **Windows, resize, and snapshots:** An older Help Center limitations page says Windows is unavailable and resize/snapshots are forthcoming. Current VM product, service terms, price, and how-to docs describe Windows images, resize, and snapshots. The current public pages do not settle whether Windows is enabled for every new account, so verify the live image catalog before relying on it.
- **Disk encryption:** The Help Center's VM limitations page says stored data is not encrypted, while Block Storage docs describe encryption for attached volumes. I did not infer encryption for the VM root disk. A dedicated Help Center article on encryption failed to load; see Field problems.
- **Unknowns checked:** For hard spend caps, I checked VM pricing, the FinOps overview, price calculator, and general cloud terms; these describe forecasts and usage visibility but publish no enforceable cap. For workload data location, I checked privacy, VM overview, region, and service-term pages; they do not promise that every VM log, backup, and workload datum remains in the selected region. For buyer geography, I checked account creation, billing information, payment methods, and cloud terms; these state CPF/CNPJ and local-card requirements but do not publish a full country eligibility or sanctions list.
