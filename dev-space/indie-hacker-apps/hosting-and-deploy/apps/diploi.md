### Shared private-repository builds

The requested workload is 20 builds × 5 minutes = 100 build minutes/month. Diploi's generated workflow runs metadata on an x64 Linux runner and builds a component/environment image matrix on an ARM Linux runner. Production/staging use built images, so the GitHub dependency is part of the deployment path. [Actual generated workflow](https://docs.diploi.com/reference/github-action).

Current GitHub Free includes **$12 USD of shared compute usage per month**, standard ARM Linux is **$0.005/minute**, and standard x64 Linux is **$0.006/minute**. Each job rounds up separately to a whole minute. There is no currency conversion into the EUR hosting subtotal. [Current included usage](https://docs.github.com/en/billing/reference/product-usage-included); [Rates and rounding](https://docs.github.com/en/billing/reference/actions-runner-pricing); [Who pays and shared usage](https://docs.github.com/en/billing/concepts/product-billing/github-actions).

For a transparent illustration, if the 100 requested minutes are one ARM build job per run, and each of 20 metadata jobs takes at most one minute:

    Build usage value = 20 × 5 × $0.005 = $0.50 USD
    Metadata usage value = 20 × 1 × $0.006 = $0.12 USD
    Illustrated compute usage = $0.62 USD
    Extra compute charge = max($0, $0.62 − unused included compute amount)

With the full $12 allowance still unused, this illustration adds **$0 USD**. With no allowance left, it adds **$0.62 USD**. These are our calculations, not promises about actual job duration or the generated matrix. Additional development/production images and other component builds can multiply jobs. For k equal five-minute ARM matrix jobs per run, the same illustration becomes **$0.50 × k + $0.12 USD** before allowance.

The exact general formula is **sum of rounded minutes for each job × its runner rate**, less the available shared allowance, plus any billable storage. The generated matrix, metadata runtime, cache/artifact sizes and other account usage are unspecified by the workload. Thus no unconditional exact CI total is claimed. Diploi hosts deployment images in its own registry; no need for GitHub Packages storage is inferred from that. [Matrix and registry](https://docs.diploi.com/reference/github-action); [Image hosting](https://docs.diploi.com/reference/technical-deep-dive); [External storage rules](https://docs.github.com/en/billing/concepts/product-billing/github-actions).
