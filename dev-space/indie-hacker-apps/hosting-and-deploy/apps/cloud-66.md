# Cloud 66

- **Official URL:** https://www.cloud66.com/
- **apps.md status:** Active (row checked 2026-11-04). The row describes a hosted deploy manager for code deployed onto your server or provider.
- **Research start (UTC):** 2026-11-07 06:40:43 UTC
- **Research finish (UTC):** 2026-11-07 07:05:08 UTC
Minutes taken: 24.42
- **Product and retirement note:** Cloud 66 is offered now. Its official product-history page says Cloud 66 for Node was merged into Cloud 66 Deploy and is no longer a separate product, but gives no merge date. Cloud 66 Deploy v1 was deprecated in December 2022; existing customers could continue using it, while new customers could not. Cloud 66 Sites was formerly Prepress, and Cloud 66 Deploy was formerly Maestro; those are renames, not stated closures. The current Deploy docs sidebar describes v2, while the changelog announced Deploy v3 general availability in October 2025. The public pricing page now lists general containerized-app features without naming a Deploy generation, so the documentation version label is unresolved. I found no acquisition or shutdown announcement in the official About, Terms, blog index, changelog, and status pages checked. The site links to a blog and changelog, not a separate newsroom.
- **Pricing switch checked:** I clicked Monthly and Annually on the official pricing page. Developer, Team, and Business display $29, $59, and $99 per month with monthly billing, and $23, $47, and $80 per month with annual billing (annual monthly-equivalent display). Prices below are the USD amounts shown on 2026-11-07.

Cloud 66 manages app deployments on servers and storage you choose and pay for. Its subscription does not include those provider resources. Managed database backups are a separate Cloud 66 usage meter.

## Cost examples

These are our calculations, not vendor-published totals. Annual amounts use the annual monthly-equivalent price multiplied by 12. Cloud 66's help pricing guide says annual billing charges a year immediately, but the current Terms describe monthly arrears and annual credits; confirm the invoice behavior before purchase.

- **A. Small commercial static site:** Developer plan, one site, 100GB traffic, and 100 build minutes. Annual: $23 × 12 = **$276/year** (equivalent to $23/month); monthly: **$29/month**. 100GB traffic and 100 build minutes fit the Developer allowances. Provider storage and domain registration charges are not included.
- **B. Small API:** Developer plan and one 1-vCPU/1-GiB server for 730 hours. Annual Cloud 66 component: $23 × 12 = **$276/year**; monthly: **$29/month**. Formula for full total: Cloud 66 fee + provider VM for 730 hours + provider IP/storage/100GB egress. The provider and region are unspecified, so the complete total is unknown.
- **C. API plus Postgres:** Developer plan can manage up to two servers. Annual Cloud 66 component: $23 × 12 = **$276/year**; monthly: **$29/month**. Add provider cost for two 1-vCPU/1-GiB servers, storage, and internal traffic, plus **$0.38 × actual stored backup GB per month**. Cloud 66 does not publish the compressed size of the seven retained daily backups, so the exact monthly total is unknown.

## Conflicts and unknowns

- Pricing calls Free suitable for personal projects, but the Terms say users must use Cloud 66 for business purposes.
- Pricing says Free has no payment-information requirement, but the Terms describe a 14-day trial and require a card before the trial ends.
- The help pricing page says annual switching charges a year immediately; Terms describe monthly arrears and annual credits.
- The current price comparison lists $12 for each extra server; its FAQ says $12–15 per month.
- Deploy docs show v2 in the sidebar, while the changelog announced v3 GA in October 2025. Current pricing does not name the version.
- No tax-inclusion statement, provider cost total, standard-plan SLA, static CDN edge list, control-plane self-host requirements, or guaranteed support response time was found in the official pages checked.
- The official product-history page dates Deploy v1 deprecation to December 2022. It gives no date for Cloud 66 for Node's merger into Deploy.
- I checked the official About page, Terms, blog index, changelog, and public status page for acquisition, product-retirement, and shutdown news. There is no separate newsroom link in the website navigation. No acquisition or service shutdown notice appeared in those pages.

## Field problems

- Pricing and Terms appear to describe different Free-plan/trial and annual-billing models. The public documents do not reconcile the differences.
- The old Cloud 66 product-history article says Deploy v2 is the current generation, while the dated changelog announces v3 GA. Pricing does not identify which generation its tier features apply to.
- The documentation site has separate Rails, Deploy, Sites, and legacy Node sections. The product-history page clarifies the intended overlap but has stale version wording.
- The examples are necessarily partial because Cloud 66 does not rent the compute servers. Full server totals need a provider, region, and workload fit.
