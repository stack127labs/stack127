## Lifecycle and access notices

**Active public service. No whole-product shutdown, sunset or acquisition notice found in the current offer, FAQ, release notes and platform lifecycle documentation.** Cluster Mode launched **September 17, 2026** alongside Standard Mode. **Amazon Linux 2 branches retired August 6, 2026**; retired runtimes are not supported new-deployment choices. The schedule's older introductory deadline differs from the actual retirement table; both are recorded below. [offer](https://aws.amazon.com/elasticbeanstalk/), [FAQ](https://aws.amazon.com/elasticbeanstalk/faqs/), [Cluster release](https://docs.aws.amazon.com/elasticbeanstalk/latest/relnotes/release-2026-09-17-cluster-mode.html), [retirement notice](https://docs.aws.amazon.com/elasticbeanstalk/latest/platforms/platforms-retiring.html), [schedule](https://docs.aws.amazon.com/elasticbeanstalk/latest/dg/platforms-schedule.html); checked **2026-11-05**.

Beanstalk's management fee is zero in both modes. Standard buys EC2-based environment resources; Cluster adds a shared EKS control plane and EKS Auto Mode infrastructure. Those are **separate AWS resource bills**, not included hosting capacity. [mode-specific pricing](https://aws.amazon.com/elasticbeanstalk/pricing/); checked **2026-11-05**.
