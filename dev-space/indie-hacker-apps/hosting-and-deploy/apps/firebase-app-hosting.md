## Cost examples — our calculations

Calculation date: **2026-11-04**. These are our calculations, not copied vendor example totals. Choose one commercial builder, Blaze, us-central1, monthly on-demand billing, one custom domain, an existing private source checkout, and no startup/trial credits, annual discounts, or optional support. Domain registration and tax are excluded. Backend custom-domain/certificate setup is documented in the [App Hosting domain guide](https://firebase.google.com/docs/app-hosting/custom-domain), checked 2026-11-04. No separate App Hosting domain fee appears in the [pricing table](https://firebase.google.com/pricing), checked 2026-11-04; this is not a claim that every optional DNS/network service is free.

Each example assumes this workload is the only consumer of its billing account's free allowances. Shared usage elsewhere would reduce them. Workload GB means decimal bytes here: **100 GB = 100,000,000,000 bytes = 93.1322574615478515625 GiB**; 1 GiB = 1,073,741,824 bytes. This is an explicit unit conversion, not a currency conversion. Displayed dollar results below are rounded to ten decimal places; formulas retain the underlying units.

Common build input: **20 × 5 = 100 build-minutes/month**. With the currently published 2,500-minute promotional allowance, excess is `max(100 − 2,500, 0) × $0.006 = $0`. If that allowance is removed or already consumed, the same minutes at this rate cost `$0.60`. The promotion is a current general builder allowance, not startup credit, and should not be described as permanent. [Cloud Build pricing](https://cloud.google.com/build/pricing), checked 2026-11-04, supplies these inputs. App Hosting-specific build-machine control remains unverified.

Inputs from fields.md: 100 MB deployed output, 1,000,000 HTTP requests, 100 GB outbound, common builds, private source, custom domain.
