### A. Small commercial static site

Inputs: 100 MB files, 1,000,000 HTTP requests/month, 100 GB outbound, 20 five-minute builds, private source, one existing custom domain. Select Basic Regular 1 GiB rather than the smallest 512 MiB entry plan to allow more working memory. Configure an ordinary static HTTP server and Certbot on the VM.

- Compute including disk, request handling, on-server builds and logs: `min(730 × $0.00893, $6 cap) = $6`.
- Outbound: `max(0, 93.1322574615 - 1,000 included GiB) × $0.01 = $0`.
- Domain DNS, certificate, primary IPv4, monitoring/firewall: `$0` incremental under selected free/included features. No compulsory CDN/load balancer selected.
- Our total: **$6/month before tax**. Build memory/time and actual request load were not tested. This does not establish that every static-site generator fits 1 GiB.

### B. Small commercial app API

Inputs: same builds/domain/private repo and 100 GB outbound; 1,000,000 requests, assumed 100 ms active CPU and 250 ms elapsed/request, 256 MiB app working memory. Select the smallest published bundled plan meeting at least 1 vCPU/1 GiB: Basic Regular $6, running 730 hours. Guest OS/runtime share that memory.

- Server cost: `min(730 × $0.00893, $6) = $6`.
- Requests, compute work, local builds/logs: inside the rented server allocation; no added per-request fee.
- Transfer within 1,000 GiB allowance: `$0` overage. Self-managed TLS/DNS and included IP: `$0` incremental.
- Our total: **$6/month before tax**.
- The request CPU assumptions do not price the VM: it is billed while idle too. No conversion of vCPU speed to function time or claim of equal performance. Burstiness/concurrency, build memory and throughput need a later deployment test.

### C. App plus persistent data

Inputs: B plus one self-managed PostgreSQL database with at least 1 GiB app memory, 10 GB data storage, daily disk backup retained seven days, 10 GB/month app-to-DB traffic.

Selected architecture: B's separate $6 app Droplet plus a $12 Basic Regular database Droplet with 1 vCPU, 2 GiB RAM and 50 GiB local SSD. Explicit resource assumption: allow 1 GiB for Postgres and the remaining 1 GiB for guest OS/process overhead; reserve at least 10 decimal GB for database data within the 50 GiB disk. Configuration and actual adequacy untested. Keep DB data on the boot disk, not an attached volume.

- App: `$6`.
- DB VM: `min(730 × $0.01786, $12) = $12`.
- Opt-in daily DB Droplet backup: `30% × $12 = $3.60`; daily images retained seven days. This includes the DB VM's OS/disk, not an application-consistent logical Postgres dump.
- App-to-DB traffic within the same VPC: `$0` public transfer; private VPC documented free in https://docs.digitalocean.com/products/droplets/getting-started/recommended-droplet-setup/ (checked 2026-11-04). Route over private interface. Public app egress remains below allowance.
