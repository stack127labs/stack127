### B. Small commercial app API

**Not compatible as a Neocities-hosted API.** The fixed one million dynamic requests, 100 ms active CPU work, 250 ms total elapsed time, and 256 MiB working memory need an app runtime. Neocities explicitly serves static content rather than PHP or other server-side code.

The file-management API is not a function execution product. There is no Neocities CPU/memory-time formula or smallest app-server instance to quote. An external API host must be selected separately, including compute, transfer, logging, and any required gateway. A Neocities static frontend could use A's subtotal, but that is not B's full bill.

### C. App plus persistent Postgres data

**Not compatible as an all-Neocities deployment.** B still needs an external app/API host. The added database needs a separately selected PostgreSQL service with at least 1 GiB RAM, 10 GB disk, daily backups retained seven days, and pricing for the 10 GB/month app-database path.

No external provider is selected, so no database rate or all-in total is invented. The dependencies are **external API/app compute** and **external PostgreSQL, backup, and network services**. A one-click download of static site files and a 30-day deleted-site restore window do not satisfy that database-backup workload. Reuploading an older static build does not restore database data.
