## Shutdown, sunset, and acquisition check

NAVER Cloud Server remains an active product. The official service dashboard lists Server, and NAVER Cloud posted Server image/OS updates in 2026. The NAVER Cloud notices, service news, and company press-release/newsroom pages were checked; no Server shutdown or acquisition notice was found. The global portal links to the official NAVER Cloud blog; its linked post could not be fetched (cache miss), so it was not used as evidence. NAVER Cloud has announced the separate Global CDN product will end on 2026-12-31, and other unrelated services also have sunset notices. Those announcements do not apply to Server.

## Conflicts and unknowns

- Foreign signup is supported for selected **business accounts**, not universally. The official FAQ lists business signup for Korea, Singapore, Taiwan, Germany, the United States, Japan, and Thailand; individual signup is currently limited to South Korea residents. Membership country, business documents, and verification phone country must match.
- Examples quote only the South Korea region in KRW. The global calculator supports currency conversion, but public static extracts do not expose exact live Server prices for other region/currency combinations; no exchange rate or foreign-region price was guessed.
- Korean public prices exclude VAT. Whether and how tax appears on a particular foreign business invoice can depend on the billing country and tax rules; these examples are pre-VAT.
- Server type and feature availability vary by region/platform. The latest g3 configuration is documented for Korea, Singapore, and Japan; many server types in other global regions use g1/g2.
- Server prices and network, public IP, backup, disk, OS, and image charges are separate. The cost examples include a public IP and transfer but do not include optional monitoring, load balancing, support, or an external CI provider.
- The Server SLA change announced for 2026-08-15 was cancelled. The older official PDF remained the published Server SLA located during this check; the cancelled change was not applied.
- The global portal links to the official NAVER Cloud blog. The linked post at https://blog.naver.com/n_cloudplatform/224317802790 could not be fetched (cache miss); the blog was not used to support product facts. The official notices/service news, newsroom and status page were still checked.
