- One Scaleway DNS zone, if used: €0.007/hour. [Network pricing](https://www.scaleway.com/en/pricing/network/)

### A. Small commercial static site

Assumptions: 100 MB deployed files, 1,000,000 HTTP requests, 100 GB outbound/month, 20 builds of 5 minutes, one private source repository, one existing custom domain. Run a static web server and build on one STARDUST1-S; use 10 GB Block Storage for OS/site files and one public IPv4. No external CI service is included. Instantaneous request peak is unknown, so performance is not guaranteed.

- Compute: `€0.0006/hour × 730 hours = €0.438`
- Persistent storage: `10 GB × €0.000130/GB-hour × 730 hours = €0.949`
