## Cost examples: our calculation, estimated, not quoted

Workload family: **logs only**. Inputs from fields.md are 5, 50 and 250 GB/month, one builder, **30-day searchable retention**, no paid archiving. These are our comparison workloads, not Graylog's description of typical users.

Graylog Open's published software charge is **FREE**, with no licensed volume cap. No currency is needed for a zero software component, and no conversion is made. Sources: https://graylog.org/pricing/ ; https://graylog.org/products/source-available/ . Checked 2026-11-05; update dates not shown.

### License component and storage planning

Assume uniform input over a 30-day month and treat workload GB as **raw log input**. Graylog does not publish an Open GB-based vendor billing meter, so compressed GELF bytes and indexed disk bytes are not silently substituted.

Vendor architecture guidance provides:
- Hot index storage estimate = daily ingest × retention days × **120%**.
- Recommended journal capacity = daily ingest × **3 to 5**.
- High-IOPS storage, preferably SSD, for the journal and search workload.

Source: https://go2docs.graylog.org/current/planning_your_deployment/graylog_system_architecture.htm . Checked 2026-11-05; update date not shown. These are general planning formulas, not measured guarantees for parsed/indexed output, compression, replicas or query concurrency.

### Compute and total-cost limitation

The published **Core** model uses two servers: Graylog with MongoDB on one and Data Node on the other. Its diagram lists eight CPU cores per server. It prints RAM per server values of **16 for Graylog and 24 for Data Node**, but does not print the RAM unit. No GB unit or tested minimum was silently invented. Sources: https://go2docs.graylog.org/current/planning_your_deployment/graylog_system_architecture.htm ; https://go2docs.graylog.org/current/resources/images/graylog_architecture/coredeploymentarchitecture.png . Checked 2026-11-05; update dates not shown.

The architecture page calls this general guidance and says actual requirements vary with log complexity, retention, search frequency and hardware. It is not a workload-specific mapping of the three monthly input levels. Therefore no provider plan was selected and no full host price was invented. Small-scale Docker deployment is documented, but a Compose file alone is not a performance/sizing guarantee. Sources: https://go2docs.graylog.org/current/planning_your_deployment/graylog_system_architecture.htm ; https://go2docs.graylog.org/current/downloading_and_installing_graylog/docker_installation.htm . Checked 2026-11-05; update dates not shown.

A complete recurring model would be:

**compute + index/journal/metadata storage + backups + network + email/downstream services + administration**, with **0 Open software-license fee**.

Those non-license inputs are not established for the three workloads, so the final totals remain **unknown**, not zero. No annual software discount applies to a free license. Paid Graylog pricing is deliberately excluded.
