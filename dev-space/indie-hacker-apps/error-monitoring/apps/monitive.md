**Shutdown and sunset notice found first:** Monitive's official company page says the rebuilt service, code-named **Freyja**, launched **June 18, 2020**. The old generation, **Monitive Classic**, was **sunset December 18, 2020**, after users migrated. Today's Free/Pro service remains actively advertised. No current full-service shutdown or acquisition notice was found in the checked official homepage, company profile, pricing, terms and release notes or targeted official-source searches.

**Other product changes:** The July 2025 security release removed the PWA component because it could cache the interface indefinitely. March 2026 releases introduced passwordless social/email-link sign-in. These component/authentication changes do not retire the monitoring service.

**Historical interruption:** A January 19, 2023 release describes OTP abuse on January 18 and temporary disabling of signups, SMS and phone alerts that day. Later releases describe telephone acknowledgment and recipient protections. This is a dated interruption, not evidence of a current shutdown.

These are exact arithmetic using publicly displayed package counts/rates, **not complete exact-workload quotes**:

- **Own-domain status hosting is not established.** Pro includes public pages with configurable branding/slug, but neither setup guide nor current StatusPage schema documents a domain/DNS option. No domain add-on price is assumed zero.
- **A single fixed selected location is not established.** Custom-location membership requires at least three locations in the published schema; the older API tutorial recommends four for effective double checking. This is distinct from running the monitor once per minute across some shared location pool.
- **Execution totals are the editorial demand.** The public sources do not give a complete per-location scheduling/quorum definition. They are not a measured count of actual Monitive requests.
- **No per-run/retry price is published.** The displayed subscription meter is monitors. An unpriced execution surcharge, geographic multiplier or hourly host fee is not invented.

Free's ten-minute interval and single monitor do not meet these workloads. Custom monitor counts may have a different quote, but no interpolation such as a guessed per-monitor rate for exactly twenty-five is used. Selecting a published thirty-monitor package is transparent.
