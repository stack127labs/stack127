**Price and retention boundary:** Direct-billed Free includes **300K transactions/month, 5K error events and 1 GB logs**. APM, extra errors and logs have different meters/enforcement. Ordinary traces retain **seven days**, individual errors **30 days**, and standard logs **14 days**. Cost examples below flag the longer requested retention as unmet. Marketplace billing can differ: AWS documentation uses a **daily** transaction limit.
