## Status, ownership, and announcements

Request Metrics is an active browser performance and monitoring service operated by TrackJS LLC, a Minnesota company. The current blog includes a security post dated October 31, 2026, and the product blog lists a feature post dated December 22, 2025. I found no acquisition, shutdown, or sunset notice in the official blog, product blog, company page, terms, or product site checked. I did not find a separate newsroom or public changelog in the site navigation; the attempted /changelog/ address was not available.

The Request Metrics name is current. TrackJS LLC also lists TrackJS, RemoteJS, and CertKit as other products; I kept those products' features and terms out of this record. The recent blog's “host it yourself” wording is about serving the browser agent file from your own site. That agent still sends telemetry to Request Metrics. Separately, the End User Data page advertises dedicated instances or on-premises installations by inquiry. Public installation, sizing, and separate licensing details for that custom full-service option were not found.

## Cost examples: our calculations

The public rate card charges by page views, not error reports. Amounts below use the plan's stated included capacity and preserve the displayed dollar sign; the pricing page does not state an ISO currency code.

- Small, 1,000 page views/month: Free, $0/month. Formula: $0 base price; 1,000 included page views.
- Growing, 75,000 page views/month: Essentials, $37/month or $34/month on annual billing. Formula: one base plan; 75,000 included.
- Busy, 500,000 page views/month: Professional, $96/month or $88/month on annual billing. Formula: one base plan; 500,000 included.
- Standard error-report examples of 5,000, 50,000, and 500,000 reports/month cannot be priced exactly because the public rate card does not meter errors by report count. Professional includes error monitoring, but the published plan meter is page views. Added traffic block prices are not shown in the static pricing text.

## Conflicts and unknowns

- The homepage says data is resident in Canada. The DPA names Montreal hosting plus Seattle backup/cloud storage and U.S. Mailgun. The exact meaning of “resident” is not reconciled by the public sources.
- The error-monitoring feature is advertised on Professional, but the public guides do not explain issue grouping, source-map upload, release tracking, or error-count pricing. Pages checked: pricing, user guide index, browser agent install/reference, FAQ, and Data API reference.
- A browser agent file can be bundled or hosted on your domain, but it still sends telemetry to Request Metrics. The separate on-prem service offer is only described as an inquiry; public deployment requirements and license terms were not found. Pages checked: agent installation, domain forwarding, October 2026 security post, pricing, End User Data, docs overview, and terms.
- The terms and DPA were last modified 2024-07-25; the privacy policy was last modified 2020-08-06. Current product pricing, docs, and blog activity are newer, but legal copy may be stale.
- No dedicated public changelog or newsroom was located. The blog and product blog were checked for acquisition, shutdown, and sunset notices; none was found there.

## Field problems

- C05 and H01-H03 required separating two different meanings of “self-host”: serving the browser script from your site versus running the complete service on premises. The first is documented; the second is only advertised by inquiry.
- E01-E04 apply because the Professional plan currently advertises Error Monitoring, although the product's documented center is browser RUM and web performance.
- U01-U04 were applied to Lighthouse performance tests. They are not uptime checks; frequency and a crawler IP are documented, but uptime retry and maintenance behavior are not.
- A01-A02 are not applicable to the documented product because it does not describe backend tracing or host-based APM. A03 covers its real-user browser performance.
- L, S, and J fields are not applicable to the product offers checked; browser activity, synthetic tests, and email performance notices are not log management, status pages, or cron monitoring.
