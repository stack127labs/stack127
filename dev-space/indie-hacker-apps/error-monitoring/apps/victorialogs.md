## Cost examples — our calculation

All examples are **our calculation, estimated, not quoted**. Cloud prices keep the **$ symbol as printed**. A specific ISO invoice currency was not established in the checked public price/billing/contract text; no conversion is performed.

Inputs: **5 / 50 / 250 raw GB incoming per month**, **30-day searchable logs**, **one builder**, no archive. Query volume is unknown and is not silently set to zero.

### Community self-hosting

The Apache core has **no software license fee** for any of the three input volumes. Set **retentionPeriod=30d** to meet the requested history; the default seven days does not meet it. The CPU/disk must actually support that history and query workload. Optional disk-based retention can delete history earlier.

| Workload | Software license formula | License result | Complete recurring running cost |
| --- | --- | --- | --- |
| Small: 5 raw GB/month | Apache license fee = 0 | **0** | **Unknown**: compute, storage, backups, network, collection/auth/alert components and labor |
| Growing: 50 raw GB/month | Same | **0** | **Unknown**, with the same missing inputs |
| Busy: 250 raw GB/month | Same | **0** | **Unknown**, with the same missing inputs |
