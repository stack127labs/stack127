## Scope and evidence

Attempted all 27 core fields, four error fields and three performance fields: 34 distinct IDs. Session/playback monitoring and report resource windows make the performance fields relevant, with beta/availability qualifications. Console/network data is attached report context, not an established independent log product. A complete self-hosted server edition, external uptime/synthetic monitors, customer status pages and missed-job monitoring were not established; those conditional field groups are not invented.

Every row records unit, plan, edition, deployment, signal, exact source URL, UTC checked date, source revision date when shown, evidence state and a specific note. Multiple sources preserve different scope or conflicts; revision dates follow their URL order. Latest changelog entry is not treated as the latest version of every SDK. The public SDK repository's licence is separate from the hosted service.

Only the owner's six states are used. not_published means not found in named checked sources. unclear means published scope or missing scenario inputs leave the answer unresolved. conflicting keeps incompatible official claims visible. check_failed records retrieval failure, not feature absence. Calculations are our estimates, not vendor quotes.

No signup, login, form submission, support contact, installation, ingest, webhook delivery, SDK performance or payment test was performed. Public repository files and API documentation were read; no live customer API, MCP or ingestion endpoint was called. No customer data or env file was read.

### Errors: 5,000, 50,000 and 500,000 reports/month

Everframe does not price these by report count. Let **I** be the combined monthly active installs across the three apps, using Everframe's device/install definition. One person with several apps/devices is not necessarily one install. Unlimited apps/seats fit the requested builder/app count.

For at least 30 days of artifact detail, Free's 14-day standard hosted artifact window fails. Copying evidence to your own webhook receiver or attaching it to a long-lived board card is a separate retention path; no zero-cost, automatic 30-day archive of every error is assumed. Starter's 90 days and Pro's 365 days fit. The pricing formula is:

**Estimated monthly price P(R,I) = lowest monthly plan price whose install allowance ≥ I and artifact window ≥ 30 days**, subject to SDK capture limits and accepted ingest volume. R is unlimited at the plan level, so it does not choose the install tier.

| Monthly reports R | Missing input | Our calculation under explicit I ≤ 10,000 assumption | Exact result without I |
| --- | --- | --- | --- |
| 5,000 | Combined active installs | 1 Starter × $19 = $19/month | Unknown |
| 50,000 | Combined active installs | 1 Starter × $19 = $19/month | Unknown |
| 500,000 | Combined active installs | 1 Starter × $19 = $19/month | Unknown |

The install assumption above is an illustration, not an estimate of how many users produce those reports. For any of the three report volumes, the known monthly ladder with sufficient artifact retention is:

Do not price sustained usage against the temporary over-limit grace period. Paid subscriptions may move to a fitting plan after notice, and sustained overuse can suspend ingestion. Unlimited plan-level reports also does not mean every raw failure is delivered: Web/React separately throttle explicit and automatic capture to one report per fingerprint and ten per SDK instance, ingest can rate/size-limit reports, and common browser noise is filtered.
