**Lifecycle and ownership check:** Prometheus is an active, independently governed open-source project hosted by the Cloud Native Computing Foundation (CNCF). CNCF records it as graduated on August 9, 2018. The official download page lists Prometheus **3.16.0**, released **2026-11-04**, as Latest; **3.13.5**, released **2026-10-21**, is listed as LTS. I found no Prometheus shutdown, sunset, or acquisition notice in the current project blog, CNCF announcements, CNCF project page, or official release list. The project site has a blog, but no separate Prometheus newsroom page was linked in the site navigation. Its own governance document names a Steering Committee as the governing body; this entry does not list individual members.

**Scope:** This record covers the self-hosted Prometheus server and its project documentation. It is a metrics time-series database and alerting toolkit, not an exception tracker, general log service, distributed tracing/APM service, hosted status page, or cron monitor. **Hosted Prometheus services exist, but they are outside this record.**

The `apps.md` row is broadly accurate. “Foundation region not checked” is not a home-country claim: the official overview says Prometheus is maintained independently of any company, and the project is hosted by CNCF. The country of an individual maintainer or a vendor's headquarters does not describe this project.

## Cost example — our calculation

Prometheus has no software license fee under Apache-2.0. Hosting is separate. DigitalOcean's public price table lists a **1-vCPU, 2-GiB, 50-GiB Basic Droplet for USD $12.00/month** and a **2-vCPU, 4-GiB, 80-GiB plan for USD $24.00/month**. These are price examples, not Prometheus hardware recommendations.

- **Small illustrative monthly bill:** inputs: software $0; 1-vCPU / 2-GiB VM $12.00. Formula: `$0 + $12.00 = $12.00/month`. Result: **USD $12.00/month**, before taxes, backups, extra storage, and operator time.
- **With weekly VM backup:** input: $12.00 VM and backup price of 20% of VM cost. Formula: `$12.00 × 20% = $2.40; $12.00 + $2.40 = $14.40/month`. Result: **USD $14.40/month**, before taxes and extras.
- **Larger example with weekly VM backup:** inputs: $24.00 VM and 20% backup. Formula: `$24.00 × 20% = $4.80; $24.00 + $4.80 = $28.80/month`. Result: **USD $28.80/month**, before taxes and extras.

For capacity context, **our calculation** using the Prometheus storage formula gives about **1.21–2.41 GiB** for 1,000 samples/second over 15 days, or **12.07–24.14 GiB** at 10,000 samples/second. These rough values exclude WAL/head peaks, compaction, the operating system, and free-space margin. The official docs publish no minimum CPU or RAM for either workload, so these VM examples are not guarantees that a workload will fit. Full running cost also depends on actual storage, backup, power, and operator time.
