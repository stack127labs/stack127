# ClickStack, using HyperDX

Official URL: https://clickhouse.com/clickstack

**Status, shutdown, sunset and acquisition check:** Active open-source ClickStack; Managed ClickStack is generally available in ClickHouse Cloud; a separate, fully managed ClickStack Cloud offer is still in private preview and has a waitlist. ClickHouse announced it acquired HyperDX on **2025-03-13**. HyperDX is now the UI in ClickStack. No ClickStack or HyperDX shutdown/sunset notice was found in the official blog, current changelog, or company newsroom. The newsroom's current press-release list was checked through **2026-09-29**; the latest ClickStack changelog covers releases **v2.39–v2.42** and was published **2026-11-03**. Sources: https://clickhouse.com/blog/clickhouse-acquires-hyperdx-the-future-of-open-source-observability ; https://clickhouse.com/blog/whats-new-in-clickstack-october-2026 ; https://clickhouse.com/company/news (checked 2026-11-06; source dates above).

**Current packaging:** These are separate offers. ClickStack Open Source is self-hosted. Managed ClickStack is GA and gives you the Cloud-hosted ClickHouse database and UI while you run the OpenTelemetry collector and ingestion path. ClickStack Cloud is a different, turnkey Cloud service that manages ingestion, buffering, scaling, storage and query serving; the latest official waitlist still calls it private preview. The older 2025 private preview and February 2026 beta referred to Managed ClickStack and are superseded by the July 2026 GA announcement. Do not treat the private-preview ClickStack Cloud as GA or assume its price from Managed ClickStack's Cloud rates. Sources: https://clickhouse.com/blog/announcing-clickstack-in-clickhouse-cloud ; https://clickhouse.com/blog/introducing-managed-clickstack-beta ; https://clickhouse.com/blog/making-clickstack-5x-faster-clickhouse-observability ; https://clickhouse.com/blog/observability-mcp-server-ai-notebooks ; https://clickhouse.com/cloud/clickstack-cloud-waitlist (checked 2026-11-06; dates in table).

**License boundary:** The self-hosted stack is open source, but it is a composition rather than a single-license repository: ClickHouse is Apache-2.0, HyperDX is MIT, and the ClickHouse OpenTelemetry Collector distribution is Apache-2.0. Managed Cloud offers are commercial hosted services and do not transfer the work of operating the stack to the customer. Sources: https://github.com/ClickHouse/quickstart-clickstack ; https://github.com/ClickHouse/ClickHouse/blob/master/LICENSE ; https://github.com/hyperdxio/hyperdx/blob/main/LICENSE (checked 2026-11-06; repository README lists component licenses; license files checked on their current branches).

- **Our calculation, storage only:** Inputs: 1 TB-month of compressed ClickHouse table data plus 1 TB-month of backup. Formula: (1 TB + 1 TB) × USD 25.30/TB-month = **USD 50.60/month**. This excludes compute, data transfer and tax; it is a storage illustration, not a total service bill.
- **Published Cloud example, not our calculation:** The current billing guide gives **USD 66.52/month** for its Basic example: one 8 GiB RAM / 2-vCPU replica active 6 hours/day, 500 GB compressed data, 500 GB backup, 10 GB public egress and 5 GB cross-region transfer. It is not a fixed minimum or a ClickStack Cloud quote.
- The error/log and performance workloads in fields.md cannot be priced exactly from raw GB or request counts. The public calculator needs storage/compression, backup, service sizing, active/query hours and transfer; all-in totals remain uncalculated. ClickStack Cloud preview has no published price.

## Conflicts and unknowns

- **Hosted offers:** The 2025 Cloud private preview and February 2026 Managed beta are superseded by the July 2026 Managed GA post. The separate May 2026 ClickStack Cloud preview is still named on the current waitlist. The latest November changelog does not announce a status change for that preview.
- **Retention:** Product marketing says indefinite Managed retention; TTL docs say 3 days by default, and the Managed quickstart includes 720h. The docs show no revision dates. Use the configured TTL, not the marketing maximum, when describing an actual deployment.
- **Pricing:** Managed ClickStack uses published Cloud meters and rates; ClickStack Cloud preview pricing is explicitly unfinished. Do not apply Managed's per-unit rates to the preview.
- **Billing control:** Spend alerts notify; payment thresholds trigger invoice collection; neither is a hard organization spend cap. A maximum compute autoscaling setting does not cap storage/transfer or the invoice.
- **Open-source error tracking:** Official docs confirm event capture and investigation but don't publish an issue-grouping/duplicate-merging workflow. Source maps are called out as Enterprise in the official demo.
- **Not published after checking:** Preview prices/quotas/regions/retention/support/export; managed user/project allowances; Basic-tier behavior exactly at 1 TB; self-host minimum CPU/RAM/disk; all-in cost for standard workload scenarios; and whether a card is required to start the Cloud trial. Pages checked for each appear in the corresponding table note.

## Field problems

- The apps.md row describes hosted + self-hosted as if there were one hosted offer. Current official materials distinguish GA Managed ClickStack from private-preview ClickStack Cloud. They are recorded separately here.
- The generic ClickStack TTL page does not separate OSS and Managed defaults, while the Managed quickstart sample sets 720h and the current Managed marketing page says indefinite retention. Actual table TTL must be checked per deployment.
- Source-map support is announced as Enterprise in a ClickHouse team demo, but the current Cloud plan table does not list the feature by tier. The tier label comes from the demo source, not an inferred mapping to a named Cloud plan.
- ClickStack captures and investigates errors, but its public documentation does not describe issue grouping/deduplication like an exception-ticket product. Error monitoring here is telemetry-based.
