## Cost examples

The three uptime examples above are **our calculations**, not vendor quotes. Each selects the cheapest current plan with enough listed monitors, assumes one probe location per monitor, uses no SMS/phone credits, and excludes tax because Xitoring does not say whether tax/VAT is included. The node guide says each selected probe location can count as another check execution, while the billing guide describes checks per enabled check, so using multiple nodes may change the allowance. The displayed `$` symbol has no stated ISO currency code, so the examples preserve the symbol without converting it.

A 5-, 25-, or 100-server monthly total cannot be calculated: the homepage advertises Synthetic + Server from $24.99/month, but the public static plan cards do not show the number of servers included or a per-server price. No server total is guessed.

## Conflicts and unknowns

- Pricing page plan cards show current monthly rates, but its FAQ has an older Pro price example ($49/month, or $39/month annually). The billing guide says annual discounts are typically 15–20%; exact annual plan amounts are not public.
- Ongoing Free limits conflict: 8 checks on the uptime page versus 20 monitors on the website-monitoring page. Pricing's FAQ mentions a Free downgrade without publishing the limit.
- Check cadence differs between the 1-minute pricing cards, a 30-second paid marketing claim, and the API guide's 30-second to 15-minute range. Node-based check usage is also described differently across the node and billing guides.
- The terms, pricing, and billing pages use `$` but do not name the ISO currency or say whether VAT/tax is included. I searched those pages for currency, USD, tax, and VAT; no matching detail appeared.
- SSL alert docs list 1, 7, 14, and 30 days; the FAQ additionally lists a 3-day warning. API-access plan statements and Free/paid Slack availability also differ across current pages.
- The newsroom route `https://xitoring.com/newsroom` could not be fetched. I checked the blog index, the latest 3.0 announcement, product pages, and release notes; no acquisition or closure notice surfaced. The failed route is not proof of shutdown.
- The public DPA says regional data residency is not standard and names multi-region subprocessors; probe locations must not be mistaken for storage regions.

## Field problems

- **Currency:** The price cards use `$` without an ISO currency code. Each quoted rate retains the symbol and flags the currency code as unclear instead of silently assuming USD.
- **C08 Free plan:** There is no reconciled standard Free plan definition. Free offers for students, startups, nonprofits, and open-source projects are separate application-based offers with no public quotas.
- **C15 plan allowances:** The pricing page has plan cards and a comparison matrix, but the matrix renders some values as blank or checkmarks. The rows use explicit card values and leave missing plan details unpublished.
- **U03 check counting:** Pricing calls quotas monitors, billing counts enabled checks, and the node guide says selected nodes multiply check executions. The cost examples therefore assume one node.
- **U02 / U05 / API access:** Current pages disagree on optional 30-second checks, one extra SSL warning date, and plan access for API/Slack. These are kept as conflicts rather than expanded into unsupported plan entitlements.
- **C04 vendor country:** Official pages identify Xitoring, LLC and Delaware law but do not give a registered office. The country wording is limited to the US legal/contact context; no individual's name is included.
