Measure is a mobile monitoring service with a continuing Free cloud plan and an Apache-2.0 self-hosted backend. Cloud pricing uses collected data volume, including context and attachments, rather than error counts. The free allowance is 5 GB/month with 30-day retention. Pro starts at $50/month for 25 GB with 90-day retention, then charges $2.00 per extra GB. Those rates do not establish an exact bill for a given number of errors.

## Cost examples: our calculation, estimated

These are **our calculations, estimated**, using the checked public rate card and explicit byte assumptions. They are not vendor quotes. The price page uses **$** without publishing a currency code; no currency conversion is made. Taxes, payment fees, negotiated terms and optional Measure Agent consumption are excluded. There is no annual discount assumed.

For total team billable volume `B` measured in decimal GB, the advertised plan model is:

- Free: `$0/month` where `B ≤ 5 GB` and the required features/retention fit.
- Pro: `$50 + $2 × max(0, B − 25)` per month. Choosing Pro costs at least $50 even when less than 25 GB is used.
- For a workload that can use Free, choose Free up to 5 GB; above 5 GB use the Pro formula. The paid allowance is 25 GB total as advertised, not 25 GB plus another assumed 5 GB.
- The decimal conversion is `GB = bytes ÷ 1,000,000,000`. The optional error illustration below uses 50 × 1024 bytes/report because that is what the vendor calculator's source assumes. These two units are stated separately.

## Conflicts and unknowns

1. **Ingest request size conflicts.** The official REST page says 9 MB including events and blobs. Main-branch code applies a strict 9,000,000-byte payload cutoff and excludes attachments from that cutoff, while still billing attachment bytes. There was no cloud-revision or live-ingestion check to resolve it. Both exact sources are in C26: https://measure.sh/docs/api/sdk/events/putEvents and https://github.com/measure-sh/measure/blob/main/backend/ingest/measure/event.go.

2. **Cloud retention wording has an edition limit.** The security page says applications have user-configured retention. Generic REST docs expose 30–365 days. The actual handler forbids direct retention updates when cloud billing is enabled, and the live rate card states Free 30/Pro 90. This scope distinction resolves the broad wording; it is not an arbitrary choice of the longest claim. Checked https://measure.sh/security, https://measure.sh/pricing, https://measure.sh/docs/api/dashboard/apps/updateAppRetention and https://github.com/measure-sh/measure/blob/main/backend/api/handlers/app.go.

The opened 100-release list did not establish those newer SDK releases. The v0.14 migration guide likewise does not establish an available v0.14 backend release; the newest plain backend release observed was v0.13.0.
