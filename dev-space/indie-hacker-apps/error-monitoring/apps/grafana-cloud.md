**Free tier and usage pricing:** Free is ongoing **USD 0 with no credit card**, one stack, and separate included allowances for each product. It includes **10k active metrics series; 50 GB/month each of logs, traces and profiles; three active visualization users; 50k frontend sessions; 2,232 application host-hours; 100k API and 10k browser synthetic execution units/month**. Core telemetry history is **14 days**. Pro starts at **USD 19/month plus usage**, keeps included base usage, and has **13-month metrics** and **30-day logs/traces/profiles** history. This is neither one shared 50 GB pool nor USD 19 for unlimited data. ### Metrics and users: what the meter means

Metrics billable series are based on the higher of **95th-percentile active series** and **95th-percentile total DPM ÷ included DPM**. Pro includes **one data point per minute per series** at the standard resolution.

For illustration, with a constant 4,000 active series all month:

- At a 60-second scrape interval: 4,000 DPM; billable series = max(4,000, 4,000/1) = **4,000**. On Pro the series component fits the 10,000 allowance, leaving **USD 19/month base**, assuming queries fit their allowance.
- At a 15-second interval: 16,000 DPM; billable series = max(4,000, 16,000/1) = **16,000**. Base-rate calculation: 19 + (16,000 − 10,000)/1,000 × 6.50 = **USD 58/month**, under the same query assumption.

These are our calculations, not a claim that 4,000 metric names always generate 4,000 series. Label combinations and histogram buckets can create many more series. The 95th percentile forgives the top 5% of usage time, not 5% of each invoice. Metrics querying includes **20 billion MQU per 1,000 billable series per month**; excess has its own charge, whose numerical rate was not established here. Sources: https://grafana.com/pricing/ (checked 2026-11-05; source updated Not shown) ; https://grafana.com/docs/grafana-cloud/platform/pricing-and-usage/metrics/ (checked 2026-11-05; source updated Not shown) ; https://grafana.com/docs/grafana-cloud/platform/cost-management-and-billing/manage-invoices/understand-your-invoice/ (checked 2026-11-05; source updated Not shown).

A visualization user who never signs in that month is not billed as active; a service account is not a visualization user. **IRM is different:** being scheduled/on an escalation chain counts. **Assistant is different again:** use, an owned automation or a Cloud MCP connection can count as AI activity. Three included users in each category are separate entitlements, not one interchangeable pool. Above the included count, current starting rates are **USD 8 visualization**, **USD 20 IRM** and **USD 20 AI** per active user/month; Enterprise Plugins have their own USD 55/user option. Sources: https://grafana.com/pricing/ (checked 2026-11-05; source updated Not shown) ; https://grafana.com/docs/grafana-cloud/platform/pricing-and-usage/users/ (checked 2026-11-05; source updated Not shown) ; https://grafana.com/docs/grafana-cloud/platform/pricing-and-usage/irm/ (checked 2026-11-05; source updated Not shown) ; https://grafana.com/docs/grafana-cloud/platform/pricing-and-usage/assistant/ (checked 2026-11-05; source updated Not shown).

## Field problems

- **C07/C08/C11:** One plan price or one free-GB number cannot describe this platform. Each product has its own meter, allowance and retention; generated telemetry can add a second charge. Cohort start dates materially change credits.
- **C11 errors:** Report counts do not predict sessions, log bytes or backend spans. No payload size or session-to-error ratio is invented to force a complete total.
- **C11 performance:** Request counts/span assumptions omit generated metric cardinality and other telemetry. Host-hour pricing is not a CPU meter, and curated Application Observability differs from DIY dashboards.
- **C11 synthetics/U03:** A saved check, one full flow execution and one billable probe-minute are different quantities. Runtime rounding, locations, metering adjustment and extra telemetry must stay beside the estimate.
- **C13:** Warnings, per-stack technical limits and pre-ingest filters are different from a universal paid hard cap.
- **C15:** Stack, application, account member, active visualization user, IRM responder and AI user must stay separate. Schedules can trigger IRM charges without login/activity that would count for visualization.
- **C14/E04:** Preview replay has its own fixed 30-day recording policy; mobile is private preview. Neither should be presented as identical to every core Free/Pro telemetry entitlement.
- **C06/H fields:** Open-source client/server projects behind Grafana Cloud are not a complete self-hosted Cloud edition. This record excludes Loki's self-hosted implementation facts as requested.
- **C27/state vocabulary:** Used only the owner's six states. “Confirmed” on a calculation means the stated inputs and arithmetic, with explicit assumptions; it does not make an unresolved full invoice confirmed.
