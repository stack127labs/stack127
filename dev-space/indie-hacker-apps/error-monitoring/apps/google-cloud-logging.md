## Cost examples: our calculation, estimated, not quoted

### Common inputs and regional scope

- **Selected bucket region: us-central1 (Iowa)**, using the public **USD Cloud Logging tariff with no regional price split**. This is a disclosed regional scenario, not a verified account-specific SKU price.
- One builder, one Google Cloud project, **one billable project log bucket**, **30-day searchable retention**, 30-day month, no archive and no duplicate destination copies.
- Ordinary application logs only. Exclude vended network logs and original _Required-bucket logs.
- The project's monthly **50-GiB ordinary-log allowance is otherwise unused**. Do not spread logs across artificial projects to invent a cheaper scenario.
- The input GB figures mean **decimal raw complete log-entry bytes before indexing**, with **1 GB = 1,000,000,000 bytes**. This is an explicit scenario interpretation, not a claim raw application-message bytes always equal billable bytes.
- Query volume is unspecified. Standard Logging API and included Logging/Observability Analytics queries have no additional Logging fee; optional BigQuery services/jobs, archive destinations, Cloud KMS, user-defined Monitoring metrics, external notification services and paid support are excluded.
