Native Firebase Crashlytics is a no-cost managed service on Spark and Blaze, including production apps. Its technical capture limits still apply. The new Web preview is materially different: the setup requires Blaze and uses Cloud Logging for telemetry, Cloud Storage for source maps and Cloud Monitoring for alerts. Do not carry the native no-cost claim, retention or alert rules across to every Web resource.
