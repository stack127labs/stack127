### Request monitoring, monthly first

For requests R, sampled monitoring traces T = R × 0.10. Recurring extra million-trace blocks B = max(0, ceil((T − 1,000,000) / 1,000,000)). Monthly subscription subtotal = 189.90 + 50 × B. These are request traces, so the scenario's ten child spans do not multiply the request-trace count. The requested 1 KB/span assumption is not the monitoring billing meter.
