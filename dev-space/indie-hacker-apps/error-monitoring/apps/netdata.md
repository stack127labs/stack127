**Lifecycle and ownership check:** Netdata is active. The official Agent release page lists v2.12.3, released 2026-11-04. I checked the current release page, official blog, and About page for an acquisition, shutdown, or sunset notice; I found none. The site has press inquiries but no separate newsroom page in its navigation. Netdata's official 2024 plan announcement did retire the Early Bird and Unlimited Community plans; this did not retire the Agent or current Cloud plans.

**Scope:** The main facts cover the free, self-hosted Netdata Agent and the separate Netdata Cloud SaaS. Netdata Cloud On-Prem and personal Homelab are mentioned separately. The Agent collects and stores monitoring data on the user's systems; Cloud adds remote access, team controls, and paid features.

**License history:** The Agent remains GPL-3.0-or-later (GPLv3+). The legacy v1 dashboard repository was GPL-3.0 and is archived. The current dashboard is free to use with Netdata Agents and Parents under Netdata Cloud UI License v1.0 (NCUL1), which restricts use to Netdata components and does not allow modification. Netdata's 2024 v2.0 dashboard announcement described retiring v0/v1 dashboards and changing how access works; the current product page documents NCUL1. The Agent's license did not change in those notices.

## Cost examples

The Cloud examples in C11 and the self-hosted Agent example in H02 are **our calculations**, not quotes. Cloud costs use published USD per-node rates, monthly billing equivalents, annual volume-discount bands, and event allowances. They exclude tax, optional products, and log/trace overages. The self-host example assumes an already-paid host has spare capacity; new Parent or object-store infrastructure is not included.

## Paid Cloud offers (separate from the Agent license)

- **Business Infrastructure:** $7/node/month with annual billing or $8.75/node/month monthly. It includes unlimited metrics, system-log viewing, synthetic API/uptime checks, and 20 million app log events per node in the pooled monthly quota.
- **Business APM:** $15/node/month annually or $18.75 monthly; includes Infrastructure, 25 million log events and 25 million trace spans per APM node. Overages are $0.10 per million with annual billing or $0.125 monthly.
- **Other add-ons:** Network Device Monitoring starts at $2/device/month. NetFlow starts at $200/month for 5,000 flows/sec on annual billing. RUM and Synthetic Browser Tests each start at $250/month for their annual minimum bundles. AI Investigations starts at $300/month annually for 100 investigations or $6 per investigation monthly; AI Co-SRE is custom-priced. Enterprise pricing is custom, with Cloud On-Prem, custom quotas, and priority support.
- **Trial and support:** Business trial is 14 days. Business includes business-hours email/ticket support with an SLA; Enterprise offers 24/7 support. The terms promise 99.5% monthly Cloud availability subject to exclusions.

## Conflicts and unknowns

- Current pricing lists paid plans and support, while the general Terms of Use still contain earlier no-charge/no-direct-support wording from its 2024 effective date. The 2026 pricing page and service terms are used for current published offers; the legal text mismatch remains visible.
- The current pricing page says Community access is up to five connected nodes. Current feature documentation clarifies that the limit controls multi-node dashboard access; every Agent continues collecting, storing, and alerting. A larger number of Agents can still be installed.
- The 2024 plan post records the retirement of Early Bird and Unlimited Community plans. The current pricing page lists Community, Business, and Enterprise, so the old plan names should not be used for a current comparison.
- The current Agent license remains GPLv3+. The dashboard license is separate: the legacy v1 repo was GPL-3.0, while the current dashboard uses NCUL1. The official sources checked do not state the exact effective date of the license transition.
- Public sources reviewed do not publish trial payment-card/automatic-charge conditions, a hard Business spend cap, a public DPA, a Cloud metadata region selector, or fixed certificate-warning lead times.

## Field problems

- C11 uses node-count workloads because Netdata publishes per-node rates and pooled event allowances. It does not price by metric count or data retention.
- H02 is optional. The Agent-only incremental example assumes a fixed-cost host has spare capacity; Netdata publishes no representative new-host price, and a total would need assumptions about Parent design, backups, and provider.
- E01–E04 are exception-tracker fields. Netdata can monitor logs and trace error signals, but the official docs checked do not describe issue grouping, source maps, release-linked error issues, or replay. These are recorded as not published rather than assumed impossible.
- The Agent and Cloud dashboard have separate licenses. Treating the entire downloadable package as GPL would be inaccurate.
