- **Shutdown, sunset, acquisition:** Cachet is active: its official blog and v3 changelog show development through July 2026, and the GitHub organization page shows repository activity through September 2026. The official 2023 v3 announcement discussion includes a prior owner’s statement that Cachet had been sold about five years earlier; that discussion does not name the buyer. The current site identifies Alt Three Services Limited as copyright holder and says it is registered in England and Wales. I found no later acquisition, shutdown, or sunset notice in the official website, blog, or repository pages checked.

> **Listing caveat:** `apps.md` describes Cachet as open-source. That is accurate for the last released v2.4.1 (BSD-3-Clause), but not for the current unreleased v3 branch: its repository declares `proprietary` and supplies a custom “Cachet license” that restricts standalone redistribution. The project site still calls v3 open-source. I record the two editions separately below.

## Conflicts and unknowns

- **Open-source label vs current license:** the website calls Cachet open-source and free. The current v3 branch’s `composer.json` says `proprietary`; its custom license restricts standalone redistribution. v2.4.1’s exact license is BSD-3-Clause. These are separate version facts, not one shared license.
- **v3 readiness:** the 2025-01-01 recap says v3 was usable in production, while the current installation guide says it is unreleased and development-only; the current migration guide says the upgrade path is incomplete. I give the current install and migration warnings priority for deployment guidance.
- **Latest release vs active work:** GitHub’s latest release is v2.4.1 from 2023-11-07. The v3 branch continues to receive development and security work in 2026, but it has no published stable release.
- **Security:** GitHub’s moderate stored-XSS advisory is dated 2026-08-27 and describes v3 revisions before `23adbb8`. The July 2026 changelog lists the sanitization fix at `23adbb`; the advisory still lists no patched release. Verify the deployed commit includes the fix, and do not assume a release tag is available.
- **Pages attempted for absent commercial policies/pricing:** checked the product home/footer, sponsor page, blog, docs index and installation guide, plus `https://cachethq.io/terms` and `https://cachethq.io/privacy`; the latter paths did not resolve as published policy pages. The site advertises free self-hosting and professional installation, but no installation-service price, hosted terms, DPA or customer privacy policy was found.
- **Uptime-check details:** checked the v3 component guide, changelog, installation docs and merged component-monitoring PR. The project confirms recent component checks and response code/time history, but does not publish check protocol, interval, timeout, probe regions, retries or expiry checks.
