## Conflicts and unknowns

All URLs in this section were checked 2026-11-04.

- **C12: stale billing examples and unclear automatic upgrades.** https://docs.rollbar.com/docs/billing uses a USD 149/month 500,000-event example; https://rollbar.com/pricing-for-agents gives Essentials USD 119/month. The dated billing-catalog table supplies our base rates. Billing's upgrade example says an upgrade can follow excess on-demand usage, while its preceding text describes emailing a cheaper-plan suggestion. Current pricing describes uncapped on-demand at the plan rate. Do not promise that enabling on-demand can never change the plan automatically. Its USD 9.53 example for 9,532 excess events is not a safe current rate source.
- **C13: thresholds.** https://docs.rollbar.com/docs/usage lists 80%, 90%, 100%; https://docs.rollbar.com/docs/avoiding-billing-surprises adds 95%. Warning support is established; the exact threshold set remains unresolved.
- **C13: AI-credit eligibility.** https://docs.rollbar.com/docs/billing says Free can buy credit subscriptions; https://docs.rollbar.com/docs/billing-faqs says initially only Essentials and Advanced can. No purchased AI credits are assumed in our scenarios. The FAQ also allows an in-flight task to make the credit balance negative, so occurrence budget claims should not become a universal charge-cap claim.
- **C23/E02: security wording.** https://docs.rollbar.com/docs/security describes encrypted storage in Iowa. https://docs.rollbar.com/docs/source-maps says uploaded source-map packages are encrypted but derived file/line/code-snippet data is stored in the clear. Do not infer that every derived code fragment has the same encryption treatment. The security page's generic 180-day retention wording is qualified by the plan-specific table and https://docs.rollbar.com/docs/data-retention.
- **C16: legacy SDKs.** https://docs.rollbar.com/docs/directory lists legacy Apple/iOS as unsupported; https://docs.rollbar.com/docs/apple explains its replacement by the supported Apple SDK. Modern Apple support is established. The directory also distinguishes community adapters from vendor-supported integrations. A repository or download link alone is insufficient to claim vendor support.
- **E03: Versions gate.** https://rollbar.com/pricing advertises deploy/version tracking on Free, but https://docs.rollbar.com/docs/project-configurations associates Versions with Advanced/Enterprise. Basic code-version metadata is documented; full UI entitlement needs clarification.
- **Replay defaults.** https://docs.rollbar.com/docs/session-replay has example privacy settings and explicit defaults. Its example masks email, but its default map does not. It also shows 60 seconds of pre-duration in triggerDefaults and 300 seconds in the common trigger table. Recording-window defaults are unresolved; no single default window is claimed here.
- **C05 self-hosting:** searched pricing, setup, security, and official-domain searches for self-host/on-premise. No complete current self-host offer established. This remains not published in checked sources, rather than a categorical no.
- **C09 trial allowance conflict:** https://rollbar.com/pricing lists 15,000 trial AI credits; https://rollbar.com/blog/rollbar-pricing-explained-plans-features-and-what-you-actually-pay/ lists 10,000.
