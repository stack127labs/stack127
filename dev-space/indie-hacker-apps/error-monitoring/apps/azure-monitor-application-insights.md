## Status, sunset, acquisition and product changes

Azure Monitor and Application Insights are active Microsoft-hosted services. I found no whole-product shutdown or acquisition notice in the Azure Monitor release/deprecation pages, Microsoft Azure Blog, Azure Updates, Microsoft News Center, or Microsoft Newsroom pages checked.

Several older features need attention:

- Classic Application Insights resources stopped ingesting telemetry on June 15, 2025. Microsoft completed automatic migration attempts in 2025. Any remaining classic resource needs manual conversion to a workspace-based resource before it can ingest again; its existing data remains queryable.
- The Node.js Application Insights Classic API SDK 2.x is retired. The .NET Classic API SDK 2.x retires on March 31, 2027. Microsoft recommends OpenTelemetry for new applications and migration.
- URL Ping tests are deprecated, but the retirement deadline was extended to September 30, 2028. Existing tests are removed then. Standard tests are the recommended replacement and are billed when enabled.
- Multi-step web tests had an official retirement date of August 31, 2024, but the current pricing page still lists them and a monthly charge. Current availability is not clear from those pages.
- API keys for querying were scheduled to retire on March 31, 2026, with Microsoft Entra ID as the replacement. The exact current enforcement status is unclear: the date is past, while current Microsoft retirement guidance still labels the keys as retiring.
- These are feature and migration changes, not an announced shutdown of the hosted product.

## Product and price boundary

Application Insights is Microsoft's application-performance and telemetry product within the wider Azure Monitor family. This record covers Application Insights telemetry, its Log Analytics workspace storage, its own availability tests, and the Azure Monitor alert meters needed to notify on those signals. It excludes prices and capabilities of App Service, Functions, Azure Storage, Azure DevOps, Azure Load Testing, and unrelated Azure Monitor services.

Application Insights is hosted by Microsoft. SDKs, agents, and optional test code may run with an application or in a customer's environment, but they do not provide a self-hosted Application Insights backend.

**Price region and currency:** Cost examples use **East US** and **USD**. The Azure Monitor pricing page exposes region and currency selectors and says its displayed converted prices are estimates. The East US/USD view and the official Azure Retail Prices API were checked, but the page rendered the relevant unit prices as `$-` and the API could not be retrieved in this environment. Numeric East US rates are therefore left unavailable. The 5 GB monthly ingestion allowance and 90-day Application Insights retention are stated as free allowances, not regional price quotes. Availability-test probe locations are separate from the East US resource price region. ## Cost examples: our calculations, not quotes

All examples assume **East US, USD**, default pay-as-you-go workspace ingestion, 30 days, and that no other Log Analytics workspace under the billing account has consumed the shared 5 GB/month allowance. App Insights raw-data retention is within the included first 90 days. Taxes, discounts, other Azure products, separately charged alert notifications, and destination storage are excluded. The East US/USD rates were not visible: the public pricing table returned `$-` for the unit rates, and the official retail-price query could not be retrieved. Therefore only the free-allowance result is numeric; paid totals remain formulas, not invented estimates.

| Workload | Inputs | Formula | Result |
| --- | --- | --- | --- |
| Small | 5 GB telemetry/month; 90-day retention; no Standard test runs | max(5 GB − 5 GB free account allowance, 0) | **$0 ingestion**; other separately used meters are excluded |
| Growing | 50 GB telemetry/month; 90-day retention | max(50 − 5, 0) GB × East US USD PAYG rate per GB | **45 GB billed; exact USD total unavailable** because rate rendered `$-` |
| Busy | 250 GB telemetry/month; 90-day retention | max(250 − 5, 0) GB × East US USD PAYG rate per GB | **245 GB billed; exact USD total unavailable** because rate rendered `$-` |

For a Standard test running every five minutes for 30 days at five locations, the input would be 8,640 scheduled runs per location × 5 = **43,200 executions**. Formula: 43,200 × East US USD price per scheduled execution. The public page showed `$-` per execution, so the exact test cost cannot be stated. URL Ping remains listed as free only until the revised retirement date; it is not a free Standard-test equivalent.
