I found no shutdown, sunset, or acquisition notice in the releases, project wiki, Uncascade's product/About pages, or its blog. I found no separate newsroom page.

> **Scope note:** cState Core is a free, MIT-licensed static status-page generator that you run and deploy. The current product site also advertises a separate managed setup and hosting service from Uncascade on European infrastructure. It does not publish a plan or rate. Hosted-plan fields below are not applicable to the open-source Core; this separate service is recorded where relevant.
