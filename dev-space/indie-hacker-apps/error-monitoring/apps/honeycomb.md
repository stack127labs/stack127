### How the event model works

Free includes **20 million actually ingested events/month**, plus a **separate 100 million native metric datapoints/month**. A trace is not one event: each span, each SpanEvent and each Link counts. Logs also consume the shared event allowance. Metrics sent using the older events-based model still consume events. Upstream discarded telemetry and rejected events do not count. Query weighting from sample-rate metadata does not multiply the invoice's stored-event count. Sources: https://docs.honeycomb.io/get-started/manage-costs/how-honeycomb-calculates-usage.md ; https://www.honeycomb.io/pricing ; https://docs.honeycomb.io/manage-data-volume/sample/sampled-data-in-honeycomb.md (checked 2026-11-05; revision dates not shown; pricing FAQ answers read from its public embedded FAQ data).

Pro is a **capacity-tier subscription**, billed in advance. Entry: **USD 150/month for 50M events and 250M metric datapoints**. The 2026 rate is **USD 3 per million subscribed events**, with four tiers up to 750M events/month. It is not a published automatic overage rate. The Free 20M is not an extra subtraction from a paid tier. Unused capacity does not roll over. Sources: https://www.honeycomb.io/pricing ; https://docs.honeycomb.io/get-started/honeycomb/2026-pro-plan-changes.md ; https://www.honeycomb.io/terms (checked 2026-11-05; terms effective 2025-05-22; change effective 2026-07-01).

Counts follow the **calendar month**, even if billing renews on another date. The daily enforcement target is monthly capacity ÷ 30.4; the directory's 30-day workload is not substituted for that vendor divisor. Assume steady usage, no burst-protection benefit and no separate metric quota overage in these examples. Sources: https://docs.honeycomb.io/get-started/manage-costs/how-honeycomb-calculates-usage.md ; https://www.honeycomb.io/pricing (checked 2026-11-05; revision dates not shown).

- **C07/C11/L01:** a request, a span, a span event, a log record and a raw GB are different units. Count each successfully ingested event, and price subscribed capacity rather than inventing a pay-as-you-go overage.
