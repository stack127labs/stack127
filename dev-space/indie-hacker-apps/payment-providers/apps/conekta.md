## Cost examples

These are our calculations using the publicly posted standard prices. They are examples, not a quote. Inputs are a successful MXN 1,000 payment before any optional product charge; the published percent is applied to that amount. The quoted provider fee is before IVA.

- Card: 3.4% × MXN 1,000 + MXN 3.00 = MXN 37.00 + IVA.
- Conekta Efectivo, retail/e-commerce/other: 2.6% × MXN 1,000 + MXN 3.00 = MXN 29.00 + IVA. The MXN 5.40 minimum does not change this example.
- SPEI transfer: MXN 12.50 + IVA per successful transaction; the public page gives a flat fee, so the example is MXN 12.50 + IVA.
- These examples exclude any issuer/plan-specific MSI rate, BNPL provider rate, 3DS fee, buyer-paid cash-point charge, bank fee, or account-specific price.
- The pricing page marks its posted prices as valid from 1 July 2024. It remained the official public fee page checked on 6 November 2026; no newer public rate card was found.

- **First payout timing:** The contract card table and first-payment clause, pricing FAQ, and current help-center payout articles describe different stages/ranges. Their pages and dates are recorded under F33; none supplies one reconciled end-to-end guarantee.
- **Charge currencies:** The plan API reference mentions MXN/USD, while the Spanish subscription guide says MXN only. The current order reference accepts an ISO code but does not list supported currencies; no complete current matrix was found.
- **Refund fee:** Current merchant terms say the processing commission is not refunded. - **Subscription currency:** Current API order docs accept an ISO currency code; the plan reference mentions MXN/USD; the older Spanish subscription guide says MXN only. No complete current currency and method matrix was found, so F11 records the ambiguity rather than assuming USD is supported.
- **BNPL fee mapping:** Pricing exposes 4% and 6% plus IVA but its page's logo/image text does not name which partner maps to each rate. The merchant's partner enablement and quoted offer matter.
- **Company ownership:** Grupo Conektame, S.A. de C.V. is the contracting/operator entity. Conekta's About page shows investors but not a controlling shareholder or current corporate parent; the reviewed newsroom and blog had no acquisition announcement.
- **Product coverage and limits:** Cash acceptance is partner/giro-specific. The currently published help minimum/maximum table is per method, while cash outlet caps can be lower and BNPL partner decisions are separate.

- F23 gives BNPL fee percentages but the website's image labels do not map them to named providers in accessible text. Do not assign 4% or 6% to a named provider without a direct public source or merchant quote.
