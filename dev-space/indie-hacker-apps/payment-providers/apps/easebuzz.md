## Cost examples — our calculation

The gateway product page publishes **1.5% average pricing per transaction**. The main pricing page instead describes customised, agreed commercial terms. An average is not a guaranteed domestic-card rate. These examples show only that headline percentage component, using the full stated payment as an assumed fee base. They are not an all-in quote. Sources: https://easebuzz.in/online-payment-gateway-India/; https://easebuzz.in/pricing/; https://easebuzz.in/terms/ (checked 2026-11-05).
