## Scope and current status

This record separates IntaSend's current Africa payments API from older Kenya merchant pricing, card, Bitcoin, and Shopify material. The current site describes a live API for local mobile money and bank payments in Kenya, Uganda, Tanzania, Rwanda and DRC. Its developer docs also retain country guides for Ghana, Nigeria, Senegal, Côte d'Ivoire, Burkina Faso and Cameroon. Those extra API guides do not establish that sellers based in all 11 countries can open accounts.

The company newsroom/blog archive, homepage, About page, current product pages and developer docs showed no shutdown, sunset or acquisition notice. The current homepage and developer docs are active; the docs were updated as recently as November 2, 2026. The company is IntaSend Solutions Limited, a Kenyan company. Current homepage FAQ says the current API does not process cards. Older pricing, checkout and subscription docs still describe cards and other methods, so those are recorded as a separate legacy/unclear offer.

All 45 general fields and all five crypto-conditional fields were attempted. Crypto fields apply because official legacy support and checkout material still describes Bitcoin and crypto methods, although the current marketing page says the current service does not process cards. - Verification review estimate differs between 1-2 business days and 1-3 days. The docs do not resolve the difference.
- The PesaLink payout fee bands overlap at KSh 50,000.
- Public pages checked for unpublished values include pricing, terms, coverage, country guides, checkout/subscription/wallet/payout docs, support verification/limits/settlement articles, contact, restricted-business policy and the official payments/news archive.
