## Current status and urgent security notices

BTCPay Server is an active, free and open-source self-hosted payment application. The latest GitHub release checked was **2.4.7 (2026-10-29)**. Its release notes say it fixes 85 security findings (1 critical, 13 high, 52 medium and 19 low); the project recommends updating, especially on servers shared by merchants.

The project reported Bitcoin and Litecoin stolen from server hot wallets on **2026-11-01**. Its investigation says the affected installs were BTCPay Server **2.4.1 and earlier**; the incident post was published 2026-11-02. Operators who ran 2.4.1 or earlier are advised to move to a fresh server and new wallet after sweeping remaining funds, even if they updated later. Hardware wallets and wallets whose spending keys stay off-server were unaffected by those reported thefts. Treat any signs of theft or unauthorized access as a full machine and secret compromise. See the official [incident notice](https://blog.btcpayserver.org/btcpay-server-security-incident-2-4-1-and-earlier/) and [release list](https://github.com/btcpayserver/btcpayserver/releases).

An earlier August 2026 advisory described a separate LND credential vulnerability fixed in 2.4.2; attacks and stolen funds were confirmed. In September, the project's Plugin Builder was compromised, affecting plugin developers who used that builder, not BTCPay users or installed plugins. The project says it found no attempt to replace published plugins. The builder was reopened in the 2.4.5 release with isolated builds and other safeguards. Details: [August advisory](https://blog.btcpayserver.org/security-advisory-btcpay-server-2-4-2/), [2.4.4 incident disclosure](https://blog.btcpayserver.org/btcpay-server-2-4-4/) and [2.4.5 reopening notice](https://blog.btcpayserver.org/btcpay-server-2-4-5/).

## Cost example

**Our calculation:** for a sale priced at **$100 USD equivalent**, BTCPay's processing fee is `$100 × 0% = $0`. This excludes Bitcoin network/miner fees, Lightning routing or channel costs, and server/hosting expenses because those depend on the payment route and operator. It does not mean the buyer pays in USD or that BTCPay converts funds to fiat.

## Conflicts and unknowns

- The newer [server specifications](https://docs.btcpayserver.org/Docker/specs/) recommend a practical Bitcoin-only starting profile of 4 GB RAM, 2 virtual cores and 50 GB usable SSD. The older [deployment FAQ](https://docs.btcpayserver.org/FAQ/Deployment/) still says 2 GB RAM, 80 GB pruned storage and Docker for Bitcoin plus Lightning. The current detailed specs explain there is no single minimum; use the newer profile and add headroom.
- The November 2026 thefts were reported for hot wallets on 2.4.1 and earlier. The project said it had seen no impact to instances already at 2.4.2+ when the warning was issued, but tells operators of an older affected version to rebuild on a fresh server and wallet even if they later updated. The August LND credential incident was separate and fixed in 2.4.2.
- The September Plugin Builder compromise affected plugin developers using that builder, not ordinary users or installed plugins. The project reported no attempt to replace published plugins and later reopened the builder with isolated builds. This is distinct from the core hot-wallet security incidents.
- There is no BTCPay merchant pricing page or standard merchant service agreement for the self-hosted software; the repository licence and hosting terms are the relevant public terms checked. No universal limit, fiat conversion fee, host price, seller product approval rule, or tax filing service applies to self-hosted core software. External hosts, plugins, platforms and exchanges have their own current rules and prices.
- No separate current Foundation newsroom was found. The Foundation about, goals and privacy pages were checked; product status and security updates are being published through the BTCPay blog and GitHub releases.

## Field problems

- **F03–F09:** Country, legal-form and product approval fields assume a central processor account. BTCPay is software that the merchant installs, so the file records that distinction and does not infer that every use is lawful or every host accepts every product.
- **F19:** The project publishes a free software price, while infrastructure cost depends on the host; the server specs give only an approximate VPS example.
- **F11 and F22:** Fiat currency is an invoice pricing reference. Core BTCPay receives crypto and does not convert it to a fiat balance.
- **F20–F28:** Card, local-method, chargeback and payout-provider rates do not apply to the core product; network and optional third-party costs are recorded separately.
- **C01:** Supported chain definitions can change. Bitcoin and Litecoin are project-maintained; other chains are community-dependent. Check current definitions before enabling a chain.
- **C05:** Official deployment pages differ on older versus current server sizing, documented above.
