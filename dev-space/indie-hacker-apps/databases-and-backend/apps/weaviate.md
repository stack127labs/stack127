# Weaviate

- Official URL: https://weaviate.io/
- apps.md status: active (row dated 2026-11-04).
- Lifecycle and company notices: Weaviate Database and Weaviate Cloud are active. The latest stable server release shown is v1.40.4; the release page shows November 5 but does not print the year. The GraphQL API is deprecated: new Cloud clusters have it disabled, Cloud turns it off on May 1, 2027, and self-hosted deployments retain it until at least that date. Separate Weaviate products have sunset notices: Engram stops accepting new projects and existing projects end December 31, 2026; Transformation Agent is marked sunset in favor of Query Agent and Engram. These notices do not announce a shutdown of the Weaviate database or Cloud. I checked the official blog and archive, company/about pages, release page, and EOL policy; I found no Weaviate database/Cloud shutdown or company acquisition notice. I found no separate newsroom linked from the company site.

## Conflicts and unknowns

- The current pricing page says its price book took effect for usage from September 1, 2026. I used that page for current plan names and rates. The Support Plans page still uses “Plus,” while the current pricing page and SLA use Flex and Premium Shared/Dedicated. The older October 2025 blog's $280 Plus starting amount is not used as a current price.
- The pricing matrix marks Free backup retention unavailable, but the Cloud default-settings docs say every Cloud instance is backed up daily. I recorded the plan's lack of user-facing backup retention as shown in pricing and left the technical Free backup behavior conflicting.
- The pricing page says Free is available in two regions, while the CLI guide says eu-central-1 is the only Free region. I used the current pricing table for the count but did not claim exact region identifiers.
- Pricing prose says Weaviate Embeddings are included on every Cloud plan, while the plan matrix says Embeddings on Premium Dedicated are “Coming soon.” I used the plan-specific matrix for Dedicated availability.
- The pricing page shows a “$” symbol without an ISO currency code and lists storage/backup rates per GiB without an explicit time unit in the table. The monthly billing context is clear, but the displayed rate row is not more specific, so I retained its units as printed.
- Exact paid costs require Cloud Console Running Costs data, including region and index/compression configuration. The public calculator and table support a known minimum and starting rates, not a precise quote for the stated workload.
- No complete public Cloud region list was found. Pricing gives region counts; the CLI guide disagrees about the current Free count. No Cloud console login was attempted.
- No public Weaviate-wide status-page URL was found. The support page refers to public status-page monitoring and the Cloud docs expose cluster status information.
- I searched the product overview, deployment docs, API references, replication/consistency docs, and batch-import docs for transaction guarantees. They do not publish multi-object ACID semantics or relational isolation levels.
- The official blog and archive, company/about pages, EOL policy, and release list showed current development and the notices recorded at the top. No corporate acquisition or Weaviate Database/Cloud shutdown announcement was found. Engram and Transformation Agent are separate products with their own sunset notices.
- The privacy policy, self-serve terms, DPA, and subprocessor list were read. The DPA's personal-data deletion schedule is not treated as a promise that all non-personal database data is erased on the same timeline.
