## Notices

- Convoy is an active webhook gateway operated under the Frain Technologies name. The official changelog reports Convoy 26.8.0 on 2026-09-28; the GitHub release page lists self-hosted release **v26.9.2**, dated 2026-10-20. The repository is public and not marked archived. I checked the official blog index, company blog posts, changelog, GitHub repository, and release page for acquisition or shutdown notices and found none.
- **License change:** a company blog post dated 2024-09-02 announced a move from MPL 2.0 to Elastic License 2.0 in an upcoming release. The current repository `LICENSE` says Elastic License 2.0. I did not establish the first release tag governed by the new license. The source is available, but the current license restricts offering Convoy as a hosted or managed service to third parties; calling the current code simply “open source” would hide this restriction.
- The website changelog is behind GitHub: its latest entry checked was 26.8.0, while GitHub lists 26.9.2. I report both with their sources rather than treating the dates as conflicting release data.

## Conflicts and unknowns

I used the official fallback values ($99 Pro, $499 Premium, contact-based Enterprise) only with that qualification. The current live catalog could not be checked without signing in.
- The old 2022 Cloud pricing blog described free usage and monthly event-volume tiers that are not the current pricing model. I gave precedence to the current pricing FAQ and plan UI source, which describe fixed monthly prices and throughput limits. The old article checked: https://www.getconvoy.io/blog/Convoy-Webhooks-is-free-for-developers
- The current license file is ELv2; the exact release tag where the change from MPL 2.0 took effect was not established.
- A hard payload limit, exact cloud data-transfer charges, cloud inactivity deletion rule, and general self-service export/account deletion schedule were not found after checking the Events docs, pricing, docs index, Cloud policy, privacy policy, and terms.

## Field problems

- **C03 / license wording:** Convoy markets its Community gateway as open-source, but the current repository license is Elastic License 2.0 and restricts third-party hosted/managed offerings. I describe it as source-available with that restriction.
- **C12–C16 / Cloud billing:** the public pricing page does not expose the dynamic Cloud catalog in its searchable text. The official repository contains static fallback comparison prices, not proof of the current checkout catalog. Recheck the plan catalog before publication or purchase.
- **H01 / single dependency claim:** the private-network page says “one PostgreSQL dependency,” while standard deployment docs require PostgreSQL and Redis. A paid experimental PostgreSQL queue changes that setup; do not assume it is a general default.
- **C04 / changelog recency:** the website changelog and GitHub release feed are updated on different schedules. Both dates are reported above.
