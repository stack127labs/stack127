## Conflicts and unknowns

- The current product page says “750 GB/h” free for 90 days, while the FAQ describes 750 GB total across the two Standard classes. The FAQ gives the detailed sharing and overage rules, so this file uses that specific amount and records the discrepancy.
- The FAQ's trial eligibility line contains a past cutoff date, 2023-11-30. It does not say whether the old cutoff still governs new accounts.
- The live pricing page currently shows Glacier at €0.0000034/GB-hour and approximately €0.00246/GB-month. A cached official search copy showed €0.0000035 and €0.00254; the directly opened live table was used.
- The price page's readable table shows Paris. Attempts to load it with region query parameters were inaccessible, so prices for Amsterdam, Warsaw, and Milan are not asserted. The current availability matrix was used for region and class availability.
- The egress footnote identifies some inter-region routes but does not give their separate per-GB rate or explain how those routes use the 75 GB allowance; Milan is absent from the route list.
- The contracts page lists a current General Terms version and Specific Conditions Storage. The PDF download controls were not exposed as readable links in the page view; account closure and data deletion behavior were checked in the official docs instead.
- The 2022 Object Storage product sheet describes an older 75 GB inter-region transfer allowance. Current prices and allowances above use the current pricing page.
- Older July 2025 documentation omits Milan from its Standard Multi-AZ text. The current product availability matrix includes Milan for both Standard classes and excludes only Glacier there.
