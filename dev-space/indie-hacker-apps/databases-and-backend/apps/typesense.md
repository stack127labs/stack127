## Conflicts and unknowns

- The Cloud calculator is interactive and does not expose a readable rate table in the research view. The official Cloud Management API documents regional/configuration prices in US cents, but its prices endpoint requires a `billing:read` key. I did not create an account or attempt to obtain a key, so no paid node total or exact per-region amount is claimed.
- The billing guide gives an approximate USD $0.09–$0.12/GB outbound range but does not map each number to a named region. I kept that rate as a range rather than assigning a region.
- The release page marks v30.2 latest but the rendered date omits the year. I recorded the version and the visible month/day, without importing a year from non-official sources.
- Typesense recommends a separate primary/source-of-truth database. The docs checked do not describe a multi-document transaction API or isolation model, so this file does not imply transactional correctness for money or inventory workflows.
- The one-time Free usage allowance (720 node-hours and 10 GB outbound) and the Free support tier are different offers. The support plan's critical-production response target applies only to HA clusters; it is not a general Cloud uptime SLA.
- Typesense gives a 7 bytes × dimensions × vector count memory estimate. That is vector memory only; the exact workload also depends on indexed metadata, schema, search settings, model execution, and cluster overhead. No precise record capacity is inferred.
- The Cloud locations guide lists cluster locations. The privacy policy, DPA, security, and subprocessor pages do not establish a blanket guarantee that every account/support/operational datum remains in the selected cluster region.
- The blog, release page, and current status page were checked for company acquisition, shutdown, and sunset notices. No separate official newsroom was found; no notice was located in those sources.

## Field problems

- Typesense is a search engine/vector database, not a general application database. Its own use-case guide recommends keeping a separate primary datastore; transaction semantics were still attempted and recorded as not published after checking document, collection, syncing, and use-case docs.
- F01–F07 and J01–J05 are not applicable because Typesense does not sell customer file storage or user job execution. Database snapshots and Cloud backups remain under D05, not object-storage fields.
- The Free allowance has node-hour and outbound limits but no separately published record or request quota; RAM and configuration bound practical capacity.
- The exact paid Cloud rate API is account-capability protected. The public calculator and billing documentation were still checked; accessible source material does not support an exact regional paid quote.
