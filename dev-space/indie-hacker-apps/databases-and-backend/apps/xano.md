### 1. Small SQL app

Therefore $99 is a conditional subscription estimate, not a tested all-cost quote. Free has 1GB SSD/100k stored records and a 10-per-20-second request window, but reads are not stored record counts; traffic bursts, overhead and Free's development/location scope prevent claiming this production scenario is free. ### 2. Full app backend

Inputs: the same database/read/write/connection load, **1,000 MAU**, 1GB files, 100,000 file reads, 10,000 uploads, **20GB total output**, 10,000 short custom function calls with a **128MB working-set assumption**. Assume one second/call for illustration; Xano does not publish a selectable 128MB per-call machine.

Public-file variant: `Essential $99/month + $0 selected add-ons = $99/month known subscription`, or $1,020/year annually. One GB files is within 100GB media allowance, and 20GB is below the advertised 250GB **file** bandwidth number if it is accounted there. No extra published MAU/invocation charge. **Actual CPU fit, API-output accounting, period/cutoff and any external-service costs remain unresolved.** [Resources and features](https://www.xano.com/pricing/), [Auth implementation](https://docs.xano.com/building-backend-features/user-authentication-and-user-data.md), [Lambda execution](https://docs.xano.com/the-function-stack/functions/apis-and-lambdas/lambda-functions.md), [Billing](https://docs.xano.com/your-xano-account/billing.md).
