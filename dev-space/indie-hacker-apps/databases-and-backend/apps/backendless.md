## Cost examples: our calculations

Checked 2026-11-04. These are our calculations, not vendor quotes. Use one North American Cloud app, a 30-day billing cycle, no custom paid support/security features and no external CDN. Taxes, external email/SMS/model services and unknown transfer charges are excluded. Data is retained for the full month. Database objects, table distribution and record size must fit the chosen plan; the approved 1GB database workload does not specify those inputs.

Rates: [Variable daily tiers](https://backendless.com/introducing-scale-plan/), [Fixed monthly tiers](https://backendless.com/how-does-billing-for-scale-fixed-plan-work/), [storage/function packs and limits](https://backendless.com/pricing/backendless-cloud/), checked 2026-11-04. General formulas: Variable API fee = sum of the 30 daily peak-tier prices. Fixed API fee = selected tier's monthly fee + hourly overages. Add required packs and other charges. API requests are not automatically the same as rows read or returned.

| --- | --- | --- |

Variable: 30 × $0.50; Fixed Tier 1: $15. | **$15 API subtotal** either way under that pacing.
