**Lifecycle and company news:** Filebase Object Storage is active; the company launched it on 2026-05-20 as S3-compatible storage with a built-in CDN and free object egress. The Filebase blog's newest visible post was dated 2026-09-08. I checked the blog and the News section on About for acquisition or current shutdown notices; I found no Filebase acquisition or notice that the current S3 or IPFS services are closing, and no separate newsroom. There are older notices for retired integrations: Skynet and Storj were removed in 2022, and the Sia integration was sunset in 2023. The status page listed the API, dashboard, dedicated IPFS gateways, and public IPFS gateway as online on 2026-11-05; it does not list S3 Object Storage as its own component. ## Cost examples — our calculation

All scenarios use the currently published USD plan prices and rates checked on 2026-11-06. Amounts exclude taxes.

1. **Free S3 use:** 4 GB pooled storage, no downloads, and 100K Class A / 1M Class B operations. Calculation: $0/month plan + $0 overage = **$0/month**. This stays below the current pricing-page request allowances; it does not resolve the conflicting 5 GB Free egress cap in older docs.

2. **Pro S3 use:** 600 GB stored, 2M Class A requests, 12M Class B requests, and 100 GB object egress. Calculation: $7.50 base + (100 GB × $0.015) + (1M excess Class A × $4.50/M) + (2M excess Class B × $0.36/M) + $0 S3 egress = **$14.22/month**. Assumes full-month usage, no IPFS traffic, and no taxes.

3. **Pro mixed S3 and IPFS use:** 300 GB in S3 and 300 GB pinned on IPFS (600 GB pooled total), 100 GB S3 egress, and 400 GB IPFS egress. Calculation: $7.50 base + (100 GB over pooled storage × $0.015) + (150 GB over Pro IPFS egress × $0.015) + $0 S3 egress = **$11.25/month**. Assumes no S3 request overages, no taxes, and the plan page's GB units without conversion.

## Conflicts and unknowns

- **Free egress:** Current pricing and Free pages call object egress free, without a numeric limit. The current docs and signup page say the Free tier is capped at 5 GB of monthly egress and blocks downloads after the cap. I use the docs for enforcement and the current pricing table for the plan label; the actual Free S3 bandwidth cap remains conflicting.
- **Free IPFS egress:** The current pricing/free pages list 10 GB per month; the signup docs list 5 GB. I use 10 GB as the current tier value and record the older documentation conflict.
- **Free S3 request allowances:** The current plan table shows 100K Class A and 1M Class B. The detailed pricing guide shows 1M and 10M; its text directs users to the plan page for current tiers, so I use the plan page.
- **Terms scope:** The November 2025 Storage Terms describe distributed third-party storage nodes and local encryption. Filebase's May 2026 S3 launch says its new object storage runs on company-operated bare metal. The Terms page incorporates older Terms of Use, and the current product-specific legal scope is not clearly reconciled.
- **Commercial Free use:** The current Free page promotes lightweight launches and small real projects. The 2019 Acceptable Use Policy prohibits offering commercial paid services from free trial accounts. The current plan is called a free tier, not a trial; the policy's application is unclear.
- **GB unit:** The detailed billing guide defines GB as 2^30 bytes, while the current pricing page says GB without repeating the definition. The IPFS calculator calls its own display unit 1 billion bytes. Cost examples use the plan's published GB amounts without converting.
- **Gateway counts:** Current pricing says “Gateway + CDN” but does not fully clarify whether the number refers to public gateways, dedicated gateways, or a combined quota. The dedicated gateway guide explains features but does not reconcile the plan label.
- **Location:** Filebase gives a global S3 endpoint and region auto, but no selectable S3 region or clear current data-residency guarantee. IPFS region us-east-1 is an API setting only. An older IPFS blog described three-country replication; I do not assume that architecture applies to current S3.
- **News check:** I checked the company blog through its visible September 2026 posts and the About page's News section. No separate newsroom or Filebase acquisition/current service shutdown announcement was found. The historical Skynet, Storj, and Sia notices concern retired integrations.
- **Status check:** The status page listed API and IPFS gateway components but no dedicated S3 Object Storage component. It therefore does not independently establish S3 Object Storage uptime.
- **Unpublished limits:** Filebase does not publish a numeric monthly Free API request allowance, an IPFS-specific maximum object size, a public spend cap, an inactivity deletion interval, or a contractual SLA percentage in the pages checked.
