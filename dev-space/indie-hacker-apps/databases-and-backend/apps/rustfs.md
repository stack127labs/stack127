## Conflicts and unknowns

- The official blog and about page describe the project as production-ready after the 1.0.0 GA announcement. The hardware docs still require operators to size and validate their own production cluster; GA is the vendor's maturity claim, not a workload guarantee.
- GitHub Releases identifies 1.0.4 as the latest stable release checked on 2026-11-06. The 2026-10-27 security post says deployments at 1.0.3 and earlier should upgrade.
- The official site has a blog, but no separate newsroom link was visible on the pages checked. The direct /newsroom/ URL failed; the blog archive and GitHub release history were checked instead.
- The official footer Legal link points to the Apache license. A direct /terms/ URL did not load. The Apache-2.0 license and official Privacy Policy were checked; no separate self-host Terms of Service was found.
- No overall maximum object size or fixed bucket capacity was published in the docs pages checked. The production guide's 500 active bucket figure is a recommendation, not a hard limit.
- The S3 compatibility matrix is dated 2026-08-09 and lists a tested subset. Its snapshot can change; verify current behavior for critical operations.
