- Current status: Active managed object storage. Tencent Cloud’s COS notice dated 2026-10-21 says that from 2026-12-01, new or modified origin-pull rules cannot use redirect mode, and synchronous/asynchronous origin-pull cannot disable 3xx following. Existing rules are not affected. I checked COS release notes and announcements, Tencent’s newsroom, and the official blog URL; I found no COS shutdown, Tencent Cloud shutdown, or acquisition notice in those sources. The blog URL did not return a readable page, so the product announcement index and company newsroom were the usable news sources.
- Scope: Tencent Cloud’s hosted object-storage service only. COS storage, request, retrieval, transfer, and management charges are kept separate from CDN, Cloud Infinite (CI), and other Tencent products. International pricing is shown in USD, but the live COS rate table did not render during this check; no numeric rate is inferred from older examples.
