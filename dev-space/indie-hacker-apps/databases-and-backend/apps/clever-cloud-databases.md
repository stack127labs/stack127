## Current status and retirement notices

Checked **2026-11-05**. The main public database family is active. No complete database-platform shutdown or parent-company acquisition notice was found in the inspected official product, documentation and lifecycle pages. This is a bounded notice search, not a future availability guarantee. Sources: [product](https://www.clever.cloud/product/postgresql/), [database index](https://www.clever.cloud/developers/doc/deploy/databases/), [lifecycle notices](https://www.clever.cloud/developers/changelog/2025/09-01-backups-dev-db/).

- **PostgreSQL 11/12:** new provisioning stopped April 30, 2025; existing add-ons remain manageable. [Official notice](https://www.clever.cloud/developers/changelog/2025/03-24-postgresql-11-12-eol/) (checked 2026-11-05).
- **MySQL:** 5.7 and 8.0 are marked end of life. The docs say Percona 8.0's final release was June 2026 and recommend 8.4/9.7. This is an engine-version warning, not closure of MySQL hosting. [Supported versions](https://www.clever.cloud/developers/doc/deploy/databases/mysql/) (checked 2026-11-05).
- **Free SQL backups:** PostgreSQL/MySQL DEV backups ended October 1, 2025; the testing plans continue. [Official change](https://www.clever.cloud/developers/changelog/2025/09-01-backups-dev-db/) (checked 2026-11-05).
- **MongoDB DEV:** no longer available; the page does not establish its withdrawal date. The paid guide still documents MongoDB 4.0.3 and makes higher versions subject to a separate MongoDB license/subscription and contact with the vendor. [MongoDB guide](https://www.clever.cloud/developers/doc/deploy/databases/mongodb/) (checked 2026-11-05).
- **Materia:** KV is Beta and free during testing, with a warning against sensitive or production-grade data. TS needs private-access activation. [KV](https://www.clever.cloud/developers/doc/deploy/databases/materia-kv/), [TS](https://www.clever.cloud/developers/doc/deploy/databases/materia-ts/), [access-stage index](https://www.clever.cloud/developers/doc/deploy/databases/) (checked 2026-11-05).
- **PostgreSQL default changes:** dedicated PostgreSQL 18 became default September 15, 2026; the DEV version-18 update was announced October 14, 2026. [Dedicated change](https://www.clever.cloud/developers/changelog/2026/09-01-postgresql-18-default/), [DEV change](https://www.clever.cloud/developers/changelog/2026/10-14-postgresql-18-dev/) (checked 2026-11-05).

## Scope and evidence

This is a provider-family record, not one interchangeable database plan. Hosted PostgreSQL, MySQL/Percona, MongoDB, Redis and Elastic have separate limits. Materia KV/TS have different access stages and semantics. Cassandra's public self-service availability is unresolved. Commercial On-Premises is an adjacent edition, with its operating requirements recorded under H01.

Every fact row carries its own exact official source links and checked date. Upstream engine/extension sources are labelled as upstream references; they do not prove the provider's installed configuration. Unknowns include the pages inspected. Cost examples are our calculations, not vendor quotes. Original display units and raw allocation bytes are kept separate.
