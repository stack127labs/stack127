- Current status and ownership notice: Uploadcare is operating. Uploadcare's blog had posts through 2026-10-07, its release notes through 2026-10-20, and its status page showed service components operational when checked. I found no shutdown or sunset notice in those official pages. I did not find a separate Uploadcare newsroom; I checked Uploadcare's company blog, changelog, status page, and Tiugo's acquisition announcement. - Scope: Hosted Uploadcare file infrastructure: file intake, storage, file and image processing, and CDN delivery. Enterprise customers can connect their own AWS S3 storage; that option is recorded separately from Uploadcare's managed storage and is not an S3-compatible Uploadcare endpoint.

## Cost examples

Both totals are **our calculations**, not Uploadcare quotes. They use USD monthly billing before tax and the public Pro rates. The active estimate assumes 10,000 total operations, 30 GB of traffic, and 12 GB average stored files for one month. It excludes separate AWS, CDN, or app-hosting costs. The idle estimate assumes no file requests or processing and storage within the included allowance.

- **Small active project on Pro monthly:** $79 subscription + 5,000 overage operations ÷ 1,000 × $1.60 + 5 GB excess traffic × $0.35/GB + 2 GB excess average storage × $0.35/GB = **$89.45/month before tax**.
- **Idle project:** Pro costs **$79/month** even when there is no activity, as long as the project remains on the monthly plan. Free is **$0/month** within its 1 GB storage and usage allowances, but is restricted to personal use.

## Conflicts and unknowns

- **Free file types/card:** The 2026-04-24 release note says Free-plan restrictions on non-image types were removed. The current upload guide still says Free permits image uploads only and that other types require a card for KYC. I use the newer release note for the file-type change, but whether a card is still required is unclear.
- **Free over-limit behavior:** The pricing FAQ says service is temporarily suspended until the next month; the terms allow some Free accounts to pay overages to unblock service. The FAQ is used as the normal outcome; the paid-unblock option is discretionary.
- **Older max-size wording:** The general FAQ describes a lower range than the current plan grid. The current plan table and current upload docs support the listed 500 MB / 1 GB / 10 GB / 5 TB plan values.
- **Data location:** The subprocessor list names AWS in the United States for stored data, but I found no exact managed-storage AWS region or customer region selector. Enterprise customers can use their own AWS bucket and select its region.
- **Data deletion:** Terms end access immediately after termination. Privacy policy says account data can remain for varying periods, no longer than 12 months after closure. It does not give a specific deletion time for stored file contents.
- **No S3-compatible endpoint:** Uploadcare's documented API is its own Upload/REST/URL API. The own-AWS-S3 feature is a destination/storage mode, not an S3-compatible endpoint.
- **Company news:** The official Uploadcare blog, release notes, service status, and Tiugo acquisition announcement were checked. I found no separate Uploadcare newsroom and no official shutdown/sunset notice in the searched sources.
