## Cost examples

All figures below are USD. The license arithmetic is **our calculation** from SeaweedFS's published capacity rates. It is not a vendor quote and excludes infrastructure, power, taxes, network, and optional support.

- Community software: `$0` license fee under Apache-2.0. Total monthly operating cost is unknown without the operator's server, disk, power, and network prices.
- Enterprise, 1 TB used physical capacity, monthly billing: `1 TB × $2/TB/month = $2/month` license.
- Enterprise, 1 TB used physical capacity, annual billing: `1 TB × $20/TB/year = $20/year` license.
- Enterprise, 1 TB logical data with 2× replication: licensed capacity is 2 TB; `2 TB × $2/TB/month = $4/month` or `2 TB × $20/TB/year = $40/year` license. This follows the pricing page's rule that replicas count as used storage.

A complete small-file-store estimate is not possible from SeaweedFS prices alone: the product has no hosted storage/request/egress bill, and official pages do not name a standard hardware size or infrastructure rate.

## Conflicts and unknowns

- The current site emphasizes Enterprise, while the GitHub repository is the canonical source for the Apache-2.0 community project. This is a product presentation difference, not a license conflict.
- The critical S3 gRPC advisory lists affected versions `<=4.45`, no patched version, while the latest release is 4.52. The published advisory does not explain whether later code fixes it; do not infer a remediation version from the version number alone.
- The 256 MB `fileSizeLimitMB` default applies to a request path and is configurable. It is not the maximum S3 multipart object size. The API, large-file, master, and volume pages checked did not state an overall multipart cap.
- The 30 GB default describes a volume size, not a bucket or object ceiling.
- Replication and erasure coding need distinct failure domains and operational repair. Neither alone is a backup against deletion or corruption.
- The official `/news/` address did not open in the browser tool. The blog index, product/legal pages, repository releases, and security history were checked instead; no shutdown or acquisition announcement was found there.
- A separate privacy policy was not found through the official footer or legal pages checked. Enterprise terms say the vendor does not access customer cluster data; this does not establish a broader website privacy policy.
