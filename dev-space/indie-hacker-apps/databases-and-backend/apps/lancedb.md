## Cost examples — our calculations

The standard small vector scenario is 100,000 vectors with 1,536 float32 values and 1 KiB metadata each, plus 100,000 searches, 10,000 updates, and 5 GB internet transfer each month.

- Raw vectors: 100,000 × 1,536 × 4 bytes = **614,400,000 bytes**.
- Metadata assumption: 100,000 × 1,024 bytes = **102,400,000 bytes**.
- Combined raw payload: **716,800,000 bytes** (683.59 MiB).
- Embedded license: **$0** under Apache-2.0; hardware, object storage, storage requests, backup, transfer, and any embedding or reranking provider remain separate. Monthly total: **incomplete** because no region or infrastructure provider was selected.
- Enterprise or Cloud monthly total: **unknown**. There is no public LanceDB plan price or complete usage meter to calculate this workload. Cloud terms point to an Order Form and contractual Service Capacity.
- Idle project: **incomplete** for Embedded because retained storage and any stopped/allocated host are provider-billed. Enterprise/Cloud idle fees are unknown.

These calculations are raw payload arithmetic, not a storage bill or capacity guarantee. They exclude IDs, indexes, compression, table versions, source files, cache, backups, and temporary working space. The 5 GB transfer and request counts cannot be priced from LanceDB’s public pages.

The other starter scenarios do not produce comparable LanceDB totals: it is not a full app backend with hosted auth/functions/files, a general SQL database service, a file bucket, or an arbitrary job queue. Those needs require separate services.
