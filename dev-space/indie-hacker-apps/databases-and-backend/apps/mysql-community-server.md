## Cost examples

**Our calculations**, checked 2026-11-05. These are workload comparisons, not measured benchmarks or vendor quotes. The database baseline is one self-hosted MySQL Community Server 8.4 LTS using InnoDB. No hosting vendor, machine, geographic region, tax jurisdiction or external service was selected. Therefore there is no defensible all-in hosted price. Dollar amounts below retain the official calculator's USD currency.

### 1. Small SQL app

Inputs: one production database, 1 GB stored for a month, 100,000 reads, 20,000 writes, 10 peak connections, 5 GB internet transfer, 730 always-on hours. The [GPL license](https://raw.githubusercontent.com/mysql/mysql-server/8.4/LICENSE) has no workload fee; [8.4 connection limits](https://docs.oracle.com/cd/E17952_01/mysql-8.4-en/server-system-variables.html#sysvar_max_connections) are configurable and default to 151. This does not prove that an unspecified machine can handle the workload.

Formula: **Community license = 1 server × USD 0 = USD 0**. Total = USD 0 software + host compute for 730 hours + persistent storage + backup/log storage + 5 GB transfer under the chosen provider's rules + administration. **Result: USD 0 software; total incomplete.** There is no expiring trial or a paid usage tier that automatically replaces this license.

Optional paid-software comparison: [published reference prices](https://www.mysql.com/de/tcosavings/) give Standard 1–4 sockets at **1 × USD 2,140/year = USD 2,140/year**, and Enterprise at **1 × USD 5,350/year = USD 5,350/year**. These are separate editions with annual support subscriptions, not an invoice for hosting this workload. The [US store](https://shop.oracle.com/apex/product?p1=MySQL) shows matching starting amounts but subscription ranges; taxes and the selected order term were not established. Do not silently divide an annual contract into a cancellable monthly plan.

Backup variant: a full logical dump plus retained binary logs enables [point-in-time recovery](https://docs.oracle.com/cd/E17952_01/mysql-8.4-en/backup-types.html). Software formula remains USD 0; total adds the unknown size/retention of full backups and logs, backup-transfer charges, scheduling and recovery work. Input data size alone cannot predict binary-log or backup-storage use.

Replica variant: **2 Community servers × USD 0 = USD 0 software**; add two suitably sized hosts, replicated disk capacity, network transfer and monitoring. A Group Replication deployment also needs its actual members and [client redirection](https://docs.oracle.com/cd/E17952_01/mysql-8.4-en/group-replication.html) priced. A commercial deployment must license the [appropriate installations](https://www.mysql.com/products/enterprise/compare/); it cannot reuse a one-server price for every replica.

### 2. Full app backend

Inputs: the SQL case plus 1,000 monthly active users, 1 GB files, 100,000 file reads, 10,000 uploads, 20 GB total internet transfer, and 10,000 function calls. Function assumption: each runs actively for 1 second using 0.5 vCPU and 0.5 GB RAM on an external worker where that allocation exists.

Formula: **10,000 × 1 second = 10,000 worker-seconds**; nominal resource arithmetic is 5,000 vCPU-seconds and 5,000 GB-seconds, before the actual host's allocation/billing rules. Total = SQL infrastructure + application identity/authentication + file storage/delivery/request charges + external workers + operations/logs. Use **20 GB total transfer**, not 20 GB plus the SQL case's 5 GB.

**Result: incomplete and outside Community Server's bundled scope.** [Community features](https://www.mysql.com/products/community/) and [SQL events](https://docs.oracle.com/cd/E17952_01/mysql-8.4-en/create-event.html) do not supply a hosted application-user directory, object delivery and general function compute. No price is invented for those external components. Email/SMS are also unpriced. The free software and optional commercial editions both still need these components.

### 3. Small file store

Inputs: 100 GB hot files for a 30-day month, 100,000 writes, 1 million reads and 100 GB internet transfer; files remain for the month.

**Result: not applicable as a standalone object-service quote.** No Community storage class, signed-link delivery tier or S3 request tariff exists in the [database connector/product scope](https://docs.oracle.com/cd/E17952_01/mysql-8.4-en/connectors-apis.html). If an application chooses to store binary data in SQL, that is a different design: total = database capacity + host storage + backups + transfer + an application upload/delivery service. Record/packet limits and database recovery then apply; USD 0 licensing is not a USD 0 file-hosting quote.

### 4. Small vector search app

Inputs: 100,000 vectors, 1,536 float32 values each, 1 KiB metadata per vector, 100,000 searches, 10,000 updates and 5 GB internet transfer per month. This does not assume that the 8.4 baseline has the newer native vector datatype.

**Our raw-payload calculation:** 100,000 × [(1,536 × 4 bytes) + 1,024 bytes] = **716,800,000 bytes**, before identifiers, row/storage layout, indexes, replication and backups. Four-byte entries are documented for the [26.10 VECTOR type](https://dev.mysql.com/doc/refman/26.10/en/vector.html). This is payload arithmetic, not billable index size.

The 26.10 type can store these dimensions, but the documented [DISTANCE function excludes Community](https://dev.mysql.com/doc/refman/26.10/en/vector-functions.html), and VECTOR cannot be used as a key. **Result: incomplete for the requested search workload.** A separately implemented search path/service, hardware, latency target, filter/index overhead and model/embedding charges remain unpriced. No amount is assigned to a non-included native ANN index or to external model tokens. Current datatype support must not be carried back into the 8.4 comparison baseline.

### 5. Small job workload

Inputs: 10,000 jobs × 1 active second, peak 5 concurrent jobs, nominal 0.5 vCPU/0.5 GB RAM where such a worker is offered, no retries or waits in the base case.

For SQL-only work using [CREATE EVENT](https://docs.oracle.com/cd/E17952_01/mysql-8.4-en/create-event.html), software remains USD 0, but events share database resources; there is no dedicated Community worker-machine SKU. **10,000 × 1 second = 10,000 active seconds** is an assumption, not a MySQL benchmark or a billing unit.

For general code, total = external worker hosting + orchestration/queue if used + database infrastructure + logs and transfer. **Result: incomplete.** The workload alone does not specify a compatible worker host or price.

Retry/wait variant, explicitly assumed for comparison: 1,000 additional attempts of 1 active second add **1,000 seconds**, giving **11,000 active seconds**; 1,000 jobs waiting 60 seconds add **60,000 seconds of elapsed waiting**. Neither duration establishes a MySQL invoice. Whether an external worker remains allocated while waiting and how retries are billed depends on that provider. SQL event recurrence is not a managed retry/deduplication contract; overlapping events require [application controls](https://docs.oracle.com/cd/E17952_01/mysql-8.4-en/create-event.html).

### 6. Idle project

Inputs: retain the SQL case's 1 GB of data for a month, zero reads/writes, zero active jobs; keep whatever backups were selected.

Formula: **Community license = USD 0**. Total = retained host/storage/backups and any operational costs. If the host remains allocated for the comparison month, its 730-hour allocation can remain billable even without queries. Stopping the process only changes the software's running state; actual savings depend on the host.

**Result: USD 0 software; idle total incomplete.** There is no Community cloud-project inactivity deletion rule or automatic scale-to-zero credit. Optional annual [commercial subscriptions](https://www.mysql.com/de/tcosavings/) remain annual commitments during their purchased term; zero queries do not create a per-second refund. The [18-month optional Oracle Account rule](https://www.oracle.com/legal/privacy/privacy-policy/) concerns website account information, not the operator's local database.

- C09/C10 must distinguish a GPL software grant from a hosted free allocation; assigning monthly GB or request quotas would misdescribe the product.
