## Scope and evidence

This record covers the hosted, provisioned PostgreSQL/MySQL service: Cost Optimized and Production Optimized nodes, standalone/HA/read replicas, storage, backups, PostgreSQL vector extensions and scheduled SQL. Separate Serverless SQL, MongoDB, Redis, Object Storage, general functions and queues are outside this product's bundle. Prices are the visible **Paris EUR prices before tax**, not converted to another currency.

All 46 field IDs were attempted. The task's six states override the vocabulary in `fields.md`. `not_published` means not found in the named public-page search; it is not proof of absence. Calculations are our own and remain separate from published facts. Product classification and comparison choices are researcher judgments.

Official product, pricing, SLA, contract index, privacy policy and accessible legal PDFs were read with public web retrieval. Direct requests to www.scaleway.com returned HTTP 403. No signup, login, form submission, database access or workload was used.

## Cost examples — our calculation

These are incomplete comparisons, not vendor quotes or measured sizing recommendations. All source checks below are dated **2026-11-05**. Normal paid prices apply with no recurring free allowance. A Founders credit application may reduce eligible costs for an accepted applicant, but acceptance, balance and coverage were not assumed. [Founders promotion](https://www.scaleway.com/en/startup-program/founders-program/)

Use these variables for a full month:

- `B`: actual billed GB-months of database Block Storage, including the selected allocation and any required per-node volumes. It is not necessarily the 1 GB of application records.
- `K`: actually billed GB-months of retained backups/snapshots. Seven retained snapshots are not assumed to equal seven full database copies.
- `T`: applicable network/transfer charges, including the scenario's 5 GB internet transfer; current route-specific rates were not verified.
- `X`: other required charges, if any, for the chosen configuration. Paid support, app hosting, model APIs and separate file/function services are excluded and must be added if used.

Storage coefficients below use **5K Block Storage**. For 15K, replace the storage coefficient with the published 15K rate in C13. Sources: [Paris SQL pricing](https://www.scaleway.com/en/pricing/managed-databases/), [volume and backup billing](https://raw.githubusercontent.com/scaleway/docs-content/main/pages/managed-databases-for-postgresql-and-mysql/how-to/manage-volumes.mdx), [automatic backup settings](https://raw.githubusercontent.com/scaleway/docs-content/main/macros/databases/autobackups.mdx).

### Small SQL/document app and idle project

Inputs: one production database, 1 GB application data retained for a month, 100,000 reads, 20,000 writes, 10 peak connections, 5 GB internet transfer, 730 provisioned hours. This service is SQL; the document-store part of the generic scenario does not apply.

The lowest listed main-node price gives a **compute component** of:

`DB-DEV-S: 730 × €0.0156 = €11.388`

Conditional monthly formula using that node and eligible 5K volumes:

`€11.388 + (€0.0993 × B) + (€0.03 × K) + T + X`

For a newer listed Cost Optimized alternative:

`DB-PLAY2-PICO compute: 730 × €0.0233 = €17.009`

The cheapest configuration **proven to meet the full workload was not established**. ### Small vector search app

Inputs: 100,000 vectors, 1,536 float32 values per vector, 1 KiB metadata per vector, 100,000 searches and 10,000 updates/month, 5 GB internet transfer.

Our raw-data calculation is:

`100,000 × [(1,536 × 4 bytes) + 1,024 bytes] = 716,800,000 bytes = 0.7168 decimal GB`

Upstream pgvector's stored vector representation adds eight bytes per vector, bringing this narrowly defined vector-plus-metadata subtotal to:

`716,800,000 + (100,000 × 8) = 717,600,000 bytes = 0.7176 decimal GB`

Neither number includes SQL tuple/page overhead, indexes, WAL, operational free space, replicas or backups. A 1,536-dimensional vector fits the documented vector index dimension limit, but no node capacity/performance benchmark was run. Source for representation and index dimensions: [pgvector v0.8.1](https://raw.githubusercontent.com/pgvector/pgvector/v0.8.1/README.md); managed extension version: [Scaleway PG17 version notes](https://raw.githubusercontent.com/scaleway/docs-content/main/pages/managed-databases-for-postgresql-and-mysql/reference-content/pg-version-updates.mdx).

Use version-specific documentation for a supported capability; do not treat a historical list as a current ordering catalog.
