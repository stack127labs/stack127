# Deno KV

**Retirement and team-move notice:** on October 9, 2026, Deno announced that its team is joining Cloudflare. The announcement says **Deno Deploy will operate for six more months before shutting down**, with migration support for paying customers moving to Workers. Deno-led runtime development is scheduled to end after one more year of monthly bug/security releases; its source remains open. A separate denokv maintenance deadline is not stated. Preserve these relative periods rather than invent an exact final cutoff. Source: [Deno is joining Cloudflare](https://deno.com/blog/cloudflare), checked 2026-11-05 UTC.

**Earlier migration and API status:** Deploy Classic had a separate **July 20, 2026** shutdown deadline; Classic KV data does not automatically migrate to new Deploy. New Deploy was announced GA on February 3, 2026, but KV runtime APIs remain labelled unstable. Current new-Deploy KV queues are unsupported. Sources: [Classic migration](https://docs.deno.com/deploy/migration_guide/), [Deploy GA](https://deno.com/blog/deno-deploy-is-ga), [KV Quick Start](https://docs.deno.com/deploy/kv/) and [runtime API](https://docs.deno.com/api/deno/cloud/), checked 2026-11-05.

### Small database application
