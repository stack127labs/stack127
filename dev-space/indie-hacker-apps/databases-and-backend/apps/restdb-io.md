## Conflicts and unknowns

- **Discount billing period:** [Pricing](https://restdb.io/pricing/) displays $19/month Standard and $79/month Premium, with $29/$99 explicitly stated for monthly payment. Page text and markup say plans are per month or year but never label the lower rates as annual or show the upfront charge. [Terms](https://restdb.io/terms/) do not resolve billing/cancellation/tax conditions. Monthly-payment rates are recorded as confirmed; discounted commitment is unclear.
- **Free secure custom domain:** Pricing lists one limited custom secure domain for Development; [Features](https://restdb.io/features/) reserves automatically secured HTTPS domains for paid plans. [Custom-domain setup](https://restdb.io/docs/using-custom-domains-with-restdb-and-letsencrypt) gives no plan qualifier. This is a real entitlement conflict, not proof the free plan includes automatic TLS.
- **Hosted location:** [Privacy](https://restdb.io/privacy/) states Norway processing for personal information, while [Quick start](https://restdb.io/docs/quick-start) and [External MongoDB](https://restdb.io/docs/external-mongodb) give no managed region matrix. - **Billing and idle use:** searched pricing, Database limits, Quick start, API/media documentation, Terms and Privacy for inactivity intervals, scale-to-zero, egress, overage response and bill controls. These details were not found. Published subscription/rate maxima do not establish charge-free overages, a spend cap or unlimited paid traffic.
- **Database guarantees:** searched REST API, query/mutation docs, codehook database methods, External MongoDB, Database limits and both legal pages. - **Backups and leaving:** manual [Snapps](https://restdb.io/docs/snapps) explicitly include data/media/metadata/Pages; [pricing](https://restdb.io/pricing/) lists automatic backups without full coverage/retention detail for Standard. ## Field problems

- C10/C13 use the combined label Devs/Editors/Users, while the app-auth docs discuss external users separately. An allowance must not be converted directly into monthly active users without vendor clarification.
- Record quotas cannot be converted reliably to GB. Ten API calls/second is a throughput throttle, not ten concurrent connections. Daily operation distribution and media/internal-hook accounting also matter.
- C17's region requirement remains an evidence gap; a privacy processing location is not a full infrastructure residency guarantee.
- C12 needs an explicit discounted billing period and currency/tax terms. Only the plainly stated monthly-payment prices support firm base calculations.
- F05 distinguishes an S3 API from a native media API; F07 distinguishes data-record versioning, snapshot recovery and object versioning.
- J02 cannot be priced from “x seconds”; job inclusion does not imply unlimited compute. Codehooks.io features remain outside this app.
- H01 is not applicable to the complete hosted product. Customers may operate external MongoDB, but that does not make the restdb.io server self-hostable.
- No apps.md row error found. The active listing is supported by the current public offer, with no signup or uptime test.
