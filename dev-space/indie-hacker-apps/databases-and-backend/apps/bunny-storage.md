## Storage tiers and regional pricing

- **Standard HDD:** Lower-cost storage, any Standard region can be primary, up to 9 regions. Bunny lists variable 30–300 ms latency. The published formula is USD $0.01/GB-month per region for the first two regions, then USD $0.005/GB-month for each additional region.
- **Edge SSD:** Frankfurt (DE) must be primary; up to 15 regions are advertised. Bunny lists 1–5 ms latency. The published formula is USD $0.02/GB-month for each enabled region. The current region table lists 14 active codes; the Storage page marks Mumbai as planned.
- Both tiers list pay-as-you-go, no API request fees, free Storage API egress, free Storage-to-CDN transfer, RAID 6, and a $1 minimum account usage. The minimum conflicts with a “no monthly minimums” line lower on the marketing page; the current pricing and billing docs explicitly define the $1 account-wide minimum, so that is the rule used here.
- Bunny’s API reference identifies `PricePerGigabyte` as USD per GB-month and documents a regions API that returns a price per region. That endpoint needs an account AccessKey; the named-region response was not accessible here. The static page gives the regional count formulas above, but this file does not assign those rates to specific locations. Taxes are extra where applicable. CDN-to-user bandwidth is billed separately by Bunny CDN region/network tier.

## Conflicts and unknowns

- Bunny Storage’s product page says “no monthly minimums” in one section, but the same page’s price card, Storage pricing docs, and newer billing docs state $1 minimum usage for an active account. I use the specific billing rule: one $1 monthly minimum for the account, not for each zone.
- Edge SSD documentation and pricing advertise a maximum of 15 regions, but the current region table lists 14 codes and the product page labels Mumbai as planned. I do not count Mumbai as available.
- Storage durability docs state a 99.99% availability SLA and the general SLA page lists outage credits. The Terms of Service instead says 99.995% is an aim for the content delivery service and disclaims uninterrupted service. The exact Storage contractual credit terms are unclear.
- The Storage API reference says its regional price values are USD per GB-month and documents an authenticated region list API. The static pricing docs do not list its named-region response values; the endpoint could not be read in this check, so those location-specific prices remain unresolved.
- The maximum upload-file size was not stated in the HTTP guide, limits docs, S3 docs, or official Upload File API reference; no maximum is inferred.
- No storage-specific encryption-at-rest method or customer-managed-key option was found in the Storage docs, privacy policy, or terms. The privacy page only gives general encryption language.
- No storage zone version restore, recycle bin, or independent backup restore process was found. Replication copies writes and deletes.
