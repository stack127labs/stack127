## Notices

- Cloud Tasks is an active, generally available Google Cloud service. Its release notes list new regions on October 19, 2026, and task-level retries and batch task methods reaching general availability on September 30, 2026. The Cloud Tasks release notes and Google Cloud blog pages checked did not show a shutdown or acquisition notice.
- I checked the Cloud Tasks release notes and Google Cloud blog posts about launch, multi-region queues, and HTTP buffering. The release notes do not list a retired Cloud Tasks feature. Recent updates are listed below; the older blog posts are product background, not current pricing evidence.
- Cloud Tasks is a regional queue and HTTP dispatch service. It stores and dispatches tasks; your app or another HTTP handler does the work. It is not Pub/Sub, Cloud Run, or App Engine compute.

## Cost example

**Our calculation, USD:** If 2.5 million tasks are each at or below 32 KB, each is created once, and each gets one successful dispatch, that is 5 million billable operations. Subtract the 1 million free operations: 4 million × USD $0.40 / million = **USD $1.60** for Cloud Tasks operations. This excludes worker compute, network transfer, retries, and any other API calls.

## Conflicts and unknowns

- The canonical Cloud Tasks pricing page opened on November 6, 2026 lists USD $0.40 per million operations from 1 million and above. An older indexed copy with ?authuser=09 showed that rate only through 5 billion operations, then “contact sales.” I use the live canonical page checked today; the older search snapshot was crawled last month.
- Cloud Tasks is regional, but the current Google Cloud data-residency terms list does not include it. The location docs show where queues can be placed, but the checked sources do not establish a separate contractual residency commitment or backup-location promise.
- The Cloud Tasks pricing page says regular network costs apply for HTTP targets but does not give one transfer rate. The actual cost depends on the endpoint, its region, and network path. The checked Cloud Tasks price and App Engine target pages did not state a separate App Engine-target transfer rate.
- The Cloud Tasks docs checked describe scheduled task times but do not specify a recurring schedule or a native dead-letter queue. No assumption is made that either is included.

## Field problems

- C15 data transfer depends on the destination and its cloud/network pricing. A single Cloud Tasks rate would be misleading, so the file records the explicit rule and leaves the universal rate unpublished.
- C17 regional queue selection is documented, but the current contract data-residency list omits Cloud Tasks. The region table should not be presented as a legal residency guarantee.
- C21 is an example for a small workload. More attempts, payloads over 32 KB, list/get calls, logs, or network charges change the total.
