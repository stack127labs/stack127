## Cost examples — our calculations

These are estimates of required inputs, not a vendor quote or a benchmark. No host, region or currency has been selected. The software license does not supply compute, disks, backup space or network transfer. Sources: [Apache license](https://raw.githubusercontent.com/chroma-core/chroma/1.5.9/LICENSE), [self-hosted Docker deployment](https://docs.trychroma.com/guides/deploy/docker.md), [single-node sizing](https://docs.trychroma.com/guides/performance/single-node.md); checked 2026-11-06.

**Small vector search app.** Inputs from fields.md: 100,000 vectors, 1,536 float32 values each, 1 KiB metadata each, 100,000 searches/month, 10,000 updates/month and 5 GB internet transfer.

Our raw-data calculation:

- Vector payload = 100,000 × 1,536 × 4 bytes = **614,400,000 bytes**.
- Metadata payload = 100,000 × 1,024 bytes = **102,400,000 bytes**.
- Combined raw payload = **716,800,000 bytes**.

This excludes IDs, documents, HNSW graph overhead, SQLite/index overhead, write-ahead logs, free space, model files and backups. It is neither the required RAM nor total disk capacity. Supply precomputed 1,536-dimensional embeddings or configure a matching model; do not assume the default model matches that dimension. [Embedding functions](https://docs.trychroma.com/docs/embeddings/embedding-functions.md), [dimension validation](https://docs.trychroma.com/docs/collections/add-data.md); checked 2026-11-06.

Monthly total = **mandatory core license fee (none) + chosen host compute + primary disk + backups + 5 GB applicable network transfer + optional embedding/reranking + operations/monitoring**. Result: **incomplete; no exact monthly amount**. Query/update counts do not determine peak concurrency, CPU or recall requirements. There is no separate trial-expiry or paid-core-license path to calculate. External provider charges, taxes and region rates need the selected provider's evidence.

**Idle project.** Retain the same data, with zero searches and updates for a month. Monthly cost = continuing host allocation, retained disk, backups and monitoring, plus any applicable provider minimums. If the operator stops the process, retained persistent files can be loaded again; in-memory data has no persistence. Whether a stopped VM still incurs charges is the chosen host's policy. Result: **incomplete, not zero**. [Persistent/in-memory clients](https://docs.trychroma.com/docs/run-chroma/clients.md); checked 2026-11-06.

**Other approved scenarios.** The small SQL/document scenario's 1 GB, 100,000 reads, 20,000 writes, 10 peak connections, 5 GB transfer and 730 hours do not establish a suitable host: this is a vector collection API, not SQL, and query complexity is unspecified. The full backend scenario additionally needs app identity, file delivery and code execution outside this database. File-store and job-execution scenarios do not fit this product. No all-in amount is assigned to any of them.
