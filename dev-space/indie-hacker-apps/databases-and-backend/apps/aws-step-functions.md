## Cost examples

Prices below are for US East (N. Virginia), us-east-1, in USD. The AWS Price List API offer file did not open in this environment, so I used the AWS Step Functions pricing page's published us-east-1 examples and rates.

- **Our calculation — 10,000 Standard executions/month with 5 state transitions each:** (10,000 × 5 − 4,000 free) ÷ 1,000 × $0.025 = **$1.15 USD**. Excludes connected services, CloudWatch Logs, network transfer, retries, and taxes.
- **Our calculation — 100,000 Express executions/month, 200 ms duration each, 64 MB billed memory:** request charge = 100,000 ÷ 1,000,000 × $1.00 = $0.10; duration = 100,000 × 0.2 sec × 64/1,024 GB × $0.00001667 = $0.02084; total = **$0.12084 USD**. Assumes a small state-machine definition and payload fit one 64 MB block. Excludes connected services, logs, transfer, and taxes.
- **Our calculation — no workflow executions and no connected resources running:** Step Functions usage charge = **$0 USD**. Other AWS resources may continue billing independently.

## Conflicts and unknowns

- The requested AWS Price List JSON at https://pricing.us-east-1.amazonaws.com/offers/v1.0/aws/AWSStepFunctions/current/us-east-1/index.json could not be fetched by the web reader or direct shell request in this environment. The shell request failed DNS. I followed the fallback in the request and used the Step Functions pricing page, which publishes the us-east-1 Standard rate, Express request rate, and duration pricing examples.
- The AWS pricing page shows Express duration both as $0.00001667 per GB-second and, for high-volume usage, as monthly GB-hour tiers. I recorded both forms because the examples use different workload levels.
- The Step Functions pricing page still refers to the general AWS Free Tier as a 12-month term when describing its 4,000-transition allowance. AWS's current Free Tier FAQ describes introductory account plans as lasting up to six months; I treat these as separate offers and use the Step Functions page's indefinite transition allowance.
- AWS Infrastructure Composer's end-of-support notice says its standalone console shuts down on December 7, 2026 and removes the Step Functions console's export-to-Composer action; it does not announce a Step Functions service shutdown.
- I searched the AWS What's New pages, Step Functions Recent Feature Launches, and AWS Compute Blog and AWS News Blog categories for service retirement or shutdown notices. I found feature updates but no closure notice for Step Functions.
- A complete AWS account country list and exact service-data deletion interval after account closure were not established. I checked the setup guide, AWS Agreement, Service Terms, Privacy Notice, Free Tier FAQs, and DeleteStateMachine API reference. The Free Tier FAQ says payment method is not required for most new customers, though AWS may request one for identity verification in some cases.
