## Current status and notices

Amazon S3 remains an active AWS service. The AWS lifecycle list checked on 2026-11-06 does not list Amazon S3 as in sunset. AWS’s Amazon S3 News Blog and Storage Blog show current S3 development, including an October 2026 marketplace announcement and S3 posts through October 2026. The AWS newsroom pages checked did not show an S3 shutdown or acquisition notice. This is limited to the official pages listed in the table below.

A significant regional service incident is separate from product retirement: the AWS Health Dashboard page checked on 2026-11-06 lists disrupted service in **Middle East (Bahrain), `me-south-1`**, and **Middle East (UAE), `me-central-1`**. Its latest September 15 update says AWS cannot restore access to resources and data hosted only in one UAE Availability Zone; its April 30 update says the Bahrain region is unavailable and customers should recover from remote backups in other regions. The page also contains earlier incident updates describing S3 impact. This does not mean S3 is shut down globally. Users with buckets in either region should check their account health page and AWS’s current regional guidance.

Two narrower retirements are relevant to API planning: Amazon S3 Select and S3 Glacier Select stopped accepting new customers on 2024-07-25, while the S3 SOAP API reached end of life on 2025-08-31. Neither notice retires general purpose S3 buckets or the REST API.

## Cost example — our calculation

**Scenario:** Paid AWS account, bucket in US East (N. Virginia), `us-east-1`; USD list rates; one month; 100 GiB average S3 Standard storage, 100,000 Standard PUTs, 1,000,000 Standard GETs, and 100 GiB internet egress. Assumes the account has not used the global 100 GiB/month internet egress allowance elsewhere. No tax, free credits, versions, KMS, CloudFront, replication, archive retrieval, or optional management features.

| Input | Formula | Our calculation |
| --- | --- | ---: |
| Storage | 100 GiB × USD $0.023/GiB-month | USD $2.30 |
| PUT requests | 100,000 ÷ 1,000 × USD $0.005 | USD $0.50 |
| GET requests | 1,000,000 ÷ 1,000 × USD $0.0004 | USD $0.40 |
| Internet egress | 100 GiB within unused global monthly allowance | USD $0.00 |
| **Total** | USD $2.30 + $0.50 + $0.40 + $0.00 | **USD $3.20/month** |

This is our calculation from the cited rates, not an AWS quote. AWS calls its billing unit “GB” but defines it as 2^30 bytes (GiB). Rates can vary by Region and may change; the sample uses the named N. Virginia Region only.

## Conflicts and unknowns

- **Object size limit:** AWS S3 FAQ says 50 TB; the General Reference quota table says 48.828125 TB. The sources do not define the units consistently, so both values remain recorded as a conflict.
- **Payment method:** AWS Customer Agreement section 2.1 says an account needs a valid payment method. The newer Free Tier signup FAQ says most new customers do not need one, though AWS may request it for identity verification. The FAQ is used for the current signup path.
- **Regional incidents:** AWS Health reports prolonged service disruption in Bahrain and UAE, including unavailable or unrecoverable data in some affected locations. Check the live account health page before relying on buckets in those Regions.
- **Current pricing table limits:** The official pricing page and docs show the charges and many rules, but some dynamically rendered dollar tables were not exposed as readable text. The exact Intelligent-Tiering monitoring fee and current archive restore-tier rates are marked `check_failed`; older official blog values were not carried forward for these rows.
- **S3 terms:** The AWS Service Terms page (https://aws.amazon.com/service-terms/) was checked; no distinct S3-specific clause was found by searching “Amazon S3” and “Amazon Simple Storage Service.” AWS Customer Agreement, Privacy Notice, Acceptable Use Policy, and S3 SLA were read for the general legal and service terms that apply.
- **News check:** Checked the AWS News Blog, AWS Storage Blog S3 category, September 2026 service-availability update, AWS services-in-sunset list, About Amazon AWS newsroom, and current S3 product page for shutdown, sunset, or acquisition notices. No product-wide retirement notice appeared in those pages; feature/API retirements are listed above.
