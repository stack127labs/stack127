## Operating status and notices

**Security incident (2026-09-09 to 2026-10-07; disclosed 2026-10-19):** PingCAP reported unauthorized access to internal systems and copying of customer-related account, query-history and business/billing records. It reported no evidence that customer TiDB database contents were accessed or that the reviewed production systems were used. Customer-specific impact review was still underway; PingCAP recommended rotating management API keys and secrets shared in support. [Incident report](https://www.pingcap.com/trust-hub/security/security-update-october-2026/) · [Customer actions](https://www.pingcap.com/trust-hub/security/customer-actions-october-2026/).


The product/release/support-policy review was originally checked 2026-11-05 and the lifecycle/security notice sweep was rechecked 2026-11-09; the attempted status.pingcap.com endpoint was not accessible. No overall TiDB shutdown, sunset or acquisition notice was found in the official product, release notes or support policy checked. TiDB remains offered as self-hosted software and TiDB Cloud. Several newer Cloud products are previews, including PostgreSQL-compatible Starter, Essential, Premium, BYOC, Filesystem and Lake. Sources: https://www.pingcap.com/tidb/cloud/, https://www.pingcap.com/pricing/, https://docs.pingcap.com/tidbcloud/tidb-cloud-release-notes/, https://www.pingcap.com/tidb-release-support-policy/.

- **2026-10-20:** Chat2Query and its API stopped being supported in Starter SQL Editor and Data Service. Other SQL Editor/Data Service features remain. Source: https://docs.pingcap.com/tidbcloud/tidb-cloud-release-notes/, October 20 section.
- **2026-10-27:** Essential Regional High Availability entered public preview in AWS Tokyo; other regions are rolling out. Regional price changes apply immediately to instances created on/after October 26, and in January 2027 to earlier Regional instances. Source: https://docs.pingcap.com/tidbcloud/tidb-cloud-release-notes/, October 27 section.
- **Self-hosted v8.5:** Community maintenance ends 2027-12-19 and EOL is 2028-12-19; Enterprise maintenance ends 2029-12-19 and EOL is 2030-12-19. These support windows are not a TiDB shutdown. Source: https://www.pingcap.com/tidb-release-support-policy/, v8.5 table, policy updated 2026-06-09.

## Cost examples — our calculation

These are calculations from checked public rates, not vendor quotes or benchmarks. Decimal **GB = 1,000,000,000 bytes**, **GiB = 1,073,741,824 bytes**, **KiB = 1,024 bytes**. Calculations below retain extra decimal places to expose the conversion; displayed subtotals rounded to cents are explicitly labelled. Actual monthly invoice precision can differ. Source for TiDB storage/RU units: https://www.pingcap.com/tidb-cloud-starter-pricing-details/; taxes/contract fees: https://www.pingcap.com/legal/tidb-cloud-services-agreement/, §4.

### Small SQL app: hosted MySQL Starter, AWS Oregon

Inputs: one database, 1 GB of billed row data for a full month, 100,000 reads, 20,000 writes, 10 peak connections, 5 GB public outbound transfer. Assume no TiFlash, changefeed or extra security add-on. Storage means **billed data including indexes**; if 1 GB instead means payload only, index/storage overhead is another unknown. Ten connections fit the documented 400 free-connection limit. Sources checked 2026-11-05: https://www.pingcap.com/tidb-cloud-starter-pricing-details/, https://docs.pingcap.com/tidbcloud/serverless-faqs/, https://docs.pingcap.com/tidbcloud/serverless-limitations/.

- Stored size: `1,000,000,000 / 1,073,741,824 = 0.931322574615478515625 GiB`.
- Egress usage: `5,000,000,000 / 1,024 = 4,882,812.5 RU`.
- Let **R** be all other monthly RUs: storage reads/writes, request batches/payloads, SQL CPU, background activity and indexes. Read/write counts alone do not determine R; replicated writes and multiple components count.
- **Eligible first-five instance:** storage is within its 5-GiB row allowance. Published-meter cost is `max(0, R + 4,882,812.5 - 50,000,000) / 1,000,000 × USD 0.10`. This is USD 0 only if R stays at or below **45,117,187.5** and no other billable feature is used. The supplied workload cannot prove that condition, so the total is **incomplete**.
- **Without free allowance**, for example an additional paid instance: storage `0.931322574615478515625 × USD 0.20 = USD 0.186264514923095703125`; egress RU charge `4,882,812.5 / 1,000,000 × USD 0.10 = USD 0.48828125`. Known subtotal **USD 0.674545764923095703125/month** (USD 0.67 rounded to cents), **plus `R / 1,000,000 × USD 0.10`**. This is not a complete monthly bill.
- **Idle with the same 1 GB retained:** free-eligible storage can remain USD 0, but background RUs are unknown. With no allowance, retained row storage alone is USD 0.186264514923095703125/month, plus background RUs. Request-driven compute has no 730-hour reserved-node charge; storage persists. A USD 0.01 configured spend ceiling would be insufficient for the non-free subtotal.

Starter automatic backup settings differ between free and positive-spend instances; no separate backup storage meter is listed on its checked rate card. This does not establish free backups on other plans. Sources: https://docs.pingcap.com/tidbcloud/backup-and-restore-serverless/, https://www.pingcap.com/tidb-cloud-starter-pricing-details/.
