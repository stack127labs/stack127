## Lifecycle, licence and contract notices

No product-wide shutdown, sunset or acquisition notice was identified in the initial targeted official-site and release search. Product/pricing pages continue to offer new deployment, and the official repository publishes releases. This is a bounded check, not a guarantee of every region's availability. Sources: https://sealos.io/products/databases/, https://sealos.io/pricing/ and https://github.com/labring/sealos/releases (checked 2026-11-05).

**Self-host licence:** the repository currently uses the **Sealos Sustainable Use License v1.0**. It permits internal business and personal non-commercial use, but prohibits providing cloud services to third parties, whether free or paid. The README says it is not a standard open-source licence. The Chinese platform install guide also documents licence activation/purchase. Do not describe this as an unrestricted open-source hosting platform. Sources: https://raw.githubusercontent.com/labring/sealos/main/LICENSE.md, https://raw.githubusercontent.com/labring/sealos/main/README.md and https://raw.githubusercontent.com/labring/sealos.io/main/content/docs/self-hosting/install.zh-cn.mdx (checked 2026-11-05).

**Contract scope needs care:** English service terms name Labring Inc. and Delaware law; the Chinese original names 珠海环界云计算有限公司 and PRC law. The public material does not map these documents to every account/region. This is not evidence of an acquisition. Sources: https://raw.githubusercontent.com/labring/sealos.io/main/content/docs/msa/terms-of-service.en.mdx and https://raw.githubusercontent.com/labring/sealos.io/main/content/docs/msa/terms-of-service.zh-cn.mdx (checked 2026-11-05).

**Pricing scope:** the current English catalogue uses fixed monthly resource packages. The Chinese system-design billing document describes usage metering/balance deductions. This file uses the current public English package rates and does not carry historical/regional usage rates into them. Sources: https://sealos.io/pricing/, https://raw.githubusercontent.com/labring/sealos.io/main/app/%5Blang%5D/%28home%29/pricing/config/faqs.ts and https://raw.githubusercontent.com/labring/sealos.io/main/content/docs/system-design/billing-system.zh-cn.mdx (checked 2026-11-05).

### Small job workload

Inputs: **10,000 executions × 1 second**, **0.5 vCPU and 0.5 GB RAM where that configuration exists**, **peak five concurrent jobs**, no retries/waiting.

Our arithmetic for activity only: 10,000 × 1 = **10,000 active job-seconds**; 10,000 × 0.5 = **5,000 vCPU-seconds**; likewise **5,000 GB-seconds** of active memory at the scenario's stated unit. These are workload quantities, not Sealos billable units.
