## Cost examples

**These are our calculations**, checked 2026-11-05. They show the known Community software-license subtotal and the missing operating costs. A free engine is not ranked as an all-in hosted database plan.

Deployment assumption: one operator-managed **US East** installation using Community **11.8 LTS/InnoDB**. This is a scenario location, not a MariaDB Server region SKU or residency promise. No specific provider, machine, electricity tariff, storage service, tax jurisdiction or currency was selected. Consequently no complete regional hosting total can be quoted.

Let **H** be the chosen host cost, **D** retained database storage cost, **T** actual transfer cost, **B** backup/log-storage-and-recovery cost and **O** administration/monitoring cost. Their values and billing units depend on the operator's choices. If the host charges hourly, H for an always-on month is 730 × its hourly rate; a monthly host must use its own actual subscription rule instead.

The confirmed license input is GPLv2 Community Server with no required software purchase. Commercial Enterprise quotes are a separate paid path; a defined subscription Compute Unit is not a public dollar rate. ### 1. Small SQL app

Inputs: one production InnoDB database, 1 GB stored for a month, 100,000 reads and 20,000 writes, 10 peak connections, 5 GB internet transfer and 730 available host-hours. Ten connections fit below the documented default max_connections=151, but that does not establish a safe CPU/RAM size or latency.

**Our calculation:**

`Total = 0 Community license fee + H(730 hours, required size) + D(1 GB) + T(5 GB) + B + O`

**Known result: zero Community Server software license fee. Complete result: unknown.** MariaDB does not bill these queries by request count, but a chosen host, disk and network still cost money. Read/write counts do not predict their CPU time, IO or memory needs.

There is no hosted recurring allowance to “use up.” Normal ongoing Community software use remains free after testing; no trial expiry changes its license subtotal. Optional Enterprise subscription changes the quote/maintenance/support relationship, and its amount is not publicly established.

**Backup/PITR variant, our calculation:** base operating total + offsite full/incremental backup storage + retained binary logs + shipping/restore costs + operator work. The software paths exist without a managed retention entitlement; actual retained GB and restore infrastructure are unpriced. Baseline 11.8 uses documented backup-plus-binary-log recovery. The new 13.0 InnoDB archive mode is not silently substituted.

**Replica/HA variant, our calculation:** two Community Server copies have 2 × 0 = **zero software-license fee**, but require H_primary + H_replica, separate storage, replication transfer, monitoring, backup and any routing/failover implementation. An asynchronous replica alone is not a zero-loss automatic failover service. Galera is another architecture requiring its own nodes/provider/quorum/routing design; no speculative cluster dollar total is supplied.
