## Cost examples — our calculation

These are our calculations, not vendor quotes. Region assumption: Frankfurt (`fra`), an available core/native database region ([Regions](https://appwrite.io/docs/products/network/regions)). One project, one database, no other organization usage, no frontend hosting/build usage, no images transformed, no paid messages and no optional replicas/PITR unless stated. Count each database read/write as one affected row; empty reads still count one ([operation counting](https://appwrite.io/docs/advanced/billing/database-reads-and-writes)). GB and MB use vendor labels. Taxes, charge rounding and external delivery/model bills remain outside the known subtotal. The conditional totals below require quotas and access to be available; they are not measured performance promises.

### Small database: serverless TablesDB

Inputs: 1GB retained for a full month, 100,000 row reads, 20,000 row writes, ten peak application connections and 5GB transfer. TablesDB is accessed by API, so ten application connections are not ten direct SQL connections. A request-rate/latency fit cannot be inferred from monthly counts.

Free formula: base $0 + no read excess (`100,000 < 500,000`) + no write excess (`20,000 < 250,000`). Storage/transfer fit the published Free bundle only if counted stored data stays within it and no other traffic consumes the allowance. **Conditional metered subtotal: $0**, subject to the inactivity rules and unresolved request-capacity fit. No promise that this is an always-on production database. Sources: [Free allocation](https://appwrite.io/docs/advanced/billing/free), [published plan comparison](https://appwrite.io/blog/post/introducing-appwrite-cloud-start-plan), [row meters](https://appwrite.io/docs/advanced/billing/database-reads-and-writes), [pause](https://appwrite.io/changelog/entry/2026-02-20-1).

Paid Pro formula: base $25 + read excess $0 + write excess $0 + storage/bandwidth excess $0 under the documented bundle = **$25 known monthly subtotal**. No dedicated database compute charge for serverless TablesDB. Capacity, taxes and exact billing-period interpretation remain unpriced. Start offers a lower base for eligible accounts, but its read/write bundle was not established, so it is not substituted as an exact cheaper total. Sources: [Pro base/project charges](https://appwrite.io/blog/post/appwrite-pricing-update), [Pro allocation](https://appwrite.io/docs/advanced/billing/pro), [database billing](https://appwrite.io/pricing), [row meters](https://appwrite.io/docs/advanced/billing/database-reads-and-writes).
