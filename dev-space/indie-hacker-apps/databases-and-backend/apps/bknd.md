## Cost examples: our calculation

These are workload mappings, not vendor quotes. Software license charge = 0 under [Apache-2.0](https://raw.githubusercontent.com/bknd-io/bknd/main/LICENSE.md); this has no trial expiry or recurring cloud allowance. No currency conversion is involved. The normal paid path is buying and operating infrastructure, not upgrading to a paid bknd edition. No provider or region was selected, so infrastructure prices and taxes remain unknown.

For an illustrative standalone deployment, use [Docker with persistent data](https://docs.bknd.io/integration/docker/) and a configured SQLite database. Assume an always-on host for 730 hours where required. Do not use memory-only mode for retained data. This is a comparison scenario, not a production recommendation: the [project still warns against production use](https://docs.bknd.io/start/).
