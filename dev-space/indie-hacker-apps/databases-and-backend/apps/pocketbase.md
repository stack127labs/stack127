## Cost examples — our calculation

All examples use one operator-selected Frankfurt deployment with local persistent files, unless stated otherwise. Frankfurt is our location assumption, not a PocketBase region. No infrastructure supplier, hardware configuration or promotion was selected. No workload was executed. The MIT license establishes a zero software-license fee; it does not establish a currency-denominated zero hosting bill. Free software eligibility continues on both a free-host and paid-host path, but neither external path has been priced.

Define **H** as the monthly cost of a continuously available server with suitable CPU/RAM; **D(x)** as allocated persistent disk cost for x stored data plus indexes, logs and free space; **B** as backup storage/operations; **T(x)** as network cost for x transfer; **E** as any mail/OAuth/other external-service costs. These are unknown infrastructure inputs, not PocketBase rates. Base examples exclude high availability; a reliable failover setup would need separate design and costs.

Pricing basis, checked 2026-11-04: [MIT permission](https://ganigeorgiev.com/api/git/pocketbase/pocketbase/content/LICENSE.md), [self-hosting and no cloud functions](https://pocketbase.io/faq/), [deployment and backups](https://pocketbase.io/docs/going-to-production/), [local/S3 files](https://pocketbase.io/docs/files-handling/).
