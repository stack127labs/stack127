## Conflicts and unknowns

- The product marketing page says selecting a location can meet data-residency needs, while the detailed object docs explicitly say a location is not a residency guarantee. The Sevalla API documents a separate `jurisdiction` setting, including `eu` and `fedramp`; I treated location and jurisdiction as different controls.
- FedRAMP is listed in Sevalla's create-bucket API schema, but Sevalla does not state which customers can use it. Cloudflare says R2 FedRAMP access is restricted to Cloudflare Enterprise customers.
- The direct Sevalla `/newsroom/` and `/news/` pages failed to open. The active official blog, changelog, product pages, and Kinsta transition notice were checked instead; no shutdown, sunset, or acquisition notice was found.
- The pricing table shows one USD rate and no location-specific rate, but it does not publish a minimum billable object size or minimum stored duration.
- The DPA's 45-day deletion language is about Customer Personal Data; it does not specify a deletion deadline for every bucket object after account termination.
