## Cost examples

- Our calculation, Serverless read lower bound: 100,000 requests × 6 minimum vCUs/request = 600,000 vCUs. 600,000 ÷ 1,000,000 × $4 = $2.40 read compute. Actual reads can be higher based on the collection scanned and fields returned. Storage, writes, and transfer are not included.
- Our calculation reproducing the published AWS us-west-2 Enterprise On-Demand example: 8 query CUs × 30/60 hour × $0.41 = $1.64; 120 indexing CU-minutes/60 × $0.41 = $0.82; total compute = $2.46. This reproduces the official example’s inputs and rates. Storage, request, and transfer charges are excluded.
- Small vector workload estimate: exact total not available from public inputs. The official read-cost guide says query vCUs depend on scan size and returned fields, and write costs use encoded request size. The $2.40 calculation is only the minimum read cost for 100,000 reads, not an all-in estimate.

- Dedicated Enterprise “from” price: the current pricing page says $197/month; the Business Critical article updated July 8, 2026 says $155/month. I use the newer pricing-page value. Neither source provides the region and exact configuration needed to reproduce that starting amount.
- Dedicated per-CU price: the current pricing guide displays $0.273/CU/hour for performance/capacity and $0.41/CU/hour for tiered storage, while its cloud/region selectors appear unset. The dedicated billing guide’s AWS us-east-1 Enterprise example uses $0.248/CU/hour. I use the current list guide for general listed rates but cannot identify the exact current AWS us-east-1 rate.
- Transfer allowance: the current list page says the first 100 GB is free; the data-transfer guide says each organization receives a $10 monthly discount covering the first 100 GB. Because the rates vary by transfer type and region, I did not combine these as a guaranteed 100 GB waiver.
- Plan limits: the current limits/pricing pages say Standard clusters up to 32 CUs and Enterprise console scaling up to 2,048 CUs with CU × replicas capped at 204,800. The older cost-optimization page describes lower Enterprise/Business Critical CU ceilings and a Standard 99.9% SLA. I use the current limits and plan comparison, not the older summary.
- The public price guide’s cloud and region selectors were not set in the page view. I recorded per-region prices only where a current official example named the region, such as AWS us-east-1 storage and AWS us-west-2 On-Demand compute.
- The Terms of Service page is dated April 28, 2023, and does not resolve current free-tier commercial-use permissions. The docs and pricing pages were checked for those rules; they do not say whether the free cluster may be used commercially.
