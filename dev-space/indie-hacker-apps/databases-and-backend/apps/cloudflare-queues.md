## Notices

Cloudflare Queues is generally available and active. The product changelog, Queues blog tag, Cloudflare acquisitions blog tag, and press-release newsroom were checked; no Queues shutdown, sunset, acquisition, or retirement notice was identified. Cloudflare has announced company acquisitions, but none of the reviewed notices described a change to Queues. Recent Queues changes include a Free allowance announced February 4, 2026, backlog metrics added April 28, and EU, US, and FedRAMP jurisdiction controls announced October 12. The latest blog-tagged use case found is Cloudflare's July 30, 2026 cdnjs migration article. The Cloudflare status page showed Queues Operational when checked; this is a live snapshot, not an uptime promise.

The Workers Free plan includes Queues. Workers Paid is optional for small use: paid-plan Queue overage pricing applies only when using Workers Paid. A separate $5 USD per account monthly Workers Paid minimum applies if you choose that plan. It is not a Queues-only fee.

## Conflicts and unknowns

- Producer setup wording differs across official docs. The JavaScript API page says a Worker is needed to send and receive messages. The direct HTTP example and current API reference show token-authenticated message publishing without a Worker. The Worker requirement is clear for the Queue binding API; direct HTTP publishing is separately documented.
- Cloudflare's product page says Queues can be started free without a credit card; account creation was not attempted. The Terms also contain a specific payment-card-data restriction for websites using Free Services; they do not say that all commercial use is prohibited.
- Cloudflare does not state on the reviewed Queue pages what happens after a Free account exceeds its daily Queue-operation allowance.
- Queue-specific encryption detail, backup snapshots, history retention, and uptime SLA were not published in the official pages searched.
- The 30-day Developer Platform term is a possible post-termination access window, not a guarantee of retention. The service terms say Cloudflare has no obligation to retain Customer Content after termination.
