## Field problems

- C03/C06 require per-engine and edition licensing. SQL Server Developer's non-production restriction, Web hosting terms, Oracle BYOL and Db2 Marketplace licensing cannot share one undifferentiated price.
- Current credit-funded Free, expired legacy 750-hour offers and free engine software licenses are different concepts. A free SQL Server/Db2 license still has an RDS infrastructure bill.
- C13 must keep allocated storage, surplus CPU credits, public IPv4 and engine-specific license meters. Logical1 GB data does not reduce a 20 GiB allocation to 1 GB.
- C16 must distinguish normal delayed budget notifications from the new AWS experience's project spend limits and their 90-day deletion consequence.
- D05 retention depends on creation method and deployment type. RDS excludes stopped time from retention; Aurora's different rule must not be reused.
- D06 must distinguish an unreadable synchronous standby, two readable semisynchronous cluster replicas and ordinary asynchronous read replicas.
- F01–F07 do not apply to database files/snapshots as independent app-file storage. S3 integration is not an S3-compatible RDS file API.
