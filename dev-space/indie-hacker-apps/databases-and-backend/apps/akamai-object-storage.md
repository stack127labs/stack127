# Akamai Object Storage

- Official URL: https://www.akamai.com/products/object-storage
- apps.md status: active (row dated 2026-11-04).
- Lifecycle and company notices: The hosted service is active. Akamai acquired Linode in March 2022; the service is the successor to Linode Object Storage. The official Akamai blog and newsroom show continuing cloud and storage updates, including an E3 endpoint upgrade in Chennai on October 19, 2026. I found no product-specific shutdown, sunset, or acquisition notice in the product pages, blog, newsroom, or changelog. A rollout of default SSE-S3 encryption for E2/E3 endpoints is scheduled from October 6 through November 16, 2026. The pricing guide, updated about a month before this check, says API requests currently cost nothing and any request charges will not appear before October 1, 2027.

## Cost examples — our calculations

Checked: 2026-11-06. These are our calculations, not Akamai quotes or measured workloads. The public page displays dollar prices; use USD for the arithmetic only, because Akamai's current payment documentation conflicts on non-US currency (see C12). The guide currently says API requests are not charged. No Akamai compute or CDN delivery charge is included.

- North America, Europe, and other data centers except Jakarta and São Paulo: storage = $5 base including up to 250 GB; 100 GB outbound transfer is within the added 1 TB shared monthly pool under these assumptions; requests are currently uncharged. **Our total: $5.00 for the month.**
- Jakarta, Indonesia: 100 GB storage stays within the included 250 GB and the 100 GB transfer stays within the assumed unused global allowance. **Our total: $5.00 for the month.** If storage exceeds 250 GB, Jakarta's current listed storage-overage rate is $0.024/GB/month; its transfer overage is $0.015/GB.
- São Paulo, Brazil: the same workload stays within the included 250 GB and assumed unused global allowance. **Our total: $5.00 for the month.** Above the allowance, São Paulo storage overage is $0.028/GB/month and transfer overage is $0.007/GB.
- Prices are shown in dollars by the product page. These calculations use USD as display-list-price arithmetic, exclude taxes, and do not convert local currencies. Akamai's Cloud billing FAQ says USD-only while the August 2026 general Terms specify local currency for non-US customers unless their transaction document says otherwise. Akamai bills Object Storage capacity in binary GB (GiB); the workload uses vendor GB labels without converting decimal bytes.
