## Conflicts and unknowns

- The Vector pricing page calls the last plan Enterprise on its cards but Pro in the plan comparison. Its table says 5,000 maximum dimensions; the FAQ says 5,376. I recorded the two values separately instead of selecting one.
- The current API and feature docs describe sparse and hybrid indexes; the FAQ says hybrid search is unsupported, and the pricing matrix says sparse vectors are “Coming soon.” The Vector changelog says sparse and hybrid indexes were introduced in January 2025. The pages disagree about the current feature state.
- The FAQ says Vector is on AWS in two regions; the changelog says GCP US-Central1 was added, and the current status page lists that GCP component as operational. The pricing table adds region names by plan but does not consistently map cloud providers and region IDs.
- Free plan materials say “1 Free DB” and the Terms allow one free database, while the pricing FAQ says up to 10 Vector indexes can be created for free and then $0.50 per additional index up to 100. The fee's billing period is not stated.
- Price table calls the Free limit 10,000 daily queries/updates; the effect of reaching that limit is not described in the pricing, FAQ, or Getting Started pages. The table's “maximum data” value and the FAQ's “soft limit” language also leave enforcement unclear.
- Vector pricing calls 1,000 the “default limit” for `topK`, while the API docs give a default `topK` value of 10 and no hard maximum in the parameter description.
- The pricing table states 99.9%/99.99% plan SLAs; the general Upstash SLA page covers Prod Pack or Enterprise at 99.99% and its examples discuss Redis/QStash. The Terms also disclaim uninterrupted service. The exact contract coverage of the Vector table's lower-tier SLA is unclear.
- Upstash's general compliance/security documents mention snapshots and regional backups but do not give Vector customers a Vector-specific snapshot/restore endpoint, backup cadence, or retention period. No customer-operated restore process was found in Vector docs, API pages, FAQ, or CLI docs.
- The Terms say a cancelled account's data may be deleted immediately after cancellation or termination and also state a six-month cancellation deletion period. The DPA describes deletion according to customer instructions and backup routines but does not give one universal number of days.
- The Upstash blog, About page, Vector changelog, and status page were checked for acquisition, shutdown, or sunset notices. I found none and found no separate official newsroom page.

## Field problems

- Upstash Vector is a hosted-only vector service. F01–F07, J01–J05, and H01 are not applicable; self-hosting and license facts from Upstash Redis or its Redis vector commands were not carried over.
- Official Vector plan, FAQ, status, and changelog pages appear to be updated at different times. The release stage, sparse/hybrid support, region list, top-tier name/dimension, free index allowance, `topK` limit, and some SLA terms need vendor clarification or a fresh page update.
- Storage and metadata are billed/limited using different labels on the pricing and FAQ pages. The cost example therefore shows a raw-data calculation and states its assumptions rather than promising that a project will fit a plan cap.
