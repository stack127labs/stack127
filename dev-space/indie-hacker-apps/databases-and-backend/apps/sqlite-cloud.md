## Cost examples — our calculation

Inputs checked on 2026-11-05. These are calculations from public rates, not quotes or benchmarks. Prices retain the published $ symbol; ISO currency is unconfirmed. Applicable taxes are excluded. A current region list and region-specific price adjustments were not established, so these use the standard public plan table without asserting a deployment region. Missing charges remain unknown.

### Small SQL app

Inputs: one production database; 1GB stored for a full month; 100,000 reads; 20,000 writes; ten peak connections; 5GB internet transfer; 730 hours of desired availability.

Free’s 512 MB does not hold the full 1GB scenario. Dev provides 3 GB storage and 100 maximum connections; its allocated one CPU and 1 GB RAM are not a benchmark of this request mix.

Formula: **one Dev plan × $19/month = $19/month known subscription component**. Reads/writes are not mapped to a published per-query charge. The plan is monthly, so 730 hours is not multiplied by an invented hourly price. **Total = $19 + unknown applicable transfer/usage charges + tax**. We cannot publish an exact full bill without the missing general SQL/REST transfer and overage rules. No CPU demand is inferred from operation counts.

Pro is marketed for production and has higher resources. Its alternative known component is **one Pro plan × $79/month = $79/month**, with the same missing-charge caveats. The inspected terms did not establish that every production app must buy Pro, so it is not presented as a mandatory minimum.

Sources: https://www.sqlite.ai/pricing, SQLite Cloud Plans; https://www.sqlite.ai/terms, Pricing and Payments; https://docs.sqlitecloud.io/docs/overview, engine/platform scope.

### Backups and high availability

Free has no snapshots. Dev/Pro include daily snapshots in the public plan table, and the backup guide describes second-level incremental capture and point-in-time recovery for paid projects. Our calculation of the **Dev subscription component with its listed backups is still $19/month**; Pro is $79/month. Exact retained history, backup-space allocation and any extra backup charges for the named plans are not sufficiently specified for an all-in recovery-price comparison.

A separate guaranteed HA variant cannot be priced. The architecture documents follower elections and learner read scaling, but public plans do not map default node counts or extra-node prices. **HA total = selected subscription + unknown required extra-node/service charges**, not a guessed threefold multiplication of Dev.

Sources: https://www.sqlite.ai/pricing ; https://docs.sqlitecloud.io/docs/backups ; https://docs.sqlitecloud.io/docs/backup-commands ; https://docs.sqlitecloud.io/docs/architecture ; https://www.sqlite.ai/terms.

Illustrative additional inputs: ten synchronized devices and **5GB metered CloudSync traffic in the billing month**. This traffic assumption is separate from the small SQL app’s general internet-transfer input. Actual traffic metering/compression accounting was not established.

**Known paired-plan subtotal = Dev database $19 + Pro CloudSync $149 = $168/month**.

That is a subscription subtotal, not a complete transfer/overage/tax quote. Buying CloudSync alone for an existing external database costs the sync component separately and does not include that external database’s bill. Sources: https://www.sqlite.ai/pricing, independent products and CloudSync plans; https://www.sqlite.ai/changelog, June 4, 2026 quota windows.
