# SurrealDB

**Lifecycle notices:** SurrealDB is active, with stable **4.0.0 released 2026-11-03**. No whole-product shutdown, sunset or acquisition notice was found in the official product, launch, release and legal pages searched. **RocksDB was removed in 4.0**; existing self-hosted users must follow the SurrealKV migration path. **Earth is a separate beta hosted service**, and the MSA limits Beta Services to internal evaluation despite production-oriented guidance in the Earth docs. ## Cost examples — our calculations

Checked 2026-11-05. These are arithmetic examples, not vendor quotes or measured capacity tests. Prices keep the source's `$` symbol; the ISO dollar currency is unresolved. Tax is additional. Cloud examples choose **AWS Europe (Ireland)**, which the create guide lists; the pricing table publishes no region-specific variation. Earth examples use **EU residency / Western Europe preferred location**; this is a preference within the selected residency, not an Ireland node. Eligibility and current beta terms still apply.

1. **Small document app: 1 GB data, 100,000 reads, 20,000 writes, 10 peak connections, 5 GB internet output, 730 hours.** Cloud production-labelled General Purpose Medium has 1 vCPU/4 GB RAM and starts with **16 GB provisioned disk**. Compute is `730 × $0.135 = $98.55`. If the first 1 GB egress allowance applies to this month's workload, transfer is `(5 − 1) × $0.09 = $0.36`; known subtotal **$98.91**, plus disk, backups and tax. Without that allowance, output is `5 × $0.09 = $0.45`, subtotal **$99.00**. Storage pricing does not state its billing period or clearly settle the charged-capacity treatment of the first free GB, so neither subtotal is an exact bill. For comparison, development-labelled Burstable Small compute is `730 × $0.021 = $15.33`, but its minimum 4 GB disk is also additional. The docs describe Free as development/evaluation; no production-free total is claimed.

   Earth request units cannot normally be inferred from read/write counts. Under the explicit narrow assumption that every read fetches one ≤16 KiB record, every write commits one ≤4 KiB record with **no secondary index/edge writes**, and each operation is one WebSocket request, the base is `100,000 × 1 + 20,000 × 3 = 160,000 request units`. One HTTP request per operation adds `120,000 × 2 = 240,000`, for **400,000 units**. Extra index reads/writes and scans change both figures. Both illustrative amounts are below Free's 3M and Pro's 10M allowance, and 1 GB is below their storage allowances. Free is **$0 only if aggregate cell activity is ≤100 hours and every other shared quota fits**; a continuously active one-cell month uses 730 hours and cannot fit Free. One continuously active cell fits Pro's 1,000-hour allowance, giving a conditional **$15 launch subscription** before other organisation use. **Earth is beta and the MSA's internal-evaluation restriction prevents presenting this as an approved production option.**

   Sources: [Cloud prices](https://surrealdb.com/pricing?pricing-plan=cloud), [minimum disk and type purpose](https://surrealdb.com/docs/manage/instances/scaling), [deployment regions](https://surrealdb.com/docs/manage/instances/create), [Earth meters, locations and limits](https://surrealdb.com/docs/manage/instances/earth), [Earth prices](https://surrealdb.com/pricing), [Free purpose](https://surrealdb.com/docs/manage/organisations/faqs), [beta terms](https://surrealdb.com/legal/msa).

Minimum advertised disk quantity is `3 × 128 GB = 384 GB`; the published storage rate is $0.20/GB, but its time denominator is absent. Backups are another $0.20/GB with the same missing period; billed snapshot size and cross-AZ traffic are unspecified. Result: **$420.48 compute plus incomplete storage/backup/transfer costs**, not an exact HA total. Start cannot provide this topology. Sources: [node/storage/transfer prices](https://surrealdb.com/pricing?pricing-plan=cloud), [topology](https://surrealdb.com/docs/manage/instances/create), [failure behavior](https://surrealdb.com/docs/manage/instances/high-availability), [backup scope](https://surrealdb.com/docs/manage/instances/backups).

3. **Idle retained project: 1 GB data, no requests/jobs for a full month.** A running Cloud General Purpose Medium still incurs `730 × $0.135 = $98.55` compute plus unresolved disk/backup charges. The current Billing page explicitly says a **manually paused** instance retains data and stops accruing usage charges; result **$0 instance usage while it stays paused**, with no endpoint availability. Existing invoices, other instances and organisation contracts remain separate. Earth at zero cells consumes zero active hours; a 1 GB organisation with no other use fits Free's storage allowance, conditionally **$0**, while Pro keeps the **$15 monthly launch subscription** until cancellation takes effect at month end. Exact automatic idle delay is not published. Self-hosted core permitted software use is **$0 license fee**, plus an unspecified server/storage/backup bill. Sources: [Cloud prices](https://surrealdb.com/pricing?pricing-plan=cloud), [paused billing](https://surrealdb.com/docs/manage/organisations/billing), [pause behavior](https://surrealdb.com/docs/manage/instances/configure), [Earth usage/subscription](https://surrealdb.com/docs/manage/instances/earth), [pricing](https://surrealdb.com/pricing), [license](https://surrealdb.com/license).
