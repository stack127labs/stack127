## Cost examples — our calculations

Checked **2026-11-05**. Valkey is upstream self-hosted software. These are **our calculations**, not managed-service quotes or benchmarks. There is no project region/currency tariff to apply. No hosting vendor, machine price, disk price or transfer price was supplied, so none is invented. Software-license charges and infrastructure costs stay separate.

### Small persistent database

Inputs: one production database, 1 GB retained data, 100,000 reads and 20,000 writes/month, 10 peak connections, 5 GB internet transfer, and 730 hours for an always-on machine.

- **Known upstream license component:** **0 mandatory Valkey software-license charge**, under BSD-3-Clause and its conditions. This is not 1 GB of free hosting.
- **Infrastructure formula:** 730 × chosen host's machine-hour rate + persistent-disk capacity × storage rate + off-box backup storage/requests + internet/inter-node transfer + optional monitoring/support + applicable taxes.
- The ten client connections are below the example config's 10000 maxclients default, but host file descriptors and other connections still matter. The monthly command count does not establish peak ops/sec or CPU sizing.
- One GB of application payload needs RAM above that payload for keys, data structures, allocator overhead, persistence work and optional indexes. A replica needs another dataset copy and its own overhead; Sentinel/cluster processes also consume resources.
- **Result: incomplete total.** Only the zero upstream license component and workload inputs are known; there is no eligible recurring hosted free allowance or paid Valkey plan to subtract.

Sources: [core license](https://raw.githubusercontent.com/valkey-io/valkey/9.1.3/COPYING), [pinned config](https://raw.githubusercontent.com/valkey-io/valkey/9.1.3/valkey.conf), [administration/sizing](https://valkey.io/topics/admin/), [persistence/backups](https://valkey.io/topics/persistence/), [replication](https://valkey.io/topics/replication/).

### Idle month

Inputs: retain the same 1 GB, zero reads/writes/jobs for a month.

- **Running server:** same provisioned-machine and retained-storage formula, with whatever transfer/backup activity actually continues. There is no upstream paid scale-to-zero product.
- **Stopped server:** operator can retain compatible RDB/AOF files and restart later, but live cache/database access stops. Formula becomes retained disk + backups + any host charges that remain after stopping a machine.
- **Result:** upstream license component remains zero; external total and host pause-billing behavior remain unknown. Eviction, expiration and shutdown behavior must not be mistaken for a hosted inactivity-retention promise.

Sources: [long-running server/restarts](https://valkey.io/topics/admin/), [configuration](https://valkey.io/topics/valkey.conf/), [persistence](https://valkey.io/topics/persistence/), [license](https://raw.githubusercontent.com/valkey-io/valkey/9.1.3/COPYING).

### Small vector search application

Inputs: 100,000 vectors; 1536 float32 values/vector; 1 KiB metadata/vector; 100,000 searches and 10,000 updates/month; 5 GB internet transfer.

Using the scenario's float32 encoding at four bytes/value, **our raw-payload calculation** is:

- Vector bytes = 100,000 × 1536 × 4 = **614,400,000 bytes**.
- Metadata bytes = 100,000 × 1024 = **102,400,000 bytes**.
- Total raw bytes = **716,800,000 bytes**.
