## Cost examples — our calculation

All rates and inputs were checked **2026-11-05**. Currency: **USD, excluding applicable taxes**. Baseline: **AWS us-east-1 (Northern Virginia), Base, network-attached PostgreSQL PS-5**, selected as a **single-node production branch**, not PS-DEV. It has a published **$5/month** cluster price, **512 MiB RAM**, **1/16 vCPU**, **10 GB disk included**, **10 GB public egress/month**, and included local PgBouncer. The equivalent HA PS-5 cluster is **$15/month for all three nodes**, with 100 GB production public egress. Sources: [catalogue, Postgres EBS tables](https://planetscale.com/pricing.md), [single-node configuration](https://planetscale.com/docs/postgres/cluster-configuration/single-node), [Postgres pricing, included storage/egress](https://planetscale.com/docs/postgres/pricing); checked 2026-11-05.

These are allocation estimates, not proof that any particular SQL workload fits. Use default included disk performance, no extra replicas/dedicated PgBouncer, no paid support, and backup/WAL storage within the included **2× allocated disk**. With 10 GB disk, that allowance is **20 GB**. If compressed backup/WAL usage exceeds it, the additional full-month component is `max(B − 20 GB, 0) × $0.023/GB-month`, where **B is actual measured compressed backup/WAL space**, not logical data size or query count. [Backup billing](https://planetscale.com/docs/postgres/pricing), checked 2026-11-05. Longer backup retention is a separate variant; no data-loss insurance or automatic external backup is priced.
