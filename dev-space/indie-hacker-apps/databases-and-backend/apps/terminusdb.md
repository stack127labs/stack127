# TerminusDB

**Maintainer and lifecycle notices:** TerminusDB is currently maintained by **Gettier, operated by DFRNT AB in Sweden**, with community contributors. The official project says Gettier assumed stewardship in **2025**. No whole-database shutdown or acquisition transaction notice was found in the official product, repository, hosting and legal pages searched. The repository is not archived and reports activity on 2026-11-04. Sources checked 2026-11-05: [project](https://terminusdb.com/), [product explanation](https://terminusdb.com/docs/terminusdb-explanation/), [Gettier operator](https://gettier.ai/imprint), [repository metadata](https://api.github.com/repos/terminusdb/terminusdb).

**Recent releases:** **v12.0.9 was published 2026-10-28**, eight calendar days before checking, and is a security release recommending an update. **v12.1.0-rc2 was published 2026-11-03**, two calendar days before checking. Its title/notes call it a release candidate even though GitHub marks `prerelease=false` and returns it as latest. Keep the RC label; do not equate it with a final 12.1 release. [12.0.9](https://github.com/terminusdb/terminusdb/releases/tag/v12.0.9), [12.1 RC2](https://github.com/terminusdb/terminusdb/releases/tag/v12.1.0-rc2), [latest-release metadata](https://api.github.com/repos/terminusdb/terminusdb/releases/latest).

**Component retirement and hosted access:** The **legacy built-in dashboard was discontinued from v11.2** and is no longer maintained; a newer admin console is a separate component. Managed Cloud is **early access**, and Azure Marketplace is still described as coming autumn 2026. [Legacy dashboard notice](https://terminusdb.com/docs/dashboard/), [new admin console](https://terminusdb.com/docs/admin-console/), [Cloud](https://terminusdb.com/docs/cloud/), [Azure](https://terminusdb.com/docs/deploy-on-azure/).

## Cost examples — our calculations

Checked 2026-11-05. These are cost structures and arithmetic, **not vendor quotes or tested capacity**. Community software is explicitly free; no current managed price table was found. [TerminusDB's pricing route](https://terminusdb.com/pricing/) redirects to [Cloud hosting options](https://terminusdb.com/docs/cloud/), which directs readers to Gettier. [Gettier's pricing page](https://gettier.ai/pricing) describes its finance-platform beta, not a priced TerminusDB instance.

1. **Small document app.** Inputs: one production database, 1 GB stored for a month, 100,000 reads, 20,000 writes, 10 peak connections, 5 GB internet transfer and 730 always-on hours. Self-hosted Community software charge is **0**; this is a license/software component, not a hosted total. The structure is `total = 0 software + 730 × selected host hourly rate + persistent-disk charge + backup charge + 5 GB × applicable transfer rate + tax`. None of the required host/region/rates has been selected or priced in this product research; document/commit history and replicas can add storage. **Result: incomplete**, with no currency or region assigned. It is not a $0 managed database. Sources: [free Community](https://terminusdb.com/), [license](https://raw.githubusercontent.com/terminusdb/terminusdb/v12.0.9/LICENSE), [production responsibilities](https://terminusdb.com/docs/run-terminusdb-in-production/), [self-hosting](https://terminusdb.com/docs/self-hosted-installation/), [managed offer](https://terminusdb.com/docs/cloud/).

2. **Managed paid path and idle variant.** Inputs: the same 1 GB, with zero requests/jobs for a full idle month. Managed commitment, instance size, storage/backup rates, inactive-project handling and scale-to-zero are not publicly specified for the early-access offer. Formula: `idle managed total = contract minimum + retained capacity/storage/backups + other required fees`. **Result: unknown**, not zero. Self-hosted software stays **0**, but keeping an allocated server and retained volume depends on that provider's invoice even if the database process is stopped. [Linked SaaS terms](https://gettier.ai/terms-saas) describe a 3-month initial term, 12-month renewals and tax-exclusive invoices, but their application to a new managed contract is not established. Sources: [Cloud](https://terminusdb.com/docs/cloud/), [Azure/managed options](https://terminusdb.com/docs/deploy-on-azure/), [service terms](https://gettier.ai/terms-saas), [self-hosted persistence](https://terminusdb.com/docs/self-hosted-installation/).

3. **Backup/high-availability variants.** Community CLI backup includes branches, commits and data; an external copy adds storage and transfer. Formula: `backup variant = base host + archive bytes × selected backup-storage rate + transfer + scheduling resources`. Exact archive size/compression cannot be derived from the 1 GB live-data assumption. Community cloning/push/pull is not evidence of automatic failover; managed/Enterprise replica topology and charges were not published. **Result: incomplete for both backup and HA variants**. Sources: [Community backups](https://terminusdb.com/docs/self-hosted-installation/), [Enterprise HTTP bundles](https://terminusdb.com/docs/enterprise-backup-restore/), [git-for-data transport](https://terminusdb.com/docs/git-for-data-reference/), [Enterprise](https://terminusdb.com/docs/enterprise/), [Cloud](https://terminusdb.com/docs/cloud/).

4. **Small vector search app.** Fixed reference inputs: 100,000 vectors, 1,536 float32 values/vector, 1 KiB metadata/vector, 100,000 searches, 10,000 updates and 5 GB internet output/month. Raw input is `100,000 × (1,536 × 4 + 1,024) = 716,800,000 bytes = 0.7168 decimal GB` (`÷ 1,000,000,000`). **This is not indexed or billed size**: versions, chunks, search-store files, metadata representation, embedding cache and model-runtime storage are additional. The documented RC default is 768-dimensional; using the reference 1,536 dimensions requires a matching selected provider/model and rebuilt store parameters. Formula: `total = database host + search engine/store + embedding runtime or provider usage + backup + transfer`. **Result: incomplete**; no hosted search tariff or workload-to-resource benchmark is supplied. Sources: [RC search](https://terminusdb.com/docs/versioned-search/), [embedded configuration/locked parameters](https://terminusdb.com/docs/versioned-search-embedded/), [chunking/snapshots](https://terminusdb.com/docs/versioned-search-concepts/), [local model setup](https://terminusdb.com/docs/versioned-search-quickstart/), [Cloud](https://terminusdb.com/docs/cloud/). The repository explicitly says the 12.1 RC example is **not for production data yet**: [vectorsearch README](https://raw.githubusercontent.com/terminusdb/terminusdb/main/vectorsearch/README.md).

5. **Full backend, file-store and job scenarios do not fit this product as complete bundles.** The reference 1,000 MAU + 1 GB uploaded files + 100,000 file reads + 10,000 uploads + 20 GB output + 10,000 short functions requires an application authentication design, file storage and a function/worker architecture beyond the priced database offer; database access users and plugins do not supply those independently priced modules. A 100 GB hot-file-store workload has no native S3 bucket rate here. For the job reference, `10,000 × 1 second = 10,000 seconds = 2.777777… hours`, but there is no sold 0.5 vCPU/0.5 GB isolated worker or guaranteed five-job concurrency to apply that time to. One retry each gives `20,000 seconds = 5.555555… hours`; adding 30 seconds waiting/job gives `300,000 seconds = 83.333333… hours` of application wait time. Neither number maps to a TerminusDB job bill or free-wait guarantee. **Result: not a like-for-like native workload; wider architecture costs are incomplete**, rather than zero. Sources: [product capabilities](https://terminusdb.com/docs/terminusdb-explanation/), [HTTP data API](https://terminusdb.com/docs/http-documents-api/), [access scopes](https://terminusdb.com/docs/access-control/), [plugin execution](https://terminusdb.com/docs/writing-plugins/), [self-hosted resource pools](https://terminusdb.com/docs/self-hosted-installation/).
