## Cost examples — our calculation

All inputs below were checked on 2026-11-04. Sources: [traffic prices, pooled custom events and exact annual charges](https://usefathom.com/pricing); [each public API request consumes a pageview unit](https://usefathom.com/api/v1); [API capacity add-on prices](https://usefathom.com/api/v1/rate-limits); [site-pack prices](https://usefathom.com/docs/troubleshooting/sites). The public pricing HTML's `pricing-tiers-data` lists monthly price, annual price and included sites for each band. These exact annual charges are used; the billing FAQ's rounded 17% description is not an annual-price formula.

Define monthly billable units `B = pageviews + custom-event completions + authenticated public API requests`. Choose the smallest listed traffic tier with allowance ≥ B. Then add any required site packs and API capacity subscription. Paid API capacity increases the hourly/concurrent limit; it does not remove request units from B.

The traffic scenarios assume one site, one owner account, zero API requests, no paid add-ons, no referral credit and no extra custom events unless shown. Prices are USD. They exclude taxes whose amount/treatment was not established. Annual amounts are prepaid annual charges for that monthly allowance, not a yearly usage pool.

| Workload/month | Inputs and formula | Monthly result | Annual result |
| --- | --- | --- | --- |
| Website: 10,000 pageviews | B = 10,000; smallest tier 100,000 | 1 × USD 15 = **USD 15/month** | 1 × USD 150 = **USD 150/year** |
| Website: 100,000 pageviews | B = 100,000; tier 100,000 | 1 × USD 15 = **USD 15/month** | 1 × USD 150 = **USD 150/year** |
| Website: 1,000,000 pageviews | B = 1,000,000; tier 1,000,000 | 1 × USD 60 = **USD 60/month** | 1 × USD 600 = **USD 600/year** |
| Events: 100,000 completions, zero views | B = 100,000; tier 100,000 | 1 × USD 15 = **USD 15/month** | 1 × USD 150 = **USD 150/year** |
| Events: 1,000,000 completions, zero views | B = 1,000,000; tier 1,000,000 | 1 × USD 60 = **USD 60/month** | 1 × USD 600 = **USD 600/year** |
