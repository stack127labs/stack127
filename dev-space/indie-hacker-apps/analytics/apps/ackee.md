## Conflicts and unknowns

- **Website terms versus software license:** the [publisher's terms](https://electerious.com/terms-of-service) grant only personal, non-commercial transitory viewing of website materials and prohibit copying/modification/commercial use under that website use license. The [application's MIT license](https://raw.githubusercontent.com/electerious/Ackee/master/LICENSE) separately grants software use, copying, modification, redistribution and selling. Both are checked 2026-11-04. The website does not clearly explain this scope boundary. F07 preserves that uncertainty without rewriting the explicit software license as non-commercial.
- **Pricing and hosted access:** checked the home, README, getting-started, FAQ, donation links, publisher terms and privacy policy. No official hosted signup, subscription price, free hosted allowance, paid feature matrix, event overage rate or spend-control policy was found. Deployment on Netlify/Vercel/other providers is not an Ackee-operated subscription. No current provider prices or historic “free hosting” promises were carried over.
- **Privacy policy scope:** the linked Electerious policy describes its own websites, including server logging, cookies, provider disclosures and processing locations. It is not the policy of every independent Ackee deployment. The project supplies a separate default-mode privacy-policy example and detailed-mode guidance. No fixed software-wide analytics region, backup location or public Ackee-hosting DPA was established.
- **Cookie wording:** the no-cookie visitor claim must be read alongside the `ackee_ignore` operator-exclusion cookie and the docs' suggestion to remember detailed-mode consent with a cookie. Default visitors do not need a tracking cookie, but “Ackee never uses any cookies” would be too broad. The current exclusion-cookie source requires an exact `ackee_ignore=1` match.
- **Identification and data minimization:** a daily salt, IP, User-Agent and domain ID produce a hash. Repeat matching records have their prior identifiers and detailed dimensions cleared. Daily rotation is not deletion of all stored history. Raw IP is not a visit-record field, but reverse-proxy/server-host logging depends on the deployment. The homepage's broad privacy wording is not evidence that custom event text or URL parameters cannot identify someone.
- **URL handling:** the tracker sends the full page URL and referrer before the server removes selected campaign/source query keys. Other private URL content is not guaranteed removed. Manual attributes can redact before transmission. This distinction is based on read-only official source inspection, not a captured request.
- **History and deletion:** checked options, FAQ, anonymization/privacy docs, upgrade guide, record/action schemas and related data-handling source. No fixed record/action retention duration, supported retention-days option, backup lifetime or person-specific erasure workflow was established. `ACKEE_TTL` is authentication-token lifetime. Domain/event deletion and full database reset are documented; no deletion was performed.
- **Exports and migration:** checked API examples, current GraphQL definitions, FAQ, docs listing, README and related-project links. Aggregated reporting API access is explicit. No complete CSV/raw-history export or ready-made GA/GA4 history importer was found. Nginx-log import is expressly unsupported as a built-in feature. Normal record creation does not expose a historical timestamp input; a hypothetical custom importer must not be listed as a supported history migration.
- **Additional reports and platforms:** checked the site, FAQ, events, anonymization, tracker, API examples and current report schemas. No full native SDK/offline matrix, native funnel/cohort/group identity system, replay/heatmap recorder, recurring-billing accounting model or country/city report was established. The README's integration links, including Dart/Flutter, are leads for supported community clients, not proof of official feature parity.
- **Sampling, weight and scale:** checked tracker code/docs, report schemas, options, setup, FAQ and release notes. No formal unsampled-data guarantee, completeness percentage, comparable tracker transfer size or minimum CPU/RAM/disk sizing table was found. Report result limits are not sampling rates or history retention.

Some web-cache results showed older source filenames and release metadata.
