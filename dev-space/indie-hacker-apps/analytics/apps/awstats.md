AWStats is a self-operated log analyzer for web and other server traffic. This record covers the public software and the AWSTATS_8_0 source tag. It separates ordinary log-only use from optional browser capability tracking, synthetic logs and outbound-link wrappers. No vendor-managed AWStats subscription was established. Matomo is named on the official site as a recommended migration path; it is a different product.

The latest official lifecycle notice overrides no facts silently: the older overview still describes ongoing original-author development. That disagreement, differing Perl minimums and stale security wording are recorded below. No signup, login, form submission, install, tracker execution, log analysis, crawl or private system access was performed. Only this app's research file was written.
