GoAccess is an actively distributed, self-operated log analyzer. It can analyze local or remote HTTP logs and produce terminal, static HTML or live HTML reports. This record covers the downloadable software, with v1.12 source used where version-specific settings matter. No vendor-operated subscription was established. A free software license is separate from the cost of running it.

Official download and release pages identify v1.12. The get-started page still mentions v1.9.4 in its introduction, and some documentation details disagree. Those differences are preserved below. No install, signup, login, log-processing job, tracker execution, website crawl or private system access was performed.
