# HubSpot Service Hub

**Lifecycle notices checked first:** Service Hub is active. No whole-product shutdown, acquisition, or sunset notice was found in the official searches and pages checked on 2026-11-05. There is a narrower developer sunset: from **September 23, 2026**, integrations cannot create internal thread comments through the Conversations API for Help Desk channels; they must use CRM Notes associated with the ticket. Conversations Inbox comments have different rules. [Official API notice](https://developers.hubspot.com/changelog/upcoming-breaking-change-conversations-api-help-desk-and-comments), [current product](https://www.hubspot.com/products/service).

**Knowledge-base transition:** Migration guide says remaining legacy knowledge bases were scheduled for automatic migration between November 2025 and January 2026. After publishing the migrated version, the original stays read-only for 30 days and is then deleted. This is an editor/content migration, not Service Hub closure. [Migration guide](https://knowledge.hubspot.com/knowledge-base/migrate-your-knowledge-base).

**Buying distinctions:** Free/Starter conversations inbox is different from the Professional/Enterprise help desk workspace. For accounts created after April 1, 2024, connected inbox channels cannot automatically create tickets. Also, the new Service SMS beta **does not support sole proprietors**. This is a channel restriction, not a restriction on all Service Hub use. [Inbox guide](https://knowledge.hubspot.com/inbox/set-up-the-conversations-inbox), [Service SMS](https://knowledge.hubspot.com/help-desk/set-up-sms-messaging-for-support-communications).

**Regional pricing transition:** HubSpot also publishes an eligible-account flexible seats-and-credits programme, with euro prices, GTM/Ops seats and different allowances. It is not a universal replacement for the USD Service Hub offer. Keep those records separate. [Programme supplement](https://www.hubspot.com/flexible-seats-and-credits-pricing-supplement), [migration eligibility](https://www.hubspot.com/flex-seats-and-credits-migration-faq).
