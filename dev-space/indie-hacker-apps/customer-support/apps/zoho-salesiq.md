Legacy payment/discount wording is not used for current calculations.
- Main pricing's translation description names Google/Azure; the newer comparison/release also names built-in Zia and additional translation features. This supports several routes with different gates, not a single all-plan unlimited translator. Provider-specific limits and customer-surface language lists remain separate.
- The price page references a public JSON file containing multiple currency/region branches. USD rows use the `USD` branch, not `OLDUSD` or the separate `USDAFRICA` branch; INR uses `INR`. The template maps India to INR. Other country branches were not exhaustively collected. No IP masking, country simulation or checkout used. Final applicable country pricing should be rechecked before purchase.
- The [bot-session add-on](https://www.zoho.com/salesiq/pricing.html) is visibly labelled 5K, although the JSON key contains `500chatbots`. The field records the visible 5,000-session unit and links both sources; it does not infer a 500-session product from a legacy identifier.
- Ordinary incoming support-email intake, native SMS/Slack/Discord customer channels and a separate custom-domain help center were not established after reviewing pricing/comparison, the integration directory, website-channel settings and conversation/Smart Reply docs. Confirmed chat follow-up email does not settle the mailbox comparison.
- Vendor-branding removal, exact domain count per brand, total storage, collision warnings, numeric API caps and hard-stop/auto-purchase behaviour were not found after the specific pricing/docs/terms checks named in their rows. No value was changed to “no” because it was missing.
- AI model tokens, chat sessions, configured agent counts and human seats are different units.
