## Cost examples — our calculation

These are our calculations, not checkout quotes. All examples use ordinary monthly usage before tax, no introductory discount, one user, one sender domain, one recipient per message, shared sending infrastructure and no attachments. They exclude extra test messages, confirmations, paid ads and optional tools. Any additional email activity changes the bill.

### Hosted formulas and evidence

The pricing page's public HTML loads its rates from `https://dashboard.mailcoach.app/api/prices`. The endpoint was read without authentication. Its observed response was:

```json
{"currency":"usd","monthly_price":999,"tiers":[{"limit":2000,"price":0},{"limit":null,"price":0.002}],"provider_tiers":[{"limit":2000,"price":0},{"limit":null,"price":0.001}]}
```

The HTML divides `monthly_price` by 100 and calculates extras above the included tier. With `E` recipient emails/month:

- Managed hosted fee: `M(E) = US$9.99 + max(0, E − 2,000) × US$0.002`.
- Own-provider hosted platform fee: `B(E) = US$9.99 + max(0, E − 2,000) × US$0.001`.
- Named external sender: Amazon SES **à la carte**, base outbound `A(E) = E / 1,000 × US$0.10`.
- Known own-provider subtotal: `B(E) + A(E)`. This is not an exact all-in total: AWS data/optional-feature charges and tax can add cost.

Sources checked 2026-11-05: https://www.mailcoach.app/pricing/ ; https://dashboard.mailcoach.app/api/prices ; https://aws.amazon.com/ses/pricing/

The first 2,000 are included in Mailcoach's platform fee; a customer's external sender may still bill for those emails. This model deliberately selects SES à la carte, rather than assuming every new AWS account is already on that option. No AWS free credits or introductory allowance is applied. Source checked 2026-11-05: https://aws.amazon.com/ses/pricing/

The main website's €9.99 headline is a separate currency observation. Its EUR marginal rates were not established, so these USD calculations are not relabelled as EUR. The live subprocessor page explicitly identifies a currency-determination supplier. Sources checked 2026-11-05: https://www.mailcoach.app/pricing/ ; https://www.mailcoach.app/subprocessors/
