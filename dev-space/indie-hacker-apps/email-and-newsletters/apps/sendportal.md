## Cost examples: our calculation

The self-hosted software has **zero licence fee** under MIT. There is no paid SendPortal plan in this baseline and no annual software prepayment. “Unlimited” software counts do not include a server, delivery-provider allowance or operations. Sources: https://sendportal.io/ ; https://github.com/mettle/sendportal/blob/master/LICENSE ; https://github.com/mettle/sendportal-core/blob/master/LICENSE . ### Named setup

Our illustration uses a **DigitalOcean Basic Regular Droplet: 2 GiB RAM, one vCPU, 50 GiB SSD and 2,000 GiB transfer, USD 12/month**, with a maintained PHP 8.3+/nginx/database stack and Redis/queue workers. This is a cost assumption, not a benchmark or a recommendation that this small host will fit every 50,000-contact workload. SendPortal does not publish a universal RAM/throughput requirement in the inspected installation guide.

Sources: https://www.digitalocean.com/pricing/droplets ; https://sendportal.io/docs/v4/getting-started/installation ; https://sendportal.io/docs/v4/getting-started/configuration-and-setup . Checked 2026-11-05; update dates not stated. A current standalone build uses Laravel 13; embedded core accepts Laravel 12/13.

Use the native **SES API** integration, not SMTP. The released adapter calls the SES v1 SDK's sendEmail method and sends one recipient. This avoids assuming that the app host permits outbound SMTP. Campaign tracking uses SES configuration sets/SNS callbacks and the webhook queue; those are separate usage dimensions.

Sources: https://github.com/mettle/sendportal-core/blob/v4.0.1/src/Adapters/SesMailAdapter.php (file history 2020-08-07, inspected at released core v4.0.1); https://sendportal.io/docs/v4/email-services/aws . Checked 2026-11-05.

External price input: choose **Amazon SES Essentials**, USD 0.16/1,000 outbound recipients plus USD 0.12/GB outgoing data. Assume **32 KB/message = 0.000032 GB/message** as in AWS's example, no attachments, no promotional credits, no optional dedicated IP/VDM purchases, and one recipient per message. Other SES purchasing modes exist; this explicitly selected plan is not claimed to be the cheapest possible SES choice.

Source: https://aws.amazon.com/ses/pricing/ . Checked 2026-11-05; update date not stated.

Formulas, **our calculation**:

- Newsletter messages M = unique subscribed contacts N × four campaigns/month.
- SES USD/month = (M ÷ 1,000 × 0.16) + (M × 0.000032 × 0.12).
- Known host + send USD/month = 12 + SES; software component = 0.
- Annual known host + send = 12 × monthly result, assuming identical volume each month. This is an arithmetic equivalent, not an annual discounted bill.
- Exact all-in total = known components + domain/backups/storage/taxes/labour + any notification/transfer/operational-message charges. Those extra amounts are unknown.
