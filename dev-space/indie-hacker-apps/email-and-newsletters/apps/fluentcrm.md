## Cost examples: our calculations

All sources checked 2026-11-05. Main prices exclude introductory discounts and applicable tax. FluentCRM Free costs US$0 for software; the ordinary single-site Pro licence is **US$129 paid annually**. There is no established month-to-month Pro tariff. Its **US$10.75/month equivalent** is our calculation, `129 ÷ 12`, used only to spread the annual software cost across months. Displayed first-year offers are not used in the comparison. Sources: https://fluentcrm.com/pricing/, https://wpmanageninja.com/products/fluentcrm-campaign-pro/?selected=42, https://fluentcrm.com/free-vs-pro/.

### Common hosting and sender inputs

Our named setup: one DigitalOcean Basic regular Droplet, **US$12/month**, 2 GiB RAM, 1 vCPU, 50 GiB SSD, 2,000 GiB transfer; WordPress/PHP/database on the same server. Source: https://www.digitalocean.com/pricing/droplets. This is a costing illustration, not a FluentCRM capacity benchmark or proof that the largest list will fit.

Use **FluentSMTP**, a free separate plugin, connecting to **Amazon SES HTTP API**, one verified sender domain, one production-approved AWS region, shared/default external sending and no attachments. Source: https://docs.fluentcrm.com/sending-emails-and-email-deliverability, https://fluentsmtp.com/docs/set-up-amazon-ses-in-fluent-smtp/. DigitalOcean blocks SMTP ports 25/465/587, but this selected API connection does not use them: https://docs.digitalocean.com/support/why-is-smtp-blocked/.

Choose **SES Essentials**, whose current price is **US$0.16/1,000 recipient emails** at these volumes. For transparent data costing, use AWS's own worked-example assumption: **32 KB/message = 0.000032 decimal GB**, billed in that example at **US$0.12/GB outgoing mail data**. No free credits, dedicated IP, optional SES add-ons or multi-region routing. Source: https://aws.amazon.com/ses/pricing/. SES also lists an à-la-carte model; these calculations deliberately use Essentials rather than silently combining its plan features with the lower à-la-carte base.

`SES monthly estimate = (recipient emails ÷ 1,000 × US$0.16) + (recipient emails × 0.000032 GB × US$0.12/GB).`

`Known Free subtotal = US$0 software + US$12 host + SES monthly estimate.`

`Known Pro monthly-equivalent subtotal = known Free subtotal + US$129 ÷ 12.`

Exact all-in totals are **not established**. Excluded: SNS bounce/complaint notification charges, domain/reply mailbox, backups, monitoring, maintenance labour, extra storage/host upgrades, related plugins, tax and optional channels/AI. The SES pricing page explicitly identifies other AWS service costs, including SNS; setup is documented at https://docs.fluentcrm.com/bounce-handler-with-amazon-ses. An existing website may have a different incremental host bill, which is not automatically zero.

### Quotas and burst conditions

SES sandbox allows only verified recipients, **200 messages/24 hours and 1/second**. Production approval and adequate account/region quotas are assumptions, not guaranteed results: https://docs.aws.amazon.com/ses/latest/dg/request-production-access.html. Even the 3,000-month workload may violate sandbox restrictions depending on recipients and clustering.

FluentCRM exposes an emails-per-second setting. The developer guide describes the global default calculation (setting minus 3, or 14 if unset, floored at 4), default mailer batch size **20**, and handler loop window **50 seconds**: https://developers.fluentcrm.com/hooks/filters/emails-and-sending. These plugin controls do not grant the same rate at SES. The selected setup must match the provider's actual approved rate; daily-peak assumptions above are not published product limits. The server, queue generation, cron and API request processing need their own performance checks.
