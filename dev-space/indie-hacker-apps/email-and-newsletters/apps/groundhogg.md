## Cost examples — our calculation

The following are **our calculations**, not Groundhogg hosting/delivery bundles. All inputs and sources were checked 2026-11-05.

### Newsletter workload and selected setup

One publication, one operator, one site/domain and 1,000 / 5,000 / 10,000 / 50,000 unique subscribed contacts. Send four campaigns per contact per month: 4,000 / 20,000 / 40,000 / 200,000 recipient emails.

Select free Groundhogg core plus the standalone **AWS integration at USD 129/year for one site**, which provides automatic provider feedback handling. No Basic/Pro bundle is assumed.
