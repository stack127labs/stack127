# Zoho CPaaS

- Official URL: https://www.zoho.com/cpaas/
- \`apps.md\` status: \`active\` (row checked 2026-11-04). The row's Delivery label fits this email-sending service. The current product also offers other communications channels, but this file covers only email sending. No row correction proposed.
- Current name and history: Zoho CPaaS is the current product name. It is the same transactional email service previously called ZeptoMail; existing domains, API keys, SMTP settings, Agents, and suppression lists carry forward. The older name before ZeptoMail was TransMail. No reconfiguration is required for existing email customers.
- Zoho email product boundaries: CPaaS email is transactional sending through SMTP or API. Zoho Campaigns is the separate product Zoho directs customers to for promotional email and newsletters. Zoho Mail is hosted business mailboxes. Paid Zoho Mail and Workplace organizations can also access CPaaS from Mail's Admin Console; that route allocates credits according to the Mail/Workplace plan and user count. It is a separate billing route from buying CPaaS credits directly.
- Shutdown, sunset, acquisition, and newsroom check: The CPaaS product page, current help, release notes, CPaaS blog index, and Zoho Press Releases page show an active product and the September 2026 ZeptoMail rebrand. I found no CPaaS shutdown, sunset, or acquisition notice in those sources. The press release index had no CPaaS-specific announcement when checked. This is a bounded search, not proof that no notice exists elsewhere.

## Conflicts and unknowns

- Pricing page: standalone email credit price is displayed in USD and says email is available across all regions. It does not name a country or show a country-specific email-credit price. CPaaS subscription docs describe credit validity but not the final checkout currency. The general Zoho Store currency page says product currency can depend on customer country, but it does not establish that rule for CPaaS. I recorded public price in USD and left checkout currency unclear.
- Domain authentication: the current Domain Addition & Verification guide (updated 2026-10-22) says DKIM and CNAME are required and SPF is not required. The DMARC guide (updated 2026-09-23) says CPaaS mandates SPF and DKIM authentication. I follow the newer setup guide for the DNS steps and retain the official-source conflict.
- Recipient ceiling: the current Agents guide says maximum 500 recipients total; an undated API FAQ lists field limits that could sum to 540. The FAQ does not say whether the maxima can be used together. I use 500 as the safer total and preserve the mismatch.
- Data center list: the CPaaS API region guide lists ten regions, while the CPaaS GDPR page lists six. Neither page shows a last-updated date. The API guide has the operational API mapping, but the legal page needs reconciliation.
- Export archive: the Export Logs guide says ZIP downloads stay available three days in its summary and two days in detailed instructions. The newer Settings guide says three days. Exact retention of the generated archive is therefore conflicting.
- Other values not published: I checked current CPaaS pricing, subscription help, email send API, batch-send API, error codes, terms, webhook docs, API overview, export guide, regional docs, privacy pages, status-domain notice, and help index. I could not confirm duplicate-recipient deduplication, a per-second send API quota, a complete export of templates and consent history, webhook retry/idempotency guarantees, a CPaaS-specific public status component, or a numeric service uptime commitment.

## Field problems

- F08/F10 are affected by a product-specific USD display and an unverified checkout currency. The examples state exactly which public currency they use and make no conversion.
- The new Zoho Mail Admin Console integration means “included CPaaS email” can refer either to standalone credits or to credits bundled by paid Mail/Workplace plan. Those are recorded separately to avoid calling a required Mail subscription a CPaaS base fee.
- F24, F27, F28, and F30 have conflicting official statements. The newer operational page is used where possible, but the conflicting page and scope are kept visible.
- F09 and F13–F16 are not-applicable or conditional because CPaaS prohibits promotional newsletters and does not manage paid reader subscriptions. The recipient-sending and export checks that still apply are recorded separately.
- No access failures affected product or help pages. The current regional Zoho status endpoints did not load in the web extract, so the CPaaS-specific status component remains unclear.
