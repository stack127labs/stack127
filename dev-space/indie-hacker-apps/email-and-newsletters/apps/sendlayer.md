## Conflicts and unknowns

- **Refund conditions:** The pricing page promises a full 14-day refund “no questions asked.” The Terms and refund guide require no more than 20% of the monthly email quota to have been used and a timely support request. The detailed Terms and guide provide the applicable conditions; the pricing-page summary is broader.
- **API key versus account rate-limit scope:** The current API Rate Limits reference says the limit applies to the API key. The older Understanding SendLayer Rate Limiting guide says a user account’s limit is shared across domains. The pages do not explain whether separate API keys have separate counters or how SMTP sends interact with the API limit.
- **Message size:** Older SendLayer marketing pages say API attachments can reach 25 MB. The current API reference, developer attachment guide, and SMTP guide state a 10 MB total message limit. The current developer documentation is used in the facts table.
- **Multiple recipients and quota accounting:** The current API Rate Limits page lists 10 To, 10 Cc, and 5 Bcc addresses. The current Send Email to Multiple Recipients guide recommends up to 100 recipients per request. The docs do not reconcile those values or say whether each recipient or each message consumes monthly quota. Cost scenarios assume one recipient per email.
- **Data export and ownership:** The Events API exposes event records, but a full suppression/contact export is not documented. The Terms’ customer-Content exception and separate generated-data clause do not define ownership of recipient or event records.
- **Status page:** The official site and docs navigation did not surface a status page. The candidate `status.sendlayer.com` URL returned an internal error, so status availability is `check_failed` rather than an assertion that no status page exists.
- **Not published in the checked pages:** Complete customer eligibility countries and language list; trial expiry/card requirement; monthly-paid pricing; tax treatment; Scale price; no-card over-quota behavior; recipient-count billing rule; custom tracking domains and white-label options; native automation journeys; suppression-list export and consent-history archive; dedicated/shared IP options; retries and idempotency guarantees; inbound email; data region/DPA/subprocessor list; automation/team role details; and a named independent deliverability benchmark.
- **Shutdown/acquisition/news check:** Checked About, Editorial Policy, SendLayer blog, Press & Brand Assets, Terms, AUP, and official-site searches for shutdown, sunset, acquisition, and rename notices. No notice was found. The product’s official company page says it is part of the Awesome Motive family, but no separate acquisition notice or date was found.
