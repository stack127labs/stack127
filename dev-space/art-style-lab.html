art style lab.

six candidate styles for stack127 artwork. every style renders the same nine figures with the same data: bar chart, donut, line chart, flow diagram, decision tree, step path, icon set, logic gates, and annotations. only the style changes, so you can compare them fairly.

everything is drawn at runtime with rough.js, the same library excalidraw is built on. every shape uses a fixed seed, so a style renders identically on every reload. whichever style wins becomes a config object first, then a small set of react components for the site.

judge with the two second squint test: can you get each figure without reading? then ask if it feels like stack127. open this file directly in a browser; it needs internet once for the fonts and rough.js.
