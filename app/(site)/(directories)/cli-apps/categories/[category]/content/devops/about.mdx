## How do you choose a DevOps CLI?

Start with the platforms you run. Many tools here are the official CLI for one service, so that choice is already made for you.

- **Pricing.** Some tools are tied to a paid service. Check the Pricing filter and the service's own plans.
- **Source model.** A few tools here are source available or closed source. Check the Source model filter if that matters to you.
- **State and credentials.** Infrastructure tools keep state files and keys. Check where each tool stores them, and keep both out of Git.
- **Platform.** Check the Platform filter for your CI runners as well as your own computer.

## What should you keep in mind?

These tools can change production with one command. Use a read-only or plan mode first where the tool has one, and give CI tokens only the permissions they need.
