## How do you choose a terminal chat or mail client?

Start with the service. Email, IRC, Mastodon, and feeds each need a different client.

- **Mail setup.** Some mail clients connect to your server over IMAP and SMTP. Others read mail that a separate sync tool downloads. Check which way each works before you set it up.
- **App type.** Some are full-screen TUI apps you keep open all day. Others are commands you can script. The App type filter separates them, including a Mail client type.
- **Platform.** Most of these are built for Linux and macOS. Check the Platform filter if you're on Windows.
- **Config.** Terminal mail and chat clients reward time spent on configuration. Look for sample configs in the docs before you start.

## What should you keep in mind?

Passwords often end up in config files. Use an app password from your provider, and a keyring or a password command where the client supports one.
