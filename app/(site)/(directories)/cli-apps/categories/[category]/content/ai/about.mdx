## How do you choose an AI tool for the terminal?

Most of these send your text or code to a model, so start with where that model runs.

- **Pricing.** Coding agents are often free to install but charge for use, through a model provider's API or a subscription. Check the Pricing filter, then the provider's plans.
- **Local or cloud.** Tools that run models on your machine keep your data local, but they need plenty of RAM and ideally a GPU.
- **Permissions.** Agents can edit files and run commands. Check how each one asks before acting, and start in a project that's under version control so you can undo changes.
- **Platform.** Check the Platform filter, and read the install docs for Windows notes.

## What should you keep in mind?

Read what each tool sends to the provider and what it stores. API keys live in config files or environment variables, so keep them out of your shell history and out of any dotfiles you publish.
