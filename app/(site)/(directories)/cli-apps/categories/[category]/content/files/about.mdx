## How do you choose a file tool?

Name the job first: search, move, sync, back up, or browse.

- **Search defaults.** Some newer search tools skip hidden files and anything in `.gitignore` by default. Check that this matches what you want to find.
- **Sync and backup.** Check which remotes it supports, such as S3 or SFTP, and whether backups are encrypted and keep older versions.
- **App type.** File managers are full-screen apps you move around in, while finders are commands you can pipe into others. The App type filter separates them.
- **Platform.** Check the Platform filter, especially on Windows.

## What should you keep in mind?

Commands that delete, move, or remove duplicate files can't be undone. Run a dry run first when the tool has one, and keep a backup before a big cleanup.
