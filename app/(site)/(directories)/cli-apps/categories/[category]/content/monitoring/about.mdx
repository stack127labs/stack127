## How do you choose a monitoring CLI?

Decide what you're watching: processes, disk space, network traffic, or logs.

- **Live or one-off.** Process monitors refresh on screen as things change. Disk usage tools take one snapshot and exit. The App type filter separates them.
- **Permissions.** Tools that watch network traffic often need root or extra permissions to see it.
- **Platform.** Monitoring depends on the operating system, so check the Platform filter. Some features only work on Linux.
- **Remote servers.** Check that the tool runs over SSH with nothing extra to install on your side.

## What should you keep in mind?

These tools show what's happening right now. For history and alerts, you need a monitoring server. Search the [self-host apps directory](/self-host-apps) for one you can run yourself.
