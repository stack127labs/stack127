## How do you pick a terminal game or toy?

These are small and quick to try, so the checks are simple.

- **Platform.** Most are built for Linux and macOS. Check the Platform filter if you're on Windows, or run them in WSL.
- **Install.** Check the Install filter for a package manager you have.
- **Your terminal.** Some games need color, Unicode, or a minimum window size. If one looks wrong, try a bigger window, another font, or another terminal.
- **Controls.** Check the docs for the keys. Many use the arrow keys or Vim-style keys.

## Why play in a terminal?

Terminal games start instantly, use almost no resources, and work over SSH on any server. Some are long-running classics with deep rules, so expect to spend time learning them.
