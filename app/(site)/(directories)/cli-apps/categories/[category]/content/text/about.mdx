## How do you choose a text tool?

Name the job first: edit, search, transform, compare, or convert.

- **Editors.** Modal editors like Vim take time to learn, but vi or Vim is on almost every server. Others work like a desktop editor from the start.
- **Structured data.** For JSON, YAML, or CSV, use a tool built for that format instead of search and replace.
- **Pipes.** Check that the tool reads from standard input and writes plain output, so it fits into scripts.
- **Platform and install.** Check the Platform and Install filters for your system.

## What should you keep in mind?

Commands that edit files in place can't be undone. Keep files in Git, or try the command on a copy first.
