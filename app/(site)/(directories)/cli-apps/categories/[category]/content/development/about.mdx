## How do you choose a development tool?

This category is broad, so search for the job first, such as "formatter" or "version manager". Then narrow it down:

- **Install.** Check the Install filter for the package manager you already use, such as Homebrew, cargo, or npm.
- **Language.** Tools written in Go or Rust usually ship as one binary. Python and Node tools need their runtime installed.
- **Platform.** Check the Platform filter if you work on Windows, or if your team uses different systems.
- **License.** If you'll ship the tool inside your own product, check the License filter.
- **Health.** Build tools end up in every project, so prefer ones the Health filter marks Active.

## What should you keep in mind?

Pin tool versions in each project, with a version manager or a lock file, so everyone on the team gets the same results.
