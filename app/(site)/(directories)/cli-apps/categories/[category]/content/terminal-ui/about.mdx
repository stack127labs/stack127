## How do you choose a terminal, shell, or prompt?

These pieces stack. A terminal emulator runs a shell, the shell shows a prompt, and TUI apps run inside it all. Pick each layer on its own.

- **Terminal emulators.** Check for splits, tabs, and image support. Some include cloud or AI features, so read their privacy notes.
- **Shells.** Bash and Zsh run most scripts you'll find online. Other shells trade that compatibility for nicer defaults.
- **Prompts and themes.** Many need a Nerd Font, a font with extra icons, to look right.
- **Platform.** Check the Platform filter. Some emulators only run on macOS or Linux.

The App type filter separates terminal emulators, shells, prompts, multiplexers, and TUI apps.

## What should you keep in mind?

Keep your shell and terminal config in a dotfiles repository, so a new machine feels like home in minutes.
