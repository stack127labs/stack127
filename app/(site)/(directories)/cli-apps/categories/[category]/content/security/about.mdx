## How do you choose a security CLI?

Name the job first: scan code, scan systems, encrypt files, or manage certificates.

- **Scanners.** Check what they detect and how noisy the results are. Running them in CI catches problems before code is merged.
- **Encryption.** Check the key formats and how you share keys with others. A tool with fewer options is easier to use safely.
- **Source model.** For encryption, open source lets others check the code. The Source model filter shows this.
- **Health.** Security tools need regular updates. Prefer ones the Health filter marks Active.

## What should you keep in mind?

Only scan systems you own or have permission to test. Keep private keys off shared machines, and back them up somewhere safe and offline.
