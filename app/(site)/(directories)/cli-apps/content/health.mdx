## What do the health labels mean?

Health shows how recently the project's code changed when we reviewed it.

| Health | Meaning |
| --- | --- |
| Active | Code pushed in the 110 days before review |
| Slow | Last push 110 to 395 days before review |
| Stale | No push for more than 395 days before review |
| Archived | The repository is archived on GitHub |
| Unknown | Not set at review |

Health only changes when we review an app again, except Archived, which follows GitHub. Stars and the last commit date update from GitHub, so the last commit date is the fresher sign of activity.

Most popular sorts by star count. Apps with no star count sort last.
