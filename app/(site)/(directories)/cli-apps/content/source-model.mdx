## What does the source model mean?

It says whether you can read and change the code.

| Source model | Meaning |
| --- | --- |
| Open source | Under a license that lets you use, change, and share the code |
| Source available | You can read the code, but the license limits use or sharing |
| Closed source | The code isn't public |

Free to use and open source aren't the same thing, so check Pricing too. For what common licenses allow, see [software licenses for self-hosting](/software-licenses-for-self-hosting).
