## Which launch directories give a dofollow link?

Choose Dofollow under Link type to see them. Each result comes from one published listing we opened, or from the plan the site's terms describe, so free and paid listings on the same site can differ.

[Google says](https://developers.google.com/search/docs/crawling-indexing/qualify-outbound-links) links marked nofollow, ugc, or sponsored will generally not be followed. A dofollow link still doesn't promise indexing, rankings, or traffic.

| Link type | What it means |
| --- | --- |
| Dofollow | The sampled link had no nofollow, ugc, or sponsored value, or the site's terms promise that. |
| Nofollow | The link asks search engines not to follow it. |
| UGC | The link is marked as user-generated content. |
| Sponsored | The link is marked as paid. |
| Mixed | The link carried more than one value, such as ugc and nofollow. |
| Varies | Free, paid, or top-ranked listings get different links. The place's page says which. |
| No link | The sampled listing doesn't link to the maker's own site. |

These two labels mean we have no checked result:

| Label | What it means |
| --- | --- |
| Likely nofollow | We couldn't read a sampled link, but other evidence points to nofollow. |
| Couldn't verify | We couldn't open a published listing or read its link. |
