## Where do these shortcuts come from?

Each app's list follows a published shortcut reference, usually the maker's own help pages, and shows the default keys. When the source gives no key for a platform, the row says "Not documented" instead of guessing.

Mac keys get their own line because many apps swap Ctrl for Cmd and Alt for Option, but not all of them do. The printable sheet names each app's source and the date it was checked.
