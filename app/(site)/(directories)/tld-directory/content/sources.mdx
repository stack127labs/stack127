## Where does this data come from?

- Type and operator: [IANA's root zone database](https://www.iana.org/domains/root/db).
- DNSSEC: DS records in the [root zone file](https://www.internic.net/domain/root.zone).
- Lookups: [IANA's RDAP directory](https://data.iana.org/rdap/dns.json), the RDAP services we added by hand, and WHOIS servers listed in IANA's root zone database that passed our tests.

A script rebuilds the table from these sources. If a source changes shape, the script stops instead of saving a partial list.
