| Family | Examples | What you owe |
| --- | --- | --- |
| Permissive | MIT, Apache-2.0, BSD | Keep the copyright notices when you pass it on. Your fork can stay closed. |
| Weak copyleft | MPL-2.0, LGPL | Changes to the covered files or library stay open when you ship them. The rest of your product stays yours. |
| Copyleft | GPL, AGPL | The whole program stays open when you pass it on. AGPL adds a network rule, explained below. |
| Restricted | SSPL, Elastic, BSL, FSL, PolyForm | The code is public, but the terms limit some uses, often hosting it as a service or competing with the publisher. These are source-available, not open source. |

Self-hosting a restricted app for yourself or your company is usually allowed, but each license's own text decides. Public domain dedications work like permissive licenses. Creative Commons licenses usually cover docs and media, not the app's code.
