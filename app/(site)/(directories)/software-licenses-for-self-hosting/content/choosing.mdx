## Which license should I choose for my self-hosted app?

Start from what you want to allow and what you want to prevent.

| If you want | Consider |
| --- | --- |
| As many users as possible, and you don't mind who profits | MIT, or Apache-2.0 for an explicit patent grant |
| Changes to your files shared back, without rules for whole products | MPL-2.0 |
| A library others can use in closed products | LGPL-3.0, or MIT |
| No closed, hosted copies of your changed app | AGPL-3.0 |
| A business on top of open source code | AGPL-3.0 plus a paid commercial license. You need the rights to all the code, often through contributor agreements. |
| To block resale as a managed service, and you accept losing the open source label | BSL 1.1 or FSL, which turn into open source licenses after a set time. Elastic-2.0 or Sustainable Use if you want no conversion date. |
| Free personal use and paid company use | PolyForm Noncommercial. Expect fewer business users. |

Whatever you choose, add a short note beside the LICENSE file that says in plain words what self-hosters may do.
