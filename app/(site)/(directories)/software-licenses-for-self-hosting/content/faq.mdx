## Questions people ask

### Can my company change a GPL app and keep the changes private?

Yes, as long as the copies stay inside the company. GPL applies when you distribute, and internal use isn't distribution.

### Is code on GitHub automatically open source?

No. Code is open source only when its license meets the Open Source Definition. SSPL, BSL, FSL, Elastic, and PolyForm code is often public, and none of those licenses are open source.

### Can I sell hosting for an MIT-licensed app?

Yes. Permissive licenses allow it. That's one reason some projects later move to AGPL or a source-available license.

### Do two BSL 1.1 projects grant the same rights?

No. Each project sets its own Additional Use Grant and change date, so read both.

### Can I use code from a repository with no license?

First look for a license grant in the README, the docs, or other files. If there's none anywhere, normal copyright applies, so treat it as all rights reserved. [GitHub's licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository) explains this.
