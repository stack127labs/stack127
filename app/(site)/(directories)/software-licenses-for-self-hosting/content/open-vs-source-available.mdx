## What is the difference between open source and source-available?

Open source means anyone may use, study, change, and share the software for any purpose, including commercial use, as set out in the [Open Source Definition](https://opensource.org/osd). MIT, Apache-2.0, GPL, and AGPL all qualify. A duty to share source isn't a limit on use, so copyleft licenses count.

Source-available means the code is public, but the terms limit some uses. SSPL, Elastic License, BSL, FSL, and PolyForm each limit something different.

A public repository or a free download doesn't tell you which one you have. Read the license before company use, redistribution, or paid hosting.
