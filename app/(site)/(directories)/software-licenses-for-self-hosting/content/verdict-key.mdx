## How do I read the license table?

| Column | The question it answers |
| --- | --- |
| Self-host | Can you run it on your own hardware, for yourself and your household? |
| Company | Can it run on a work server for internal use? |
| OSI | Is it approved by the Open Source Initiative? `pd` means a public domain dedication, which works like open source without being on the list. |
| Service | Can you host it for people outside your household or company, including paid hosting? |
| Modify | Can you change the code, and what do you owe when your changes leave your server? |
| Redistribute | Can you pass it on in images, appliances, forks, or products? |
| Copyleft | Do conditions travel with the code, and how far? |

| Value | Meaning |
| --- | --- |
| **yes** | Allowed. Routine notices or attribution may still apply. |
| **careful** | Allowed with a real obligation, such as sharing source, share-alike, or a limit on competing. The license's card explains it. |
| **depends** | Project terms, a chosen option, or a separate agreement decide. |
| **no** | The license doesn't allow it. |

WTFPL, for example, allows everything, but some company policies ban it anyway. That's a policy question, not a license one. The [self-hosted apps](/self-host-apps) directory uses the same license names, so you can filter apps by license there.
