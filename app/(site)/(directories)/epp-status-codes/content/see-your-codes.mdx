## How do I see the status codes on my domain?

Enter the domain in [domain lookup](/domain-lookup). It lists each code on the domain with what it means. To move a domain, [transfer readiness](/transfer-readiness) shows which public codes could block it. For the expiry stages, use the [domain expiry checker](/domain-expiry).

For the formal definitions, see [ICANN's EPP status codes page](https://www.icann.org/resources/pages/epp-status-codes-2014-06-16-en).
