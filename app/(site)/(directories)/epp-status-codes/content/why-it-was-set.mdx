## Why was this status code set on my domain?

The code doesn't say, and the reason isn't public. `serverTransferProhibited`, for example, can come from a dispute, a court order, a registry security action, or a lock you asked for and forgot. Your registrar can usually find out.

Some registries return codes outside the standard set. [Domain lookup](/domain-lookup) shows them as returned, with no explanation, because only that registry's own documentation defines them.
