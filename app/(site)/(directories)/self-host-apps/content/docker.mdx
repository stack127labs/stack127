## What is the difference between an official and a community Docker image?

An official image comes from the app's publisher. A community image is built by someone else, such as [LinuxServer.io](https://www.linuxserver.io/). It can work well, but the publisher doesn't support it, and updates depend on whoever maintains it. The Docker filter includes both, and each app says which it has.
