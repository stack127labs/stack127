## What do the health labels mean?

Health shows how recently the code changed, from the last commit in the app's public repository.

| Health | Meaning |
| --- | --- |
| Active | A commit in the last year |
| Slow | Last commit one to two years ago |
| Stale | No commit for more than two years |
| Archived | The repository is archived |
| Not verified | We couldn't check it |

Repository facts refresh automatically. Apps without a public repository get their health from our review instead. A quiet project isn't always abandoned, since some apps are simply finished, but check for security fixes before you rely on one.
