## How do you choose a file sync or sharing app?

Decide whether you want files to sync between devices, to share links with other people, or to move and download big files.

- **Sync clients.** Real sync needs desktop and phone apps. Check the app's links for clients on every device you use.
- **How files are stored.** Some apps keep files as normal folders on disk. Others use their own format. Normal folders are easier to back up and to leave.
- **Resources.** Full suites run a database and background jobs. Single-purpose tools are much lighter. Compare them with the RAM filter.
- **Sharing.** For public links, check for expiry dates, passwords, and upload limits.

## What should you know before you run one?

Sync is not a backup. A deleted or encrypted file syncs to every device, so keep separate backups with older versions. If you share public links, the app faces the internet, so keep it updated.
