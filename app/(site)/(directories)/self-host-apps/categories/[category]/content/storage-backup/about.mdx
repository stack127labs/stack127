## How do you choose a storage or backup app?

Decide whether you need more storage, backups, or both. They're different jobs.

- **Backups** should be encrypted and keep older versions, so you can go back to last week. Check which destinations it supports, such as S3 storage or another server.
- **Restores.** Check how you'd restore one file and how you'd restore a whole machine. Test it before you need it.
- **Object storage** gives your apps an S3-compatible bucket. Check the License and Source model filters before you build on one.
- **NAS systems** are full operating systems, not apps. Check the Install method filter to see what runs where.

## What should you plan for when you run one?

Keep at least one copy off site, since a backup on the same disk or server fails with it. Watch your backup jobs too. A job that fails silently looks fine until the day you need it.
