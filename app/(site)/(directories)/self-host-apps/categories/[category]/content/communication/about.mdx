## How do you choose a chat or messaging server?

Start with who will use it. A team moving off Slack needs similar channels and threads, and a family needs good phone apps.

- **Phone apps and notifications.** Check the official links for iOS and Android apps. Push notifications often go through a relay the publisher runs, so read how that works.
- **Federation.** Matrix and XMPP servers can talk to other servers. Others only connect your own users. Decide which you want.
- **Paid editions.** Some chat servers keep features such as single sign-on in a paid edition. Check the License and Source model filters, then the feature list.
- **Resources.** A federated server can grow large once users join big public rooms. Treat the RAM and Storage estimates as a starting point.

## What should you plan for when you run one?

People use chat all day, so updates and uptime matter. Back up the database and uploaded files. Notification servers are a different kind of app and much lighter, so they often run beside your other apps.
