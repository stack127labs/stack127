## How do you choose a time tracker?

Decide whether you're tracking time for clients or just for yourself.

- **Billing.** For client work, check for rates per project, reports, and invoice export.
- **How you track.** Some apps use a timer you start and stop. Others record what you do automatically. Pick the one you'll keep using.
- **Where you track from.** Check for a phone app, browser extension, or desktop widget.
- **Privacy.** Automatic trackers record which apps and sites you use. Keep that data on a machine you trust.

## What should you plan for when you run one?

Back up the database, since lost hours are lost money. If several people log time, set up HTTPS and separate accounts. Some personal trackers run on your own computer instead of a server.
