## How do you choose a project or task app?

Start with how you work: kanban boards, sprints, timelines, or simple to-do lists.

- **Views.** Check for the views you'll use every day, such as boards, lists, and Gantt charts.
- **Import.** If you're leaving Jira, Asana, or Trello, check for an importer.
- **Paid editions.** Some project tools keep features such as single sign-on or Gantt charts in a paid edition. Check the License and Source model filters, then the feature list.
- **Integrations.** Look for Git, chat, and calendar connections if your team relies on them.

## What should you plan for when you run one?

Many of these need a database and send email notifications, so plan for both. The Needs database signal shows the ones we've confirmed. Back up the database and attachments, and use HTTPS if people log in from outside.
