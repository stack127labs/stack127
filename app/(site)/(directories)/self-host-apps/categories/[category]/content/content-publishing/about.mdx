## How do you choose a CMS or blog platform?

First decide how the site gets built. A blogging platform gives you the editor and the site in one. A headless CMS stores content for a front end you build. A static site generator turns files into a site, with no app running on a server at all.

- **Who writes.** Writers who don't code need a web editor. If only you write, Markdown files in Git can be enough.
- **Database.** Most blogging platforms and headless CMSs need one. Static generators don't. The Needs database signal shows the ones we've confirmed.
- **Install method.** Some only ship as a binary or a system package, not Docker. Check the Install method filter.
- **Themes and plugins.** These can carry their own licenses, so check them if you build sites for clients.

## What should you plan for when you run one?

A public website faces the internet all the time, so keep the app and its plugins updated. Back up the database and the media folder. A static site needs neither and can go on almost any web host.
