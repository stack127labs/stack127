## How do you choose a design or whiteboard app?

Start with how many people work together. A team needs live collaboration, while one designer can pick a lighter tool.

- **File formats.** Check what you can import and export, such as SVG, PNG, or PDF, and whether it opens files from the tool you're leaving.
- **Collaboration.** Live editing often needs an extra service for shared sessions. Read the install docs for everything you'll have to run.
- **GPU for image generation.** Image generators need a capable graphics card. The RAM estimate doesn't cover its video memory.
- **Model licenses.** Image models have their own licenses. Check them before you use the results commercially.

## What should you plan for when you run one?

Back up the files and boards people create. Some whiteboards keep drawings in your browser unless you set up storage on the server, so check where your work is saved before you rely on it.
