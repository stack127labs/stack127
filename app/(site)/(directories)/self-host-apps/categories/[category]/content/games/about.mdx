## How do you choose a game server or game app?

Start with the game and how many people will play.

- **Players and RAM.** A game server uses more memory as players and mods grow. Treat the RAM estimate as the floor for a small group.
- **License.** Many game servers are closed source but free to run, while each player still needs the game. The Source model filter shows which are open.
- **Getting friends in.** Players outside your home need a way to reach the server: an open port, a tunnel, or a VPN they join.
- **Game streaming** needs a GPU in the host and a fast local network, not just a server.

## What should you back up?

Back up world saves before every update or mod change, since a bad update can break a world. Game library and ROM managers hold large collections, so check the Storage filter before you pick one.
