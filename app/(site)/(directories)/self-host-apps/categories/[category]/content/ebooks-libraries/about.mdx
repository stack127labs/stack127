## How do you choose an e-book or comic server?

Start with what you read and on which device.

- **Formats.** Check support for your files, such as EPUB, PDF, CBZ comics, or audiobook formats.
- **Reader apps.** Many servers offer OPDS, a catalog feed that e-reader apps can browse and download from. Check for it if you read in an app rather than a browser.
- **Your existing library.** If you already use Calibre on a computer, some servers can read its library folder directly.
- **Family use.** Check for separate accounts and reading progress for each person.

## What should you back up?

The book files are the big part, so check the Storage filter. Back up the app's database too, since it holds reading progress, collections, and your metadata edits. If you want the server on a NAS, use the RAM filter to find one that fits.
