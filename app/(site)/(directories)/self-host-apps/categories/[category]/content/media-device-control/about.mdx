## How do you choose a media control app?

Start with the devices you want to play on: speakers, TVs, cameras, or a photo frame.

- **Device support.** Check which devices and protocols it works with, such as Chromecast, AirPlay, or DLNA.
- **Where it runs.** Some apps run on the playback device itself, such as a media center on a TV box. Others are a server that sends to many devices.
- **Multi-room sync.** For music in several rooms, check that it keeps the rooms playing in time.
- **Smart home.** Some of these plug into a home automation hub. Check the install docs if you want to control playback from yours.

## What should you plan for when you run one?

These apps have to find devices on your local network, so Docker setups often need host networking. They store little data, so backups are mostly config files. Keep them off the open internet.
