## How do you choose a wiki?

Start with who writes and how they like to write.

- **Editor.** Team wikis use a visual editor. Classic wikis often use their own markup. Git-based wikis use Markdown files.
- **Permissions.** For a team, check permissions for spaces or pages and support for single sign-on.
- **Storage.** A wiki on a database is easy to search. A wiki on plain files is easy to move and back up.
- **Search.** Check for full-text search, including inside attachments if you need it.

## What should you plan for when you run one?

Back up the database or files along with the attachments. If the wiki holds internal docs, keep it behind a login or a VPN. For a public docs site, a static site generator may suit you better.
