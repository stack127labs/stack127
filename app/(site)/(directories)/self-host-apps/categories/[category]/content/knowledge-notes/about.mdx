## How do you choose a notes app?

Start with where your notes are stored and how you'd move them out if you had to.

- **Storage format.** Some apps keep notes as Markdown files. Others keep them in a database. Plain files are easier to move and back up.
- **Sync and offline.** Check how the phone and desktop apps sync, and whether you can write offline.
- **Encryption.** If the server runs on someone else's machine, end-to-end encryption keeps your notes private from it.
- **Paid features.** A few apps keep sync or collaboration in a paid edition. Check the Source model filter and the feature list.

## What should you back up?

Notes pile up over years. Back up the notes, attachments, and database together. Try an export once, so you know you can leave if the project stops.
