## How do you choose a dashboard app?

This category covers three different jobs, so name yours first: a start page for your services, charts from your data, or web analytics.

- **Start pages** should be light and easy to configure. Use the RAM filter, and check for widgets that show the status of the services you run.
- **Data dashboards** connect to your databases. Check that the app supports yours and can limit what each user sees.
- **Web analytics** collect visitor data. Check whether it uses cookies, since that decides whether you need a consent banner in some countries.
- **Health.** Some dashboards are small one-person projects. The Health filter shows which still get updates.

## What should you plan for when you run one?

A start page often holds API keys for your other services, so keep it behind a login or a VPN. An analytics app must be reachable from the internet to count visits, and its database grows with your traffic.
