## How do you choose home automation apps?

Start with your devices. The way they talk decides much of the rest.

- **Protocols.** Zigbee and Z-Wave devices need a USB radio or a hub. Wi-Fi devices may need a cloud account unless the app supports local control.
- **Install method.** Some hubs run best as their own operating system. The Install method filter shows options such as Home Assistant OS and Docker.
- **Hardware access.** In Docker, a USB radio has to be passed through to the container. Check the install docs.
- **Integrations.** Check the app's integration list for your brands before you buy more devices.

## What should you plan for when you run one?

A hub runs your lights and locks, so give it a stable machine that stays on, such as a small PC or a Raspberry Pi. Back up its config before updates. Keep it off the open internet, and use a VPN to reach it from outside.
