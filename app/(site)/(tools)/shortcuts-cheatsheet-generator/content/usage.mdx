## How to make a sheet that fits on a page

Pick one platform per app unless the sheet is for a shared desk. Windows, macOS, and Linux often use the same action with a different modifier, such as `Ctrl` and `Cmd`, and one platform makes a much shorter sheet.

Then untick the groups you don't need. Each group is a task, such as navigation or search, so drop the ones you rarely do.

<Example title="VS Code on a Mac">

VS Code has 153 shortcuts across seven groups. Choose `macOS` and keep only `Basic editing` and `Navigation`, and the sheet drops to 46 shortcuts.

</Example>

Each app keeps its name and each group its heading on the paper. So when two apps share a key, such as `Cmd+K`, the sheet shows which app it belongs to.

To print, use `Print sheet`. In the browser's print dialog, turn off headers and footers for a cleaner page.

## Share or bookmark a sheet

Add `?apps=` to the page address, followed by each app's name as it appears in its keyboard shortcuts page address, such as `vscode` from `/keyboard-shortcuts/vscode`. For example, `/shortcuts-cheatsheet-generator?apps=vscode,chrome` opens with both apps picked. Platform and group choices aren't saved in the link.
