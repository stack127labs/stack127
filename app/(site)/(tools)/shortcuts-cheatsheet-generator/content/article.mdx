## Where do the shortcuts come from?

Each app's shortcuts come from its own documentation, such as Microsoft's [VS Code default keyboard shortcuts](https://code.visualstudio.com/docs/reference/default-keybindings). The bottom of each app's section on the sheet names the source and the date it was last checked.

The sheet shows default shortcuts only. If you changed a key in an app's settings, or use a mode such as Vim keys in your editor, the sheet won't know.

## How many shortcuts should a cheat sheet have?

Fewer than you think. A sheet you can scan in a few seconds is one you'll keep next to the keyboard. Start with the shortcuts for things you do many times a day, and make a new sheet once those stick.

A sheet built around one task, such as an editor, a terminal, and a browser for coding, is often more useful than one for a single app.

## Where can I see every shortcut for an app?

The [keyboard shortcuts directory](/keyboard-shortcuts) has a full page for each app, with notes on modes, key sequences, and platform differences. The sheet uses the same data as those pages, such as [VS Code](/keyboard-shortcuts/vscode) and [Chrome](/keyboard-shortcuts/chrome).
