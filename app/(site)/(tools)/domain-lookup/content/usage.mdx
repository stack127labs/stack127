## How to read the record

Start with the question that brought you here. Each one points to a different part of the record.

| Your question | Look at |
| --- | --- |
| Who do I transfer through or report abuse to? | Registrar |
| When does it expire? | Dates, especially registry expiry |
| Why won't it transfer? | Status codes |
| Why doesn't the site load? | Status codes and nameservers |
| Who owns it? | Contacts and redaction |

The line under `Registered` names the status code with the most effect, such as one that blocks transfers or stops the domain from working. The [EPP status codes](/epp-status-codes) page explains every code and who can remove it. If the site doesn't load, the [domain report](/domain-report) checks the registration and live DNS together.
