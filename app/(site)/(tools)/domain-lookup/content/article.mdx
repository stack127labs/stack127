## What is the difference between RDAP and WHOIS?

RDAP is the newer way to read public domain registration data, and it replaced WHOIS for generic endings such as `.com` and `.org`. Both read the same registry records. RDAP returns labeled fields and standard event dates, and can declare which data is withheld. WHOIS returns free text that differs by provider.

Since 28 January 2025, ICANN no longer requires generic registries and registrars to run WHOIS, except for `.com`, `.name`, and `.post`. [ICANN's RDAP page](https://www.icann.org/rdap) explains the change. This lookup uses RDAP whenever the registry offers it.

Country endings such as `.uk` or `.it` set their own rules. Many publish RDAP, and some offer only WHOIS. For those, the lookup asks the registry's WHOIS server and reads the text into the same fields: dates, registrar, statuses, and nameservers. A field the text doesn't clearly state stays unknown, and the source line names the server, such as `whois.nic.it`.

A few endings offer neither, or their WHOIS server didn't pass our tests. For those, the result shows `Cannot determine`, which says nothing about whether the name is registered. Use the registry's own lookup, which the ending's page in [IANA's root zone database](https://www.iana.org/domains/root/db) links to. The [TLD directory](/tld-directory) shows how each ending is checked.

A WHOIS site can show different details because it reads WHOIS text or an older saved copy. Owner details are a separate question, covered in the [registrant lookup](/domain-owner).

## Why are the registry and registrar shown separately?

They are two different organizations, and each publishes part of the record. The registry runs the ending, such as Verisign for `.com`, and holds the core record: dates, statuses, and nameservers. The registrar is the company the owner registered through, and often holds the contacts.

Their expiry dates can differ. The [domain expiry checker](/domain-expiry) explains why, and which one decides when the domain is deleted.

If the registrar doesn't answer, the result keeps the registry's facts and says the registrar part is missing.

## Does the last changed date mean the owner changed?

No. `Record last changed` says the registration record changed, but not which field. `Registry database updated` is when the registry last refreshed its whole database, not this domain. These are [standard RDAP event names](https://www.rfc-editor.org/rfc/rfc9083.html#section-10.2.3), and neither is a history of past owners.

## Where does the lookup go?

Your lookup goes from stack127 to the registry and the registrar, not to the website. A registered result can be a saved answer up to 24 hours old, and the source line under the result shows when each part was fetched.
