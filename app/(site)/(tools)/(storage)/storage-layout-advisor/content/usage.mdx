## What to enter

Protected failures is the number of drives that can fail at once, in any order, without losing data. Only layouts that meet it are compared.

Workload changes the order of the list, not the space. VMs and databases put mirrors first, because they handle small random writes better. Bulk files and General put parity first, because it keeps more space.

For striped mirrors, drives pair up in the order you enter them, so put same-size drives next to each other.

`Share layout` makes a link with your inputs, so anyone you send it to can see them.
