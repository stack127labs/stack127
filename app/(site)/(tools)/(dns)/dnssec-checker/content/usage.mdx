## What do Secure, Insecure, Bogus, and Indeterminate mean?

| Result | What it means |
| --- | --- |
| Secure | The answer is signed, and every link checks out to the root. This includes a signed proof that a record or name doesn't exist. |
| Insecure | The name isn't signed, and the chain proves that on purpose. Nothing is broken. |
| Bogus | The name should be signed, but a link fails. Resolvers that check DNSSEC return SERVFAIL, so the name stops working for their users. |
| Indeterminate | The check couldn't finish. Run it again before you change anything. |

DNSSEC signs each answer, not the domain as a whole. Pick the record type that's failing, or A for a general check.
