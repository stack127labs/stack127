## How to read the results

The summary counts how many endings have no registration. Each row then shows one of four results.

| Result | What it means |
| --- | --- |
| `No registration found` | The registry has no record of the name with that ending. |
| `Registered` | Someone holds it. The registrar and expiry date show when published. |
| `Cannot check` | The ending has no public lookup service. Use the registry's own search, listed in the [TLD directory](/tld-directory). |
| `Check failed` | The registry didn't answer or limited requests. Try again in a few minutes. |
