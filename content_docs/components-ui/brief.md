# Brief: Components UI

## Who is here

The stack127 team is choosing and checking shared components for tools, directories, courses, catalogs, and content pages.

## The job

They can try controls and upload states, trigger validation, inspect directory filters and cards, results and charts, use pagination and a dialog, and see how content components render from Markdown. They can switch themes and check narrow widths.

## Show vs say

The development-only page at `/components-ui` uses working components and realistic data. Short headings separate inputs, actions, feedback, content, data, charts, and navigation. It is a practical gallery, not a public article.
