# Brief: self-hosted app resource planner

## Who is here

Someone choosing a small host for several self-hosted apps, or checking whether an existing host has room for one more service. They know the apps they want but do not want to turn scattered requirement notes into a resource plan.

## The job

They leave with a transparent RAM and storage envelope for the selected app mix, a clear indication of the closest known budget, and a list of assumptions or unknowns that need verification. An app outside the curated facts remains usable through a custom row without receiving a guessed requirement.

## Show vs say

Show the app editor, host budget inputs, and one answer-first result in a single workbench. Use exact allocation bars and a table for repeated resource totals, with a visible unknowns list for evidence quality. Supporting prose should explain how reviewed app estimates, headroom, and runtime verification relate. Do not add runtime monitoring, Docker inspection, automatic image analysis, security scoring, or a universal compatibility claim.
