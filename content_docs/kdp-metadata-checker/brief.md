# Brief: KDP metadata checker

## Who is here

An author is in the last pass before entering a title, subtitle, description, and seven keyword fields into KDP. They already have the words and need to know which details need attention. They do not want an AI rewrite, an Amazon scrape, or a verdict that pretends to know KDP's private review system.

## The job

They leave with a field-by-field list of documented formatting problems and clearly labelled review prompts, plus counts and a safe approximation of the description preview. The original description stays intact and can be copied without a hidden rewrite.

## Show vs say

The interactive workbench carries the answer. It shows the form, local character counts, an answer-first result lead, findings grouped by field, and a safe rendered description preview. The findings explain the difference between a source-backed check and a heuristic prompt. A short source disclosure states the rule date, links the official KDP pages, and says that a clean local result is not KDP approval. No chart, marker drawing, screenshot, AI-generated copy, or long explanatory block is needed for this job.
