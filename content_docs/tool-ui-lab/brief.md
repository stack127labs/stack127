# Brief: tool UI lab

## Who is here

The stack127 team is checking shared tool controls, upload patterns, and data visuals before using them on published tools.

## The job

They can operate every control, add files by browsing or drag and drop, inspect upload recovery states, trigger validation, add and remove a repeated row, and inspect each supported result and chart format in both themes and at narrow widths.

## Show vs say

The page contains working controls and realistic technical data. Upload examples show one PDF and a small image batch. Clean charts show exact comparisons and change over time. A process flow shows ordered stages. Short section headings separate controls, uploads, data visuals, feedback, and results. There is no explanatory article, marker art, catalog copy, or decorative card grid.
