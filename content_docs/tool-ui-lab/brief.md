# Brief: tool UI lab

## Who is here

The stack127 team is checking shared tool controls before using them on published tools.

## The job

They can operate every control, trigger validation, add and remove a repeated row, and inspect each supported result format in both themes and at narrow widths.

## Show vs say

The page contains working controls and realistic technical data. Short section headings separate inputs, choices, repeated rows, feedback, and results. There is no explanatory article, marker art, catalog copy, or decorative card grid.
