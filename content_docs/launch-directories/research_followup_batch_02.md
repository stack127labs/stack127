# Launch directories research follow-up: batch 02

Checked: 2026-09-29
Scope: Recheck of the 34 held candidates in categories 3 and 4 from [research batch 02](research_batch_02.md).

## How to read this check

I reopened current official submission, pricing, policy, and sample pages where available. I did not treat a blocked page as proof that a service is closed. I also did not treat a missing `rel` value as evidence of a dofollow link.

The parent agent later checked the live HTML for SaaSHub, AppRater, Startups.gallery, and SideProjectors. Their sample-specific raw link findings and current card decisions are included in the table below.

The live browser was unavailable to this research agent, and direct shell requests could not resolve external hosts. The web reader could show page text and destinations but not the listing anchor's HTML `rel` tokens. The original batch report records several same-day raw HTML checks; I identify those as previous observations and do not claim that I retested them here. Where a current link type remains unverified, the site stays on hold until a raw HTML check is available.

## Batch 02 summary

- All 34 held candidates were rechecked against current official material where it was accessible. A direct live HTML check on 2026-09-29 now upgrades SaaSHub, AppRater, Startups.gallery, and SideProjectors to card-ready. These decisions supersede their Hold values in the table above.
- SaaS Browser remains held because its sample returned a Cloudflare challenge and its link type could not be checked. Other candidates remain held for the specific blockers in their rows.
- Do not convert optional promotion or leaderboard costs into submission fees. This matters for AppRater, SaaS Browser, Startup Ranking, and Startups FYI.
- Some sites publish no price or review estimate. Those values can be stated as “not published” only where the official page supports that wording. A missing raw link attribute must stay unknown until inspected.
