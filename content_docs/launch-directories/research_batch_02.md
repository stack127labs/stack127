# Launch directories research batch 02

Checked: 2026-09-29
Scope: categories 3 and 4 in the candidate inventory.

## Research method

This batch accounts for all 48 names in the two categories. AlternativeTo is the one existing record and is marked as skipped. SourceForge is the published sample card; its current facts are audited below so the existing row can be corrected without a duplicate.

An **include** means the available official terms and a public example support all five card fields. An official source can say that no deadline is published; that is still a useful, explicit value. A **hold** means an essential fact, usually the submission price or actual link behavior, cannot be stated accurately yet. An **exclude** means the site does not fit a product launch or software listing submission.

Link type comes from an official link policy or direct inspection of a public product listing. `nofollow`, `sponsored`, and `ugc` are the actual `rel` tokens that matter here. A `noreferrer` or `noopener` token alone does not make a link nofollow. If a listing could not be opened or its outbound link could not be inspected, the site is held; that is not evidence that it has no link.

### SourceForge correction for the existing row

The current official [Create a Project page](https://sourceforge.net/create/) says project setup is free and projects that meet Open Source Directory rules are added to that directory. The [new project form](https://sourceforge.net/p/add_project) requires a SourceForge account, a 3 to 30 character URL name, and SMS phone verification for a new administrator. The official [project creation guide](https://sourceforge.net/p/forge/documentation/Create%20a%20New%20Project/) describes creation after the user completes the form and verification; it does not describe an editorial waiting period.

Update the current sample card's review-time wording to **“Project page is created after setup and phone verification; no editorial review time is stated.”** Keep eligibility specific to open-source projects with a license accepted by SourceForge. The KeePass example's external “KeePass Web Site” link was verified in a raw HTML fetch as `rel="nofollow"`. Set the link type to **Nofollow in KeePass sample**; this describes the checked listing, not every SourceForge project.
