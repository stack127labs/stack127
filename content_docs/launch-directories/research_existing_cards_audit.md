## LibHunt: research follow-up

LibHunt's current [project submission guide](https://www.libhunt.com/site/project_submit) says submissions must be open-source projects hosted on GitHub or GitLab and are suggested as alternatives to an existing project. The guide does not publish a submission fee or review time. Public profiles such as [React](https://www.libhunt.com/r/react) have links to source code and an official site. A direct page request during this check returned a Cloudflare 403, so the example link's `rel` treatment could not be verified from its HTML. Keep the existing record unpublished until the maker-site link can be checked and the remaining terms can be confirmed.

The sample HTML observations above were checked on 2026-09-29. They describe one public listing per site and do not promise that every plan or every other listing uses the same link relation.
