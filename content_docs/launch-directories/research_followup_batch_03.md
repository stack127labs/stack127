## Link checking limit

The in-app Browser reported that no browser is available. The web reader could open many current pages and show visible links, but it does not expose the actual HTML `rel` attributes. I therefore did not claim that a sample link is dofollow, nofollow, sponsored, or UGC unless the current official submission page itself promises that type. Any raw `rel` observations mentioned below are explicitly identified as earlier observations from the original report, not newly checked here. Sites that depend on the sample's actual `rel` value remain held until that value can be checked.

For prices, listing charges are kept separate from optional ads or placement. “Not published” means I checked the current official page and it does not disclose that fact; it does not mean the service is free.
