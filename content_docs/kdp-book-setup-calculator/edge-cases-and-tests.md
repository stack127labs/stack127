# Edge cases and tests: KDP book setup calculator

Status: ready
Tool: KDP book setup calculator
Route: `/kdp-book-setup-calculator`
Depends on: `competitive-report.md`, `implementation-report.md`, `interface-contract.md`, `brief.md`

## Risk model

| Priority | Meaning for this tool |
| --- | --- |
| P0 | A wrong dimension, margin, spine, eligibility classification, or estimate could send an author to production with a plausible but unusable file. P0 also covers accepting an unsupported tuple, leaking setup data, or making the primary result inaccessible. |
| P1 | A common setup, edit, copy, reset, keyboard, focus, warning, or responsive flow fails, or the interface leaves stale or misleading output visible. |
| P2 | An uncommon presentation, performance, browser-resilience, theme, or recovery issue does not change the calculation but still needs a defined outcome. |
