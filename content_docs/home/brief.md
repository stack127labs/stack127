# Brief: Home

## Who is here

A technical reader has landed without a specific tool in mind, or has heard about stack127 and wants to see what is available. They understand the broad subjects but should not need to learn the site structure first.

## The job

They should identify the useful surface for their current task and reach it in one click. A newcomer should also see a short path into the course, app directory, or license reference.

## Show vs say

The sidebar and linked card grid are the product map. Each card uses one marker drawing to signal the subject, a short description to set scope, and a live count only when the repository or database can provide it. The opening needs only one sentence to define the territory. The small Start here list carries the few recommendations that require words rather than another card.
