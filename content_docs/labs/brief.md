# Brief: stack127 Labs

## Who is here

A tinkerer has found stack127 and wants to see the projects behind the site, including tools they can inspect, use, or self-host.

## The job

The page should explain the relationship between stack127, stack127 Labs, and the public GitHub repositories without making a small project studio sound like a large company.

## Show vs say

Use a compact project table because every project repeats the same facts: what it is, where to use it, and where its source lives. Keep the introduction short. Do not invent activity metrics, stars, or release counts, and do not use decorative art where the repository links are the actual proof.
