# Brief: Storage tools

## Who is here

A self-hoster or storage operator is comparing layouts before buying drives or changing an array. They need the right calculator without learning every storage system first.

## The job

They should reach the planner that matches their storage system, enter the drives and protection target, and see capacity, waste, reserve, or risk without false precision.

## Show vs say

The hub sidebar links to published tool catalogs and marks the current catalog. Individual tools appear once in the main card grid. Tool pages retain their family-specific sidebar.

The hub uses the shared three-column catalog grid. Each card has one simple tool name, one scope sentence, and one small marker drawing of the storage relationship it models. There is no second heading inside a card. Individual tools keep inputs and results in one clear frame, use diagrams for layouts and failure domains, and use tables for repeated drive or scenario facts.
