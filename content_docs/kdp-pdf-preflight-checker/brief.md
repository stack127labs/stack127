# Brief: KDP PDF preflight checker

## Who is here

An author or formatter has a finished KDP interior or paperback cover PDF and wants to understand a warning before uploading it again. They know their trim, material, and book page count, but they may not know which PDF property caused the warning.

## The job

They leave with a page-level report of actual dimensions, expected dimensions, mixed-size pages, page boxes, and other measurable file conditions. The report also says what could not be measured, so the user knows what still needs KDP's own preview and review.

## Show vs say

The tool UI comes first. A compact issue list answers whether the file needs attention, then tables compare actual and expected page geometry and list box, font, image, count, and empty-page findings. A small paperback cover relationship can explain the exact width and spine calculation, but exact values stay in the result table. Sentences only explain local processing, source date, unknown measurements, and the limit that a preflight report cannot guarantee KDP acceptance. No marker art, clean chart, or screenshot adds useful information in v1.
