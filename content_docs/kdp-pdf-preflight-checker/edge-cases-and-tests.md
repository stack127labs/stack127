# Edge cases and tests: KDP PDF preflight checker

Status: ready
Tool: KDP PDF preflight checker
Route: `/kdp-pdf-preflight-checker`
Depends on: `competitive-report.md`, `implementation-report.md`, `interface-contract.md`, `brief.md`

## Risk model

| Priority | Meaning for this tool |
| --- | --- |
| P0 | A wrong dimension, count, or state can send an author toward a bad PDF. A leaked local file, inaccessible check, or published unpublished route is also P0. |
| P1 | A common check, recovery action, browser state, or accessible result fails. The user can still recover, but the main job is broken or misleading. |
| P2 | An uncommon parser, layout, copy, or performance edge causes friction without changing the measured answer or exposing private data. |

## Test data and mocks

Use deterministic byte builders with stable object numbers and no timestamps. Keep fixture names descriptive and use one fixture per behavior so a failure identifies the branch. The minimum fixture set includes:

- 6 x 9 interior pages with and without bleed, exact tolerance, just-outside tolerance, mixed sizes, odd counts, page-limit boundaries, inherited boxes, missing optional boxes, malformed boxes, and boxes outside MediaBox.
- A one-page paperback cover for each supported paper and interior coefficient, plus wrong-cardinality covers and cover widths that exercise inferred-spine tolerance.
- Font objects with readable embedded references, no embedding reference, unresolved descriptors, and subset markers. Tests must assert counts and states, not commercial license claims.
- Image objects with pixel dimensions and placement transforms at 300 DPI, below 300, above 600, and unavailable or malformed measurement inputs. Use the lower effective axis as the oracle.
- Content streams that are empty, whitespace-only, measurable, unreadable, compressed, invisible, or hidden. Unknown content must not become `appears empty`.
- Valid partial files with missing EOF, encryption, unresolved references, and optional boxes absent. Invalid inputs include empty bytes, short bytes, non-PDF bytes, no-page PDFs, and a generated over-limit byte length.
- Hostile file names and parser strings containing markup, URL schemes, control characters, prototype keys, repeated text, and path separators. Expected output is text-only and bounded.
- A fixed clock with ruleset date `2026-09-16`. No random IDs, current time, network response, or browser locale may affect engine output or serialized reports.
- Browser mocks for `fetch`, XHR, sendBeacon, WebSocket, analytics, storage, history, clipboard read and write, download, delayed parser completion, and worker failure. The default mock rejects any network or storage call.
- Source oracles: KDP paperback submission guidance for file size, pages, fonts, images, and page counts; KDP trim and bleed guidance for interior geometry; KDP paperback cover guidance for cover formula and spine coefficients; Adobe PDF Reference 1.7 for page boxes and inheritance. The exact URLs are listed in RF-001 through RF-014 and must be reviewed when the ruleset date changes.
