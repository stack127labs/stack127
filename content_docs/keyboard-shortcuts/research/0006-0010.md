# Keyboard shortcut research: backlog 0006 to 0010

Checked August 31, 2026. Only current first-party vendor documentation was accepted. A shortcut entered the dataset only when the vendor supplied the action, key sequence, platform, and any required editor or focus context.

## 0006: ActiveCampaign

Status: Blocked.

ActiveCampaign does not publish a current product-wide shortcut reference. Its help center documents isolated bindings inside separate builders:

- [Updated Link Modal](https://help.activecampaign.com/hc/en-us/articles/14618639644956-Updated-Link-Modal), updated August 14, 2024, documents Command+K for the updated email designer only. It is unavailable in the classic email designer and the article does not document a Windows binding.
- [Overview of page blocks](https://help.activecampaign.com/hc/en-us/articles/360016067000-Overview-of-page-blocks), updated July 21, 2026, documents copy and paste for landing-page blocks on Windows and macOS.
- [How to undo and redo changes on a landing page](https://help.activecampaign.com/hc/en-us/articles/360016086480-How-to-undo-and-redo-changes-on-a-landing-page), updated June 17, 2026, documents undo and redo inside the landing-page editor.

Those articles yield a handful of context-specific editor actions, not a stable ActiveCampaign keymap. Browser and operating-system commands mentioned elsewhere in the help center are not ActiveCampaign bindings. No app record was created, and no binding was inferred from common web-editor behavior.

## 0007: Adobe Acrobat Pro

Status: Verified.

Source: [Keyboard shortcuts in Acrobat on desktop](https://helpx.adobe.com/acrobat/desktop/get-started/preferences-and-settings/keyboard-shortcuts.html), updated September 23, 2025.

- Platforms: Windows and macOS. Adobe combines Windows and UNIX in one source column; stack127 records the Windows platform only.
- Version context: the current Acrobat desktop interface. The source does not attach a numbered release to the table.
- Scope: 167 normalized shortcut records covering tools-pane focus, single-key tool selection, task panes, comments, PDF pages and zoom, form authoring and entry, PDF portfolios, document tabs, search, navigation panels, bookmarks, and Read Out Loud.
- Platform differences: the dataset preserves Command, Option, Control, Return, Delete, document-window, and search-navigation differences instead of applying a blanket Ctrl-to-Command conversion.
- Alternatives: every clear `or` sequence in the source remains an alternative binding. Compound range entries such as F5 through F8 remain a single documented family where the chosen function key selects a snapshot slot.
- Omissions: the 10-row Help-window table was left out because it mixes Acrobat commands with navigation delegated to the default browser and several unavailable macOS bindings. The Windows-to-macOS terminology comparison is not a command table. Browser-hosted PDFs can reserve commands before Acrobat receives them, so that caveat stays in the app context.

The single-letter tool commands require Preferences > General > Use single-key accelerators to access tools. That requirement is explicit in the app context and the tool-group introduction.

## 0008: Adobe Acrobat Reader

Status: Verified.

Sources:

- [Accessibility features, Adobe Acrobat Reader](https://helpx.adobe.com/reader/desktop/accessibility-features.html), updated in 2026, states that Acrobat Reader and Acrobat have the same keyboard shortcuts and directs readers to the Acrobat shortcut table.
- [Keyboard shortcuts in Acrobat on desktop](https://helpx.adobe.com/acrobat/desktop/get-started/preferences-and-settings/keyboard-shortcuts.html), updated September 23, 2025, is Adobe's linked full list.

- Platforms: Windows and macOS.
- Version context: current Acrobat Reader desktop. Adobe does not attach a numbered Reader release to the table.
- Scope: 134 Reader-relevant records from the shared Acrobat desktop keymap. Reader exposes viewing tools, comments, form entry, PDF portfolios, navigation, search, and accessibility directly. Acrobat-only editing and form-authoring commands are not repeated on the Reader page.
- Platform differences and alternatives: preserved from the same Adobe table used for Acrobat Pro.
- Omissions: mobile shortcuts were not mixed into the desktop record. Adobe publishes a separate Android and iOS reference, and Android keyboard support is limited to Chromebooks.

The Reader record reuses the source-checked Acrobat groups only where the command belongs to Reader's surface. The shared document-tool group is filtered to viewing tools, the form-authoring group is excluded, and Action Wizard dialog navigation is excluded. This keeps Adobe's stated shared keymap without presenting paid Acrobat authoring features as Reader features.

## 0009: Adobe After Effects

Status: Verified.

Source: [Keyboard shortcuts in After Effects](https://helpx.adobe.com/after-effects/desktop/get-started/keyboard-shortcuts/keyboard-shortcuts-reference.html), updated May 5, 2026.

- Platforms: Windows and macOS.
- Version context: the After Effects Default preset on a supported U.S. English keyboard. Adobe shows that preset when the keyboard is unsupported.
- Scope: 368 normalized records covering general commands, projects, preferences, panels, workspaces, tools, compositions, time navigation, previews, viewer display, footage, effects, layers, Timeline and Effect Controls properties, property editing, 3D views, keyframes, text, masks, paint, shape layers, markers, motion tracking, saving, and render queues.
- Platform differences: Command, Option, Control, Return, Delete, numeric-keypad alternatives, and macOS-only main-keyboard preview alternatives remain explicit. Function-key conflicts on macOS remain in the app context and the affected group introductions.
- Alternatives: Adobe's separate sequences are preserved as alternatives. Direction pairs and numbered families remain compact only when the source itself presents them as one result row.
- Omissions: custom presets and assignments are not defaults. Mouse-only commands and mouse-only alternatives without a keyboard modifier were left out; modifier-click and modifier-drag commands remain because Adobe lists them as shortcut gestures. Startup-only preference reset was left out because it is not an in-app command. The source currently renders the macOS shortcut for "Switch to 3D view 3" as `b`; that malformed value was not corrected or guessed, so the record keeps the Windows F12 binding and omits the corrupted macOS value. Adobe's repeated add-or-remove-property-keyframe row is represented once.

Numeric-keypad commands need Num Lock on Windows. Double-letter Timeline property commands must be typed in quick succession. Panel shortcuts override application shortcuts while their panel has focus.

## 0010: Adobe Audition

Status: Verified.

Source: [Default keyboard shortcuts](https://helpx.adobe.com/audition/desktop/keyboard-shortcuts/default-keyboard-shortcuts.html), updated June 17, 2026.

- Platforms: Windows and macOS.
- Version context: current defaults, including Adobe's Audition 26.3 note. The source says CD authoring features were removed in 26.3 and later.
- Scope: Adobe's published expert-selected shortcuts for playback, zoom, markers, Waveform Editor processing, spectral display, Multitrack routing, mixer adjustments, and clip nudging.
- Platform differences: Command and Option variants remain explicit. Adobe lists Alt+period for nudging right on both systems, so stack127 preserves that unusual macOS binding instead of changing it to Option.
- Alternatives: M and asterisk remain separate documented ways to add a marker.
- Omissions: Adobe labels the web list as partial and directs users to Edit > Keyboard Shortcuts for the complete installed map. The undocumented remainder, custom shortcut sets, and removed CD-authoring commands are omitted. No older Audition table was used to fill the gaps.

Audition remains verified because the current first-party page supplies a useful, versioned, platform-specific set and clearly marks its boundary. The app context tells readers where the installed complete map lives.

## Independent review

Independently rechecked August 31, 2026 against the five first-party sources above.

- ActiveCampaign remains blocked. Its three current help articles document only isolated email- and landing-page-editor commands, with no stable product-wide map or complete platform coverage.
- Acrobat Pro now includes every actionable desktop table outside Adobe's mixed browser Help section and terminology table. The review restored the omitted form-authoring and PDF-portfolio sections, filled the incomplete navigation tables, corrected Adobe's previous/next document-window mapping, and removed the false Windows key value previously derived from “Not available.”
- Acrobat Reader now reuses only the verified Reader-relevant portion of Adobe's shared Acrobat map. It no longer lists Acrobat-only form authoring and editing accelerators as Reader commands.
- After Effects now covers every current first-party table row except the documented exclusions above. The review restored omitted channel-display, property-adjustment, text, 3D, mask, paint, shape, modifier-pointer, and panel-scoped commands while preserving Adobe's platform-specific alternatives and its two conflicting Effect Controls macOS mappings in their original table scopes.
- Audition's 31 entries match Adobe's complete published expert-selected web list. The unusual macOS `Alt`+`.` nudge remains unchanged because that is Adobe's current value.

All four app files have unique shortcut IDs, non-empty platform bindings, and no inferred Ctrl-to-Command substitutions.
