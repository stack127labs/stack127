# Shortcut research: WhatsApp Desktop through Zulip

This report records the 23 candidates checked in the final backlog tail. The checked candidates are WhatsApp Desktop, Whimsical, Windows File Explorer, Windows Snipping Tool, Windsurf, WinMerge, WinRAR, Wireshark, Wix, Wondershare Filmora, WordPress Admin, WPS Office, Wrike, X (Twitter), Xcode, YouTrack, YouTube, ZBrush, Zen Browser, Zendesk, Zeplin, Zoom, and Zulip.

All source checks below were completed on September 1, 2026. A candidate is marked verified only when a current first-party reference exposes enough default keyboard bindings for a useful desktop record. A blocked candidate has no module because its public source is incomplete, platform-mismatched, or not current enough to support a no-guess map.

## WhatsApp Desktop

Status: Blocked.

Sources: [WhatsApp keyboard shortcuts](https://faq.whatsapp.com/6204576529560565/) and [WhatsApp desktop download](https://www.whatsapp.com/download/desktop).

Evidence: The official help page exposes a keyboard shortcut table for WhatsApp Web and shows separate Windows and Mac tabs. The retrievable first-party table does not expose the native Windows or Mac desktop values, so the Web bindings cannot be presented as native desktop defaults.

Decision: No shortcut module was created.

## Whimsical

Status: Verified.

Sources: [Whimsical shortcuts](https://whimsical.com/learn/shortcuts), [PC shortcuts](https://whimsical.com/learn/shortcuts/pc), and [Mac shortcuts](https://whimsical.com/learn/shortcuts/mac).

Evidence: Whimsical publishes complete PC and Mac tables for files, workspace search, boards, diagrams, mind maps, sticky notes, and editor controls. Pointer-only operations are outside the module.

Module: lib/shortcuts/apps/whimsical.ts.

## Windows File Explorer

Status: Verified.

Source: [Keyboard shortcuts in Windows](https://support.microsoft.com/en-us/windows/keyboard-shortcuts-in-windows-dcc61a57-8ff0-cffe-9796-cb9706c75eec), Microsoft Support.

Evidence: Microsoft publishes a current File Explorer section with address-bar, search, tabs, folder-tree, pane, refresh, rename, and window commands for Windows 10 and Windows 11.

## Windows Snipping Tool

Status: Verified.

Source: [Use Snipping Tool to capture screenshots](https://support.microsoft.com/en-US/Windows/Apps/use-snipping-tool-to-capture-screenshots), Microsoft Support.

Evidence: The current page publishes screenshot and recording overlays, the Print Screen capture action, and editor commands for capture mode, delay, copy, and save.

Module: lib/shortcuts/apps/windows-snipping-tool.ts.

## Windsurf

Status: Blocked.

Sources: [Getting started](https://docs.windsurf.com/pt-BR/windsurf/getting-started), [Autocomplete overview](https://docs.windsurf.com/pt-BR/autocomplete/overview), and [Command overview](https://docs.windsurf.com/es/command/plugins-overview).

Evidence: Windsurf lets users choose or import VS Code and Vim keymaps, and its public docs expose only feature-specific bindings for autocomplete and Command. There is no complete current product-wide default map that is stable across those keymap choices.

Decision: No shortcut module was created.

## WinMerge

Evidence: The current manual publishes keyboard tables for folder and file comparison, merge mode, search, bookmarks, and zoom. Pointer-only controls are excluded.

Module: lib/shortcuts/apps/winmerge.ts.

## WinRAR

## WordPress Admin

Status: Verified.

Sources: [Block Editor keyboard shortcuts](https://wordpress.org/documentation/article/keyboard-shortcuts-block-editor/), [Classic Editor keyboard shortcuts](https://wordpress.org/documentation/article/keyboard-shortcuts-classic-editor/), and [Site Editor](https://wordpress.org/documentation/article/site-editor/).

Evidence: WordPress publishes Windows, Linux, and Mac tables for the Block Editor and Classic Editor, plus comment navigation and the Site Editor command palette. The module states its scope, because plugin-specific admin screens can add their own controls.

Evidence: WPS publishes product-specific Windows tables for Writer, Spreadsheets, and Presentation, plus a Mac shortcut reference. The module keeps those contexts separate and does not infer Linux bindings from product availability.

Module: lib/shortcuts/apps/wps-office.ts.

## Xcode

Status: Blocked.

Sources: [Archived Xcode command shortcuts](https://developer.apple.com/library/archive/documentation/IDEs/Conceptual/xcode_help-command_shortcuts/Introduction/Introduction.html) and [Xcode 26 release notes](https://developer.apple.com/documentation/xcode-release-notes/xcode-26-release-notes).

Decision: No shortcut module was created.

## Zen Browser

Status: Verified.

Source: [Zen Browser shortcuts](https://docs.zen-browser.app/user-manual/shortcuts).

Evidence: The current Zen Browser manual publishes a Windows and Linux desktop table for compact mode, workspaces, split views, tabs, navigation, search, page controls, and developer tools. The page does not provide a separate Mac table, so the module records only the platforms with published Ctrl and Alt bindings.

Module: lib/shortcuts/apps/zen-browser.ts.

## Zulip

Status: Verified.
