# Shortcut research 0041 to 0045

Checked on August 31, 2026. Bindings in this batch come only from current first-party product help or the vendor's own manual. Proposed bindings, third-party clients, mouse gestures, and user-created mappings are not published as defaults.

## 0041. Bitbucket

Status: Verified.

- Record: `lib/shortcuts/apps/bitbucket.ts`
- Primary source: https://support.atlassian.com/bitbucket-cloud/docs/keyboard-shortcuts/
- Source revision: Current Bitbucket Cloud support article retrieved August 31, 2026. Atlassian's page does not publish a separate revision date.
- Scope: All 15 entries in Atlassian's table for global pages, repositories, and pull requests.
- Platform handling: Bitbucket Cloud is a browser product. Atlassian publishes one key set without operating-system differences, so the record applies it to Windows, macOS, and Linux.
- Omissions: The page does not document additional defaults. Bitbucket can disable the complete shortcut set in Personal Bitbucket settings.

## 0042. Blender

Status: Verified.

- Record: `lib/shortcuts/apps/blender.ts`
- Primary source: https://docs.blender.org/manual/en/latest/interface/keymap/blender_default.html
- Upstream implementation reference: https://github.com/blender/blender/blob/main/scripts/presets/keyconfig/keymap_data/blender_default.py
- Source revision: Blender 5.2 LTS Manual page published August 30, 2026 and upstream default keymap on the official Blender mirror checked August 31, 2026.
- Scope: 54 common keyboard defaults for hovered properties, files, history, general commands, shared editor controls, 3D Viewport modes, animation, drivers, and Python scripting helpers.
- Platform handling: Windows and Linux use the documented keys. The manual says Command can replace Ctrl on macOS except for a few operating-system conflicts, so each Ctrl-based macOS row keeps Ctrl and shows Command as the documented alternative. Alt is labeled Option on macOS. Command+Comma is included as the one separately documented macOS command.
- Omissions: Blender explicitly says the manual page is not comprehensive. Pointer-only selection, mouse navigation, drag modifiers, configurable Spacebar behavior, reserved function keys, and the optional Industry Compatible and Blender 27x keymaps are excluded.

## 0043. Bluebeam Revu

Status: Verified.

- Record: `lib/shortcuts/apps/bluebeam-revu.ts`
- Primary source: https://support.bluebeam.com/revu/resources/keyboard-shortcuts.html
- Source revision: Current Bluebeam support table for Revu 21 and Revu 20, retrieved August 31, 2026.
- Scope: All 178 keyboard rows in the vendor table, covering markups, measurement, forms, views, search, files, editing, selection, page operations, panels, navigation, and Help.
- Platform handling: The vendor table covers the Windows editions of Revu 20 and 21, so the record is Windows-only.
- Omissions: Mouse navigation and 3D mouse gestures appear below the keyboard table but are not keyboard records. Revu can remap existing commands or add user shortcuts, which are outside the default set.

## 0044. Bluesky

Status: Blocked.

- First-party app repository: https://github.com/bluesky-social/social-app
- Blocking evidence: https://github.com/bluesky-social/social-app/issues/640
- Evidence checked: August 31, 2026. The official repository's keyboard-shortcut issue remains open, labeled as a feature request and roadmap item, with no linked branch or pull request. Its key table is the request author's proposal, not implemented product documentation.
- Decision: No module was created. Publishing the proposed letters as defaults would invent behavior. Search results for the first-party help and repository did not reveal a current implemented keymap or vendor shortcut reference.
- Recheck condition: Revisit when Bluesky publishes a help page, ships an in-app shortcut reference, or links an implemented keymap from its official repository.

## 0045. Buffer

Status: Verified.

- Record: `lib/shortcuts/apps/buffer.ts`
- Primary source: https://support.buffer.com/en-us/articles/using-buffers-keyboard-shortcuts-jvc735UOsa
- Source revision: Current Buffer Help Center article retrieved August 31, 2026.
- Scope: All 16 documented actions for the shortcut dialog, command bar, page navigation, content creation, Community refresh and comment movement, scheduling, and threads.
- Platform handling: Buffer publishes Ctrl for Windows and Linux and Command for macOS on modified commands. Letter sequences and unmodified keys are shared across all three desktop browser platforms.
- Omissions: Quick Navigator is retired according to the source and is not included. Global shortcuts are suppressed in text fields. Home navigation is conditional on Buffer Home being enabled.
