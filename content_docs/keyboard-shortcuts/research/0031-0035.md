# Shortcut research 0031 to 0035

Checked on August 31, 2026. Every binding in this batch comes from a current first-party manual or versioned vendor reference. Mouse gestures, unassigned commands, user-created mappings, and optional legacy keymaps are not converted into records.

## 0031. Audacity

Status: Verified.

- Record: `lib/shortcuts/apps/audacity.ts`
- Primary source: https://manual.audacityteam.org/man/keyboard_shortcut_reference.html
- Source revision: Current Audacity Development Manual retrieved August 31, 2026. The page does not publish a separate revision date.
- Scope: 69 shortcuts for project files, audio and clip editing, selections, labels, timeline views, playback, recording, looping, mute controls, preferences, and effect reuse.
- Platform handling: The manual states that Mac users replace `Ctrl` with `Command` and `Alt` with `Option`. The record applies that rule across Windows, Linux, and macOS, then preserves the explicit Mac exceptions for Preferences and Add Label at Playback Position.
- Omissions: Audacity's optional Full set is marked as Extra in the manual and is not enabled by default. Unassigned commands and mouse combinations are not listed. Users can customize the Standard set in Shortcuts Preferences.

## 0032. AutoCAD

Status: Verified.

- Record: `lib/shortcuts/apps/autocad.ts`
- Primary source: https://help.autodesk.com/cloudhelp/2026/ENU/AutoCAD-Customization/files/GUID-B6A9C126-230D-47F5-8973-464BC80E3736.htm
- Source revision: AutoCAD 2026 English CUIx shortcut reference.
- Scope: All 75 entries in Autodesk's current table, covering application and drawing files, palettes, selection, clipboard editing, drafting aids, layouts, viewports, function keys, and 3D subobject filters.
- Platform handling: The source describes the Windows CUIx keymap and includes Windows Clipboard commands. The record is Windows-only. Autodesk's separate AutoCAD for Mac product and keymap are not inferred from these bindings.
- Omissions: A customized CUIx file can change any assignment. The record identifies AutoCAD defaults and does not add command aliases from unrelated shortcut sheets. Some entries are marked AutoCAD only in the source and do not apply to AutoCAD LT.

## 0033. Autodesk Maya

Status: Verified.

- Record: `lib/shortcuts/apps/autodesk-maya.ts`
- Primary source: https://help.autodesk.com/cloudhelp/2026/ENU/Maya-KeyboardShortcuts/files/GUID-30CACC9D-8FBE-4B85-8A8F-C5ADF32DDD4E.htm
- Source revision: Maya 2026 English All Maya Hotkeys reference.
- Scope: 137 keyboard-only defaults for tools, scene files, display, animation, bookmarks, playback, painting, snapping, component selection, menu sets, editing, rendering, panels, pick walking, and polygon modeling.
- Platform handling: Autodesk states that macOS uses `Option` for `Alt`, `Control` for `Ctrl`, and `Command` for the Windows key. File and clipboard rows that explicitly show the Mac command-key alternative use `Command`; other control-key operations remain `Control`. Windows and Linux use Autodesk's primary column.
- Omissions: Mouse buttons, drags, marking menus, and mouse-plus-modifier camera controls are not keyboard records. The Hotkey Editor can replace defaults. Autodesk warns that macOS function keys and punctuation on non-US layouts can conflict.

## 0034. Autodesk Revit

Status: Verified.

- Record: `lib/shortcuts/apps/autodesk-revit.ts`
- Primary source: https://www.autodesk.com/revit-keyboard-shortcut-list-pdf-2026-enu
- Source page: https://help.autodesk.com/cloudhelp/2026/ENU/Revit-Customize/files/GUID-39D549F2-75EE-4C06-8B6A-3DADE1FBEF59.htm
- Source revision: Autodesk's Revit 2026 default keyboard shortcuts PDF, 22 pages.
- Scope: 87 useful defaults for interface windows, views, modify tools, architectural and structural elements, MEP systems, annotation, detailing, and navigation.
- Platform handling: Revit 2026 is represented as Windows-only. Letter shortcuts are sequential commands, so each group states that the letters are pressed in order. Alternatives separated by `#` in Autodesk's PDF remain alternatives in the record.
- Omissions: The PDF contains more than 2,000 command rows, most without a default shortcut. Unassigned commands, debug-only internals, add-in commands, and narrowly contextual steel or fabrication entries are not listed. Revit's Keyboard Shortcuts dialog can change non-reserved assignments.

## 0035. Axure RP

Status: Verified.

- Record: `lib/shortcuts/apps/axure-rp.ts`
- Primary source: https://docs.axure.com/axure-rp/reference/keyboard-shortcuts/
- Source revision: Current Axure RP 11 shortcut reference retrieved August 31, 2026.
- Scope: 134 shortcuts for files, clipboard operations, text, canvas navigation, widget insertion and editing, vectors, sitemap management, cursor tools, panes, preview, generators, publishing, and account login.
- Platform handling: The record preserves the official Windows and Mac columns. Axure's single-key column is represented as an alternative when a full shortcut also exists and as the primary key when it is the only documented binding.
- Omissions: Mouse-wheel scrolling, modifier-plus-drag duplication, and modifier-only deep-selection gestures require pointer input and are not listed. Single-key Canvas shortcuts are enabled by default but can be disabled in Axure RP preferences.
