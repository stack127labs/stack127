# Shortcut research 0051 to 0055

Checked on August 31, 2026. This batch uses current first-party product help and versioned vendor manuals only. A candidate stays blocked when the vendor does not publish enough current defaults for a useful page.

## 0051. ChatGPT Desktop App

Status: Blocked.

- Current app overview: https://help.openai.com/en/articles/20001276-moving-to-the-new-chatgpt-desktop-app
- Current browser command: https://help.openai.com/en/articles/20001277-using-the-built-in-browser-in-the-chatgpt-desktop-app
- Chat Bar reference: https://help.openai.com/en/articles/9295241-accessing-the-launcher-chatgpt-macos-app
- Classic release notes: https://help.openai.com/en/articles/9703738
- Evidence checked: August 31, 2026. Official OpenAI documentation says the new ChatGPT desktop app and ChatGPT Classic are separate products. The current new-app help documents Command+Shift+B on macOS and Ctrl+Shift+B on Windows for its built-in browser. The Chat Bar article documents configurable Option+Space on macOS. OpenAI's older shortcut release notes now sit under ChatGPT Classic.
- Decision: No module was created. One new-app command and one configurable macOS access command do not support a useful shortcut reference. Mixing Classic release-note bindings into the new app would misstate product scope.
- Recheck condition: Revisit when official OpenAI documentation publishes a shortcut reference for the new ChatGPT desktop app or states which ChatGPT Classic bindings carry over.

## 0052. Cinema 4D

Status: Verified.

- Record: `lib/shortcuts/apps/cinema-4d.ts`
- Primary source: https://help.maxon.net/c4d/2026/en-us/Content/html/Shortcuts.html
- Supporting source: https://help.maxon.net/c4d/2026/en-us/Content/html/5224.html
- Source revision: Cinema 4D 2026 manual and default shortcut table retrieved August 31, 2026.
- Scope: 226 useful keyboard defaults for Timeline animation, key interpolation, managers, project files, materials, nodes, objects, Picture Viewer, viewport modes, modeling, mesh selection, rendering, and sculpt modifiers.
- Platform handling: Maxon says macOS users press Command instead of Ctrl. The record preserves Windows Ctrl and converts only that documented modifier for macOS. Hierarchical letter pairs use a visible `then` token. Published alternate bindings remain alternatives.
- Omissions: Pointer-only gestures, mouse-button alternatives, drag modifiers, and controls that require moving the mouse are not keyboard records. Command Manager presets can replace or add shortcuts, and local commands can differ by manager.

## 0055. ClickUp

Status: Verified.

- Record: `lib/shortcuts/apps/clickup.ts`
- Primary source: https://help.clickup.com/hc/en-us/articles/6309030550167-Use-keyboard-shortcuts
- Desktop app source: https://help.clickup.com/hc/en-us/articles/6311884486423-Use-the-ClickUp-desktop-app
- Source revision: Current ClickUp Help articles retrieved August 31, 2026.
- Scope: 96 documented actions for global navigation, ClickUp Brain, text editing, tasks, Chat, Inbox, views, SyncUps, and desktop-wide commands.
- Platform handling: The record preserves ClickUp's Mac and PC columns as macOS and Windows. The source currently labels Create and open subtask as Command+Enter on PC and Control+Return on Mac; the record retains those labels with notes rather than silently correcting them.
- Omissions: The primary article links to separate Docs and Whiteboard references without duplicating their tables. Slash commands and typed Markdown syntax are not keyboard chords. Workspace shortcuts are disabled by default, Chat requires the Chat ClickApp, temporary unmute requires full-screen SyncUp, and desktop-wide commands require the desktop app.
