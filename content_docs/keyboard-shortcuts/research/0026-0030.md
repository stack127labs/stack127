# Keyboard shortcut research: backlog 0026 to 0030

Checked August 31, 2026. Only current first-party vendor documentation was accepted. A binding entered the dataset only when the vendor supplied the action, keys, platform, and any required focus or sequence context.

## 0026: AnyDesk

Status: Verified.

Source: [Keyboard and hotkeys](https://support.anydesk.com/keyboard-hotkeys), published July 30, 2025.

- Platforms: Windows. AnyDesk labels its reserved hotkey table as Windows-only.
- Version context: current desktop hotkeys. Mouse capture requires AnyDesk 8 or later.
- Scope: remote-display navigation, numbered session tabs, full screen, sound transmission, input permission, screenshots, mouse capture, secure-attention forwarding, and the 1:1, shrink, and stretch view modes.
- Platform differences: no macOS or Linux bindings were added because the official hotkey table supplies none.
- Alternatives: the Left and Right remote-display directions are separate actions. Numbered tabs remain one documented 1 through 9 family.
- Omissions: AnyDesk's Command+C and Control+V examples explain remote keyboard translation; they are not AnyDesk commands. The pointer-only full-screen gesture and keyboard-mode behavior were omitted.

Every published Windows hotkey begins with Control+Alt+Shift. The reference writes the complete chord on each row so the reserved prefix is not hidden.

## 0027: Apple Music

Status: Verified.

Sources:

- [Keyboard shortcuts in Apple Music on Windows](https://support.apple.com/guide/music-windows/keyboard-shortcuts-mus1019/windows), current Windows user guide checked August 31, 2026.
- [Keyboard shortcuts in Music on Mac](https://support.apple.com/guide/music/keyboard-shortcuts-mus1019/mac), current macOS Tahoe user guide checked August 31, 2026.

- Platforms: Windows and macOS.
- Version context: current Apple Music desktop applications. Apple warns that bindings can vary with language and keyboard layout.
- Scope: 84 records covering playback, seeking, volume, equalizer, playlists, library files, item-information editing, player windows, iTunes Store navigation, visualizer options, macOS application windows, settings, help, and the complete Windows access-key tables.
- Platform differences: Windows playback uses Control chords where macOS often uses bare Space or arrow keys. macOS-only playlist, deletion, library, window, and visualizer commands remain platform-only. Windows access keys remain Windows-only.
- Alternatives: seek directions, album directions, chapter directions, Info-window navigation, and both macOS MiniPlayer commands remain alternatives exactly where Apple presents one action with multiple keys.
- Omissions: pointer-only window resizing and Control-click menu actions were omitted. The Option-at-launch library selector is outside the normal in-app shortcut scope. No Windows equivalent was inferred for a macOS-only action.

Windows access keys are sequential. Press Alt first, then type the two published letters in order. The group introductions state that behavior rather than presenting the letters as a simultaneous chord.

## 0028: Apple Notes

Status: Verified.

Source: [Keyboard shortcuts and gestures in Notes on Mac](https://support.apple.com/guide/notes/keyboard-shortcuts-and-gestures-apd46c25187e/mac), current macOS Tahoe user guide checked August 31, 2026.

- Platforms: macOS.
- Version context: current Notes for Mac. Apple warns that bindings can vary with language and keyboard layout.
- Scope: notes and folders, main views, global search, pane focus, printing, shared-note activity, linked notes, attachments, links, paragraph formats, lists, checklists, content zoom, and table editing.
- Platform differences: no Windows entry was created because Apple Notes does not have a Windows desktop application with a first-party shortcut reference. iCloud.com browser behavior was not treated as a Windows Notes keymap.
- Alternatives: list indentation, row and column selection, and table movement retain Apple's documented alternatives.
- Omissions: trackpad and Magic Mouse gestures for pinning, deleting, and sharing were omitted from this keyboard-only dataset. Menu commands absent from Apple's shortcut table were not inferred.

Table commands depend on cell focus. Command+A selects a cell's contents, while pressing it twice selects the table; both contexts remain explicit.

## 0029: Arc Browser

Status: Verified.

Source: [Keyboard Shortcuts](https://resources.arc.net/hc/en-us/articles/20595231349911-Keyboard-Shortcuts), current Arc Help Center reference checked August 31, 2026. The official Help Center API reports that the article was updated November 5, 2024.

- Platforms: Windows and macOS.
- Version context: current documented defaults from the official article updated November 5, 2024. Arc allows shortcuts to be edited in Settings.
- Scope: tabs, windows, incognito browsing, pinning, URL copying, sidebar visibility, unpinned-tab cleanup, tab and Space navigation, history, Split View, webpage zoom, reload, and find.
- Platform differences: Little Arc remains macOS-only. Tab and Space number modifiers, history commands, and tab or Space navigation preserve the platform-specific Control, Command, Alt, and Option combinations.
- Alternatives: Windows URL focus keeps Control+L and Alt+D. macOS forward and back history keep both arrow and bracket forms.
- Omissions: commands absent from Arc's current help table and all customized bindings were omitted. Common Chromium shortcuts were not added unless Arc documents them on this page.

## 0030: Asana

Status: Verified.

Source: [Keyboard shortcuts](https://help.asana.com/s/article/keyboard-shortcuts), current Asana Help Center reference checked August 31, 2026.

- Platforms: Windows and macOS. Asana also mentions iPad's Command-key overlay, but does not publish an iPad table on this page.
- Version context: current Asana web and desktop defaults. Some shortcuts may not work with non-English keyboard input. Desktop-window commands apply only to the native desktop app.
- Scope: 62 keyboard-only records covering Inbox, task details, task creation and movement, navigation, selection, the shortcut overlay, comment submission, and desktop windows and tabs. Repeated rows with the same action, context, and binding are consolidated.
- Platform differences: task completion, movement, shortcut overlay, and native-window commands preserve Control versus Command. Tab switching retains Asana's different Windows and macOS chords.
- Alternatives: I and E remain Inbox archive alternatives. Up and Down task movement, section movement, and selection remain paired alternatives.
- Omissions: modifier-plus-click selection gestures are not keyboard-only commands. The valid Windows Create task chord is included, but the source currently prints `Shif` in the macOS chord, so that malformed platform entry is omitted instead of silently corrected. Rich-text editing uses a separate Asana reference and was not mixed into this app-level table.

Asana presents its Tab-letter shortcuts as chords rather than a release-between-keys sequence. The Right Arrow field-navigation command is a sequence and is labeled as two presses. Tab+B is included with its official requirement: the Tab-B hack must first be enabled in Settings.

## Independent review

Rechecked all five records against the rendered first-party sources on August 31, 2026. AnyDesk already matched its complete 11-row Windows table, represented as 12 lookup records because Left and Right display navigation are separate actions. Apple Music gained six omitted macOS commands covering Genius Playlist refresh, visualizer options, iTunes Store search and page navigation, and CD eject. Apple Notes' repeated Command+A table command now states “press twice” instead of encoding “then” as a key. Arc's 30 records match every current help-table action and now disclose the article's November 2024 update metadata. Asana now excludes two pointer gestures, includes two omitted contextual task commands and the valid Windows half of its malformed Create task row, and describes Tab-key chords and the two-press Right Arrow sequence accurately. All five modules have unique shortcut IDs and only declared-platform entries.
