# Earlier shortcut research entries

This report preserves the earlier source checks for Milanote, Miro, monday.com, and OBS Studio, plus the follow-up entries below. The assigned Mixpanel through Shopify Admin review is recorded in [the current batch report](0145-0191.md).

## 0151. Milanote

Status: Verified.

Source: [Keyboard shortcuts](https://help.milanote.com/en/articles/111393-keyboard-shortcuts), Milanote Help Center.

Source revision: Current help article checked September 1, 2026. It publishes Mac and Windows bindings for board basics, formatting, tables, drawing, navigation, and appearance, and tells users to press `/` to open Milanote's shortcut menu.

Coverage decision: The page records the documented desktop and browser actions. iPad gestures and mobile long-press actions stay out of the keyboard reference because this route's platform contract covers Windows, macOS, and Linux only.

## 0152. Miro

Status: Verified.

Source: [Shortcuts and hotkeys](https://help.miro.com/hc/en-us/articles/360017731033-Shortcuts-and-hotkeys), Miro Help Center. Desktop-only additions come from [Desktop app](https://help.miro.com/hc/en-us/articles/360017572854-Desktop-app).

Source revision: Current English help articles checked September 1, 2026. Miro documents the tool keys, object editing, canvas navigation, board traversal, toolbar navigation, and desktop wrapper commands for Windows and Mac.

Coverage decision: Single-character tools are included with the accessibility caveat that Miro lets users disable them. Pointer gestures such as Alt-drag remain written as key plus gesture because the source defines the action that way.

## 0154. monday.com

Status: Verified.

Source: [monday.com Shortcuts](https://support.monday.com/hc/en-us/articles/115005339905-monday-com-Shortcuts), monday.com Support.

Source revision: The support article reports a last modification of August 20, 2026 and was checked September 1, 2026. It lists Mac and PC bindings under system navigation and board navigation.

Coverage decision: The page records the published account, board, cell, selection, group, export, and batch-selection shortcuts. The Shift-click range action remains a note because it combines a key with a pointer selection.

## 0162. OBS Studio

Status: Verified.

Source: [Keyboard Shortcuts](https://obsproject.com/kb/keyboard-shortcuts), OBS Project Knowledge Base.

Source revision: The official page is dated August 25, 2021 and was checked September 1, 2026. It publishes Windows/Linux and macOS bindings for general commands, source-list operations, transforms, and the preview window.

Coverage decision: The record preserves the source's older date in its version context. It does not claim that the published list is a complete map of newer OBS releases. Users can customize hotkeys in OBS Settings, so the page describes defaults only.
