# Keyboard shortcut research: backlog 0046 to 0050

Checked August 31, 2026. Only current first-party vendor documentation was accepted. A binding entered the dataset only when the vendor supplied the action, keys, platform, and any required focus or product context.

## 0046: Cal.com

Status: Blocked.

Evidence:

- [Cal.com Help documentation index](https://cal.com/help/llms.txt), current first-party index checked August 31, 2026, lists every published Help Desk page and contains no keyboard-shortcut reference.
- [Cal.com Help Desk](https://cal.com/help/welcome), current user-documentation home checked August 31, 2026, routes users to the indexed product guides but does not expose an app keymap.

- Platforms: web application; no platform was added to a dataset because Cal.com does not publish a current platform-specific shortcut table.
- Scope: blocked before implementation.
- Omissions: browser conventions and bindings visible only in source code were not treated as a supported user-facing default keymap. No shortcut was inferred from another calendar product.

No module was created. A complete current first-party reference or supported in-app shortcut overlay is needed before Cal.com can be verified.

## 0048: Canva

Status: Verified.

Source: [Canva keyboard shortcuts](https://www.canva.com/help/canva-keyboard-shortcuts/), current Canva Help Center reference checked August 31, 2026.

- Platforms: Windows and macOS. Native desktop-app window commands are labeled separately from shortcuts inside the editor.
- Version context: current Canva editor and desktop app. Canva Docs-only text styles are identified in the Text group.
- Scope: core editing, element creation, keyboard focus, pages, selected-element arrangement, movement, rotation and resizing, text formatting, video playback, canvas zoom, page views, comments, and the native Mac app's windows, tabs, navigation, and interface scaling.
- Platform differences: every Control/Command and Alt/Option row follows Canva's separate platform tables. Windows-only editor commands and Mac-only desktop-app commands remain platform-only.
- Alternatives: Windows redo retains Control+Shift+Z; Quick actions retains slash and its modifier chord; element deletion and comment line breaks retain the alternatives Canva publishes.
- Omissions: missing platform equivalents were not inferred. The current Windows comment-submit row renders Command+Enter and was omitted as malformed. Windows desktop-app bindings and Mac equivalents for Windows-only additions were omitted where the source output did not expose an unambiguous value. Mobile touch gestures are outside scope.

Canva uses the same Control+Enter Windows chord for adding an empty page and adding a page break in different editor contexts. Both actions remain separate.

## 0049: CapCut

Status: Blocked.

Evidence:

- [CapCut Help Center](https://www.capcut.com/help), current first-party support catalog checked August 31, 2026, does not publish a complete desktop default shortcut table.
- [CapCut Desktop download guide](https://www.capcut.com/resource/capcut-desktop-download), current first-party guide checked August 31, 2026, instructs users to customize keyboard shortcuts but supplies no default set.
- [CapCut PC video editor](https://www.capcut.com/resource/pc-professional-video-editor), current first-party guide checked August 31, 2026, documents a few examples such as split, playback, and frame navigation rather than the full customizable keymap.
- [Export a part or clip](https://www.capcut.com/help/export-clip-of-video), current first-party Help article checked August 31, 2026, documents Shift+X and I/O markers for one workflow only.

- Platforms: Windows and macOS desktop, web, and mobile are current CapCut surfaces, but no platform was added to a dataset.
- Scope: blocked before implementation because the public sources provide isolated examples, not the current default set shown in CapCut's customizable Shortcuts panel.
- Omissions: scattered tutorial bindings were not combined into an app-wide page. No Windows/macOS substitution was inferred, and mobile gestures were not treated as shortcuts.

No module was created. An official export or complete current table from CapCut's default shortcut configuration is needed.

## 0050: Capture One

Status: Blocked.

Evidence:

- [What are the hotkeys in Capture One?](https://support.captureone.com/hc/en-us/articles/360003399778-What-are-the-hotkeys-in-Capture-One), updated March 16, 2025, tells users to generate a summary from the currently selected in-app shortcut set. Its only published key list is explicitly an update for Capture One 20, not the current release.
- [Keyboard shortcut sets](https://support.captureone.com/hc/en-us/articles/360002490637-Keyboard-shortcut-sets), current first-party guide checked August 31, 2026, explains the default, localized Logic Keyboard, legacy, and custom sets without publishing their key assignments.
- [Creating a custom shortcut set](https://support.captureone.com/hc/en-us/articles/360002490757-Creating-a-custom-shortcut-set), current first-party guide checked August 31, 2026, confirms that shortcuts can be edited only after duplicating a default set.

- Platforms: Windows and macOS. No platform was added because the current defaults are not exposed in the public reference.
- Scope: blocked before implementation. Capture One's generated summary reflects the selected local set, which may be default, localized, legacy, or customized.
- Omissions: the Capture One 20 changes and older attached manuals were not presented as current defaults. Community posts and user-supplied mappings were excluded.

No module was created. A current first-party export of the untouched default set for each platform is required.
