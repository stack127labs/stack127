# Keyboard shortcut research: backlog 0036 to 0040

Checked August 31, 2026. Only current first-party vendor documentation was accepted. A binding entered the dataset only when the vendor supplied the action, keys, platform, and any required focus or sequence context.

## 0036: Azure DevOps

Status: Verified.

Source: [Keyboard shortcuts](https://learn.microsoft.com/en-us/azure/devops/project/navigation/keyboard-shortcuts?view=azure-devops), Microsoft Learn, updated February 17, 2026.

- Platforms: Windows and macOS web browsers.
- Version context: Azure DevOps Services and Azure DevOps Server web portal. Microsoft publishes most portal commands in one shared table, while rich-text commands have separate Windows and macOS columns.
- Scope: global service navigation, focused lists, Git and TFVC Repos, work-item lists and forms, rich-text fields, Boards, backlogs, queries, Delivery Plans, Test Plans, shared parameters, test runs, and Wiki management and editing.
- Platform differences: shared portal Control chords remain Control on both platforms because Microsoft does not publish Command substitutions for those rows. Only the rich-text rows use Microsoft's explicit Control/Command variants.
- Alternatives: Search, focused-list movement, backlog child creation, query movement, and query refresh retain Microsoft's published alternatives. Letter pairs are recorded as sequential keys.
- Omissions: Team Explorer commands were omitted because they control the Visual Studio plug-in rather than the Azure DevOps web app. The macOS rich-text redo row displays the same Command+Z chord that the source assigns to undo, with capitalization as its only distinction. It was omitted rather than interpreted as Command+Shift+Z.

Global navigation sequences are disabled while an input control has focus. Page-specific commands remain in separate groups because the same letter or number can have a different action in another Azure DevOps service.

## 0037: Balsamiq Wireframes

Status: Verified.

Sources:

- [Keyboard shortcuts](https://balsamiq.com/support/docs/creating-and-editing/shortcuts/), current Balsamiq Wireframes reference checked August 31, 2026.
- [Your first wireframe](https://community.balsamiq.com/learn/first-wireframe/), Balsamiq tutorial confirming the published Control/Command variants for duplicate, group, and ungroup.
- [How to hide the UI panels](https://balsamiq.com/learn/hide-ui-panels/), Balsamiq tutorial confirming Control/Command panel shortcuts.

- Platforms: Windows and macOS.
- Version context: current Balsamiq Wireframes editor. The vendor warns that web-browser and operating-system commands can override some bindings.
- Scope: selection, moving, resizing, stacking, clipboard editing, grouping, alignment, icons, text editing, Quick Add, drawing, projects, boards, panels, zoom, and presentation mode.
- Platform differences: the main reference writes generic Control-based editing commands without stating a Mac substitution. Those entries are labeled Windows. macOS is supplied only for a Mac-specific row or an explicit Control/Command pair from Balsamiq.
- Alternatives: text editing, redo, clipboard operations, board navigation, zoom, and full-screen presentation retain the alternatives in the official tables. Mac board navigation retains both Page Up/Page Down and Fn-arrow forms.
- Omissions: no Command equivalent was inferred for a generic Control row. Pointer-only actions without a keyboard modifier were outside scope.

The shortcut reference includes both app and web editions. Platform labels show exactly which system Balsamiq names for a binding rather than implying that every browser accepts it.

## 0038: Basecamp

Status: Verified.

Sources:

- [Keyboard cheat sheet](https://basecamp.com/keyboard), current Basecamp keyboard reference checked August 31, 2026.
- [Basecamp 5](https://basecamp.com/5), current product page confirming the active product generation.

- Platforms: Windows and macOS web browsers.
- Version context: Basecamp 5. Hold Shift outside an input to reveal available keycaps; press Shift twice inside an input to enable hotkey mode.
- Scope: Jump menu, main navigation, personal views, notifications, projects, project tools, filtering, Campfire or comments, assignments, to-dos, calendar, browser-style history, sidebar read state, and Jump-menu search.
- Platform differences: macOS adds Command+J and Command+K as Jump-menu alternatives. Current-project search uses Alt on Windows and Option on macOS. Other published commands are shared.
- Alternatives: all three Jump-menu bindings remain one action. Shift+C and Shift+D stay as separate contextual actions because their behavior depends on the open page.
- Omissions: Basecamp's text editor uses system and editor conventions not listed on this cheat sheet; none were inferred. The `:wq` logout sequence is represented as sequential input, not a chord.

## 0039: Bear

Status: Verified.

Source: [Mac keyboard shortcuts](https://bear.app/faq/mac-keyboard-shortcuts/), current Bear reference checked August 31, 2026.

- Platforms: macOS.
- Version context: current native Bear for Mac application.
- Scope: headings, typography, links, lists, quotes, code, highlighting, footnotes, attachments, tables, to-dos, line movement, list nesting, dates, editor control, note panels, search, zoom, notes, sidebar navigation, history, import, export, layouts, settings, full screen, and the main window.
- Platform differences: no Windows binding was added. Bear Web has a separate beta shortcut reference and was not merged into the native Mac dataset.
- Alternatives: the Mac reference gives one binding per included action. Heading and sidebar number ranges remain a single published key family where the action varies by number.
- Omissions: Bear Web beta commands and undocumented system editing conventions were omitted. Bear notes that back and forward may vary with localization and keyboard layout; that limitation remains in the version context.

Several identical chords are focus-dependent. Command+A selects text in the editor and notes in the note list, while arrows navigate whichever list or pane has focus. Separate groups retain that context.

## 0040: Beyond Compare

Status: Blocked.

Evidence:

- [Commands options](https://www.scootersoftware.com/v5help/optionscommand.html), current Beyond Compare 5 help checked August 31, 2026, explains that keyboard shortcuts are viewed and assigned under Tools > Options > Commands. Commands are filtered by session view, and users can reset mappings to factory defaults, but the page does not publish those default key values.
- [Commands reference](https://www.scootersoftware.com/v5help/commands_reference.html), current Beyond Compare 5 help checked August 31, 2026, lists commands by session type without a default shortcut table.
- [Beyond Compare 5 change log](https://www.scootersoftware.com/all/v5changelog), current first-party release history checked August 31, 2026, identifies version 5.2.5 dated August 3, 2026. It documents isolated shortcut changes, not a complete default keymap.

- Platforms: Beyond Compare 5 is available on Windows, macOS, and Linux, but no platform was added to a dataset because the current official help does not expose the complete factory bindings.
- Scope: blocked before implementation. Commands are customizable and context-specific to session views.
- Omissions: older Beyond Compare manuals were not used because they do not establish the current version 5 defaults. Isolated change-log bindings cannot support a complete or representative app page.

No module was created. A verified dataset requires a current first-party table or export of the factory key assignments for each supported platform.
