# Keyboard shortcut research: backlog 0056 to 0060

Checked August 31, 2026. Only current first-party vendor documentation was accepted. A binding entered the dataset only when the vendor supplied the action, keys, platform, and any required focus or configuration context.

## 0056: Clip Studio Paint

Status: Verified.

Sources:

- [Menu Shortcuts](https://help.clip-studio.com/en-us/manual_en/780_shortcuts/Menu_Shortcuts.htm), current Clip Studio Paint 5.0 User Guide checked August 31, 2026.
- [Shortcut Settings](https://help.clip-studio.com/en-us/manual_en/720_preferences/Shortcut_Settings.htm), current configuration reference checked August 31, 2026.

- Platforms: Windows and macOS.
- Version context: Clip Studio Paint 5.0 factory shortcuts at initial startup. Users can modify shortcuts in Shortcut Settings.
- Scope: files, preferences, history, clipboard operations, erase and fill, tonal correction, transforms, layers, selections, canvas zoom and rotation, rulers, snapping, canvas switching, palettes, menu visibility, and tutorials.
- Platform differences: the official guide writes commands in Windows notation and instructs Mac users to replace Control with Command and Alt with Option. Mac canvas switching is an explicit exception and retains Control. Tablet-only T1 was omitted.
- Alternatives: Save As, redo, cut, copy, paste, erase, fill, invert selection, and canvas zoom retain every published factory alternative.
- Omissions: commands without an initial shortcut were not assigned one. iPad, Android, Galaxy, and Chromebook bindings were outside the desktop scope. Custom user mappings were not included.

## 0057: Clockify

Status: Verified.

Sources:

- [Track time](https://clockify.me/help/track-time-and-expenses/creating-a-time-entry), current Clockify Help article checked August 31, 2026.
- [Mac app](https://clockify.me/help/apps/mac-desktop-app), current Clockify Help article checked August 31, 2026.
- [Favorite time entry](https://clockify.me/help/track-time-and-expenses/favorite-time-entry), current feature reference checked August 31, 2026.

- Platforms: Windows, macOS, and Linux for the web Time Tracker; macOS for native desktop commands.
- Version context: current web and Mac desktop apps. User-defined global shortcuts are configurable and therefore not listed as defaults.
- Scope: starting, continuing, and stopping timers; manual entry mode; favorite entries; Mac save, discard, sync, and logout commands.
- Platform differences: the web's single-letter commands are shared across desktop browser platforms. Command chords belong only to the Mac desktop app.
- Alternatives: none are published for the included actions.
- Omissions: the Windows app documentation describes custom shortcuts without publishing stable default values. Browser-extension shortcuts and project-form submission are separate surfaces and were not mixed into the main app reference.

Web single-key commands work only on the Time Tracker page while no editable field has focus. Number keys require Favorite entries to be enabled and pinned.

## 0058: Coda

Status: Verified.

Source: [Keyboard shortcuts](https://help.coda.io/hc/en-us/articles/39555894316173-Keyboard-shortcuts), current complete Coda Mac and PC reference checked August 31, 2026.

- Platforms: Windows and macOS.
- Version context: current Coda docs. Coda labels Windows as PC and separately publishes both platform lists.
- Scope: clipboard and history, search, page navigation, panels, presentation, section folding, text styles, paragraphs, lists, insertion triggers, comments, dates, and table selection, movement, insertion, navigation, and editing.
- Platform differences: page history, redo, paragraph styles, folding, movement, and table edges preserve Coda's Control, Command, Alt, and Option distinctions. Mac indentation intentionally remains Control-based.
- Alternatives: table cell editing retains Space and F2. Directional row, column, paragraph, and table-edge operations are separate actions so their direction remains searchable.
- Omissions: the source links a few action names to community explanations, but the key values come from Coda's first-party table. Markdown syntax is covered in a separate Coda guide and was not mixed into this app-command dataset.

The shortcut overlay itself differs from Explore: Mac uses Control+slash for shortcut help and Command+slash for Explore; Windows uses Control+Shift+slash and Control+slash respectively.

## 0059: Confluence

Status: Verified.

Source: [Keyboard shortcuts and autocomplete](https://support.atlassian.com/confluence-cloud/docs/keyboard-shortcuts-markdown-and-autocomplete/), current Atlassian Confluence Cloud reference checked August 31, 2026.

- Platforms: Windows and macOS.
- Version context: Confluence Cloud pages, live docs, the current editor, and whiteboards. General shortcuts can be disabled in the shortcut dialog.
- Scope: global navigation, content creation and actions, comments, publishing, block and text formatting, insertion, table selection and structure, autocomplete, Markdown entry, and whiteboard tools, editing, navigation, and advanced actions.
- Platform differences: every Windows and Mac value follows Atlassian's separate columns. Control-based Mac navigation and Option-based Mac text formatting remain literal even where they differ from common platform conventions.
- Alternatives: redo, shortcut help, table selection and insertion, and whiteboard zoom retain valid published alternatives.
- Omissions: the Windows left-arrow alternative for Select table row prints Control+Alt+Shift+Shift+Left. That malformed alternative was omitted and documented on the remaining row. Confluence Data Center, legacy-editor wiki markup, and shortcuts supplied by Marketplace apps were excluded.

Markdown rows are typed sequences, not simultaneous chords. Their group introduction calls out the trailing Space required for block forms.

## 0060: ConvertKit (Kit)

Status: Blocked.

Evidence:

- [How to take actions in your Kit account with the search bar](https://help.kit.com/en/articles/6384168-how-to-take-actions-in-your-kit-account-with-the-search-bar), updated July 22, 2026, documents Command+K on Mac and Control+K on PC for search. It explains the two-letter Find, New, and Go pattern but publishes only a few examples, not the complete action-to-key map shown inside an account.

- Platforms: Kit web app on Windows and macOS, but no platform was added to a dataset.
- Scope: blocked before implementation because the public article does not enumerate the current complete set of two-letter actions.
- Omissions: F+T, N+B, and G+F were not expanded into guessed combinations from the article's mnemonic letters. A four-row sample would not be an app shortcut reference, and account-only search results could vary with enabled Kit features.

No module was created. A current first-party export or full table from Kit's in-account search palette is required.
