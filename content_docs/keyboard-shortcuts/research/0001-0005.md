# Shortcut research 0001 to 0005

Checked on August 31, 2026. A verified record needs a current first-party reference for every listed binding. A vendor homepage or an old third-party list is not enough.

## 0001. 1Password

Status: Verified.

- Record: `lib/shortcuts/apps/1password.ts`
- Primary source: https://support.1password.com/keyboard-shortcuts/
- Source revision: 1Password published the current support article on August 17, 2026.
- Scope: 71 shortcuts for the Windows, macOS, and Linux desktop apps, Quick Access, global commands, and the browser extension.
- Platform handling: The record preserves the separate Windows, macOS, and Linux keys. It also keeps the X11 limitation on Linux global defaults and the vendor's current Linux `Ctrl+W` entry for zoom out.
- Omissions: The user-defined "Show 1Password" global shortcut has no default binding. Wayland commands are examples that users configure in GNOME, KDE Plasma, or Sway, so the record does not present them as defaults. iPhone and iPad commands fall outside the catalog's Windows, macOS, and Linux platform contract. The 1Password website exposes its shortcuts inside the signed-in product rather than in the public reference.

## 0002. 1Writer

Status: Blocked.

- First-party evidence: https://1writerapp.com/
- Source revision: Current vendor homepage retrieved August 31, 2026. The page identifies 1Writer as an iOS app and describes a customizable extra keyboard row.
- Blocked evidence: The vendor does not publish a first-party hardware keyboard shortcut table on the product site. The current stack127 shortcut contract also has no iOS or iPadOS platform.
- Result: No app record was created. A page would require guessed bindings, a third-party source, or a false desktop platform.
- Recheck condition: Reconsider this candidate if the vendor publishes a current external-keyboard reference and stack127 adds iOS or iPadOS to its platform model.

## 0003. 7-Zip

Status: Verified.

- Record: `lib/shortcuts/apps/7-zip.ts`
- Primary source: https://github.com/ip7z/7zip/blob/26.02/CPP/7zip/UI/FileManager/PanelKey.cpp
- Action source: https://github.com/ip7z/7zip/blob/26.02/CPP/7zip/UI/FileManager/App.cpp
- Selection source: https://github.com/ip7z/7zip/blob/26.02/CPP/7zip/UI/FileManager/PanelSelect.cpp
- Release source: https://github.com/ip7z/7zip/releases/tag/26.02
- Source revision: 7-Zip 26.02, tag commit `f9d78aff31a5f2521ae7ddbdc97c4a8855808959`, released June 26, 2026.
- Scope: 46 keyboard actions implemented by the Windows graphical File Manager key handler. The record covers file operations, clipboard and selection work, two-panel navigation, list layouts, sorting, bookmarks, refresh, comments, and closing the window.
- Platform handling: 7-Zip ships console binaries for Linux and macOS, but the cited File Manager implementation is Windows-only. The record therefore exposes Windows only.
- Omissions: The 7z command-line program, Explorer context-menu access keys, pointer actions, and commented-out key-handler cases are not listed. F1 help is absent because the tagged key handler comments out that case. `Ctrl+Page Down` is also absent because the handler consumes it without running an action.

## 0004. Ableton Live

Status: Verified.

- Record: `lib/shortcuts/apps/ableton-live.ts`
- Primary source: https://www.ableton.com/en/manual/live-keyboard-shortcuts/
- Source revision: Ableton Reference Manual version 12, chapter 41, retrieved August 31, 2026.
- Scope: 240 keyboard-only action records for Windows and macOS. The record covers views, focus, sets, devices, editing, automation, grids, loops, Clip View, Session View, Arrangement View, comping, tracks, transport, the Browser, sample similarity, and mapping modes.
- Platform handling: Every record keeps Ableton's Windows and Mac columns separate. This includes `Ctrl` versus `Cmd`, `Alt` versus `Option`, the Mac-only Hide Live command, the different redo keys, and `Ctrl+Space` versus `Option+Space` transport behavior.
- Omissions: Pointer gestures, drag modifiers, context-menu procedures, VoiceOver sequences, commands without a key binding, and user Key Map or MIDI Map assignments are outside this keyboard table. The Computer MIDI Keyboard changes single-letter commands. The record carries Ableton's instruction to hold Shift when that keyboard is active.

## 0005. Abstract

Status: Blocked.

- First-party evidence: https://www.goabstract.com/release-notes
- Acquisition context: https://blog.adobe.com/en/publish/2022/01/10/adobe-acquires-abstracts-notebooks
- Source revision: The first-party release archive was checked August 31, 2026. It contains isolated shortcut changes and a command for opening an in-app shortcut view, but not a complete current binding table.
- Blocked evidence: Abstract's public help material does not provide a complete, versioned shortcut reference that can support a source-checked page. Release notes prove a few individual commands, but they do not establish the full current keymap.
- Result: No app record was created. Combining old release-note fragments with AltPlusCtrl or another third-party list would violate the first-party requirement.
- Recheck condition: Reconsider this candidate if Abstract or Adobe publishes a current full shortcut reference for a supported Abstract release.

## Independent review

Reviewed again on August 31, 2026 against the same first-party sources. The review found one missing Quick Access binding in 1Password, five omitted 7-Zip File Manager actions, and 40 omitted keyboard-only Ableton actions. It also removed one Ableton modifier that only works with a pointer drag. The three records now have 71, 46, and 240 unique action IDs. Platform columns and alternatives match the cited sources. The blocked decisions remain sound: 1Writer is iOS-only and has no public hardware-keyboard table, while Abstract publishes isolated shortcut changes but no complete current keymap.
