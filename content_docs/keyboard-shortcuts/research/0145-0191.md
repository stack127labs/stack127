# Shortcut research: Mixpanel through Shopify Admin

This report records the assigned backlog candidates from Mixpanel through Shopify Admin. It names only the candidates checked in this pass. Existing records for candidates already completed in this interval remain in their earlier research reports.

All source checks below were completed on September 1, 2026. A candidate is marked verified only when a current first-party reference exposes enough default keyboard bindings for a useful desktop record. A blocked candidate has no module because its public source is incomplete, in-app only, platform-mismatched, or not current enough to support a no-guess map.

## Mixpanel

Status: Blocked.

Source: [Mixpanel Help Center](https://help.mixpanel.com/hc/en-us).

Evidence: The current first-party help center does not expose a maintained product-wide default keyboard shortcut table. Search results and product documentation provide isolated navigation guidance rather than a stable map.

Decision: No shortcut module was created.

## Mural

Status: Blocked.

Sources: [Navigating around the mural](https://learn.mural.co/lessons/navigating-around-the-mural) and [Faster co-creation with shortcuts](https://learning.mural.co/lessons/faster-co-creation-with-shortcuts).

Evidence: Mural publishes a small set of navigation and tool keys in learning lessons, but not a complete current default map. The lessons direct users to in-product or device-specific guidance for the broader set.

## Netflix

Status: Verified.

Source: [Keyboard shortcuts](https://help.netflix.com/en/node/24855), Netflix Help Center.

Evidence: Netflix publishes the complete desktop player list for play and pause, full screen, exit, rewind, fast forward, volume, mute, and skip intro. It identifies the Windows app exceptions where they differ from browser behavior.

Module: `lib/shortcuts/apps/netflix.ts`.
