# Keyboard shortcut research: backlog 0016 to 0020

Checked August 31, 2026. Only current first-party vendor documentation and vendor-hosted manuals were accepted. A binding entered the dataset only when the official source supplied the action, key sequence, platform, and relevant working context.

## 0016: Adobe Premiere Rush

Status: Verified.

Source: [Keyboard shortcuts for Premiere Rush](https://helpx.adobe.com/premiere-rush/desktop/introduction/keyboard-shortcuts.html), updated June 11, 2026.

- Platforms: Windows and macOS desktop.
- Version context: Adobe's final documented desktop defaults. Premiere Rush was discontinued and became unavailable for download after September 30, 2025, but Adobe keeps the shortcut reference for existing installations.
- Scope: all 67 desktop rows covering projects, sequences, title-text clipboard editing, clips, panels, timeline navigation, shuttle playback, Large Preview, and Media Browser.
- Platform differences: Control and Command variants, Option and Alt variants, macOS Delete, Windows Backspace or Delete, and different quit commands remain explicit.
- Alternatives: both Windows delete keys remain alternatives. Repeated actions stay in their focus-specific groups because their behavior depends on the timeline, Large Preview, or Media Browser.
- Omissions: Adobe's separate iOS table was not mixed into a desktop record. Pointer gestures and actions with no published binding were omitted.

The discontinued product status does not make the source ambiguous. The page calls itself a comprehensive reference and provides a stable final keymap for installed copies.

## 0017: Adobe Substance 3D Painter

Status: Verified.

Source: [Keyboard shortcuts](https://experienceleague.adobe.com/en/docs/substance-3d-painter/using/interface/settings/shortcuts), updated July 3, 2026.

- Platforms: Windows and macOS.
- Version context: current Substance 3D Painter defaults. Adobe separates editable commands from fixed layer, mouse, and modifier shortcuts.
- Scope: application and project commands, workspace modes, manipulators, paint tools, brush and stencil controls, camera navigation, viewport display, channels, masks, animation, texture export, and layer-stack editing.
- Platform differences: the source's Command, Control, Option, Alt, mouse-button, and camera-drag differences remain explicit. The unusual macOS camera snap chord is preserved as Adobe publishes it.
- Alternatives: the two Windows camera-translation gestures remain alternatives. Adobe's distinct viewport and projection commands remain separate rows.
- Completeness: 90 assigned records cover the editable and fixed tables. Save As has empty shortcut cells and is omitted. Windows-only Autofocus and Windows-only stencil translation remain platform-specific instead of receiving invented macOS bindings.

## 0018: Adobe XD

Status: Verified.

Source: [Keyboard shortcuts in Adobe XD](https://helpx.adobe.com/xd/desktop/introduction/keyboard-shortcuts.html), updated June 3, 2026.

- Platforms: Windows and macOS desktop.
- Version context: the current official maintenance-mode XD reference. Adobe no longer develops new XD features, but continues to publish this as the product's shortcut list.
- Scope: 127 keyboard and modifier records covering files, editing, exports, tools, vector paths, layers, components, artboards, alignment, arrangement, distribution, text, interface modes, canvas view, Design Specs, preview, and prototyping.
- Platform differences: alignment bindings, resize modifiers, Delete and Backspace, close and quit commands, and Control versus Command or Option remain explicit.
- Alternatives: paired arrow directions and field-value increments remain alternatives only where Adobe presents one result with more than one key.
- Omissions: browser gestures, Magic Mouse gestures, trackpad gestures, pointer-only actions, and mouse-wheel-only operations were omitted. macOS-only export, full screen, window switching, and preview recording, plus Windows-only maximize, are now represented only on their documented platforms.

## 0019: Affinity Designer 2

Status: Verified.

Sources:

- [Affinity Designer 2 keyboard shortcuts help](https://affinity.help/designer2/English.lproj/pages/Workspace/shortcuts.html), current Affinity V2 help checked August 31, 2026.
- [Affinity Designer 2 shortcuts for Windows](https://resources.serif.com/spotlight/learning/shortcuts/Affinity-Designer-2-Shortcuts-Windows.pdf), Serif shortcut sheet dated May 23, 2024.
- [Affinity Designer 2 shortcuts for macOS](https://resources.serif.com/spotlight/learning/shortcuts/Affinity-Designer-2-Shortcuts-macOS.pdf), Serif shortcut sheet dated May 23, 2024.

- Platforms: Windows and macOS desktop.
- Version context: Affinity Designer 2, checked against the current versionless V2 help. The vendor sheets use English UK and British Magic Keyboard layouts.
- Scope: document editing, Designer Persona tools, Pixel Persona tools, view and zoom, opacity, colour selectors, brush size, grids and guides, drawing modifiers, pixel selection, and zoom-tool gestures.
- Platform differences: Control and Command, Alt and Option, and Control versus Command center-scaling remain explicit. The modifier tables in each platform PDF were read separately.
- Alternatives: no physical-key position was translated across keyboard layouts. The documented action key is recorded, not a guessed location on another layout.
- Omissions: Export Persona mouse tools, gesture-only diagrams, advanced text characters, and transform-field expressions were outside the keyboard-command scope. Unassigned customizable commands were not added.

The current HTML help renders modifier symbols as images in its tables. The two official platform PDFs supplied the readable modifier evidence; no third-party shortcut list was used.

## 0020: Affinity Photo 2

Status: Verified.

Sources:

- [Affinity Photo 2 keyboard shortcuts help](https://affinity.help/photo2/English.lproj/pages/Workspace/shortcuts.html), current Affinity V2 help checked August 31, 2026.
- [Affinity Photo 2 shortcuts for Windows](https://resources.serif.com/spotlight/learning/shortcuts/Affinity-Photo-2-Shortcuts-Windows.pdf), vendor file last modified September 19, 2023.
- [Affinity Photo 2 shortcuts for macOS](https://resources.serif.com/spotlight/learning/shortcuts/Affinity-Photo-2-Shortcuts-macOS.pdf), vendor file last modified September 19, 2023.

- Platforms: Windows and macOS desktop.
- Version context: Affinity Photo 2, checked against the current versionless V2 help. The vendor sheets use English UK or British Magic Keyboard layouts.
- Scope: documents, layers, adjustments, Photo Persona tools, Liquify Persona, Develop Persona, view and zoom, opacity or brush hardness, brush controls, painting modifiers, pixel selections, sampling, and zoom-tool gestures.
- Platform differences: Control and Command, Alt and Option, layer-selection modifiers, pixel-selection modifiers, and center-scaling remain explicit from the separate platform sheets.
- Alternatives: tool-family letters stay as one action only when Serif labels the key as cycling that family.
- Omissions: Panorama and Export Persona pointer tools, gesture-only diagrams, advanced text characters, and transform-field expressions were outside the keyboard-command scope. Custom assignments and commands without a published default were omitted.

As with Designer, the platform PDFs were required because the current HTML help's modifier icons do not survive plain-text extraction. The official sheets and current help agree on the covered default keymap.

## Independent review

Independently rechecked August 31, 2026 against the current vendor pages and platform sheets.

- Premiere Rush's first-party page is newer than recorded: June 11, 2026. Four focus-specific Timeline rows were restored, bringing the desktop record to all 67 published rows.
- Substance 3D Painter now includes all 90 assigned actions from Adobe's editable and fixed tables. The review restored excluded-geometry visibility, Windows-only Autofocus, Texture Set selection, the viewport context menu, and both manipulator modifiers. The blank Save As row remains omitted, and stencil translation no longer receives an invented macOS binding.
- Adobe XD's source is also newer than recorded: June 3, 2026. The record now has 127 keyboard or modifier actions, including the platform-only commands and missing operation, padding, scroll-group, Design Specs, and comment-entry bindings. Pointer-only and browser-device gestures remain out of scope.
- Affinity Designer 2 and Affinity Photo 2 now include the three macOS-only application shortcuts exposed by current V2 help. The public names include the major version, and the unsupported V2.6 claim was removed because the help pages identify V2 but publish no minor version.
- Affinity Photo's platform-sheet freshness now uses Serif's September 19, 2023 file timestamp rather than the unsupported September 1 date.

All five records have unique IDs, non-empty bindings, and explicit platform availability. No blank or unavailable source value is rendered as a key.
