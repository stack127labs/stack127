# Shortcut research 0121 to 0150

Checked on September 1, 2026. This batch uses current first-party product help, vendor manuals, and official source repositories. A candidate stays blocked when the vendor does not publish enough current default action-to-key mappings for a useful reference.

## 0121. Joplin

Status: Verified.

- Record: `lib/shortcuts/apps/joplin.ts`
- Primary source: https://joplinapp.org/help/apps/terminal/
- Source revision: Current Joplin Terminal guide checked September 1, 2026.
- Scope: Terminal navigation, focus movement, links, search, note and notebook creation, console and metadata toggles, and note copy or move commands.
- Platform handling: Joplin Terminal is documented for macOS, Linux, and Windows through WSL. The guide uses sequential key sequences rather than simultaneous modifier chords, and the record keeps that distinction in its copy.
- Omissions: The complete keymap is available inside the terminal with `help keymap`. The record keeps the useful public commands and does not infer bindings for commands that the guide does not list.
