# Shortcut research 0021 to 0025

Checked on August 31, 2026. Every binding in this batch comes from a current first-party help page. Commands that require pointer input, user-configured hotkeys, undocumented operating-system mappings, and commands outside the documented shortcut scope are not converted into records.

## 0021. Aider

Status: Verified.

- Record: `lib/shortcuts/apps/aider.ts`
- Primary source: https://aider.chat/docs/usage/commands.html
- Source revision: Current Aider command and keybinding documentation retrieved August 31, 2026. The page does not publish a separate revision date.
- Scope: 39 actions covering prompt interruption, multiline entry, external-editor handoff, the default Emacs input map, and the optional vi input map.
- Platform handling: Aider publishes one terminal keymap rather than operating-system columns. The record carries those combinations unchanged across Windows, macOS, and Linux and warns that a terminal or operating system may intercept a combination.
- Omissions: Slash commands are typed commands rather than keyboard shortcuts and are not listed. Vi bindings require `--vim`; they are kept in their own group. Shift+Enter is not included because Aider explicitly says terminals cannot detect it portably.

## 0022. Airtable

Status: Verified.

- Record: `lib/shortcuts/apps/airtable.ts`
- Primary source: https://support.airtable.com/articles/7980233311-airtable-keyboard-shortcuts
- Source revision: The current support article displayed “Last updated 23 days ago” when checked August 31, 2026. It did not expose a stable calendar revision date.
- Scope: 55 keyboard-only actions for general base and view control, Grid editing and selection, Gallery, Kanban, Gantt, interface search, and expanded records.
- Platform handling: The record preserves Airtable's separate Mac and Windows tables, including `Command` and `Control`, `Option` and `Alt`, and the operating-system-specific interface search binding. Linux is not listed because Airtable does not publish a Linux column.
- Omissions: Screenshot combinations are operating-system features rather than Airtable commands. Modifier-plus-click and drag gestures are not keyboard-only commands. The extensions binding is omitted because the rendered official table does not expose its final key. Attachment upload is a context-dependent multi-step workflow, not one stable combination, and is not listed.

## 0023. Alfred

Status: Verified.

- Record: `lib/shortcuts/apps/alfred.ts`
- Primary source: https://www.alfredapp.com/help/getting-started/cheatsheet/
- Source revision: Current Alfred 5 official cheatsheet retrieved August 31, 2026. The HTML build marker was generated August 28, 2026, but the page does not publish a separate content-revision date.
- Scope: Search and result actions, File System Navigation, the File Buffer, Clipboard History, snippets, and Music Mini Player controls.
- Platform handling: Alfred is a macOS application, so every binding is macOS-only. Alternative default bindings for Quick Look and file actions are represented as alternatives rather than duplicate actions.
- Omissions: Typed keywords are not keyboard combinations and are not listed. User-created workflow hotkeys and modified preferences are outside the default map. Powerpack requirements are labeled in the relevant group, shortcut note, and version context.

## 0024. Amplitude

Status: Verified.

- Record: `lib/shortcuts/apps/amplitude.ts`
- Primary source: https://amplitude.com/docs/analytics/charts/chart-basics#keyboard-shortcuts
- Source revision: Current Amplitude Analytics chart basics page retrieved August 31, 2026. The page does not publish a separate revision date.
- Scope: All 12 shortcuts in Amplitude's official table, covering event, filter, and group selectors, hovered definitions and values, refresh, save, copy, URL sharing, organization, new charts, and the shortcut modal.
- Platform handling: Amplitude publishes one browser-app table with no operating-system variants. The documented combinations are carried unchanged across Windows, macOS, and Linux.
- Omissions: The page states that these bindings work on chart creation pages and excludes Data Tables. They are not presented as global Amplitude shortcuts.

## 0025. Android Studio

Status: Verified.

- Record: `lib/shortcuts/apps/android-studio.ts`
- Primary source: https://developer.android.com/studio/intro/keyboard-shortcuts
- Source revision: Google updated the Android Studio shortcut reference on March 6, 2026.
- Scope: 133 records covering tool windows, general IDE actions, search and navigation, generic visual-layout controls, Layout and Navigation editors, code generation and editing, build and run, debugging, refactoring, and version control. Opposite-direction actions that Google combines in one row are separated when that makes lookup clearer.
- Platform handling: The record follows Google's shared Windows and Linux column and its separate macOS column. Documented alternative keyboard bindings remain alternatives on the relevant platform.
- Omissions: Modifier-plus-click and drag gestures are not keyboard combinations and are omitted. Android Studio supports preset and custom keymaps, which can replace the defaults. The upstream IntelliJ IDEA reference is not mixed into this record because Google's Android Studio page is the authoritative product-specific table.

## Independent review

Rechecked all five records against the rendered first-party sources on August 31, 2026. The review merged Aider's Escape-then-Enter fallback into the documented multiline action, added Airtable's shortcut-list command, converted its alternate Find binding to an alternative, and removed its five pointer-dependent records. It also clarified Alfred's Powerpack boundaries and restored Android Studio's four generic visual-layout actions. Amplitude remains at 12 records because those 12 rows are the complete current official shortcut table, not a sample. All five modules have unique shortcut IDs and platform entries limited to each module's declared platforms.
