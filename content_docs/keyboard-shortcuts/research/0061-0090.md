# Keyboard shortcut research: backlog 0061 to 0090

Checked September 1, 2026. Only current first-party vendor documentation was accepted. A binding entered a module only when the source supplied the action, key, platform, and any required context. This batch has 23 verified candidates and 7 blocked candidates. Eight verified candidates already had modules, and 15 new modules were added.
