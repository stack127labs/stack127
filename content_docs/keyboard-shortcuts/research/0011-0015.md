# Shortcut research 0011 to 0015

Checked on August 31, 2026. Every published binding in this batch comes from Adobe's current product documentation. Pointer-only gestures, user presets, and commands with no default binding are not converted into keyboard records.

## 0011. Adobe Illustrator

Status: Verified.

- Record: `lib/shortcuts/apps/adobe-illustrator.ts`
- Primary source: https://helpx.adobe.com/illustrator/using/default-keyboard-shortcuts.html
- Source revision: Adobe's English reference, updated February 17, 2026.
- Scope: 122 defaults for Windows and macOS. The record covers documents, common editing, tools, views, artboards, guides, grids, object selection, stacking, color, type, panels, and effects.
- Platform handling: The record preserves Adobe's separate Windows and macOS columns, including `Ctrl` and `Command`, `Alt` and `Option`, artboard ruler differences, and platform-specific panel modifiers.
- Omissions: The Adobe table also includes many mouse-plus-modifier gestures and stateful key sequences used while dragging. Those do not fit a normal key-combination table and are not listed. Custom shortcut sets and commands shown only in menus or tooltips are outside this source.

## 0012. Adobe InDesign

Status: Verified.

- Record: `lib/shortcuts/apps/adobe-indesign.ts`
- Primary source: https://helpx.adobe.com/indesign/desktop/get-started/settings-and-preferences/keyboard-shortcuts.html
- Source revision: Adobe's InDesign keyboard reference, updated July 28, 2026.
- Scope: 117 defaults for Windows and macOS. The record covers tools, frames, selection, transformations, type formatting and navigation, tables, documents, panels, styles, and production preview.
- Platform handling: Mac-only commands such as Preferences, Minimize, and Hide appear only for macOS. The record keeps distinct `Control`, `Command`, `Alt`, and `Option` combinations where Adobe lists them.
- Omissions: The record uses the InDesign Default set. InDesign can switch to optional Illustrator, Photoshop, PageMaker, QuarkXPress, or user-created sets, which would change the keymap. Pointer gestures and commands with no key in Adobe's table are not included.

## 0013. Adobe Lightroom Classic

Status: Verified.

- Record: `lib/shortcuts/apps/adobe-lightroom-classic.ts`
- Primary source: https://helpx.adobe.com/lightroom-classic/desktop/introduction-to-lightroom-classic/keyboard-shortcuts.html
- Release context: https://helpx.adobe.com/lightroom-classic/desktop/troubleshooting/fixed-issues.html
- Source revision: Adobe updated the shortcut reference on July 5, 2026. Adobe's current fixed-issues page, updated August 4, 2026, identifies the August 2026 release as Lightroom Classic 15.5.
- Scope: 134 action records for Windows and macOS. The record follows Lightroom's modules and covers the workspace, catalog and files, Library views, ratings, filters, collections, metadata, Develop settings, crop, repair, masks, and local adjustments.
- Platform handling: The tables preserve `Command` versus `Control` where Adobe uses each on macOS. Mac-only email and Windows-only alternate redo commands remain platform-specific.
- Alternatives: Adobe's Windows-only `Ctrl+Y` Redo is retained as an alternative to `Ctrl+Shift+Z`, not presented as a second action.
- Omissions: Pointer gestures, Book, Slideshow, Print, Map, Web, and Help commands with narrow use, and custom shortcuts are not listed. The result covers the everyday catalog-to-Develop workflow, not every row in Adobe's module tables.

## 0014. Adobe Photoshop

Status: Blocked.

- Current first-party page: https://helpx.adobe.com/photoshop/desktop/get-started/settings-and-preferences/view-keyboard-shortcuts.html
- Source revision: Updated February 23, 2026.
- Blocked evidence: Adobe's current page does not publish the default keymap. It directs users to open Photoshop's Keyboard Shortcuts and Menus dialog and inspect Application Menus, Panel Menus, and Tools inside the installed app.
- Old reference rejected: Adobe still hosts `photoshop_reference.pdf`, but its embedded metadata dates it to November 2019. It cannot prove the latest 2026 default set.
- Result: No module was created. Publishing a large Photoshop page from the old PDF or a third-party list would violate the current first-party requirement.
- Recheck condition: Reconsider this candidate when Adobe publishes or exports a current, versioned default shortcut list outside the installed application.

## 0015. Adobe Premiere Pro

Status: Verified.

- Record: `lib/shortcuts/apps/adobe-premiere-pro.ts`
- Primary source: https://helpx.adobe.com/premiere/desktop/get-started/keyboard-shortcuts/default-keyboard-shortcuts.html
- Source revision: Adobe's Premiere default shortcut reference, updated January 7, 2026.
- Scope: 179 assigned defaults for Windows and macOS. The record covers projects, files, editing, clips, sequences, trimming, markers, graphics, workspaces, mixer and utility panels, panel focus, Project panel, Program Monitor, and Timeline operations.
- Platform handling: The record preserves Adobe's separate Windows and macOS columns. Important differences include Delete and Forward Delete, Enter and Return, `Ctrl` and `Command`, and the distinct Mac bindings for clear marks, previous sequence items, clip nudging, and timeline edits.
- Omissions: Premiere supports custom presets and several panel-specific commands with no default key. Unassigned commands, pointer actions, and custom presets are outside this record. Adobe's current table renders Maximize Frame as the incomplete value `Shift +` on both platforms; that malformed binding is not guessed or published.

## Independent review

Independently rechecked August 31, 2026 against the current first-party pages above.

- Illustrator's 122-record practical set still matches Adobe's February 17, 2026 Windows and macOS columns. IDs are unique, platform modifiers are explicit, and the receipt continues to state that modifier-pointer and drag-state rows from Adobe's much larger table are outside this page's scope.
- InDesign's 117-record InDesign Default set still matches Adobe's July 28, 2026 reference. Mac-only application commands remain macOS-only, and optional product-compatible or user-created shortcut sets are not mixed into the defaults.
- Lightroom Classic's source date was stale. The app context and receipt now use Adobe's July 5, 2026 revision and the August 2026 Lightroom Classic 15.5 release context. The duplicate Redo action is now one record with the Windows-only alternative preserved.
- Photoshop remains blocked. Adobe's February 23, 2026 page contains no shortcut table and directs users to inspect Application Menus, Panel Menus, and Tools in the installed Keyboard Shortcuts and Menus dialog. The 2019 PDF is still too old to establish current defaults.
- Premiere now includes all 179 usable assigned rows in Adobe's January 7, 2026 tables. The review restored the Learning workspace, Audio Track Mixer, Effect Controls, Effects, History, Media Browser, Metadata, complete Project-panel movement, five-frame Program Monitor nudges, and Timeline Clear Selection. Adobe's malformed Maximize Frame value remains explicitly omitted.

All four app files have unique shortcut IDs and non-empty platform bindings. No platform binding was inferred from another Adobe product or from common operating-system behavior.
