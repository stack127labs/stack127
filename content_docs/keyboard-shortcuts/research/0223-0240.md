# Shortcut research 0223 to 0240

This corrected batch records the source checks completed on September 1, 2026. The supplied range is tmux through WebStorm. Overlapping candidates Superhuman through TickTick were already covered in the preceding research batch and are not repeated here. Only candidates with a current first-party default reference are marked verified and added to the catalog.

## tmux

Status: Verified.

Sources: [tmux default key bindings](https://github.com/tmux/tmux/blob/master/tmux.1) and [Getting Started](https://github.com/tmux/tmux/wiki/Getting-Started), tmux project documentation.

Evidence: The current master manual publishes the default Ctrl-B prefix map for sessions, windows, panes, layouts, copy mode entry, paste buffers, and client controls. The module records the complete default command-key table and notes that tmux.conf can change it.

Module: `lib/shortcuts/apps/tmux.ts`.

## Todoist

Status: Verified.

Source: [Use keyboard shortcuts in Todoist](https://todoist.com/help/articles/use-keyboard-shortcuts-in-todoist-Wyovn2), Todoist Help.

Evidence: The reference was last updated July 2, 2026 and publishes General, Navigation, Global, Task, Sort, Sub-task, Project, Upcoming, Calendar, and Multi-window defaults for macOS and Windows. It also explains the QWERTY/QWERTZ and Linux global-shortcut limits.

Module: `lib/shortcuts/apps/todoist.ts`.

## Toggl Track

Status: Blocked.

Source: [Are there any keyboard shortcuts?](https://support.toggl.com/en-us/article/are-there-any-keyboard-shortcuts-1bcagm6/), Toggl Track Support.

Evidence: Toggl lists some web and desktop keys and says the web app's full list is available from Shift+? inside the product. Browser-extension bindings are customizable, so the public source does not provide a complete stable product-wide default map.

Decision: No shortcut module was created.

## Trello

Status: Blocked.

Sources checked: [Keyboard shortcuts in Trello](https://support.atlassian.com/trello/docs/keyboard-shortcuts-in-trello/), [Trello desktop apps](https://support.atlassian.com/trello/docs/trello-desktop-apps/), and the linked [Trello shortcuts page](https://trello.com/shortcuts).

Evidence: Atlassian's public article lists only commonly used browser shortcuts and points to a dynamic page for the full list. The desktop article has a separate set of global app keys, but the linked full browser map is not exposed as a stable text reference.

Decision: No shortcut module was created.

## Twitch Studio

## Ulysses

## Unity

Status: Blocked.

Sources checked: [Shortcuts Manager](https://docs.unity3d.com/6000.0/Documentation/Manual/ShortcutsManager.html), [Unity hotkeys](https://docs.unity.cn/Manual/UnityHotkeys.html), and the [Unity tools and shortcuts PDF](https://connect-prd-cdn.unity.com/20210225/f6245573-eb19-4a4d-a29d-b9d9b0471bad/Unity-tools-and-shortcuts.pdf).

Evidence: Current Unity documentation directs users to the in-app Shortcuts Manager, while the public legacy material lists only a small tool subset. No current complete default map is published outside the editor.

Decision: No shortcut module was created.

## WebStorm

Status: Verified.

Sources: [WebStorm keyboard shortcuts](https://www.jetbrains.com/help/webstorm/mastering-keyboard-shortcuts.html), [macOS reference card](https://resources.jetbrains.com/storage/products/webstorm/docs/WebStorm_ReferenceCard.pdf), and [Windows/Linux reference card](https://resources.jetbrains.com/storage/products/webstorm/docs/WebStorm_ReferenceCard_Windows_Linux.pdf), JetBrains.

Evidence: JetBrains' current WebStorm 2026.2 documentation links maintained default reference cards for macOS and Windows/Linux and documents search, editing, navigation, refactoring, debugging, and VCS defaults. The map notes configurable keymaps and OS conflicts.

Module: `lib/shortcuts/apps/webstorm.ts`.
