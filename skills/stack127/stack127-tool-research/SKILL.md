# stack127 tool research

Resolve only the facts needed to make a sound product or technical decision. Read `AGENTS.md`, `stack127_docs/tool-pipeline.md`, existing route docs, code, tests, and the Browser instructions before operating live competitors.

## Choose the depth

- Simple tools normally skip this skill unless one formula or expectation remains disputed.
- Standard tools use targeted research for the disputed formula, parser behavior, compatibility limit, or interaction pattern.
- High-risk tools verify primary sources, data freshness, failure behavior, abuse boundaries, privacy, and maintenance needs. Inspect competitors when their behavior affects the product decision.
- A standalone competitor-analysis request can still justify a broader report.

Do not impose a competitor count. Search until additional results repeat the same direct products or no longer change a decision. Record the queries and saturation reason.

## Evidence

Operate relevant competitors when possible. Record URL, date, backend, viewport, important inputs, action model, result hierarchy, and observed failure behavior. Label material statements as observed, documented, inferred, or unknown.

Use primary specifications and official documentation for formulas, standards, API behavior, and data contracts. Community sources can establish repeated user problems but not technical truth.

Never pay, create an account, submit sensitive data, or trigger an external side effect without authority.

## Output

For an end-to-end tool workflow, update the `Technical truth`, `Risk decision`, `Interface`, and `Blockers and decisions` sections of `content_docs/<slug>/tool-spec.md`. Link only sources that affect a decision.

When the user explicitly requests a standalone competitive report, write `competitive-report.md`. Do not create the old collection of downstream pipeline documents.

Finish with `feasible` or `blocked`. A blocked core promise needs two to four concrete options that state delivered behavior, cost or maintenance, and required approval.
